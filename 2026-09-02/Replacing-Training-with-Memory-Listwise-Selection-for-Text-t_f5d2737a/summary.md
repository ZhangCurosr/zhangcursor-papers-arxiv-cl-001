# 论文速读：Replacing-Training-with-Memory-Listwise-Selection-for-Text-t

## 一句话总结
本文提出 MAP-SQL，一种无需微调的列表式 SQL 候选选择框架，通过检索训练蒸馏的结构化记忆提供显式决策标准，并结合基于执行结果分组的排列聚合策略缓解位置偏差，在保持低推理开销的同时显著提升了 Text-to-SQL 的选择准确率。

## 研究问题与动机
1. **列表式选择微调成本过高**：生成-执行-选择流水线中，列表式选择器能联合比较多个候选，但传统方法需对长上下文训练数据进行微调，计算与数据成本随候选数线性/超线性增长，难以规模化。
2. **点式/成对选择的固有缺陷**：点式选择器独立打分缺乏候选间对比视角；成对选择器需 $O(n^2)$ 次比较，在候选池较大时效率极低。
3. **长输入引发的位置偏差（Lost-in-the-middle）**：列表式输入包含 Schema、多条 SQL 及执行结果，模型易对中间位置的候选关注度下降，导致排序不稳定。
4. **现有偏差缓解策略开销不可接受**：全排列自洽等方法理论需 $O(n!)$ 次调用，实际不可行；亟需一种免微调、低开销且能同时提供语义判断标准与偏差鲁棒性的实用方案。

## 核心贡献（创新点）
1. **提出免微调列表式选择框架 MAP-SQL**：用推理时策略完全替代传统微调目标，无需更新选择器参数即可实现高效的联合候选排序。
2. **基于 E-T-D 框架的结构化记忆检索机制**：将自然语言到 SQL 的映射知识蒸馏为可复用记忆，作为显式决策标准注入列表式比较，弥补纯数据驱动选择器的语义验证空白。
3. **基于执行结果分组的排列聚合策略**：利用多数投票作为正确性先验，仅对执行结果相同的候选组内打乱排序，将排列空间从 $O(n!)$ 压缩至 $O(g!)$，大幅降低计算开销。
4. **统计置信度估计与可选平局裁决机制**：通过多次排列运行计算平均排名与配对差异的 t 分布置信度，自动判定顶位候选是否显著领先，仅在平局时调用轻量级点式选择器，兼顾准确性与效率。

## 方法详解
- **记忆生成与检索**：从训练集问题、Schema 与金标准 SQL 出发，按 Encoding（实体/条件到表的映射）、Translating（聚合/排序/条件操作转换）、Decoding（输出形状与格式约束）三阶段生成结构化记忆 $m_j$。推理时，使用 dense retriever（bge-m3）基于问题相似度检索顶部记忆（或填满上下文窗口），作为 prompt 前缀与候选列表一同送入选择器。
- **滑动窗口列表式重排序**：初始顺序按执行结果频率降序排列（多数投票先验）。采用滑窗（大小 $w$，步长 $s$，从后向前）对子集 $W_t$ 进行列表式打分：$\pi_t = f_{\text{list}}(x, S, \mathcal{M}(x), \{(q_i, e_i)\}_{q_i \in W_t})$，逐步更新全局排名 $R$。
- **分组排列与偏差缓解**：候选按执行结果分为 $g$ 组，组间相对顺序固定，仅组内随机打乱。执行 $K$ 次排列，计算各候选平均排名 $\mu_i = \frac{1}{K}\sum_{k=1}^K r_i^{(k)}$。对排序后的 top-1（$a$）与 top-2（$b$），计算每轮排名差 $d_{a,b}^{(k)}$，利用 Student's t 分布 CDF 估计置信度 $P(a>b) = T_{K-1}\left(\frac{\bar{d}_{a,b}}{s_{a,b}/\sqrt{K}}\right)$，低于阈值 $\tau$ 则判定平局。
- **点式平局裁决**：平局发生时，仅对并列候选调用点式 reward model 独立打分，选取得分最高者，避免对全量候选重复推理。
