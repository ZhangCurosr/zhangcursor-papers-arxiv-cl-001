# 论文速读：Ready-to-Speak-Aligning-LLMs-for-TTS-Friendly-Text-Generatio

## 一句话总结
本文提出 FaST（Feature-based Speech-TTS Alignment）对齐框架，通过浅层语言学特征奖励模型显式优化大语言模型输出文本的 TTS 可读性；在单卡 A100 与少量样本微调下，使合成语音自然度与可懂度显著提升，且无需修改 TTS 前端管线。

## 研究问题与动机
- LLM 生成文本普遍包含紧凑数字格式、缩写、括号注释、URL/公式等非口语化符号，会严重干扰 TTS 前端解析，导致发音错误与听感割裂。
- 现有文本对齐方法（SFT/DPO）主要优化人类语义偏好或连贯性，未显式建模“对 TTS 友好”的语言学属性，造成生成目标与语音合成终端需求错位。
- 端到端语音-文本联合训练或大规模平行语料依赖成本过高，亟需一种轻量、可解释、跨领域泛化的纯文本层对齐方案，使现有 LLM 直接具备“口语化输出”能力。

## 核心贡献（创新点）
1. **提出基于特征的 TTS 友好性奖励建模方法（FaRM）**：将生成对齐转化为 40 个语言学特征权重的对比学习任务，与依赖隐式策略梯度的 DPO/SFT 在优化目标与可解释性上存在本质区别。
2. **构建高保真启发式 TTS-Friendliness 评分指标**：设计基于正则匹配与长度归一化的加权惩罚公式，该指标与人工 MUSHRA 听力评分全局 Spearman ρ 达 +0.84，显著优于传统可读性度量（如 Flesch-Kincaid）。
3. **自动化发现跨域与领域特异性 TTS 敏感特征**：无需人工工程标注即可学习出负向特征（数字格式、缩写密度）与正向特征（叙事散文体、口语化语调），填补了从经验观察到量化对齐的空白。
4. **实现可干预的长度-友好性帕累托权衡**：通过置零 conciseness 特征权重可在几乎无损 TTS 评分（4.73→4.74）的前提下压缩 23% 生成长度，提供了黑盒对齐框架无法支持的细粒度可控性。

## 方法详解
- **特征表示与奖励建模（FaRM）**：抽取 k=40 个语言学特征（如 `use_of_numeric_formatting`、`abbreviation_density`、`natural_conversational_tone` 等），构建文本到特征向量的映射；奖励函数以加权线性组合形式学习各特征对 TTS 友好度的边际贡献。
- **对比偏好训练**：在 CORA 与 Recipe 数据集上构建优选对（TTS 友好改写版 vs 原始 LLM 输出），采用对比损失优化特征权重，使生成策略显式抑制高风险模式。
- **启发式评分公式（文字描述）**：对文本 t，正则匹配第 k 类风险模式，记 nₖ 为非重叠匹配数、mₖ 为匹配字符覆盖总数、L = max(|t|, 20)。单类得分 sₖ = wₖ · (nₖ + 0.25 · mₖ/L)；综合惩罚 R = Σsₖ / (1 + L/200)；最终评分 S_HEUR = 5 − 4R/(R+2) ∈ [1, 5]，值越高表示越适合 TTS 朗读。
- **权重设计与校准**：URL/公式类模式权重固定为 1.0（其余 0.5），反映其对 TTS 前端干扰最大；在独立保留样本上手工校准，确保自然语言得分≈5、单条 URL/公式降分≥1，且**未使用论文评估集调参**以杜绝数据泄露。

## 实验与结果
- **数据集与基线**：CORA（客服对话）、Recipe（食谱指令）；基线包括 SFT、DPO、Promoting、PolyNorm（自行复现，108-shot）、Oracle（黄金参考）；TTS 后端统一使用 Kyu-kai Pocket TTS。
- **主要数值结果**：FaST 在 CORA 全量与 10-sample 设置下均持续逼近 Pareto 前沿；Recipe 全量训练表现最强，10-sample 时因随机样本对比度低略有退化，但仍稳定优于 SFT；SmolLM3-3B 上趋势一致，验证方法不依赖单一模型族。
