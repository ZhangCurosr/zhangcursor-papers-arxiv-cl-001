# 论文速读：Value-Over-Language-Model-Detecting-Original-Contribution-in

## 一句话总结
本文提出 **Value Over Language Model (VOLM)** 框架，旨在量化文档中人类提供的“原始信息贡献”占比，而非像现有工具那样仅统计表面文本由 LLM 生成的比例；该方法无需训练或标注数据，通过逐步抽取内容、重建文档并与仅凭任务描述生成的基线对比，实现对人类实质贡献的无监督度量。

## 研究问题与动机
- **现有检测指标的语义错位**：当前 LLM 文本检测工具主要测量文档表面词汇由模型生成的比例，无法区分“人类仅提供单句提示让模型代写”与“人类提供核心论点/具体发现、仅委托模型润色行文”这两种本质不同的使用场景。
- **信息贡献与文本归属的混淆风险**：一篇审稿意见或学术论文可能绝大部分句子由 LLM 写出，但关键洞察（如反例构造、公式推导、漏洞定位）完全来自人类作者；若仅以文本生成比例判定“可疑”，会误伤合理使用 LLM 辅助表达（尤其是非母语学者）的场景。
- **缺乏面向单篇成稿的无监督信息度量**：已有贡献归因方法要么依赖标注数据训练分类器（如 EditLens），要么需要访问完整的多轮对话日志（HCI 轨迹分析法），难以在实际学术评审、出版审核等事后场景中对单篇文档进行客观评估。
- **直接计算困惑度易受文体干扰**：若直接对原文计算 log-probability，LLM 风格的措辞、句法本身就会导致低困惑度，从而将“风格相似性”错误等价于“信息原创性低”。

## 核心贡献（创新点）
- **重构问题定义**：将评估目标从“LLM 写了多少字”转向“人类在通用任务提示之上额外提供了多少信息”，从根本上区分文本风格与内容原创性。
- **提出 VOLM 通用框架**：类比棒球 sabermetrics 的 VORP 指标，设计以“替换水平基线文档 $D_{\text{ref}}=M(T)$”为参照的评估范式，适用于任意搭配任务描述 $T$ 的文档。
- **零训练、零标注的无监督实现**：开发了一套仅依赖现成 LLM 的算法，全流程通过抽取、重建与条件 log-probability 计算完成，不引入任何分类器或标注语料。
- **验证文体不变性与信息敏感性**：在新闻、ICLR 审稿、议论文三个领域证明，VOLM 能有效分离人类撰写文档与仅用通用提示生成的 LLM 文档；同时系统揭示提取器约束强度对消除残余风格噪声的关键作用。

## 方法详解
- **核心思想**：衡量模型 $M$ 在看到任务描述 $T$ 后，对文档内容的“惊讶程度”（surprisal）。若文档内容已隐含于模型权重或提示中，揭示少量内容后模型便不再惊讶；若包含人类独有的信息，则随着内容逐步披露，模型持续保持较高困惑度。
- **流水线三步走**：
