# 论文速读：A SYSTEMATIC APPROACH TO CONSTRUCTING A CHANCE-AND-RISK MATRIX FOR SEMICONDUCTOR SUPPLY CHAINS

## 一句话总结
本文提出了一套端到端的自动化流水线，利用大语言模型（LLM）从半导体企业的公开披露文件中提取风险与机会信息，构建基于OWL本体的知识图谱，并通过"算法评分+LLM相关性调整+专家验证"三层机制进行排序，最终输出可用于ALLPROS联盟决策的机遇-风险矩阵。

## 研究问题与动机
- **核心问题**：半导体供应链面临地缘政治紧张、产能地理集中和技术快速迭代等多重风险，但现有方法缺乏可扩展的自动化系统来持续提取、结构化并优先排序来自公开企业披露的风险情报。
- **现有方法不足**：
  - AHP、FMEA、贝叶斯网络等传统风险评估方法依赖人工专家输入和定期重评估，无法实现大规模、连续性风险识别
  - Zhao等（2024）的LLM框架虽能自动化提取风险，但未将风险存储在结构化知识表示中，也缺少评分排序机制
  - Mahfouz等（2021）的知识图谱系统缺乏形式化本体支撑，扩展性和复用性受限
  - Zheng等（2025）的工作聚焦自然灾害而非半导体领域，且未建模机会和评分排序

## 核心贡献（创新点）
1. **首个面向半导体供应链的端到端风险-机会提取流水线**：与已有工作仅自动化数据采集或仅提供结构化本体的方式不同，本文首次将非结构化公开文档转化为可机器查询、带评分、受本体支撑的情报，将分析师数周工作替换为可重复、可审计的流程。
2. **OWL本体驱动的双层分类体系设计**：定义了包含180个子类的风险（9大类）和机会（8大类）分类体系，通过不相交公理显式编码风险-机会的对立统一关系，支持因果链接和跨类关系表达，超越了简单层次分类。
3. **三层评分机制融合算法与LLM智能**：第一层基于类别权重、时间衰减和事件因子的确定性公式；第二层利用LLM-as-judge对半导体制造和欧洲市场的相关性进行调整；第三层由领域专家验证，三者结合使自动化排序与专家判断达到Spearman ρ=0.55（风险）和0.72（机会）。
4. **基于Sentence-BERT语义聚类的去重与整合方法**：采用余弦相似度阈值τ=0.85进行传递闭包聚类，结合LLM整合簇内成员，在保持溯源完整性的同时减少21%-70%的冗余项。
5. **面向ALLPROS联盟的实战验证**：应用于Intel、Infineon、Texas Instruments、Air Liquide、Siltronic五家横跨价值链的公司，生成76,207个评分项，独立检查验证准确率达92.6%，识别出贸易限制为跨公司主导系统性风险。

## 方法详解
流水线分为六个阶段：

**阶段1：分类法定义**
- 构建两层风险/机会类别层次结构：风险9大类90子类，机会8大类90子类
- 8个类别对在风险-机会两侧共享，体现不确定性的双重本质（Hillson 2002）
- 开发流程：行业报告研究→LLM辅助类别生成→专家手工策展→每条目补充15-30个专业术语

**阶段2：本体设计（OWL）**
- 定义四个顶层类：
  - **Risk/Opportunity**：声明不相交，编码分类层次及数据属性（定义、关键词、同义词）
  - **Supply Chain Cluster**：将128家公司分组到12个功能段，通过faces risk/pursues opportunity属性连接
  - **Event**：捕获14种历史事件类型，携带magnitude、likelihood、relevance、duration评分
- 定义三种对象属性：depends on（风险级联）、builds on（机会强化）、mitigates（机会缓解风险，含逆属性has mitigation）
- 所有叶子类预填充策展OWL个体作为KG种子

**阶段3：来源检索**
- 输入源：经审计、法律强制、公开可访问的企业披露文件（年度报告、10-K、ESG报告、可持续发展报告、投资者演示文稿）
- 检索策略：每家公司定义44个搜索查询（公司名称+文档类型+目标年份2024/2025），通过Google Custom Search JSON API执行

**阶段4：数据提取（LLM）**
- 文本预处理：HTML转Markdown、PDF专用提取器、规则清洗移除模板内容、按200行分块
- 两遍LLM提取（GPT-4o，temperature=0.0）：
  - 第一遍：判断分块是否含风险/机会信号，丢弃无关内容
  - 第二遍：注入完整分类法（180个子类及关键词），提取每个独立风险/机会，返回描述性名称、分配的子类、一句理由
- 生成OWL实例块：名称转PascalCase IRI，子类标签通过大小写不敏感查找+子串回退归一化，两遍去重（精确IRI匹配→归一化匹配）

**阶段5：语义聚类与整合**
- 使用all-MiniLM-L6-v2编码为384维向量，计算余弦相似度
- 阈值τ=0.85进行聚类（选择保守值以避免合并实质上不同的项目，较高值保留更细区别）
- 使用带路径压缩和按秩合并的Union-Find数据结构实现传递闭包
- 聚类内一致性评估：协议比率α=共享多数子类的成员比例，完美簇(α=1.0)携带单一确认子类，非完美簇保留所有原始分配
- GPT-4o接收所有成员名称和理由，返回整合名称和合并理由，聚合所有来源引用和出版年份

**阶段6：影响分析与专家验证**
- 第一层：确定性影响评分 $S = w_c \cdot w_t \cdot f_e$
  - 类别权重 $w_c$：Systemic 1.4、High 1.2、Medium 1.0、Low 0.8（Geopolitical/Compliance/Environmental获高权重）
  - 时间权重 $w_t = \exp(-\lambda \cdot (T - t_{max}))$，λ=0.1，T=2025，无年份默认0.5
  - 事件因子 $f_e = 1 + \beta \cdot \ln(1 + \sum_{e \in E} \text{ImpactScore}(e))$，β=0.3
- 事件评分（Algorithm 1）：$Base = (M_e + L_e + R_e + D_{norm})/4$，$Net = 1 + 0.4\ln(1+n_r) + 0.2\ln(1+n_o) + 0.3\ln(1+n_t)$，$Decay = \exp(-0.05(T-y_e))$，$impactScore = Base \times Net \times Decay$
- 第二层：LLM相关性重评分，GPT-4o对半导体制造相关性$r_s$和欧洲市场相关性$r_e$打分（1-10），调整后 $S' = S \cdot \text{clamp}(1 + (r_s + r_e - 10)/20, 0.5, 1.5)$
- 第三层：领域专家对Top-100进行独立排序验证

## 实验与结果
**数据集与实验设置**
- 目标公司：Intel（IDM）、Infineon（IDM）、Texas Instruments（Fabless）、Air Liquide（特种化学品）、Siltronic（硅片制造）
- 文档来源：5家公司的年度/ESG/可持续发展报告等公开披露文件
- 历史事件库：250个预评分历史事件

**主要结果**
- 提取规模：聚类前共生成166,820个个体（Infineon 59,114；Siltronic 49,324；Intel 34,951；TI 17,534；Air Liquide 5,897）
- 聚类后：缩减至76,207个评分项，降幅21%-70%（Infineon/Siltronic最高70.3%/64.7%，TI最低21.1%）
- 提取质量：严格精确率76.0%，包含Partial项达92.6%；零幻觉项，全部无效项源于跨公司源污染
- 子类分配准确率：整体70.8%，父类别级89.4%
- 聚类效果：簇内平均余弦相似度0.89（≥τ=0.85阈值）
- 评分与专家验证：LLM重评分后，风险Spearman ρ从0.44提升至0.55，机会从0.36提升至0.72
- 事件评分：250个历史事件得分0.32-1.97（均值0.90），Top-5均为2022-2025年地缘政治/贸易政策行动
- 矩阵洞察：贸易限制为全部五家公司的系统性风险；机会呈现互补而非竞争性格局

## 相关工作脉络
1. **Zhao等（2024）**：提出基于LLM的供应链风险识别框架，证明LLM可从多源非结构化文档自动化提取风险，但未存储于结构化知识表示，无评分排序机制 → 本文在此基础上引入OWL本体和三层评分
2. **Mahfouz等（2021）**：J.P. Morgan构建的知识图谱系统用神经嵌入匹配机构风险与多语种新闻，专家评估准确率达96.6%，但KG为临时构建而非形式化本体，无评分排序 → 本文采用正式OWL本体确保可扩展性和复用性
3. **Li等（2024）**：综述246篇KG在企业风险管理中的应用文献，指出领域特定训练数据稀缺和实时能力不足的挑战 → 本文通过公开披露文件的持续抓取缓解数据稀缺问题
4. ** Zheng等（2025）**：提出本体引导的供应链风险KG提取方法，使用LLM从新闻文章提取KG（30,000+实体），但聚焦自然灾害而非半导体，未建模机会和评分 → 本文扩展至半导体双重视角并实现风险-机会联合建模
5. **Razouk等（2022）**：结合KG嵌入与BERT因果提取从FMEA文档进行根因分析，但操作内部企业数据而非外部披露，聚焦单一风险维度 → 本文面向公开披露文件并兼顾风险与机会
6. **Kuo等（2023）**：开发基于语义网的风险评估框架用于协同供应链规划，同样依赖内部数据、单维风险 → 本文首次在外部分披露场景实现风险-机会双维度自动化

## 局限性与未来方向
- **语言覆盖局限**：仅处理英语文档，Air Liquide等以法语为主的公司覆盖不足，需多语言模型支持
- **来源检索局限**：依赖44个查询模板，未涵盖财报电话会议记录、供应商审计报告等；可通过视觉语言模型扩展年报图表/信息图
- **跨公司源污染**：目标公司网站托管或链接讨论其他公司的文档，导致无效提取；需元数据预过滤+提取后归属检查的两阶段缓解
- **聚类算法局限**：固定阈值τ=0.85的单链接Union-Find在高度重复语料中可能产生过大簇；建议改用平均链接并进行阈值敏感性分析
- **簇内去重局限**：当前按公司独立聚类，无法实现跨公司同一风险的去重；需跨公司去重以实现联盟统一风险画像
- **增量处理缺失**：系统为单次批量运行；需增量 ingestion 模块监控新发布文件并仅合并新文档至现有图谱
- **验证覆盖局限**：五家案例公司仅填充12个供应链簇中的5个；需纳入更多联盟成员加强跨公司发现
- **专家验证单一**：每公司仅一位领域专家；计划收集并平均多位专家排名
- **召回未测量**：缺乏人工标注Ground Truth，未执行正式召回测量；需在小型人工标注子集上进行针对性召回研究

## 研究启发与可借鉴点
1. **三层评分机制的可迁移设计**："算法确定性评分+LLM情境调整+专家验证"的融合范式可推广至其他需要人机协同决策的风险管理场景（如金融、能源、医药供应链）
2. **OWL本体+LLM提取的协同架构**：先用形式化本体定义分类体系和约束（不相交公理、对象属性），再让LLM在结构化框架内提取，既保证机器可解释性又利用LLM泛化能力，值得在其他领域风险建模中复用
3. **语义聚类阈值的选择策略**：本文采用保守阈值τ=0.85以避免过度合并，同时记录协议比率α作为簇内一致性度量，这种"保守聚类+一致性评估"的方法论可指导类似NLP去重任务
4. **LLM-as-Judge的交叉验证设计**：用Claude 3.5 Sonnet（不同提供商）评估GPT-4o提取的结果，避免组件自评分偏差，这一"不同模型互评"策略提升了结果可信度
5. **价值链位置驱动的差异化洞察**：通过Jaccard相似度和跨公司比较，揭示不同价值链位置（制造vs化学品）的风险异质性，为联盟差异化策略提供依据，这一分析框架可复用于产业联盟决策支持

## 关键术语表
- **Chance-and-Risk Matrix（机遇-风险矩阵）**：ALLPROS联盟的优先级排序工具，将识别出的风险和机会沿影响 magnitude（百万欧元）和资源需求两轴绘制，右上象限代表需欧盟层面协调行动的最关键问题
- **OWL Ontology（Web本体语言）**：语义网技术栈中最具表达力的表示语言，支持类层次、对象属性、不相交公理等复杂约束，本文用于形式化编码风险-机会分类体系
- **Sentence-BERT（all-MiniLM-L6-v2）**：基于Siamese BERT网络的句子嵌入模型，384维向量用于语义去重，余弦相似度>0.85的项目合并为同一簇
- **LLM-as-a-Judge（大语言模型裁判）**：用LLM评估其他LLM输出质量的方法论（Zheng等2023），本文用Claude 3.5 Sonnet独立验证GPT-4o提取结果，避免自评分偏差
- **Union-Find with Path Compression（带路径压缩的并查集）**：高效实现传递闭包的并查集数据结构，配合union-by-rank优化，用于语义聚类中的簇合并操作
- **Spearman ρ（斯皮尔曼等级相关）**：衡量自动化排序与专家排序单调相关性的非参数指标，本文核心验证指标（风险0.55、机会0.72）
- **ISO 31000（国际风险管理标准）**：定义风险为"不确定性对目标的影响（潜在有害）"、机会为"不确定性对目标的影响（潜在有益）"，本文据此统一风险-机会概念框架
- **ALLPROS（处理器与半导体技术产业联盟）**：欧盟芯片法案 pillar III下的协调机制，集结半导体企业、成员国政府和欧盟委员会，本文流水线直接支撑其Supply Chain工作组的交付物
