# 论文速读：A-Dataset-for-Modeling-Iterative-Problem-Solving

## 一句话总结
本文提出了 CodeInsight 大规模数据集（300万+ C++ 提交记录），并在统一评测框架下首次系统比较了参数、序列和生成三类模型在迭代问题解决预测任务上的性能，发现适应离散潜在变量的 RSSM 在多数课程中预测精度最高，而 LLM 预测器虽能生成可分析代码，但预测信号主要由题目难度驱动而非学生行为特征。

## 研究问题与动机
1. **核心问题**：如何预测学习者在多次尝试中的表现动态（提升、停滞或倒退），以及哪些错误会持续、策略如何转变？
2. **现有方法局限**：参数模型（如 IRT）不建模技能随时间的演化；序列模型（如 BKT/DKT）仅预测二元正确性；LLM 用于模拟学习者行为的研究尚未在统一框架下与前述方法系统比较。
3. **数据缺口**：现有编程轨迹数据集要么缺乏逐测试用例层面的细粒度结果，要么缺少完整源代码和时间戳，无法支持对迭代修正过程的深度建模。
4. **实际应用需求**：理解迭代问题解决动态可支撑自适应教学、个性化反馈和自主智能体评估。

## 核心贡献（创新点）
1. **CodeInsight 数据集**：包含 3,286 名本科生在 394 道 C++ 题目上超过 300 万次提交，提供逐测试用例正确性标签、时间戳和完整源码，填补了细粒度编程轨迹数据的空白。
2. **统一基准测试**：首次在共享校准与评分协议下系统比较 IRT、CIRT、BKT、DKT、Code-DKT、TIKTOC、RSSM 和 LLM 预测器八种模型，填补了跨建模传统公平对比的研究空白。
3. **离散潜在变量 RSSM**：借鉴 DreamerV2 框架，将 GRU 隐藏状态与 16×16 离散潜在变量结合，通过后验/先验分离机制追踪解题者特征随时间的演变，在四门课程中三门取得最高 AUC。
4. **LLM 预测器的机制诊断**：通过 Kendall τ 分析和 prompt 消融实验揭示，冻结 LLM 的预测信号主要由题目难度驱动（$r=0.80$），与学生特定行为特征的相关性较弱（$r=0.40$），且编程能力越强的 LLM 预测性能反而越差。

## 方法详解
**数据预处理与过滤**：移除通过率低于 10% 或高于 90% 的题目（避免天花板/地板效应），保留至少 25% 学生尝试过的题目；尝试次数截断为 10 次；缺失尝试用哨兵值 -1 表示。

**参数模型**：
- **IRT**：单参数 logistic 模型，$P(\text{correct}) = \sigma(\theta_s - b_j)$，估计学生能力 $\theta_s$ 和题目难度 $b_j$。
- **CIRT**：在 IRT 基础上引入逐题时间斜率 $\lambda_j$，$P(\text{correct}) = \sigma(\theta_s - z_j - \lambda_j \cdot t)$，其中 $t$ 为尝试索引。

**序列模型**：
- **BKT**：隐 Markov 模型，每测试用例独立拟合先验掌握概率 $P(L_0)$、转移概率 $P(T)$、猜测概率 $P(G)$、 slips 概率 $P(S)$。
- **DKT**：单隐层 LSTM（维度 64），处理最近 600 次交互序列。
- **Code-DKT**：在 DKT 基础上融合 Qwen3-Embedding 生成的代码嵌入（投影至 32 维）。
- **TIKTOC**：多任务模型，LSTM 知识状态与 LoRA 微调的 Qwen3-0.6B 语言模型耦合，联合预测逐测试用例结果和生成学生代码。

**RSSM（核心方法）**：
- 使用预训练 LLM（Qwen3-Embedding）将代码和问题分别嵌入为 $e_t$ 和 $q_t$，经线性投影后输入 GRU。
- 离散潜在变量 $z_t$ 采用 16 维分类分布，通过 straight-through 估计器计算梯度。
- 后验模型 $q_\phi(z_t | h_t, e_t)$ 从观察到的响应推断，先验模型 $p_\phi(\hat{z}_t | h_t)$ 仅从历史预测，遵循 DreamerV2 框架。
- 损失函数：$\mathcal{L} = \sum_t \text{BCE}(r_t) + \lambda_e \text{MSE}(\hat{e}_t, e_t) + \beta[\alpha D_{KL}(q||p) + (1-\alpha)D_{KL}(q||\text{sg}(p))]$，其中 $\lambda_e=0.1$、$\beta=0.5$、$\alpha=0.8$。
- 超参数：隐藏维度 512，学习率 $3\times10^{-4}$，dropout 0.1，批次大小 64，早停 patience 50。

**LLM-as-Predictor**：
- 冻结参数的 Qwen3-14B/Gemma-4-31B/Claude Opus 4.6，无微调。
- 输入包括：学生行为画像（提交节奏、编辑距离、主题通过率等）、4 种行为原型分类、最近 5 个相似题目的检索示例（TF-IDF 余弦相似度 + 时间衰减加权）。
- 每个真实尝试节点生成一次代码预测，通过编译和自动化判题获取逐测试用例结果。

## 实验与结果
**数据集统计**：
- DSA HK231：966 学生 / 227 题目 / 2,194 测试用例 / 865,912 提交
- DSA HK221：513 学生 / 175 题目 / 1,661 测试用例 / 456,916 提交
- PF HK232：1,485 学生 / 129 题目 / 1,307 测试用例 / 854,104 提交
- PF HK222：1,413 学生 / 119 题目 / 1,201 测试用例 / 897,863 提交
- 总计：3,286 学生 / 394 题目 / 3,888 测试用例 / 3,074,795 提交

**主要结果（平衡准确率 / AUC）**：
| 课程 | 最优模型 | 关键数值 | 第二名 |
|------|---------|---------|--------|
| DSA HK231 | RSSM | Bal.Acc 0.769 / AUC 0.860（第4次尝试） | CIRT (AUC 0.833) |
| DSA HK221 | RSSM | Bal.Acc 0.696 / AUC 0.819（第4-5次尝试） | IRT (AUC 0.810) |
| PF HK232 | TIKTOC | AUC 0.986（第4次尝试） | RSSM（后期略优） |
| PF HK222 | RSSM | Bal.Acc 0.812 / AUC 0.952（第10次尝试） | TIKTOC |

**关键发现**：
1. **RSSM 优势集中在后期尝试**：前三次尝试中 RSSM 与参数模型差距不大，但从第 5 次尝试开始显著拉开差距，表明离散潜在变量更能捕捉长期演化模式。
2. **LLM 预测器性能低于所有训练模型**：Qwen3-14B 在 DSA HK231 上 Bal.Acc 仅 0.57–0.65，低于 RSSM 和参数模型。
3. **编程能力与预测性能负相关**：Opus 4.6（最强编码者）< Gemma-4-31B < Qwen3-14B（最弱编码者）的预测准确率排序，最强编码者因过度优化而偏离学生实际错误模式。
4. **LLM 预测信号以题目难度为主导**：去除题目平均得分后，LLM 与学生的 Kendall τ 均值趋近于零；无学生上下文时的 LLM 通过率与有上下文时的相关性 $r=0.80$，远高于与真实学生通过率的相关性 $r=0.40$。

## 相关工作脉络
1. **编程轨迹数据集**：CodeWorkout（~13 万 Java 提交，仅有聚合通过率）、Blackbox（3 亿编译记录，无题目结构）、ACcoding（400 万提交，单整体判题结果）均缺乏逐测试用例级细粒度标签；本文 CodeInsight 在此维度实现了突破。
2. **知识追踪模型**：BKT（Corbett & Anderson, 1994）和 DKT（Piech et al., 2015）奠定了序列预测基础，但未融合代码语义；Code-DKT（Shi et al., 2022）和 Temporal-ASTNN（Mao et al., 2021）引入 AST 表示，TIKTOC（Duan et al., 2025）进一步耦合生成与预测，但缺乏统一基准对比。
3. **迭代 IRT 模型**：Culpepper（2014）提出顺序 IRT 框架，本文 CIRT 在其基础上引入尝试索引难度斜率，是对该传统的工程化扩展。
4. **LLM 模拟学习者**：Markel et al.（2023）的 GPTeach、Miroyan et al.（2025）的 ParaStudent、Ross & Andreas（2025）的错误模拟方法，以及 Neshaei et al.（2024）发现微调 LLM 仅能匹配序列模型；本文直接比较了冻结 LLM 与专门建模方法的预测性能。

## 局限性与未来方向
1. **数据集单一性**：仅来自越南一所大学的 C++ 课程，平台为 Moodle 改造的单一评分系统；结论向其他语言、机构、课程设计推广时需谨慎。
2. **LLM 未微调**：仅评估了三个冻结参数 LLM；微调（尤其基于含错学生代码的 fault-guided 训练）可能改善行为保真度，但未在本文验证。
3. **仅评估预测能力**：未检验预测结果呈现给教师或学生是否真正改善学习 outcomes；需要对照实验部署。
4. **预测不诊断**：模型可预测重复失败但无法识别底层迷思概念或缺失的帮助类型。
5. **未来方向**：扩展到更多编程语言和 LLM、探索约束解码或替代检索策略以提升 LLM 预测行为真实性、解析 RSSM 离散潜在空间的语义可解释性。

## 研究启发与可借鉴点
1. **统一基准设计范式**：共享校准-评分协议（训练集估题难度参数→冻结→测试集校准学生能力→预测后续周）值得迁移到教育数据挖掘的其他预测任务中。
2. **离散潜在变量建模学习轨迹**：RSSM 将 DreamerV2 的世界模型思想适配到教育场景，通过 KL 平衡和后验/先验分离捕获状态演化，可借鉴到用户行为建模、推荐系统等序列预测任务。
3. **LLM 作为生成求解器 vs 预测器的定位区分**：本文揭示了"强编码能力≠好学生模拟器"的悖论，提醒后续研究需谨慎解读 LLM 在教育模拟中的角色，可考虑引入错误注入或 constraint decoding 以生成更贴近学生行为的代码。
4. **细粒度逐测试用例评估的价值**：相比聚合通过率，逐测试用例标签支持更精细的错误模式分析（如图 8 的转移流矩阵），为诊断型分析提供了数据基础。

## 关键术语表
**CodeInsight**：本文构建的大规模编程轨迹数据集，包含 300 万+ C++ 提交记录、逐测试用例正确性标签、时间戳和完整源码。
**RSSM（Recurrent State Space Model）**：借鉴 DreamerV2 的循环状态空间模型，通过离散潜在变量和 GRU 追踪解题者状态随尝试次数的演化。
**IRT（Item Response Theory）**：项目反应理论，用学生能力和题目难度两个参数预测答题正确性的概率模型。
**CIRT（Continuous IRT）**：在 IRT 基础上引入逐题目时间斜率，建模难度随尝试次数变化的动态 IRT 变体。
**BKT（Bayesian Knowledge Tracing）**：基于隐 Markov 模型的知识追踪方法，用掌握概率、转移概率、猜测和 slips 概率预测学习表现。
**DKT（Deep Knowledge Tracing）**：使用 LSTM 处理学生交互序列的深度知识追踪模型。
**TIKTOC**：耦合 LSTM 知识状态与 LoRA 微调语言模型的多任务模型，联合预测逐测试用例结果和生成学生代码。
**Straight-through Estimator**：用于离散变量梯度传播的近似技术，允许分类分布采样参数通过反向传播更新。
