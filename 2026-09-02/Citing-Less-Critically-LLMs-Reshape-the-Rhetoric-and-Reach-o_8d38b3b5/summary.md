# 论文速读：Citing-Less-Critically-LLMs-Reshape-the-Rhetoric-and-Reach-o

## 一句话总结
该论文构建了**遮蔽引用任务（masked-citation task）**，在保留每处引用的修辞上下文的前提下，让6个主流大语言模型填补被遮住的引文句，从而与人类作者的原句进行逐位置、逐意图的直接对比；发现LLM生成的引用相比人类引用更缺乏批判性、更易放大流行度/年代/团队规模偏差，且社会距离更远。

## 研究问题与动机
1. **核心问题**：LLM在科学写作中越来越广泛地辅助参考文献推荐与相关文献撰写，但这些工具是否会保持人类引用所携带的**修辞意图（rhetorical intent）**，以及引用对象选择在意图维度上的分布是否依然与人类一致？
2. **现有工作不足（已有三条主线均不够全面）**：
   - 审计类工作主要关注LLM是否编造或误归参考文献（可靠性），未考察引用的修辞角色（支持/对比/提及）。
   - 引用选择类工作仅发现LLM会放大对高影响力、小团队论文的偏好，但未将该偏差按意图分层拆解。
   - 作者层面工作主要关注性别/种族等人口学差异，忽略了对引用网络社会结构的测量。
3. **方法层面的关键缺口**：既有研究多把引用视为"扁平检索或推荐"，不保留单句位置上的修辞上下文、不对比同位置的人类选择、不以意图为条件检验偏差差异、也不测量被引者与引用者之间的合著网络距离。

## 核心贡献（创新点）
1. **提出了位置对齐的遮蔽引用基准**：每个LLM填充的引文句都是同一位置人类选择的反事实对照，严格匹配位置、截稿时间与引用数量，使唯一变量是"引用选择与修辞意图"。与已有审计类工作的本质区别：从"推荐清单比对"升级为"同槽位反事实句级对齐"。
2. **首次按意图条件分解LLM与人类的引用差异**：证明LLM在支持性引用中最强烈偏好高被引经典论文、在对比性引用中最强烈偏离引用较新论文、在提及性引用中最不倾向于引用大团队论文，将"流行度偏差"细化为意图调节效应。与已有工作的本质区别：把原来被视为整体平均的偏差拆解为可因意图而异的结构性偏差。
3. **首次在百万级合著网络上量化"作者层社会距离"**：通过构建包含2000万+边、210万+研究者的2015–2024年合著网络，计算四类作者角色偶对的最短路径距离，揭示人类在支持性引用中明显更偏近邻合作者，而LLM在各意图下都指向社会距离更远的作者。与已有工作的本质区别：从自引率这一个汇总指标，跃迁到全网络拓扑层级的短路径度量。
4. **证明了"温暖化"效应在不同判据下稳健**：无论是外部LLM-as-judge判定还是模型自报意图、无论是Gemini还是DeepSeek双重评审、无论是人类三人标注验证，都一致显示LLM削弱对比性引用并增加支持性引用。与已有工作的本质区别：从单一判定者结论变成跨三重独立判据（外部judge×自报×人工）的一致性结论。

## 方法详解
1. **遮蔽引用任务设计（slot-level reconstruction）**：
   - 输入：每个被引句的前后各一句（±1-sentence context）+ 所属section标题 + 引用计数要求 + 论文标题/会议/年份。
   - 输出：JSON格式，包含 citation_count、recommended_papers（每篇含title/authors/year/venue/doi）、citation_sentence、motivation（supporting/contrasting/mentioning）与confidence。
   - 关键约束：temperature=0；required citation count 与人类原句保持一致；模型不得看到被遮住的原始引文句与被引论文标题。
2. **意图标注（LLM-as-judge）**：
   - 主判官为 Gemini-3-Flash-Preview，鲁棒性检查用 DeepSeek-V4-Flash。
   - 判官只看到引用句及局部上下文（±500字符），**刻意不呈现被引论文标题**，以保证标签反映"修辞动作"而非"哪篇被引"。
   - 三类定义：Supporting（提供对齐证据/方法/发现）、Contrasting（对照或反驳的基线/对立工作）、Mentioning（背景/定义/一般性致谢）。
   - 与三人标注的一致性 κ=0.60；对支持/对比两类非中性标签F1分别为0.79/0.73。
3. **引文元数据匹配**：
   - 基于 DOI → 未命中时回退到 title 进行规范化匹配，来源为 Dimensions 数据库；作者姓名因格式不一致不参与匹配。
   - 人类引文匹配率 86.7%，模型侧匹配率因模型而异（39.5%–81.9%）。
4. **社会距离度量**：
   - 构建 2015–2024 年的合著无向图（团队规模上限25人），节点 2.1M+，边 20M+。
   - 对每个引用槽计算四类第一/最后作者偶对的最短路径距离（BFS），d=0 为自引，d=1 为直接合作者，取四种偶对的均值 ⟨d⟩ 作为该槽的社会距离。
   - 可达偶对覆盖率：人类 26.5%，模型 14.5%–25.5%。
5. **统计口径**：
   - 偏差分析以"每篇主论文贡献一个观测值"聚合，避免高引论文主导。
   - Citation count/team size 报告几何均值比（log(LLM/human) 反变换），recency 报告均值差；用 Welch t-test 比较三意图两两差异。
   - 共享交集（intersection）复算：保留 12,556 个 context（覆盖 1,695/1,746 篇论文），消除匹配覆盖率差异带来的混杂。

## 实验与结果
- **数据集**：ACL/EMNLP/NAACL 2025 主会论文 1,746 篇，63,944 处引用上下文、132,913 个引用槽；所有论文均为预印本发布时间晚于六模型训练截止，避免直接记忆检索。
- **六模型**：GPT-5.1、Claude-3.5-Haiku、Gemini-2.0-Flash、DeepSeek-V3.2、Llama-4-Maverick、Qwen2.5-72B-Instruct。
- **RQ1（意图分布）**：人类 baseline = 支持 21% / 对比 19% / 提及 60%；LLM 对比比例降至 10.7%–17.2%（五/六模型显著低于人类），支持比例升至 20%–41%。对比意图保留率最低（34.6%–50.6%），提及保留率最高（60%–80%）；人类→LLM 的"批判→支持"转换为 12.5%–31.1%，反向转换仅 3.6%–7.6%。
- **RQ2（意图调节的偏差）**：
  - 被引频次：LLM 引用的论文被引量为人类的 1.3–4.5 倍；对比性偏差最小，部分模型甚至低于人类（Qwen-72B 0.88×、Claude-3.5 0.78×）。
  - 年代：对比性引用中 LLM 引用比人类老 1.6–3.3 年（Gemini-2.0 +3.27 yr、GPT-5.1 +2.86 yr）。
  - 团队规模：提及性引用中 LLM 引用团队为人类 0.30–0.61 倍。
  - 共享交集复算结果：支持性引用被引倍数仍最高（DeepSeek 4.74×、Gemini 3.82×、GPT-5.1 3.74×、Llama-4 3.68×）；对比性年代差仍最大（Gemini +3.06 yr、Qwen +2.92 yr、GPT-5.1 +2.60 yr）；团队规模差仍在提及性最大（Qwen 0.38×、Llama-4 0.56×）。
- **RQ3（社会距离）**：
  - 人类平均距离 ⟨d⟩ = 3.40，LLM 分布在 3.65（GPT-5.1）至 3.89（Qwen-72B）。
  - 人类支持性引用显著更近（⟨d⟩ = 3.31 vs. 对比 3.45、提及 3.43，p < 0.001），而LLM 各意图间距不足 ±0.05。
  - 入网引用率（d ≤ 1）：人类 7%–10%（支持性 9.8%），LLM 全部低于 1.6%，且几乎无自引。
- **鲁棒性**：更换判官、扩大上下文窗口、加入实时检索（live web search）、限制于 2024 年前被引作品、同一 FoR 字段内复算，三项主发现均保持一致；即便 GPT-5.1 开启实时搜索，对比比例仍仅 ~10%（对比人类 33%），表明"温暖化"是生成阶段的系统性偏差而非检索缺失所致。

## 相关工作脉络
1. **引用可靠性审计**（Press et al., 2024; Niimi, 2025; Linardon et al., 2025; Walters & Wilder, 2023）：聚焦编造/误归，未进入修辞意图维度；本文在此基础上向前推进到"同槽位意图保留率"与"批判转支持"转化率的测量。
2. **引用选择偏差**（Algaba et al., 2025, 2026）：发现LLM放大影响力与小团队偏差；本文进一步证明该偏差并非均匀分布，而是**由意图调节**（影响力峰值出现在支持性、年代峰值出现在对比性、团队规模峰值出现在提及性）。
3. **作者层差异**（Tian et al., 2024; He, 2025）：聚焦性别/种族等人口学特征；本文从社会结构视角测量合著最短路径距离，揭示LLM无法复现人类对近邻合作者的支持性引用偏好。
4. **引用意图/极性分类**（Teufel et al., 2006; Jurgens et al., 2018; Cohan et al., 2019）：定义了三分类体系与标注范式，本文为首次将其与"LLM反事实填充"任务结合，构成"同句级位置对照"的评估框架。
5. **科学与科学的量化研究**（Merton, 1968; Price, 1976; Newman, 2001; Wallace et al., 2012; Chen et al., 2024; Kozlowski et al., 2025）：刻画了累积优势、马太效应、引用老龄化、合著同质性与社会邻近性；本文首次在这些现象上追问"LLM是否继承并如何变形"。
6. **最近似社会侧先例**（Algaba et al., 2026 仅报告 aggregate self-citation rate）：本文扩展到 20M+ 边的全网络 BFS 短路径与意图分层社会距离。

## 局限性与未来方向
1. **判官偏差风险**：双LLM判官（Gemini-3-Flash、DeepSeek-V4-Flash）之间一致，但二者都可能继承训练数据中对LLM措辞更宽容的偏向；绝对比例需谨慎解读，方向性结论已通过人工三标注器验证。
2. **匹配覆盖率差异**：模型侧 match rate 从 39.5%（Claude-3.5）到 81.9%（DeepSeek）不等；虽用 shared-context intersection 控制了混杂，但未被匹配部分（大量为 hallucinated 或标题错位，约 79%–97%）仍未进入分析。
3. **网络覆盖率偏低**：2015–2024 合著图仅有 26.5%（人类）和 14.5%–25.5%（模型）可达偶对，早期学者、非西方机构与业界从业者的社会结构系统性缺失，in-network 偏差结论仅适用于高产出活跃作者群体。
4. **学科/语言外推受限**：语料仅限 ACL/EMNLP/NAACL 英文主会论文；不同学科、地理与语言的引用规范差异可能决定"温暖化"与流行度偏好的强度。
5. **机制未明**：温暖化可能与 sycophancy 偏向正性有关、也可能源于训练语料中高被引论文更多出现在正面语境、近期论文更多出现在混合/负面语境；具体因果机制仍需后续实验剥离。
6. **生成阶段而非检索阶段**：即便加入 live web search，温暖化仍然存在，说明单纯增强检索不足以矫正修辞倾向；如何干预生成层是未来方向。

## 研究启发与可借鉴点
1. **同槽位反事实评测范式**：将遮蔽占位 + 数量守恒 + 截稿后发布时间三重约束组合，形成"同一修辞位点的人类 vs LLM 直接对照"基准，可迁移到摘要重写、论证结构改写、语气风格转换等多类科学写作的审计任务。
2. **意图-偏差解耦思路**：将"流行度/时效/团队规模"等偏差按 rhetorical intent 分层报告，揭示"同一种偏差在不同意图下的峰值方向不同"，该方法论可作为后续偏见审计的标准动作。
3. **社会网络距离替代自引率**：用 BFS 最短路径替代单一的自引率/合作者重叠率来刻画社会邻近性，能捕捉到更细粒度的"间接熟人"关系；任何涉及科学通信、知识扩散、推荐系统公平性的工作都可沿用此距离度量。
4. **双重判官 + 人工校验的稳健组合**：主判官 × 备用判官 × 三人标注的一致性设计，既保证规模又可识别判官特有风险，值得推广到所有基于LLM-as-judge的评分任务。
5. **检索增强不改变修辞**：即便开启实时搜索，温暖化不变，说明此类偏差根植于生成/对齐而非检索；提示研究者应从"检索质量审计"转向"生成层对齐审计"，并探索 prompt 干预、few-shot 反例、contrastive style prompt 等矫正手段。

## 关键术语表
- **Masked-citation task**：将真实论文中的引文句替换为占位符，要求LLM在同位置、同计数、同上下文中生成新的引文句与被引论文，构造与人类选择的反事实对照。
- **Citation intent（引用意图）**：作者引用动机分三类——supporting（支撑/对齐）、contrasting（对照/反驳）、mentioning（中性提及/背景）。
- **LLM-as-judge**：使用独立大模型作为标注器，仅凭引用句与局部上下文判断意图，刻意隐藏被引论文元信息以避免标签被"哪篇被引"污染。
- **Social distance（社会距离）**：在合著网络中以 BFS 最短路径度量引用作者与被引作者之间的结构邻近程度，d=0 为自引、d=1 为直接合作者。
- **In-network citation rate**：引用落入 d ≤ 1（自引或直接合作者）的槽比例，用来刻画"近邻引用"的集中程度。
- **Warming effect（温暖化效应）**：LLM生成的引用比人类引用的修辞语气更支持性、更少批判性，尤其体现在将人类"对比"句改写为"支持"句。
- **Shared-context intersection**：选取所有模型与人类均至少有一条可匹配引用的context集合，用于排除各模型match率差异造成的混杂。

## 可复现要素
- **数据集**：1,746 篇 ACL/EMNLP/NAACL 2025 主会论文（含 .tex/.bib 文件，来自 arXiv）；合著网络基于 2015–2024 年 Dimensions 数据构建；论文未声明单独开放原始引文语料，但声明将开源代码与去标识化聚合输出。
- **代码/权重**：代码与聚合输出拟开源（论文未给出具体仓库链接）；六模型通过官方 API 调用；判官为 Gemini-3-Flash-Preview 与 DeepSeek-V4-Flash。
- **关键超参**：generation temperature = 0；judge temperature = 0；合著网络团队规模截断 25 人；上下文默认 ±1-sentence（附录F验证了全文段落与摘要级别均稳健）。
