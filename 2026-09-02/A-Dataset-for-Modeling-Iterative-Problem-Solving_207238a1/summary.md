# 论文速读：A-Dataset-for-Modeling-Iterative-Problem-Solving

## 一句话总结
本文构建了大规模编程迭代求解数据集 CodeInsight（超 300 万次提交、3,286 名本科生、测试用例级细粒度标签），并在统一校准与评分协议下横向对比参数化、序列化和生成式三类模型；研究发现基于离散潜变量的 RSSM 预测精度最优，而冻结参数的 LLM 预测器主要反映题目难度而非学生特异性行为，其编码能力与预测准确性呈负相关。

## 研究问题与动机
1. **核心任务**：迭代问题求解是典型的序列建模任务，需预测学生在多次尝试后表现是提升、 plateau 还是退化，并刻画哪些错误会持续存在、策略如何转移。
2. **现有方法局限**：参数化模型（如 IRT）仅估计静态能力与难度，无法刻画技能随尝试的动态演变；传统序列模型（如 BKT/DKT）通常只能预测二元正确性，缺乏对代码语义与失败模式的建模；LLM 虽能生成完整提交，但是否真正模拟了学习者特有的错误分布仍存疑。
3. **评估碎片化**：上述建模传统独立发展，此前缺乏在统一数据划分、校准协议与评分标准下的系统性对比基准。
4. **数据机遇**：编程课程配合自动判题系统可自然记录完整的迭代轨迹（代码、时间戳、逐测试用例反馈），为研究此类问题提供了高保真、细粒度的时序数据源。

## 核心贡献（创新点）
1. **CodeInsight 数据集**：收录越南某高校 2022–2024 年两门 C++ 课程的 3,074,795 次提交、394 道题目与 3,888 个测试用例，提供测试用例级 pass/fail 标签、完整源代码与精确时间戳，突破既有数据集仅保留聚合正确率或缺失题目结构的局限。
2. **跨家族统一评测基准**：首次在同一时间切分、题目参数冻结、学生能力校准的协议下对比 IRT/CIRT、BKT/DKT/Code-DKT/TIKTOC、RSSM 与 LLM-as-Predictor，填补了教育数据挖掘领域跨范式可比性研究的空白。
3. **适配离散潜变量的 RSSM**：将 DreamerV2 的 posterior/prior 分离机制引入学习轨迹建模，利用 GRU 累积历史、16×16 分类潜变量压缩求解者状态，通过辅助嵌入预测与 KL 正则提升后期尝试的预测稳定性。
4. **LLM 预测器的归因诊断**：系统性证明冻结 LLM 的预测信号主要由题目难度驱动（有/无学生上下文的通过率相关 $r=0.80$，与真实学生仅 $r=0.40$），并揭示 LLM 代码能力越强反而预测越差，重新定位其为“条件生成求解器”而非“忠实行为模拟器”。

## 方法详解
- **共享校准-评分协议**：学生按 55%/15%/30% 划分；先用训练集估计题目难度参数（如 IRT 的 $b_j$）并冻结，再在校准窗口（第 1–3 周）为测试学生校准能力参数 $\theta_s$，最终预测后续周次表现。预测原子为单位测试用例的二元 outcome，缺失尝试以 -1 标记并 mask。
- **参数化基线**：IRT 采用 1PL Rasch 模型 $P(\text{correct})=\sigma(\theta_s - b_j)$；CIRT 引入尝试次数斜率 $P(\text{correct})=\sigma(\theta_s - z_j - \lambda_j \cdot t)$，其中 $\lambda_j<0$ 表示练习降低有效难度，$\lambda_j>0$ 刻画边际收益递减。
- **序列基线**：BKT 为每测试用例拟合 HMM（$P(L_0), P(T), P(G), P(S)$）；DKT 使用单隐层 LSTM 处理交互序列；Code-DKT 将 Qwen3-Embedding 提取的 4096 维代码向量投影至 32 维后与 one-hot 交互编码拼接；TIKTOC 耦合 LSTM 知识估计器与 LoRA 微调的 Qwen3-0.6B 生成器，联合预测测试用例通过率并生成下一步代码。
- **RSSM 核心设计**：代码与题目分别经预训练 LLM 编码后投影为响应向量 $e_t$ 与问题向量 $q_t$；GRU 更新隐藏状态 $h_t = f_\phi(h_{t-1}, z_{t-1}, q_t)$；后验 $q_\phi(z_t|h_t, e_t)$ 与先验 $p_\phi(z_t|h_t)$ 分离，推理时仅用先验预测下一步状态；评分头融合 $q_t, h_t, z_t$ 与难度偏置输出通过率；辅助损失预测下一时刻响应嵌入。损失函数包含测试用例 BCE、嵌入 MSE（$\lambda_e=0.1$）与双向 KL 散度（$\beta=0.5, \alpha=0.8$，含 stop-gradient）。潜变量采用 16 维分类分布与 straight-through 梯度估计。
- **LLM-as-Predictor**：冻结 Qwen3-14B/Gemma-4-3
