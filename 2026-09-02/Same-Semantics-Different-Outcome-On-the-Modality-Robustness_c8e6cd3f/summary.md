# 论文速读：Same-Semantics-Different-Outcomes-On-the-Modality-Robustness

## 一句话总结
本文系统评估了多模态大语言模型（MLLMs）在知识冲突（Knowledge Conflict, KC）场景下的模态鲁棒性，发现相同语义的外部证据以纯文本或渲染图像呈现时，模型的权威判定极不稳定；该不稳定性会直接削弱多模态 RAG 的表现并显著放大全指令图像化对抗攻击成功率，且仅冲突感知监督微调（SFT）可获得有限缓解。

## 研究问题与动机
- MLLMs 日益部署于检索增强生成与智能体工作流，外部证据常以纯文本、网页截图或扫描文档等异构形式到达，但模型对不同表面形式的处理一致性缺乏理论保障与实证检验。
- 现有研究普遍报告 MLLMs 存在“文本偏见”（盲信文本），但该结论尚未在严格的参数知识冲突设定下验证；且多数多模态冲突研究聚焦自然图像（场景/人脸），而非知识密集型文档段落。
- 当外部证据与模型参数化知识相悖时，若模型的采纳决策受证据呈现形式（模态）而非内容本身驱动，将严重损害系统的可靠性、可解释性与安全性。
- 本文旨在解耦语义内容、呈现模态与参数知识，量化 MLLMs 的模态依赖模式，并评估其对下游 RAG 性能与安全防御的实际影响。

## 核心贡献（创新点）
1. **形式化知识冲突下的模态鲁棒性**：将模态鲁棒性界定为证据权威性判定问题，通过固定语义内容仅变换模态（文本 vs. 渲染图）的设计，严格隔离模态效应与内容效应。
2. **构建单/多证据冲突评测框架**：提出单证据（文本/图像二选一）与多证据（图文共存且支持相反答案）两套设定，并引入输入顺序变量，首次揭示模态偏好随顺序与数据集构造方式任意翻转的现象。
3. **推翻“文本偏见”普适性结论**：发现单一证据时闭源模型反而显著倾向图像（如 Claude +42.86%），多证据时偏好高度依赖输入顺序与模型家族，证明既有“盲信文本”共识在 KC 场景下往往反转。
4. **证实模态不稳定的实际危害并探索缓解路径**：揭示该缺陷会加剧 RAG “迷失中间”效应并提升全指令图像化攻击成功率（平均 +6.99%）；对比提示工程、DPO、表示层导向与 SFT，证明仅冲突感知 SFT 能在不压制可靠视觉线索的前提下实现较均衡的模态依赖。

## 方法详解
- **冲突设定**：单证据对比 $x_T = (e_T, q)$ 与 $x_I = (e_I, q)$；多证据引入第三维参数知识 $p$，构成三元冲突，并在 $x_{I\to T}=(e_I, e_T, q)$ 与 $x_{T\to I}=(e_T, e_I, q)$ 两种顺序下测试。$e_I$ 由 Python Pillow 将 $e_T$ 渲染为黑字白底图像，确保语义完全一致。
- **核心指标**：外部证据跟随率 $\mathrm{EFR}(x) = \frac{1}{|\mathcal{D}|}\sum_i \mathbb{I}[\hat{a}_{x,1}^{(i)} = \hat{a}_{x,2}^{(i)} = \hat{a}_{x,3}^{(i)} = a_{\mathrm{ext}}^{(i)}]$；归一化图文差距 $G = \frac{\mathrm{EFR}_I - \mathrm{EFR}_T}{\mathrm{EFR}_I + \mathrm{EFR}_T} \times 100$（正值表图像偏好，负值表文本偏好，越接近 0 越稳健）。
- **缓解方法**：(1) 系统提示引导模型均衡使用双模态；(2) 冲突感知 LoRA SFT，在 Qwen2.5-VL-7B 上使用 NQ-SWAP 与 MMM-Fact（7:3 混合）微调，目标为拒绝误导性图像证据并保留事实性回答；(3) DPO 偏好优化（优选原始事实答案，拒选图像支持的反事实答案）；(4) 表示层导向（在 decoder 20–23 层提取文本跟随方向向量 $v_o$，解码时叠加 $\tilde{h} = h + \alpha v_o$）。
- **输入侧干预**：交叉替换视觉预处理管线（Qwen 智能缩放 vs. LLaVA 全局/局部 336×336 分块），并扰动渲染样式（全文红字/黄底 vs. 仅高亮答案跨度）。
