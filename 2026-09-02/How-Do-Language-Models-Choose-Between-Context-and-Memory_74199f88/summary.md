# 论文速读：How-Do-Language-Models-Choose-Between-Context-and-Memory

## 一句话总结
本文通过因果干预实验探究大语言模型在**上下文**与**参数化记忆**冲突时如何选择信息源，发现已知的“权威方向”虽能部分因果控制源选择，但**跨任务可重用性极弱**，表明权威计算可能是任务依赖的。

## 研究问题与动机
- **核心问题**：语言模型内部哪些计算控制着它在上下文与参数记忆之间的选择？这些计算是否在任务间可复用？
- **现有不足**：先前工作证明了激活方向可被解码和外部引导，但**可引导性≠模型内源性因果使用**，且方向跨任务可转移性未经验证。
- **研究缺口**：需要区分“表示存在”、“任务内因果使用”与“跨任务因果复用”三个层次。
- **动机**：建立更严谨的机制可解释性评估框架，为模型对齐和知识冲突缓解提供依据。

## 核心贡献（创新点）
1. **提出因果中介测试框架**：通过互换匹配提示对的权威坐标来量化表示的因果作用，而非仅依赖可解码性或加性引导。
2. **分离三层概念**：明确区分权威表示的存在性、任务内因果可用性、跨任务因果复用性。
3. **发现跨任务可重用性有限**：在颜色→材料任务迁移中，方向仅闭合自然差距的9%，而任务内局部方向闭合57%。
4. **揭示解码≠因果**：在州/国家事实任务中，权威方向跨领域高度可解码（AUROC 0.995-1.000），但单点干预几乎无行为影响。

## 方法详解
- **提示构建**：构造上下文与参数记忆明确冲突的提示（如颜色任务中上下文称“草是紫色”，模型记忆为绿色），并通过权威性措辞（“绝对”vs“未经证实的谣言”）操控来源可信度。
- **权威方向估计**：在一致性提示（上下文与记忆支持同一答案）下，计算高/低权威提示残差流的均值差，归一化为方向 $\mathbf{s}_\ell$。
- **因果中介干预**：对匹配的高/低权威提示对，在选定层互换沿 $\mathbf{s}_\ell$ 的激活坐标 $z_\ell = \hat{\mathbf{s}}_\ell^\top h_\ell$，保留正交部分不变。
- **间隔关闭率（Gap Closure）**：量化干预效果：$\text{Gap Closure} = \frac{(p_{\text{low}\to\text{high}} - p_{\text{low}}) + (p_{\text{high}} - p_{\text{high}\to\text{low}})}{p_{\text{high}} - p_{\text{low}}}$。
- **控制条件**：随机方向、协方差匹配方向、谱匹配方向等对照组。
- **跨任务测试**：在颜色任务学习方向后，移植到材料任务和州/国家事实任务上进行单点或多点互换。

## 实验与结果
- **数据集与模型**：自定义颜色任务、材料构成任务、州/国家事实任务；使用冻结的 Qwen2.5-3B/7B、Llama-3.1-8B、OLMo-2-7B 指令微调模型。
- **颜色任务内效果**：局部权威方向互换闭合自然差距的 **68%**（Qwen）、**56%**（Llama）、**30%**（OLMo）；随机方向接近零。
- **跨任务迁移（颜色→材料）**：自然权威差距为 0.560，导入的颜色方向仅闭合 **0.085**（14.8%），最强协方差控制仅闭合 0.043。
- **解码 vs 因果分离（州/国家）**：跨领域权威方向 AUROC 达 **0.995-1.000**，但单点干预最大效应仅 **0.014**（州→国家）和 **0.038**（国家→州）。
- **最强结果**：Qwen2.5-7B 在颜色任务内获得最高间隙关闭率（68%），显著优于所有对照组（18倍于最佳协方差控制）。

## 局限性与未来方向
- **样本量有限**：材料任务仅132个对象，可能影响统计效力。
- **任务几何差异**：不同任务可能在表征空间中存在非线性关系，线性互换难以捕获。
- **单点干预局限**：州/国家实验显示单层干预效果微弱，需考虑多层交互。
- **未来方向**：学习任务特定的权威子空间；在匹配非冲突提示上对齐子空间以实现跨任务投影；多层层联干预。

## 研究启发与可借鉴点
- **因果中介框架可迁移**：互换激活坐标的方法可用于其他可解释性研究，验证表示的因果作用。
- **跨任务可重用性测试重要性**：评估内部表示时，应区分任务内因果效用与跨任务泛化能力。
- **多层干预设计**：单点干预可能低估表示作用，可探索多层串联或子空间投影。
- **与本团队结合点**：可应用于检索增强生成（RAG）中上下文优先级的干预研究，或知识冲突缓解的对齐策略。
- **控制条件设计**：协方差匹配与谱匹配控制为可解释性研究提供了严格的对照基准。

## 关键术语表
- **参数化记忆（Parametric Memory）**：存储在模型权重中的知识，区别于上下文提供的瞬时信息。
- **上下文-记忆冲突**：当提示中的上下文信息与模型内部知识相矛盾时的场景。
- **权威方向（Authority Direction）**：由一致性提示学习得到的激活方向，表征模型对来源可信度的内部表示。
- **因果中介（Causal Mediation）**：通过干预特定坐标来量化某表示对最终输出的因果贡献。
- **间隔关闭率（Gap Closure）**：干预引起的行为变化占自然权威差距的比例，用于度量因果效应。
- **解码可重用性**：一个方向在不同任务上仍能区分语义或行为的程度，不保证因果效用。
- **协方差匹配控制**：去除权威方向后，保留残差协方差结构的随机方向对照组。
