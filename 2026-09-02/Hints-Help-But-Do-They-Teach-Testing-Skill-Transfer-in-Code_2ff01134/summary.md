# 论文速读：Hints-Help-But-Do-They-Teach-Testing-Skill-Transfer-in-Code

## 一句话总结
本文通过严格的对照组实验检验代码生成中“提示词让失败程序变成功”是否真正代表可迁移的技能传授；结果表明，大多数相关提示的救援实际上在无提示抽样中已可实现，提取的稳定激活方向仅扰动输出而未带来净准确率提升，跨基准隐状态正确性读出虽具备可解码性，但单样本选择优势仍未达统计显著。

## 研究问题与动机
1. 代码生成中常见的 before-after 救援现象无法区分三种解释：提示补充了缺失信息、仅将模型导向已具备的解空间，或因实现细节变化导致的输出扰动。
2. 现有干预研究多依赖单次贪婪解码比较，缺乏对重放不稳定性、无关提示安慰剂效应以及无提示抽样边界的系统性控制，易将采样变异误判为能力转移。
3. 表征工程常将激活方向的几何稳定性等同于语义特异性，需要更严密的因果验证链剥离表示稳定性、行为改变与任务特异性。
4. 虚拟-KV前缀等上下文压缩方法能否等效替代完整文本规范携带的程序技能，缺乏在可执行正确性评估下的受控对比与泛化边界刻画。

## 核心贡献（创新点）
1. 提出双模型行为审计框架，系统对比相关提示、无关提示与无提示 pass@8 抽样的救援覆盖关系；与仅报告单次提示救援的现有工作不同，本文明确划分“提示语义增量”与“抽样可及性”的边界。
2. 将几何稳定性、行为改变与任务特异性三者分离验证，证明稳定激活方向在全基准部署时仅扰动输出而不提升净准确率；区别于以往将方向余弦稳定直接等同于可解释技能向量的做法，本文要求干预必须通过 Held-out 配对损伤/救援检验。
3. 设计受控的上下文压缩测试，对比完整文本规范与训练型虚拟-KV前缀在合成程序任务上的保持与泛化能力；与通用 prefix-tuning 工作不同，本文以执行正确性而非困惑度作为迁移唯一标准，并给出负结果的条件限定。
