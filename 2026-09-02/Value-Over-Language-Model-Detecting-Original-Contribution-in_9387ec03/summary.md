# 论文速读：Value-Over-Language-Model-Detecting-Original-Contribution-in

## 一句话总结
本文提出了 **VOLM**（Value Over Language Model）框架，用于衡量文档中有多少信息内容是人类作者的原创贡献，而非语言模型仅凭通用任务描述即可轻松生成的内容，突破了现有 LLM 检测工具只关注表面文本作者归属的局限。

## 研究问题与动机
1. **现有工具测量的是文本表面，而非信息内容**：当前 LLM 检测工具（如 DetectGPT、EditLens）衡量的是文档中有多少表面文字由 LLM 生成，但无法回答"文档的信息内容/想法有多少真正源于人类作者"这一核心问题。
2. **"LLM 使用"的定义过于模糊**：同样是"使用 LLM"，可能是作者仅提供一行提示词直接采用输出，也可能是作者提供了完整的论证结构仅让 LLM 协助润色表达，这两种情况的信息原创性截然不同。
3. **现有方法会错误惩罚有益的辅助场景**：如非母语研究者用 LLM 翻译自己写的论点，或审稿人提供核心批判点让 LLM 扩写为正式审稿意见，现有工具会因大量表面文字来自模型而误判。
4. **信息论方法（如 Xie et al., 2026）存在基线和输入依赖问题**：其以无条件自信息为基线，且需要人类原始输入 x 作为条件，而实际评估者通常只有最终文档。

## 核心贡献（创新点）
1. **将问题重新定义为衡量信息内容的原创贡献**：不测量"多少文字由 LLM 生成"，而是测量"人类在提示中提供了什么模型原本不知道的信息"，与所有现有检测器回答的是不同问题。
2. **提出了通用框架 VOLM，可应用于任何文档+任务描述对**：借鉴棒球统计 VORP 的思想，以"替换级球员"类比"替换级文档"，衡量人类贡献超出语言模型从通用提示词即可产出的部分。
3. **开发了无需训练、无需标注数据的实现算法**：完全通过标准 LLM 的对数概率计算实现，不打分文档的表面文本，只打分基于提取内容重建的文档，从而免疫风格混淆因子。
4. **证明了 VOLM 对内容保持型变换具有不变性**：经过 LLM 改写、往返翻译、甚至专用 humanizer（DIPPER）处理的文档，只要信息内容不变，VOLM 分数仍保持稳定。

## 方法详解
**核心思路**：测量语言模型在看到任务描述 T 后，对文档 D 的"惊讶程度"，并观察随着文档内容逐步揭示，惊讶程度如何变化。

**Pipeline 三阶段**：
1. **提取（Extractor E）**：给定文档 D 和任务描述 T，在 k 个递增粒度级别 $g_i = E(D, T, i)$ 上生成内容摘要，$g_k$ 近似完整内容，低 $i$ 保留更粗粒度信息。
2. **重建（Reconstructor R）**：用 LLM M 生成重建文档 $\hat{D}_i = R(T, g_i, |D|)$，长度与原文档匹配（误差在 10% 内）。
3. **评分（Scoring）**：用仅含任务描述的 M 对重建文档评分：

$$s_i = \frac{1}{|\hat{D}_i|} \log P_M(\hat{D}_i \mid T)$$

**关键设计**：
- **替换级基线文档**：$D_{\text{ref}} = M(T)$，即仅由任务描述生成的文档，作为人类贡献为零的参考基线。
- **粒度扫描与持久拒绝检测**：在每个粒度级别 $i$，比较 $S_i(D)$ 与 $S_i(D_{\text{ref}})$ 的分布，用双侧检验（$p < 0.05$）。$i^*$ 是最早的**持续显著偏离**粒度级别（防止单次随机拒绝）。
- **VOLM 分数**：$\text{VOLM}(D) = 1 - i^*/k$，接近 1 表示人类贡献大，接近 0 表示内容与模型可从任务描述轻松生成的内容无异。

**提取器设计演进**（论文展示了从宽松到严格的迭代）：
1. 基于压缩的提取器：将文档压缩到固定比例长度
2. 事实提取器：提取离散事实列表并按比例选取
3. 等量 Schema 约束事实提取器：固定事实数量 + 结构化字段
4. **WordNet 规范化的等量 Schema 约束事实提取器**：用 WordNet + Lesk 算法消歧动词词义，最大程度去除风格差异

## 实验与结果
**数据集**：
- **All the News**：100 篇新闻文章，任务描述为文章标题
- **ICLR Reviews**：200 篇 ICLR 2023 审稿意见，任务描述为论文全文+审稿指南+评分量表
- **Persuade 2.0**：200 篇议论文（8 个独立题目各 25 篇），任务描述为题目标题

**模型**：Llama 3.1 8B Instruct 作为评估模型 M，Qwen 3-8B 作为对照生成模型，DIPPER 作为 humanizer

**主要结果**：
- 在 All the News 数据上，人类文档曲线在粒度 0.1 即与参考 LLM 曲线出现**统计显著差异**，分离极为迅速；而参考 LLM 自身曲线随粒度增加衰减缓慢（因为额外提供的上下文本身就是模型已掌握的）
- 三种内容保持型变换（bullet-reconstructed、德语往返翻译、韩语往返翻译）的得分曲线**紧密跟随人类曲线**，远离参考基线，证明对风格变化的不变性
- Qwen 生成文档和 DIPPER humanized 文档形成中间层：虽不含新信息，但因模型间风格差异而获得**非零 VOLM 分数**
- 提取器越严格，Llama-Humanized 差距缩小 72.4%（AUC 差值从 0.367 降至 0.101），WordNet 规范化单独贡献了 16.2% 的进一步缩减；而 Humanized-Human 差距几乎不变（0.181→0.174）
- 单文档示例：一篇人类撰写的影评得到 VOLM = 0.9

## 相关工作脉络
1. **DetectGPT**（Mitchell et al., 2023）：零样本检测，基于概率曲率判断；定位为纯风格检测器，不测量信息原创性，与 VOLM 回答不同问题
2. **EditLens**（Thai et al., 2025）：训练监督模型输出连续分数衡量 LLM 编辑比例；仍聚焦于"多少文字被 LLM 编辑"而非"内容原创性"
3. **Xie et al. (2026)**：信息论框架 $\phi = I(x;y)/I(y)$，以无条件自信息为基线且需要人类原始输入 x；VOLM 以任务描述 T 为基线、不需要 x、且不直接打分表面文本
4. **HCI 贡献归因工作**（He et al., 2025; Kim et al., 2026）：从感知或对话追踪角度归因；依赖协作转录记录，而 VOLM 只需最终文档
5. **Adversarial Compression**（Schwarzschild et al., 2024）：测量生成目标字符串所需的最短提示词长度；目标是测试模型是否记忆特定字符串，而 VOLM 评估完成文档且不需要精确复现

## 局限性与未来方向
1. **提取器设计仍是瓶颈**：当前方法仍因模型间风格差异给非原创文本赋予非零分数；论文强调需要设计更 principled 的提取器以完全剥离风格
2. **跨模型评估有待改进**：不同 LLM（如 Qwen）生成但未经人类添加实质信息的文档仍获得中间层 VOLM 分数，需引入多评估模型或智能阈值
3. **任务描述的定义因领域而异**：不同领域（新闻、审稿、论文）的任务描述形式差异大，需要针对各领域定制提取器和重建器
4. **未考虑多轮对话/协作历史**：VOLM 只输入最终文档，无法利用人类与 LLM 的交互过程信息

## 研究启发与可借鉴点
1. **训练无需求、零样本评估的设计范式**：VOLM 完全不依赖标注数据或模型微调，仅通过 LLM 推理+概率计算实现，可作为其他评估任务的参考设计模式
2. **"替换级基线"的思想迁移**：借鉴棒球 VORP 的思路，定义了有意义的零基线（模型从通用提示词可生成的内容），这一思想可迁移至代码生成、数学推理等其它 LLM 辅助任务
3. **提取器-重建器分离的架构值得借鉴**：将内容提取与风格恢复解耦，使评分免疫于表面风格变化，这一设计对研究"信息保真度"或"风格鲁棒性"很有参考价值
4. **AUC 积分聚合方法**：将粒度扫描曲线积分为一个标量，并配对计算 AUC 差值，有效抵消文档级难度差异，是一种值得复用的聚合策略
5. **可与本团队方向结合的创新机会**：若团队关注学术诚信、AI 辅助写作质量评估或同行评审自动化，VOLM 框架可直接适配；提取器设计（如 WordNet 规范化、事实Schema约束）也可迁移至知识提取、信息抽取任务

## 关键术语表
**VOLM (Value Over Language Model)**：本文提出的框架，衡量文档价值相对于语言模型从通用任务描述即可产出的"替换级"文档的贡献差值。

**替换级文档 (Replacement-Level Document)**：仅由任务描述 T 通过语言模型 M 生成的文档 $D_{\text{ref}} = M(T)$，作为人类贡献为零的基线参照。

**粒度 (Granularity)**：文档内容摘要的压缩级别，从 $g_0$（无上下文）到 $g_k$（接近完整内容），VLKM 通过扫描所有粒度来确定内容贡献的来源位置。

**持久拒绝 (Persistent Rejection)**：从某粒度 $i^*$ 开始且在之后所有粒度均持续显著偏离的检验结果，用于避免单次随机拒绝导致分数膨胀。

**WordNet 规范化**：用 WordNet 词义词典和 Lesk 消歧算法将提取的事实中的动词映射到标准词根，以消除风格差异对评分的干扰。

**AUC 差值**：配对计算两个来源在压缩扫描上的平均对数概率曲线下的面积之差，用于聚合为单标量度量。
