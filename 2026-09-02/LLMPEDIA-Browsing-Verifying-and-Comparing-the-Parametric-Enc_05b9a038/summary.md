# 论文速读：LLMPEDIA-Browsing-Verifying-and-Comparing-the-Parametric-Enc

## 一句话总结
LLMPEDIA 让三个大模型家族（GPT-5-mini、DeepSeek-V3.2、Llama-3.3-70B）**仅凭参数记忆**递归生成约 130 万篇百科文章，并分层抽样审计了 20,092 条原子声明的事实性；核心发现是模型在长尾知识上的主要失败模式是"沉默"（30.5% 不可验证），而非"错误"（仅 1.2% 被反驳），其真值率 68.4% 比 MMLU 低 21 个百分点。

## 研究问题与动机
- **可用性偏见（availability bias）**：MMLU、TruthfulQA 等基准仅探测研究者想到要测的内容，无法反映模型在广大主题空间中的真实知识分布。
- **评测模态错配**：用户日常消费的是流畅多段落散文，而现有基准几乎全部以选择题形式评估，从未检视长文本真实性。
- **已有物化工作的局限**：GPTKB（Hu et al., 2025）将物化扩展到 1 亿条三元组，但仍是结构化事实，未覆盖用户实际阅读的散文模态。
- **规模与可审计性的矛盾**：百万级生成物需要低成本但可复现的事实验证机制，此前缺乏公开的交互式资源。

## 核心贡献（创新点）
- **首个百万级纯参数百科**：从模型自身参数记忆中递归生成约 130 万篇 Wikitext 文章（无检索），每个实体有稳定 URL，公开可浏览。
- **三层声明审计视图**：将"支持/反驳/不足"三元判据可视化到页面级别，使可用性偏见从数字变为可直观操作的探索体验。
- **跨模型与跨人格对比**：在同一主题上并列展示三个模型家族的内容差异，以及三种编辑人格（左倾/科学中立/保守）下的框架效应。
- **可控的专题钻取设计**：种子列表固定、人格在各管线阶段注入，使得实体选择与行文框架均受控，可隔离模型与人格局部效应。
- **开源资源全面公开**：提示词、文章、判决、代码均以 CC BY 4.0 发布，站点为静态前端 + 客户端倒排索引，可独立复现浏览流程。

## 方法详解
- **递归文章生成**：从单一种子实体（Vannevar Bush）出发，模型以 temperature-0 + 固定 seed 生成完整 Wikitext 文章；新链接经过三阶段净化：词形归一化 → LLM 百科过滤 → embedding 去重；每个实体仅入队一次，记录 bfsParent 与 bfsLayer，BFS 扩展。
- **声明分解与事实核查**：采用 decompose–retrieve–verify 范式（Min et al., 2023；Song et al., 2024）；每篇审计文章拆成原子声明，仅以主题名检索证据，确保文章不能"自我塑造"证据；判词分三类：supported / refuted / insufficient。
- **双层证据库**：Wikipedia 作为主证据源；补充 curated web 层（133 个质量评分域名，偏好 .gov / .edu），覆盖约 43% Wikipedia 未涵盖的主题。
- **分层审计采样**：按 BFS 深度分层，共审计 2,010 个主体、20,092 条声明；其中 1,277 个主体用 Wikipedia 核证，733 个用 curated web 核证。
- **人格注入与框架分类**：三种编辑人格（left-leaning / scientific-neutral / conservative）在各管线阶段注入；使用 24 维框架词典的词表分类器打分（每 1,000 token 命中数），对 648 对比较做 Bonferroni 校正 Wilcoxon 检验。
- **前端架构**：静态站点，约 100 万篇文章渲染为纯 HTML，无服务端数据库；客户端倒排索引支撑搜索；每个页面含 Article Genealogy 面板与 Expansion Funnel 可视化。

## 实验与结果
- **数据集规模**：GPT-5-mini 约 100 万篇；DeepSeek-V3.2 与 Llama-3.3-70B 各约 12 万篇；合计约 130 万篇（含 3 个专题聚焦模式）。
- **核心事实性结果（GPT-5-mini 均匀随机样本）**：真值率 68.4%（比 MMLU 低 21 pp）；反驳率 1.2%；不可验证率 30.5%。
- **按 BFS 深度变化的梯度（表 2）**：
  - hop 1：覆盖率 100%，精度 97.9%，真值 94.0%，反驳 2.0%，不可验 4.0%。
  - hop 3：真值降至 80.3%，不可验升至 19.1%。
  - hop 6：真值 56.0%，不可验 43.0%。
  - frontier：真值 57.6%，不可验 41.8%。
- **跨模型稳定排序**：GPT-5-mini > DeepSeek-V3.2 > Llama-3.3-70B；在共享核心到长尾的推移中，GPT-5-mini 真值率从 88.6% 降至 78.6%（降幅 10 pp），DeepSeek 从 85.8% 降至 77.6%（8.2 pp），Llama 从 79.1% 降至 64.5%（14.6 pp）；最大精度跌落仅 1.1 pp。
- **跨模型实体分歧**：从同一种子出发，仅 7.3% 的主体出现在三个语料库中（Jaccard 0.17–0.22）。
- **人格框架效应**：648 对比较中 37 个显著人格效应（Bonferroni 校正），方向符合预期；例如 Dutch Colonization 主题下，左倾较保守在"被殖民方"词汇上 +5.6 hits/1k token；但在中性/控制主题上争议轴基本消失（仅 6 个显著偏移）；人格改变强调重点，不显著影响精度（单元格内 ≤ 3.6 pp）。

## 相关工作脉络
- **LAMA / MMLU / TruthfulQA**：基于采样的基准评测，仅探测研究者预设的问题集，存在可用性偏见；LLMPEDIA 从模型自身关联出发，暴露未被基准覆盖的知识区域。
- **GPTKB（Hu et al., 2025）**：将递归物化扩展到 1 亿条三元组；本文将其延伸至散文级文章模态，实现用户实际阅读的文本格式。
- **FActScore（Min et al., 2023）/ VeriScore（Song et al., 2024）**：长文本事实核查的 decompose–retrieve–verify 范式来源；本文沿用但应用于百万级规模并公开审计报告。
- **STORM（Shao et al., 2024）**：检索增强的百科生成；LLMPEDIA 完全依赖参数记忆，排除检索混淆，更纯粹地反映 parametric knowledge。
- **Grokipedia（xAI, 2025）**：大规模生成百科但公开方法论有限；本文完全开源（提示词、代码、CC BY 4.0 语料）。
- **Recursive elicitation（Cohen et al., 2023）**：首次提出从 LLM 内部知识库递归爬取；本文大幅扩展规模并引入交互审计与人格框架分析。

## 局限性与未来方向
- **单次生成局限**：temperature-0 + 固定提示词的单次采样无法穷尽模型参数知识的完整范围，省略的事实不等于模型不具备。
- **采样验证覆盖有限**：仅审计 2,010 个主体 / 20,092 条声明，约 130 万篇文章中绝大部分未经核证；insufficient ≠ false。
- **LLM 裁判残留误差**：使用 gpt-4.1-nano 作为判词器，虽经人类标注与 FActScore 校验，仍存在误判风险。
- **时间切片局限**：语料为 2026 年 1–3 月快照，随来源/模型/Wikipedia 演化，判决可能漂移。
- **模型规模不均衡**：GPT-5-mini 约 100 万篇，其他两家约 12 万篇，深度 hop 与长尾分析主要反映 GPT-5-mini。
- **幻觉实体**：递归扩展可能产出事实/关系/存在性被幻觉或混淆的主题，页面存在不意味着主体真实存在。
- **实体解析粒度**：同形异义词可区分，但不同实体共享无修饰表面形式时可能合并，需上下文感知 sense-specific linking。
- **指标覆盖范围**：仅度量单命题证据支持度，不评估连贯性、中立性、完整性、省略等文章质量维度。

## 研究启发与可借鉴点
- **"沉默优于错误"的发现范式**：在评测 LLM 知识时，应将"不可验证/缺失"作为独立且重要的失败类别显式报告，而非仅关注 precision/recall。
- **BFS 深度作为知识可信度代理**：实体离种子的跳数与真值率呈单调下降关系，可作为一种零成本的知识可信度启发式指标。
- **人格注入的可控实验设计**：在管线多阶段注入人格提示，使框架效应同时体现在实体选择与行文措辞中，为偏差研究提供可复现的实验范式。
- **纯参数物化 vs 检索增强的对照**：完全去除检索可隔离 parametric knowledge 的真实边界，为后续 RAG 贡献分解提供干净基线。
- **客户端静态索引支撑百万级浏览**：对需要公开大规模生成内容的研究，静态站点 + 客户端倒排索引是一种低成本且可复现的分发方案。

## 关键术语表
- **Parametric memory / 参数记忆**：指大模型在预训练阶段将知识编码进模型权重中的内化知识表示，无需外部检索即可生成。
- **Availability bias / 可用性偏见**：Tversky & Kahneman (1973) 提出的认知偏差，指人们依据 readily available 的例证做判断；本文借指基准只测研究者想到的问题。
- **Decompose–retrieve–verify / 分解-检索-验证**：将长文本拆为原子声明后逐条检索证据并判定支持/反驳/不足的核查范式。
- **Insufficient / 不可验证**：当前可用证据不足以裁定某声明真假的状态，既不等于错误也不等于正确，是可用性偏见的核心指标。
- **BFS layer / 广度优先搜索层**：实体在递归生成图结构中距种子的跳数，用作知识深度与可信度的代理维度。
- **Expansion funnel / 扩展漏斗**：记录每条外链经过 Raw → Dedup → NER → Enqueued 各阶段的存活数量，用于评估生成过程的净化率。
- **Persona framing / 人格框架**：通过左倾/中立/保守等编辑人格注入，观察同一主题在不同意识形态视角下的措辞与强调差异。
- **Terminal page / 终端页面**：文章已生成但其出站链接尚未进入净化管线的实体，标记当前运行扩展停止的位置，非知识边界。

## 可复现要素
- **数据集**：约 130 万篇生成文章（3 个模型家族），CC BY 4.0 发布；公开访问 https://llmpedia.net。
- **代码/权重**：提示词、文章、判决、代码均已公开于上述站点（论文未给出独立 GitHub 链接）。
- **关键超参**：temperature=0，固定 seed；审计样本 2,010 主体 / 20,092 声明；证据源为 Wikipedia + 133 个 curated web 域名；人格分类器为 24 维词表分类器；统计检验用 Bonferroni 校正的 paired Wilcoxon test。
