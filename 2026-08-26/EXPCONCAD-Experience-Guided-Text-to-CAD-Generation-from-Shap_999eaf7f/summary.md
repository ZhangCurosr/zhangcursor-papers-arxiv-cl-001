# 论文速读：EXPCONCAD: Experience-Guided Text-to-CAD Generation from Shape Descriptions with Implicit Spatial Constraints

## 一句话总结
论文针对自然语言描述过于简略、缺少必要空间约束的 Text-to-CAD 问题，提出 EXPCONCAD 框架：先通过构建结构理解恢复隐含建模过程并识别约束范围，再结合从历史失败案例中蒸馏出的可重用经验记忆补全缺失的空间约束，最终生成可执行的 CadQuery CAD 程序。

## 研究问题与动机
- **描述简略导致约束缺失**：实际用户常以高阶语义描述形状（如“带两个圆孔的平板”），省略了 CAD 构建所需的几何参数、操作顺序与空间关系，现有方法难以直接生成有效程序。
- **现有方法局限**：传统方法依赖详细描述，端到端优化方法（如 CADFusion）仅学习输入‑输出关联，未显式推理隐式空间约束，泛化性差且遇到新结构时易产生重叠、穿透等错误。
- **约束补全模式可迁移**：相似约束范围（如 cutter‑base 放置、cutter‑cutter 分离、通孔深度）在历史 CAD 案例中反复出现，积累了可复用的设计经验，可辅助当前任务的约束推断。
- **隐式约束推理是关键挑战**：从简略描述中补全缺失的空间关系，是实现精准 3D CAD 结构生成的核心难点，目前缺乏系统性的解决方案。

## 核心贡献（创新点）
- **提出经验增强的隐式空间约束补全框架**：联合构建感知推理流水线与可重用经验记忆，首次显式处理 Text‑to‑CAD 中的隐式约束补全问题。
- **设计构建‑感知空间约束推理流水线**：先将简略输入分解为 CAD 元素、建模操作与约束范围，再在识别范围内补全约束，而非直接从文本端到端生成代码。
- **构建细粒度经验记忆库**：从历史失败案例中蒸馏出包含适用范围、约束模式与 CadQuery 实现提示的经验项，并通过查询匹配检索相似范围的经验指导补全。
- **在困难基准上显著提升性能**：在 CADFUSION‑HARD 上，EXPCONCAD 相比最强基线 CADFusion 在 Qwen3.5‑27B 和 GPT‑5 背架上分别提升 VLM 得分 22.5% 和 27.9%，几何指标与无效率亦全面优化。

## 方法详解
EXPCONCAD 的核心流程包含三个递进阶段与一个经验记忆模块：

1. **构建结构理解（Construction Structure Understanding, CSU）**  
   输入简略描述 x，由 LLM 恢复隐含的构建结构 s，包括 CAD 元素（如基础体、切削器）、建模操作（布尔运算、拉伸等）以及需要补全约束的范围（如 cutter‑plate 放置、cutter‑cutter 分离）。形式化表示为 $s = L_{\text{CSU}}(x)$。

2. **空间约束补全（Spatial Constraint Completion, SCC）**  
   基于原描述 x 与恢复的结构 s，推断缺失的空间关系，生成约束集合 c（包含坐标条件、距离约束、尺寸关系、操作参数等）。无经验时 $c = L_{\text{SCC}}(x, s)$；引入经验后 $c = L_{\text{SCC}}(x, s, \mathcal{R})$，其中 $\mathcal{R}$ 为检索到的相关经验。

3. **CadQuery 代码生成与修订**  
   条件于 x、s、c 生成可执行 CadQuery 程序 y：$y = L_{\text{Code}}(x, s, c)$。随后执行代码并进行编译/渲染检查；若失败，仅根据错误信息修订代码，s 和 c 保持不变以保留已完成的约束推理。

4. **经验记忆（Experience Memory）**  
   - **经验格式**：每项经验 $e_i = (a_i, p_i, h_i)$，其中 $a_i$ 为适用约束范围（涉及哪些 CAD 元素与操作），$p_i$ 为可复用的约束补全模式（如包容、非重叠、通切），$h_i$ 为 CadQuery 实现提示（参数边界、放置规则等）。
   - **经验构建**：对历史生成失败的案例，用 VLM‑as‑judge 诊断缺失/违反的空间约束，再由 LLM 将诊断与实现上下文蒸馏为经验项。
   - **经验检索与使用**：根据当前结构 s 生成细粒度查询 Q，用 BGE embedding 模型编码查询与经验的 $a_i$，通过余弦相似度检索 Top‑K（论文取 K=3）相关经验 $\mathcal{R}$，注入 SCC 阶段。

5. **辅助设计**  
   - **CadQuery 函数指南**：在三个推理阶段均注入整理好的 CadQuery API 使用指南，减少语法与语义错误。
   - **执行验证**：代码执行失败时仅修订代码层错误，不修改已确定的空间约束与建模逻辑。

## 实验与结果
- **数据集**：主要在 **CADFUSION‑HARD**（从 CADFusion 中挑选的 200 个隐式约束困难样本）上评估，另在 Text2CAD‑HARD 上测试跨数据集泛化。
- **基线**：包括训练型方法（Text2CAD、CADRille、CAD‑Coder、CADFusion）与 LLM 方法（Vanilla、CoT、CadCodeVerify）。
- **骨干模型**：Qwen3.5‑27B 与 GPT‑5。
- **评估指标**：VLM 得分（文本‑形状一致性）、旋转不变 IoU（r‑IoU）、Chamfer Distance（CD/r‑CD）、无效率（Inv.）。
- **主要结果**：
  - **Qwen3.5‑27B**：EXPCONCAD 达到 VLM 6.26，比最强基线 CADFusion（4.22）提升 **22.5%**；r‑IoU、CD、rCD 均最优，Invalid Ratio 仅 2.00%。
  - **GPT‑5**：EXPCONCAD 达到 VLM 6.60，比 CADFusion（4.22）提升 **27.9%**；几何指标与无效率同样领先。
  - **消融实验**：逐层加入验证、CSU、SCC、经验，VLM 得分稳步上升，验证各组件有效性。
  - **经验分析**：经验库大小存在最优值（Qwen3.5‑27B 约 50 项，GPT‑5 可受益于更多项）；经验细粒度（按约束范围存储模式）比案例级存储更利于检索。
  - **跨数据集泛化**：在未见分布的 Text2CAD‑HARD 上，EXPCONCAD 仍优于基线，而 CADFusion 性能下降，表明经验记忆通过可迁移的约束模式而非数据记忆提升泛化。

## 相关工作脉络
- **Text2CAD / CADRille / CAD‑Coder**：假设输入已显式指定建模步骤与参数，仅做翻译生成，无法处理隐式约束补全。
- **CADFusion**：利用视觉监督对齐形状，但未显式推理缺失的空间约束，遇到新结构时泛化受限。
- **CadCodeVerify**：采用代理式验证‑修订流程，但未引入经验记忆，约束补全能力有限。
- **本工作定位**：首次将“构建结构理解”与“经验记忆检索”显式结合，专门针对简略描述中的隐式空间约束进行补全，填补了该方向的空白。

## 局限性与未来方向
- **经验管理机制缺失**：当前经验库未研究如何随时间更新、删除、合并或验证，可能因模式重复而无限扩张，增加存储与检索成本。
- **经验质量参差不齐**：同一模式可能存在多种实现质量，缺乏对经验有效性进行持续筛选的机制。
- **未来方向**：开发动态经验管理策略（去重、合并、质量评分），保持经验库紧凑可靠；探索更细粒度的约束模式表示与跨领域迁移。

## 研究启发与可借鉴点
- **结构化推理优先于端到端映射**：先恢复隐含结构再补全约束，可显著提高复杂生成任务的可控性与泛化性。
- **失败案例蒸馏经验并验证**：从模型失败案例中提取可复用模式，并通过重新生成验证效果，是一种低成本的经验积累方式。
- **两视图渲染评估更贴近人类偏好**：采用互补对角视角渲染替代传统正交三视图，提升了 VLM 评估与人类评分的一致性（Spearman ρ 从 0.71 升至 0.84）。
- **经验存储粒度影响检索效果**：将经验按约束范围细粒度分离，比案例级聚合更利于在新任务中精准匹配与复用。

## 关键术语表
- **隐式空间约束**：自然语言描述中省略但对 CAD 构建必需的空间关系（如位置、距离、穿透关系）。
- **构建结构理解**：从简略描述中恢复目标 CAD 隐含的建模过程，识别元素、操作与约束范围。
- **空间约束补全**：在已识别的约束范围内推断缺失的空间关系，形成可执行的参数配置。
- **经验记忆**：从历史 CAD 案例中提炼的包含适用范围、约束模式与实现提示的可重用知识集合。
- **CadQuery**：基于 Python 的可执行 CAD 程序库，用于通过代码直接生成 3D 几何模型。
- **CADFUSION‑HARD**：从 CADFusion 基准中挑选的 200 个简略描述困难样本，专门用于评估隐式约束补全能力。
- **VLM 得分**：由视觉语言模型评估生成形状与文本描述一致性（0‑10 分）的自动指标。
- **旋转不变 IoU**：考虑 24 种离散旋转后计算的最优体素重叠率，消除姿态差异对评估的影响。

## 可复现要素
- **数据集**：CADFUSION‑HARD 基于公开 CADFusion 数据集构建；源 CADFusion 数据公开，但硬子集需自行筛选。
- **代码与权重**：代码将在 GitHub 匿名链接公开（论文提供 https://anonymous.4open.science/r/ExpConCAD‑B118）；外部预训练模型使用公开权重。
- **关键超参**：LLM 推理温度设为 0，max_tokens=10000；经验检索使用 BGE‑large‑en‑v1.5 embedding，Top‑K=3；经验库从 1500 个训练样本中蒸馏；代码修订最多 3 轮。
