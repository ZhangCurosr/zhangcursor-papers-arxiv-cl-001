# 论文速读：REPOLICY-REINFORCEMENT-LEARNING-FOR-SAFETY-POLICY-INVOCATION

## 一句话总结
本文提出 RePolicy，将智能体安全策略调用建模为强化学习任务，通过冷启动 SFT 初始化后利用 GRPO 优化策略选择与安全判断的完整序列，实现了在 4B 模型规模下六个智能体安全基准上的最强性能（Overall Unsafe F1 达 88.15%）。

## 研究问题与动机
1. **现有方法局限**：当前智能体安全守护主要依赖提示词或监督微调，模型难以适应未见轨迹和动态变化的安全策略上下文。
2. **固定策略集不足**：无法预设覆盖所有真实部署场景的安全策略，同一行为在不同用户权限、组织规范、监管管辖下可能受不同约束。
3. **策略调用能力缺失**：提示词方法暴露了安全策略但未优化模型使用策略的方式；监督微调仅模仿训练分布内的轨迹-策略关联，泛化受限。
4. **缺乏统一训练数据**：现有资源多针对特定环境或风险类型，无法同时提供轨迹级判断与细粒度策略依据的监督信号。

## 核心贡献（创新点）
1. **将安全策略调用视为智能体强化学习任务**：与已有工作将策略作为被动上下文不同，本文使模型主动从候选库中选择并应用适用策略。
2. **构建 PolicyTraj-20K 数据集**：包含 20,000+ 带策略标注的轨迹，支持冷启动训练和强化学习优化。
3. **设计基于可验证规则奖励的 GRPO 优化框架**：引入格式奖励、策略调用奖励和安全判断奖励三元奖励结构。
4. **提出策略上下文扰动增强机制**：通过在候选库中注入无关策略和欺骗策略，强制模型区分策略适用性与轨迹语义。

## 方法详解
1. **任务形式化**：给定轨迹 $\tau$ 和策略库 $\mathcal{P}$，模型首先选择适用策略 $\hat{p}$，再基于策略内容生成依据和安全性判断 $(\hat{r}, \hat{y})$，形成序贯结构：策略调用→策略内容→安全推理→安全预测。
2. **冷启动训练**：使用 PolicyTraj-20K 进行监督微调，损失函数 $\mathcal{L}_{\text{SFT}} = -\frac{1}{N}\sum_i [\log \pi_\theta(p_i^*|\tau_i, \tilde{\mathcal{P}}_i) + \log \pi_\theta(r_i, y_i|\tau_i, \tilde{\mathcal{P}}_i, p_i^*, c(p_i^*))]$。
3. **GRPO 强化学习优化**：每个 prompt 采样 16 次 rollout，采用验证奖励 $R = 0.1 R_{\text{fmt}} + 0.3 R_{\text{pol}} + 0.6 R_{\text{acc}}$，其中 $R_{\text{pol}} = \mathbb{I}[\hat{p}_i = p_i^*]$，$R_{\text{acc}} = \mathbb{I}[\hat{y}_i = y_i]$。
4. **策略上下文扰动**：训练时重新采样干扰策略、打乱候选库顺序，包含来自不相关场景的有效策略和合成欺骗策略，平均每库含 9.2 个欺骗策略。

## 实验与结果
1. **评估基准**：六个智能体安全基准——ATBench、R-Judge、OpenAgentSafety、ASSEBench、HINTBench、AgentHazard，共 7,369 条轨迹。
2. **主要结果**：RePolicy-4B 在六个基准上整体 Unsafe F1 达 88.15%，超越最强外部基线 3.98 分，超越最强专用守护模型 8.46 分；在 ATBench（99.40%）、R-Judge（82.17%）、OpenAgentSafety（62.79%）、ASSEBench（88.11%）、HINTBench（97.23%）、AgentHazard（99.20%）中四项第一。
3. **策略调用提升**：GRPO 训练后正确策略调用率 $R_{\text{pol}}$ 从约 94.4% 提升至 98.5%（+4.1 分），平均每次调用策略数从 1.9 增至 3.2，欺骗策略选择率始终低于 1%。
4. **消融实验**：冷启动 SFT 使 Overall Unsafe F1 从 58.47% 提升至 86.95%（+28.48 分）；完整 RePolicy 在 AgentHazard 上比无策略调用变体提升 5.9 分。

## 相关工作脉络
1. **传统守护模型**（WildGuard、ShieldGemma、Llama Guard 4）：基于预定义风险分类的提示/响应分类，本文定位于轨迹级策略感知守护。
2. **轨迹级智能体守护**：GuardAgent（知识增强安全检测）、AgentDoG（细粒度轨迹诊断）提供轨迹级监控，本文进一步要求识别适用策略。
3. **策略感知守护**：ShieldAgent（可验证规则推理）、DynaGuard（用户定义自由形式策略）、LPG（动态策略上下文推理）将策略作为条件输入，本文区别在于显式策略选择并联合优化。
4. **智能体强化学习**：Searchr1、Retool 等将 RL 应用于工具使用，本文首次将 RL 直接应用于安全策略调用决策。

## 局限性与未来方向
1. **策略库覆盖假设**：RePolicy 假设候选策略库包含适用且精确的策略，无法处理覆盖不全、范围模糊、要求过时或策略冲突等情况。
2. **单策略关联限制**：当前将每条轨迹关联一个适用策略，而实际部署可能需要跨操作层、组织层、监管层的联合多策略应用。
3. **推理开销增加**：策略调用引入了额外交互步骤，导致推理开销高于单次通过的守护模型。
4. **评估设置局限**：仅在一个模型规模、离线轨迹级基准、二值安全标签下评估，未涵盖多语言部署、动态演化环境、在线干预及主动中断场景。
5. **理由忠实性不足**：验证奖励确保策略调用和最终预测正确，但未完全保证生成的理由中每个陈述都忠实于被调用策略。

## 研究启发与可借鉴点
1. **将策略调用建模为可优化的决策过程**：通过显式策略选择步骤提升可解释性和鲁棒性，可迁移至其他需要规则应用的领域。
2. **策略上下文扰动技术**：在候选集中注入欺骗项以增强模型选择能力，适用于任何需要从候选集中精确匹配的场景。
3. **三元可验证奖励设计**：格式、选择、判断分离的奖励结构可在类似多步决策任务中复用。
4. **冷启动 SFT + RL 的训练范式**：先用高质量策略标注数据初始化，再通过 RL 优化决策质量，为小模型能力增强提供参考。

## 关键术语表
**RePolicy**：一种通过强化学习学习安全策略调用的智能体守护模型，核心是通过 GRPO 优化策略选择和安全性判断。
**PolicyTraj-20K**：作者构建的包含 20,000+ 带策略标注的智能体轨迹数据集，覆盖多样化工具、环境和任务场景。
**GRPO (Group Relative Policy Optimization)**：基于组相对策略优化的强化学习方法，通过比较同一 prompt 的多条 rollout 的奖励来更新策略。
**策略上下文扰动 (Policy-Context Perturbation)**：训练时在候选策略库中注入无关和欺骗策略，并打乱顺序，防止模型依赖固定关联。
**Unsafe F1**：将 unsafe 作为正类计算的 F1 分数，用于评估安全守护模型对不安全行为的检测性能。
**策略调用奖励 (Policy Reward, $R_{\text{pol}}$)**：验证模型是否调用了正确策略的规则奖励，$R_{\text{pol}} = \mathbb{I}[\hat{p}_i = p_i^*]$。
**安全策略依据化推理 (Policy-Grounded Rationale)**：基于被调用策略的具体条款生成安全判断的理由，而非仅依赖表面特征。
**轨迹级安全守护 (Trajectory-Level Agent Safeguard)**：针对完整智能体执行轨迹进行安全评估，而非仅评估单一请求或响应。
