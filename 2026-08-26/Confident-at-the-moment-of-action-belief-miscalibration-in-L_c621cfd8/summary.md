# 论文速读：Confident-at-the-moment-of-action-belief miscalibration in LLM play under hidden information

## 一句话总结
论文设计了一个名为Regent Chess的隐藏信息国际象棋变体，在其中分别 elicited 模型关于对手隐藏“Regent”棋子的信念和实际走子动作，发现模型在行动时刻的高置信度信念与实际行动严重脱节（高置信度捕获奖励正确率仅1.6%），而传统评估指标（如胜率、走子合法性、成本、延迟）可以完全与该信念质量解耦，导致仅评估行动结果的评测体系无法发现这一问题。

## 研究问题与动机
- 核心问题：智能体系统日益依赖模型自身报告的置信度来触发关键行动（如“置信度低于阈值则升级给人工”），这假设了**行动时刻的报告置信度能跟踪该行动的正确性**。该假设在隐藏信息场景下是否成立？
- 现有评估不足1：标准QA基准将信念与答案混为同一输出通道，无法分离评估；竞争性游戏基准（如Kaggle Game Arena）只有行动（走子）和结果（胜负），没有 elicited 的隐藏状态信念，无法在**行动选择的 locus** 上评估信念质量并与行动对照。
- 现有评估不足2：隐藏信息基准（如Werewolf/Mafia）的隐藏状态是外生给定的（角色、发牌），且评估多关注谎言生成/检测成功率而非对隐藏状态的真实概率预测；模型信念与后续行动的对应关系也未被直接测量。
- 动机：需要一种能**同时可观测信念陈述与独立行动**，且隐藏状态真实可恢复的实验环境，以检验“行动时刻的信念-行动一致性”。

## 核心贡献（创新点）
1.  **首次测量行动时刻的信念校准失配**：设计了Regent Chess评测仪器，在两个独立批次中一致发现高置信度捕获奖励（≥0.5）的正确率仅1.6%，且99.3%的校准缺陷集中于此。*区别：不同于静态任务上的置信度校准评估或仅关注行动-信念一致性的研究，本文测量的是**行动选择时刻**的信念与事实的校准。*
2.  **证明传统评估指标可与信念质量完全解耦**：在同一模型的不同配置中，关闭扩展推理可获得在合法性、成本、延迟、完成率等所有常规轴上最优的表现，但其信念形式化率仅3.8%，是信念质量最差的配置。*区别：揭示了仅优化常规指标的评测会**主动奖励**信念跟踪能力缺失的配置。*
3.  **发现校准缺陷的模式与范围**：校准失效并非均匀分布，而是高度集中在高置信度行动时刻；该模式在跨越两个实验室（Google, OpenAI）的五个座位配置中单调排序。*区别：表明问题非单一实验室/模型特有，但排序不证明外部能力预测校准。*
4.  **提出了一种可转移的方法论设计**：隐藏状态由被测智能体**内生创建和修改**（而非外生给定），且对手为**源可见的非自适应启发式**，这使得可以计算oracle与公开预测器的可达性界限，从而区分“模型失败”与“任务不可能”。*区别：为衡量模型能力而非任务设计缺陷提供了更严谨的评估框架。*

## 方法详解
- **游戏设置（Regent Chess）**：国际象棋变体，目标不是固定的王，而是当前持有“皇家身份”的棋子（Regent）。玩家可通过“Crown Shift”秘密地将皇家身份转移给己方任意棋子，该动作不计入回合且不告知对手。转移后仍须执行一次常规走子。真实身份由游戏引擎内部记录，游戏结束后可完全恢复。
- **信念 elicitation**：每个真实回合，模型接收棋盘状态、己方历史记录等信息（不接收对手信息），返回**结构化响应**：一个选择的走子，以及一个关于对手哪个活跃棋子最可能是其Regent的概率分布（top-k列表+(square, probability)）。
- **对手设计**：所有对局均与一个固定的、非自适应的确定性启发式代理（Tier-1，中等难度）进行。这确保了座位间比较有意义，且对手策略可见是计算oracle可达性界限的前提。
- **评分机制**：
    - **捕获时间评分（Capture-only scoring）**：仅在模型捕获一个棋子时，将其在该格报告的置信度与是否为真实Regent配对。这是**暴露偏差**的群体（可被捕获的棋子与真实Regent负相关）。
    - **每步评分（Every-ply scoring）**：对每一步生成的每个候选格报告的概率与真实Regent位置配对。事件数量更多且无捕获时间暴露偏差。
    - 两种评分均以**人口匹配的均匀先验**（1/对手活跃棋子数，每步重新计算）为基线，使用**Brier分数**和**配对bootstrap置信区间**进行评估。
    - **预移位窗口排除**：棋盘步数<8（即双方各自第4回合前）的数据被排除，因为此时依据规则即可知道身份，对未阅读规则的预测器不公平。
- **预注册与座位配置**：四项关键预期在实验前预注册。每个“模型+采样配置”配对称为一个“座位（seat）”。仅有S1（Gemini 3.1 Flash-Lite）接受了完整的校准电池测试；其他座位仅提供捕获时间高置信度命中率。

## 实验与结果
- **主要发现（S1，两批次独立复制）**：
    - 原始批次：22次高置信度（≥0.5）捕获，0次正确。
    - 复制批次：40次高置信度捕获，1次正确。
    - 合并：**62次高置信度捕获，仅1次正确（1.6%）**。Brier分数比值为7.127 vs 7.094，方向与 magnitude 一致。
    - 校准缺陷集中度：99.3%（原始）/ 98.7%（复制）的Brier分数差距集中在这些高置信度捕获事件中。
- **每步评分（ply≥8）**：S1的信念显著差于人口匹配的均匀先验（delta +0.059至+0.070），且在更严格的步数 cutoff 下变得更差。
- **跨座位排序**：五个座位（S1, S7, S6-base, S6B, S5）的高置信度捕获奖励命中率单调排序：1.6%, 14.3%, 29.2%, 40.0%, 50.0%。涵盖两个实验室。*注意：相邻置信区间大多重叠，仅极端值（S1 vs S5）有统计显著性。*
- **与传统指标解耦（DeepSeek V4 Flash 案例）**：关闭扩展推理的配置在合法性（100%合法）、成本（约28倍便宜）、延迟（约25倍快）上最优，但其形式化信念率仅3.8%，信念质量最糟糕。
- **深度依赖降解**：S1的形式化率随游戏深度下降（开局85.6% → 中盘47.8% → 残局41.0%）。控制实验（无Crown Shift）也显示下降，但Regent Chess的下降更陡，表明存在**隐状态追踪的特异性残余效应**。
- **覆盖缺口**：S1 73.6%的捕获针对的是其信念分布中**从未列为候选**的格子。
- **静态筛查高估**：对孤立棋位的免费形式筛查比真实多回合游戏中的表现高出28.4-41.2个百分点。

## 相关工作脉络
- **基于游戏的LLM评估（如Kaggle Game Arena）**：使用竞争性游戏抵抗数据污染和基准饱和，但所有指标均为结果指标（胜负、筹码），不elicited也不评分隐藏状态信念。
- **LLM校准与不确定性**：研究语言模型 verbalized confidence 与答案正确性的关系，发现其受elicitation协议影响极大，且RLHF的reward model可能固有地偏向高置信度输出。本文与ConfidenceBench等工作的联系在于，本文的结果与Gemini 3.1 Flash-Lite在一般置信度校准基准上最差的发现相符，但进一步揭示了在**行动时刻**和**隐藏信息**下的特异性失效模式。
- **Agent-BRACE等智能体信念建模**：将智能体解耦为信念状态模型和政策模型，假设verbalized certainty标签足够可靠以指导政策。本文反向提问，测量了信念与行动在行动时刻的一致性，发现即使架构分离也可能存在严重失配。
- **action-belief gap研究**：并发工作发现LLM的行动可能与 separately elicited 的置信度矛盾。本文与之不同：测量的是**概率是否被校准**（即声称概率p的事件是否以频率p发生），而非简单的行动-信念一致性；且信念elicitation发生在动态交互过程中，与动作在同一回合内结构化输出。
- **心智理论与隐藏信息基准（如WOLF, MafiaScope）**：测试模型在欺骗和反欺骗中的能力，但隐藏的“角色”或“手牌”是外生固定的，且评估重点是谎言检测精度，而非对隐藏状态的精确概率预测。本文的隐藏状态是**内生、可修改**的。

## 局限性与未来方向
- **局限性**：
    1.  完整校准电池仅在一个座位（S1）上测试。
    2.  所有结果针对单一固定、中等难度的启发式对手，未测试更强或位置响应型对手。
    3.  未验证此仪器上的表现能否预测现实部署任务中的性能。
    4.  模型采样非确定性，无法完全复现特定对局；顶级elicitation格式（top-k）可能引入覆盖偏差。
    5.  论文未断言隐藏状态在任何情况下都是可推断的；对手的策略使得部分隐藏状态对所有预测器都难以预测。
- **未来方向**：
    1.  在对**位置响应型对手**上测试相同失效是否持续。
    2.  验证此平台上的得分是否能预测模型在部署设置中的行为（更具实际意义）。
    3.  系统性地用多个座位复制完整的校准电池。
    4.  探索elicitation架构（联合elicitation vs. 分离elicitation）对测量结果的影响。
    5.  研究不同deliberation预算（如更大的max_tokens）下的校准上限。

## 研究启发与可借鉴点
1.  **分离信念与行动的评估设计**：任何评估若仅测量行动结果或静态置信度，都可能错过行动时刻的关键信念失配。设计 elicitation 与 action 作为同一回合内**两个可分离的结构化输出**是评估智能体真实信念质量的有效方法。
2.  **固定非自适应对手的价值**：在评估模型自身能力的增量变化时，使用固定的、策略可见的对手可以控制环境方差，使座位间比较和深度依赖分析有意义。这也是计算oracle可达性界限的前提。
3.  **预注册与独立复制的重要性**：论文在实验前预注册了四项预期及证伪标准，并在两个独立批次中复制核心发现，增强了结论的稳健性。这对易受随机性影响的模型评测研究具有重要借鉴意义。
4.  **控制实验揭示多重成因**：通过对比“有隐藏状态”与“无隐藏状态（标准象棋）”的降解曲线，证实了性能下降不仅源于上下文增长，还有隐藏状态追踪的特异性成本。这种控制实验设计有助于分解复杂任务中的不同认知负荷。
5.  **对传统评估指标的批判性视角**：论文证明，在常规指标（合法性、速度、成本）上表现最优的配置，其信念质量可能最差。这提示在智能体系统评估中，需建立独立于任务结果的**信念校准专项指标**，防止被优化指标“误导”。

## 关键术语表
- **Regent Chess**：一种国际象棋变体，皇家身份可通过“Crown Shift”秘密转移，获胜条件是捕获对手的Regent（当前持有皇家身份的棋子）。
- **Crown Shift**：秘密转移皇家身份的内置动作，不计入回合，不告知对手，是隐藏信息的主要来源。
- **Well-formed Elicitation**：模型返回的结构化响应，包含一个合法走子和一个关于对手Regent位置的概率分布。其形式化率随游戏深度显著下降。
- **Capture-time Calibration**：在模型实际执行捕获动作的时刻，评估其对该格为Regent的置信度预测与事实的校准程度。本文核心发现所在。
- **Oracle-vs-Public Tractability Bound**：通过对比拥有完全内部信息（oracle）和仅公开信息（public）的预测器，界定任务的可解性上限，以区分“模型失败”与“任务本身不可解”。
- **Belief-Action Gap**：模型陈述的信念与其实际采取的行动之间不一致的现象。本文测量的是校准失配，是一种更严格的gap形式。
- **Deliberation Cap**：通过固定输出token预算（如4096）限制模型的思考深度，可能人为压制潜在性能，并导致高频截断。
- **Population-matched Uniform Prior**：作为信念评分基线的均匀分布，按每步对手活跃棋子数动态调整（1/N），而非使用单一常数。

## 可复现要素
- **数据集**：所有游戏记录均为真实模型对局日志，非合成。游戏引擎和规则已公布于附录。代码和数据集是否开源未在文本中明确声明，但提到了“version-controlled analysis code”。
- **代码/权重**：分析代码版本控制；模型权重通过API访问（Gemini系列、GPT-5-mini）。**代码和权重可能未完全开源**。
- **关键超参**：
    - 温度（Temperature）：大多数座位为0.7，S7（GPT-5-mini）因API强制为1.0。
    - `max_tokens`：主要座位为4096，S6B为16384。
    - elicitation格式：top-k概率分布列表（k值未在摘要明确，需查原文代码）。
    - 预移位窗口排除：board-ply < 8。
    - 评分方法：Brier分数，配对bootstrap置信区间，对手为人口匹配均匀先验。
