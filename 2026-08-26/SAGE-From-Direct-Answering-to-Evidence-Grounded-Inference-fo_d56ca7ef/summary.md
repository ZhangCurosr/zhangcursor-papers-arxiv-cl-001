# 论文速读：SAGE: From Direct Answering to Evidence-Grounded Inference for Chinese Ancient Document Understanding

## 一句话总结
本文提出 SAGE，一个面向中文古籍理解的多智能体证据支撑推理框架，将传统 LVLM 的单步直接生成范式重构为任务感知规划、工具辅助取证、主张级验证与有界重规划的证据推理过程；在 AncientDoc 基准上，SAGE + Qwen3.5-9B 在 8 项指标中斩获 7 项 SOTA，显著超越参数量大几个量级的单体 LVLM。

## 研究问题与动机
1. **中文古籍理解的复杂性远超现代文档**：竖排版式、繁体/异体字、缺标点、密集批注、隐含历史文化语义等，要求模型同时具备视觉阅读、文言解读与知识推理能力。
2. **直接 LVLM 生成范式存在根本缺陷**：现有系统大多依赖"单次前向生成"，把阅读、取证、推理、验证压缩到一个黑箱步骤，导致回答过度自信、证据薄弱、错误难以诊断。
3. **缺少可验证、可追溯的推理过程**：真正的学术实践需要分阶段取证、验证并诚实表达不确定性（甚至拒答），而直接生成无法暴露支撑证据、验证报告与执行轨迹。
4. **单纯放大模型参数并非唯一路径**：作者主张古籍理解不仅是 LVLM scaling 问题，更是证据支撑与可靠性问题，需要系统级推理框架来弥补单模型能力的不足。

## 核心贡献（创新点）
1. **将中文古籍理解重新定义为证据支撑推理问题**：系统除输出最终答案外，还显式暴露支撑证据、验证报告、拒答决策与执行轨迹，使生成过程可追溯、可诊断。
2. **提出 SAGE 多智能体框架**：通过角色分工的规划、执行、验证三个智能体，在有界共享状态运行时协调任务感知规划、工具辅助取证、主张级验证与有界重规划，本质区别在于从"黑箱单次生成"转为"白盒分步推理"。
3. **设计受限的共享状态运行时（Constrained Shared-State Runtime）**：统一维护证据状态、工具接口、预算与执行轨迹，应用 STOP/REPLAN/ABSTAIN 控制规则，区别于无约束对话式多智能体或固定流水线。
4. **在 AncientDoc 上建立全面评估**：跨三种 LVLM 骨干、四项理解任务（翻译/推理 QA/知识 QA/语言 QA）的系统实验，证明 SAGE 一致优于同规模直接基线，且小模型配 SAGE 可击败大得多的单体 LVLM。
5. **提供轨迹级行为分析**：通过执行轨迹揭示任务自适应工具调用模式与验证引导重规划的有效提升，为后续研究提供可诊断的推理过程证据。

## 方法详解
SAGE 将输入（古籍图像 I + 自然语言问题 Q）映射为结构化输出 O = (A, E, R, z, τ)，其中 A 为最终答案、E 为收集的证据、R 为证据报告、z 为拒答标志、τ 为执行轨迹。系统由以下模块构成：

1. **学术规划智能体（Scholarly Planning Agent）**：根据问题 Q 和初始预算 b₀ 预测任务类型 y，生成包含动作序列 a₀、证据需求 ρ₀ 的计划 P₀ = Plan(Q, b₀) = (y, a₀, ρ₀, b₀)。典型策略如表 1 所示——翻译需页面读取+文本规范化；知识 QA 需概念抽取+本地检索；推理 QA 以页面文本为 grounding 进行推理。

2. **工具增强执行智能体（Evidence-Grounded Execution Agent）**：在受限动作空间内实例化计划，依次执行 read（OCR/页面读取）、normalize（繁简转换/异体字规范化）、extract（实体/概念抽取）、retrieve（本地知识库检索，仅知识密集型任务）与 synthesize（生成候选答案）。形式化为：(Xₖ, Eₖ) = Exec(I, Q, Pₖ, sₖ)，随后 A̱ₖ = Solve(Q, Xₖ, Eₖ, Pₖ)，将候选答案视为待验证假设而非最终输出。

3. **学术验证智能体（Scholar Verifier Agent）**：将候选答案分解为原子主张 Cₖ = {c₁,...,cₙ}，对每个主张估计其与 grounding 上下文的支持关系 vᵢ = Verify(cᵢ, Q, Xₖ, Eₖ)，其中 V = {SUP, CON, INS, N/A}（支持/矛盾/证据不足/不适用）。聚合生成证据报告 Rₖ = Aggregate(Cₖ, Vₖ, Xₖ, Eₖ)，包含证据覆盖率、矛盾主张比例、支持置信度及拒答建议。验证标准因任务而异：知识 QA 要求严格主张-证据映射，翻译/推理/语言 QA 侧重页面一致性与完整性。

4. **受限共享状态运行时（Constrained Shared-State Runtime）**：维持状态 sₖ = (y, Pₖ, Xₖ, Eₖ, A̱ₖ, Rₖ, bₖ, τₖ)，施加三类控制决策 dₖ = Rule(sₖ) ∈ {STOP, REPLAN, ABSTAIN}：当证据充分时 STOP；证据缺失且预算允许时 REPLAN；证据不足/验证失败/预算耗尽时 ABSTAIN。设计三原则：共享状态管理（跨模块复用中间结果）、受限动作接口（预定义工具集防止幻觉调用）、预算与轨迹管理（限制工具调用次数并记录完整执行轨迹）。

5. **执行预算**（附录 A.5）：OCR 最多 3 次工具调用，翻译/推理 QA 各 5 次，知识 QA 7 次，语言 QA 6 次；每次检索最多返回 8 条知识库片段。

## 实验与结果
- **数据集**：AncientDoc（Yu et al., 2025），涵盖 OCR、翻译、推理 QA、知识 QA、语言 QA 五类任务；主实验聚焦后四项理解任务（排除主要反映 OCR 工具质量的纯 OCR 任务）。
- **评估指标**：CHRF++ 与 BERTScore F1（BS-F1）。
- **骨干模型**：InternVL3-8B、Qwen2.5-VL-7B、Qwen3.5-9B；与同规模直接回答基线对比。
- **主要结果（Table 2）**：
  - SAGE 在所有三种骨干和全部八项指标上一致优于匹配的直接基线。
  - **最强结果**：SAGE + Qwen3.5-9B 在 8 项指标中拿下 7 项 SOTA；其中翻译 CHRF++ = 16.01 / BS-F1 = 75.29，知识 QA CHRF++ = 11.81 / BS-F1 = 71.12，语言 QA CHRF++ = 7.72 / BS-F1 = 65.35。
  - 相较参数量大数个量级的单体 LVLM（如 LLaVA-OneVision-72B、Qwen2.5-VL-72B），SAGE+9B 在翻译、知识 QA、语言 QA 三项上全面超越，仅在推理 QA BS-F1 一项略逊于 Qwen2.5-VL-72B Direct。
  - 提升幅度最大在知识 QA 与语言 QA：如 InternVL3-8B 上知识 QA CHRF++ 提升 +6.09、BS-F1 提升 +6.80；语言 QA CHRF++ 提升 +4.09、BS-F1 提升 +8.55。
- **消融实验（Table 3，Qwen3.5-9B）**：移除规划器、页面读取器、检索器或验证器均导致性能下降；完整 SAGE 在推理 QA（CHRF++ 9.35 / BS-F1 69.10）和知识 QA（CHRF++ 11.81 / BS-F1 71.12）上表现最佳，验证表明主要增益来自页面支撑的证据组织、工具辅助执行与验证而非外部知识本身。
- **轨迹分析（Figure 3）**：知识 QA 中 90.39% 样本触发抽取与检索，推理 QA 仅 9.42%；验证引导的重规划使支持率从 69.23% 升至 74.45%，验证置信度从 67.99% 升至 71.59%。

## 相关工作脉络
1. **文档理解基准（DocVQA、TextVQA、OCRBench、MMLongBench-Doc）**：这些基准聚焦现代文档和场景文本，而 SAGE 针对的是具有独特排版与语言特征的古籍，评估重点从"最终输出质量"转向"推理过程的证据支撑性"。
2. **古汉语/古籍理解基准（AC-EVAL、C³Bench、Fùxì、WenyanBENCH、HisDoc1B、BABM-LLM）**：Text-based 基准关注文言文理解与翻译，SAGE 与之互补，从多模态页面图像出发，整合视觉阅读与知识推理。
3. **AncientDoc（Yu et al., 2025）**：最直接相关的工作，提供中文古籍理解的多任务基准；但 AncientDoc 仅评估直接回答范式的最终输出，SAGE 在其之上引入推理过程的可诊断性评估。
4. **古文专用模型（AnchiBERT、WenyanGPT、TongGu）**：这些工作聚焦于继续预训练或指令微调以适配古文领域；SAGE 是模型无关的推理时框架，无需训练新模型即可提升现有 LVLM 的古籍理解能力。
5. **多智能体与工具使用（ReAct、Self-Refine 等）**：SAGE 区别于通用 agentic 框架，其核心创新在于将工具调用严格约束在预定义证据获取动作内，并通过验证智能体与有界重规划实现可信推理，而非自由探索式工具使用。

## 局限性与未来方向
1. **评估范围有限**：当前仅在 AncientDoc 基准上验证，尚未扩展到更广泛的历史文献集合、不同文档版式及其他古代语言文字。
2. **验证为系统自生成诊断**：验证报告和轨迹统计基于系统自身判断，而非人工事真实性标注，只能作为运行时行为指标，不能替代人工事实核查。
3. **推理成本增加**：规划、工具调用、验证与重规划带来额外计算开销，相比单次前向生成效率较低。
4. **未来方向**：探索更强证据来源（如更丰富的外部知识库）、人工接地验证机制、更高效执行策略，以及向其他古籍语言/版式的泛化。

## 研究启发与可借鉴点
1. **"证据支撑推理"范式的可迁移性**：SAGE 将多步取证-验证-重规划框架应用于中文古籍，该范式同样适用于其他需要强事实依据的垂直领域（如法律文档、医学文献、历史档案），可作为通用可靠推理模板。
2. **受限共享状态运行时设计**：通过预定义动作接口、预算约束与 STOP/REPLAN/ABSTAIN 控制规则，实现可追踪、可诊断的推理过程，这一设计可借鉴到任何需要高可信度的 agent 系统中。
3. **任务自适应的证据路径选择**：SAGE 根据任务类型动态选择工具组合（知识密集型走检索路径，翻译/语言密集型走页面路径），为多任务系统的资源调度提供了实用的启发。
4. **小模型+强框架 > 大模型+弱框架**：SAGE+9B 击败 72B 单体 LVLM 的结果证明，结构化推理流程对性能提升的贡献可超越单纯放大模型规模，值得在资源受限场景下优先投入框架优化。
5. **验证驱动的重规划机制**：验证智能体识别支持不足的 claim 后触发重新规划，使系统能自我纠正；这一"生成-验证-修正"闭环可直接复用到需要迭代优化的长程推理任务中。

## 关键术语表
- **SAGE（Evidence-Grounded Multi-Agent Framework）**：面向中文古籍理解的多智能体证据支撑推理框架，通过规划、执行、验证三智能体协作实现可追溯推理。
- **AncientDoc**：评估 LVLM 在中文古籍理解（OCR、翻译、推理 QA、知识 QA、语言 QA）上能力的新基准。
- **CHRF++**：Character n-gram F-score 的改进版本，用于衡量机器翻译/文本生成的字符级别准确率。
- **BERTScore F1（BS-F1）**：基于预训练 BERT 嵌入计算的语义相似度 F1 指标，评估生成文本与参考文本的语义契合度。
- **Evidence-Grounded Inference（证据支撑推理）**：将答案生成建立在显式证据收集与主张级验证之上，区别于单次黑箱生成的推理范式。
- **Claim-Level Verification（主张级验证）**：将候选答案拆解为原子主张，逐一评估其与可用证据的支持/矛盾/不足关系。
- **Constrained Shared-State Runtime（受限共享状态运行时）**：维护统一证据状态、受限工具接口与预算，控制智能体间协作流程的系统级基础设施。
- **ABSTAIN（拒答）**：当证据不足以支撑可靠答案时，系统选择不输出答案而非生成推测性内容。

## 可复现要素
- **数据集**：AncientDoc（公开基准，论文引用 Yu et al., 2025）；本地知识库证据池为离线构建的冻结数据（见附录 C.5），基于 AncientDoc 知识 QA 设定的网络搜索片段整理而成。
- **代码/权重**：论文未明确声明代码开源情况（截至论文发表时的 arXiv 版本未附带 GitHub 链接）；骨干模型权重为官方开源模型（InternVL3-8B、Qwen2.5-VL-7B、Qwen3.5-9B）。
