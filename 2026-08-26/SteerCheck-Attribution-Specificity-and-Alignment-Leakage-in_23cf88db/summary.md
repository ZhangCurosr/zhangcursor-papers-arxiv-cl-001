# 论文速读：SteerCheck-Attribution-Specificity-and-Alignment-Leakage-in

## 一句话总结
论文提出 **SteerCheck** 预注册归因审计协议，通过在固定 off-target KL 预算下将真实转向方向与三类零假设（各向同性、PCA 子空间、符号随机化）对比，量化构造方法残留的“对齐泄漏”，并将转向声称拆解为均值、保护尾部、极性、迁移与语义五项可独立检验的声明。

## 研究问题与动机
- 激活转向可在不更新权重的前提下改变 LLM 行为，但仅凭行为分数变化无法证明效应来源于目标概念（如事实性、反谄媚），可能混杂广泛破坏方向、构造 artifacts 或通用对抗用户倾向。
- 现有文献多依赖单一随机方向对照，其在高维空间中仅探测近正交区域，判别边界过窄；同构构造的符号随机化对照虽保留更多几何信息，但其随机化推断条件于严格的组内符号交换性，且未经验证可能仍保留大量目标对齐。
- 缺乏在**匹配功能预算**下系统刻画“效果–对齐”关联的诊断工具，导致统计显著性常被误读为归因特异性。
- 需要一套预注册、可精确重放、多门控并强制报告交换性假设与对齐分布的审计框架，以区分“未能建立”与“确实无效”。

## 核心贡献（创新点）
1. **预注册归因审计协议 SteerCheck**：将干预声称分解为均值、保护尾部、极性镜像、迁移与语义五项独立门控。与以往仅报告行为提升的工作不同，本文强制要求同步报告对照器的保留对齐分布与交换性假设，避免显著性误读。
2. **首次量化符号随机化对照的“对齐泄漏”**：在匹配 KL 预算下，25.3% 的符号随机化抽取余弦值超过 0.5，且该族内余弦与观测效果的 Spearman ρ = 0.94，揭示了强构造对照难以区分的几何根源。
3. **提出诊断指标 A 预测对齐波动**：定义 $A = \mathrm{rms}_i(d_i^\top u) / \mathrm{rms}_i(\|d_i\|_2)$，仅需激活库线性代数即可预测符号随机化方向对齐分布的标准差，与 21 个单元格模拟结果的 Pearson $r = 0.979$、MAE = 0.075。
4. **构建三类零假设 + 交集-并集检验（IUT）门控体系**：同时使用几何零假设（各向同性）、子空间零假设（PCA）与构造匹配零假设（符号随机化）进行联合检验，非通过结论被严格界定为“未能建立”而非“效应不存在”。
5. **端到端可复现的证据链与诊断脚本**：冻结种子、追加账本、哈希完整性校验，并公开 CPU-only 脚本可精确重放 960 次干预、复现 Table 2/3/4 与 Figure 1，无需 GPU 或模型权重。

## 方法详解
- **功能预算匹配**：采用 off-target KL 散度 $\kappa = \mathbb{E}_{x \sim \mathcal{N}}[\mathrm{KL}(p_\theta(\cdot|x) \| p_{\theta,cv}(\cdot|x))]$ 而非欧氏范数。小扰动近似下 $\kappa \approx \frac{1}{2} c^2 v^\top F v$，匹配 $\kappa$ 固定 Fisher 范数，保留与行为梯度对齐的自由度供特异性审计隔离。
- **CAA 方向构造**：对 $n$ 对正负样本，取最后一层残差激活差 $d_i = h_\ell(x_i^+) - h_\ell(x_i^-)$，归一化均值 $\bar{d}$ 得 $v_{\mathrm{CAA}}$；在 prompt 结束后位置添加 $c v_{\mathrm{CAA}}$，系数 $c$ 仅通过中性 prompt 银行的 bracket search 匹配目标 $\kappa \in [0.09, 0.11]$，确认输出不参与调参。
- **三类零假设分布**：
  - 各向同性：$v_{\mathrm{iso}}^{(b)} = z_b / \|z_b\|_2,\; z_b \sim \mathcal{N}(0,I_d)$，仅保留尺度。
  - PCA 子空间：$v_{\mathrm{PCA}}^{(b)} = U_k a_b / \|U_k a_b\|_2,\; a_b \sim \mathcal{N}(0,I_k)$，保留前 8 主成分激活子空间。
  - 符号随机化：$v_{\mathrm{shuf}}^{(b)} = \frac{1}{n}\sum_i \epsilon_i^{(b)} d_i,\; \epsilon_i^{(b)} \sim \mathrm{Rad}(1/2)$，保留配对结构、激活几何与尺度，仅随机翻转符号；其有效性条件于组内符号交换性。
- **门控与统计量**：采用交集-并集检验（IUT），均值统计量 $T_{\mathrm{mean}}$ 与保护尾部 $z_7$（第 7 小 item 效果，近似第 5 百分位）须同时通过 Holm 校正 $\alpha = 0.01$；非通过结论需注明是哪个组件失效，并与随机化有效性解耦。
- **前瞻性阳性对照**：语言控制与去毒控制在确认访问前预注册，使用冻结的平衡块-Rademacher 设计独立验证门控可通行性，防止负结果因门控过紧而不可解释。
- **对齐泄漏诊断**：计算每个零方向与 $v_{\mathrm{CAA}}$ 的余弦，绘制效果–对齐剖面；指标 $A$ 由激活库直接计算，预测 $\mathrm{sd}(\cos)$ 无需前向传播。

## 实验与结果
- **模型与数据**：Qwen3-14B、DeepSeek-V2-Lite、Gemma-3-27B；构造/确认库基于 FEVER 与 OpenBookQA；中性 KL 基准为 256 条独立 prompt，冻结 64-token 输出上限。
- **确认性审计（B = 320）**：观测均值效果 $\Delta b = 4.2321$。各向同性与 PCA 族均值组件通过（Holm $p = 0.00935$）；符号随机化失败（$p = 0.01558$）；保护尾部 $z_7 = -1.500$ 对所有三族失败，完整 IUT 判为 **negative**。
- **对齐泄漏量化**：符号随机化族 $\mathrm{sd}(\cos) = 0.577$，$P(\cos \geq 0.5) = 0.253$，该族内 $\cos$ 与效果 Spearman $\rho = 0.94$；21 个单元格中 $A$ 与实测 $\mathrm{sd}(\cos)$ 相关性 $r = 0.979$。
- **迁移研究**：独立 FEVER 确认库上，仅 Qwen 连续 margin 发生迁移（0.3945，99% LCB 0.2606）；三模型准确率迁移全部失败，无单元格通过完整特异性门控。
- **极性镜像**：OpenBookQA 64 fact 上，四单元均提升 wrong-user 分数，但仅 Qwen choice-score 通过 correct-user 非劣效边界（−0.10），其余呈“通用对抗用户”模式，依赖极性对比与 exact-negation 判断而非任何零假设。
- **人工校准开放生成**：三人独立评分（Krippendorf $\alpha$ 0.985–1.000），DeepSeek 通过 O1/O2 联合门控（事实修正），Qwen 未通过；自动 judge 校准失败（macro-F1 0.562 < 0.80），语义结论仅为描述
