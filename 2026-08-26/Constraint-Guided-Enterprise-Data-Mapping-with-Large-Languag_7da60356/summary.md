# 论文速读：Constraint-Guided-Enterprise-Data-Mapping-with-Large-Languag

## 一句话总结
本文提出约束引导映射（CGM），一种神经符号三阶段流水线，通过将可执行的结构化约束作为假设空间操作符前置，解决了企业实体对齐中因隐式属性、单位/粒度不匹配导致的语义检索失效与结构违规问题；在七家企业车厂数据上实现宏观 F1 0.70，并将专家人工成本降低约 7 倍。

## 研究问题与动机
- 企业实体对齐需处理半结构化记录、隐式属性及单位/粒度不匹配，传统手动匹配难以随 schema 与数据源演进而扩展。
- 纯 LLM 匹配器虽提升了语义召回率，但缺乏硬性的结构与物理不变量约束，容易产生流畅却操作无效的对应关系（如将文本相似但发动机代号不同的车辆错误匹配）。
- 现有约束/规则系统在假设严格成立时可靠，但对 paraphrase、稀疏元数据与异构命名脆弱；而 PLM/LLM 匹配器通常在软分数层面评估，缺乏硬准入门控，易传播表示/归一化错误。
- 核心诉求：需要一种能在神经网络推理前通过符号约束定义可行解空间、支持级联松弛以应对噪声与缺失键、且保持可审计性的统一框架。

## 核心贡献（创新点）
- **约束预条件的神经符号流水线**：将硬约束作为假设空间操作符置于神经排序与大模型消歧之前，通过级联松弛保证噪声下可行集非空，使预测 $\tilde{M}(e_s) \subseteq \hat{M}(e_s) \subseteq \mathcal{H}(e_s)$ 由构造保证合法，而非事后验证。
- **可控的机制归因实验设计**：发布合成基准并逐层消融，证明硬性准入门控是性能跃升的决定性因素（F1 从 0.08 提升至 0.66），且该收益与 LLM 规模无关，小模型配合约束即可达到前沿模型无约束时的 100% 结构有效性。
- **跨企业部署与专家效率量化**：在同一流水线下通过自动约束发现适配七家企业车厂（Make A-G），宏观 F1 达 0.70；相比电子表格工作流将单车型映射专家耗时从 10.5 天降至 1.5 天（约 7 倍）。
- **严格的约束发现与评估隔离协议**：采用基于 recall×selectivity 的无 LLM 选择器，并将约束挖掘、过拟合保护与最终评测严格拆分于 60/40 训练/测试集，确保结论无污染且可复现。

## 方法详解
- **约束形式化**：每个约束 $c = \langle a_s^i, m_c, a_t^j \rangle$，元数据 $m_c = \langle \tau_c, \delta_c \rangle$ 包含类型 $\tau_c \in \{\text{hard}, \text{soft}\}$ 与可执行关系/归一化逻辑 $\delta_c$。硬约束执行相等性判定（单位换算、标识符匹配、范围包含），软约束输出二值信号并加权计入排序。
- **准入空间与级联松弛**：对源实体 $e_s$，硬约束定义的准入空间为 $\mathcal{H}_{\tilde{C}_h}(e_s) = \{ e_t \in E_t \mid \forall c \in \tilde{C}_h : c(e_s, e_t) = 1 \}$。若集合为空，按优先级依次移除约束（cascade relaxation）直至 $\mathcal{H} \neq \emptyset$，保证单调降级与可行解存在。当最佳准入相似度低于阈值时额外触发相似度松弛，解决内部编码碰撞导致的“空集但候选错误”问题。
