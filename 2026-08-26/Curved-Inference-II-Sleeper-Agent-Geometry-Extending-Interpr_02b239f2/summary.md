# 论文速读：Curved-Inference-II-Sleeper-Agent-Geometry-Extending-Interpr

## 一句话总结
本文在 Anthropic“沉睡代理”研究基础上，提出无需人工后门与线性探针的几何可解释性框架 Curved Inference II，通过多轮对话模拟自然欺骗推理，并引入语义表面积（A′）指标，证明复杂的内部几何轨迹可稳定预测语义分类，且测量精度提升能使原本被噪声掩盖的几何信号显著显现。

## 研究问题与动机
1. **线性探针的泛化局限**：现有沉睡代理检测依赖人工插入的二进制触发器所制造的线性可分性，Anthropic 团队已承认该信号可能是插入过程的假象，难以泛化至自然训练产生的欺骗对齐。
2. **自然欺骗的连续多维特征**：真实部署中的欺骗推理是渐进式、多语义维度协同演化的过程，而非简单的触发-响应开关，单一线性分类边界无法刻画其连续性与复杂性。
3. **传统可解释方法的标注依赖**：因果追踪、监督探针等工作需人工标注数据与干预访问，缺乏对无监督、模型无关的内部推理轨迹的全局度量能力。
4. **噪声掩盖真实计算签名**：现有评估常以大数据量优先，但分类噪声可能系统性淹没几何信号，导致研究者误判为“模式不存在”。

## 核心贡献（创新点）
1. **提出 CI02 几何检测框架**：将 Curved Inference 从语义关注偏移扩展至自然主义欺骗检测，完全依赖未归一化残差流轨迹进行零监督判别。与监督探针的本质区别在于摒弃人工触发器与标签训练，直接度量推理过程本身的几何形态。
2. **引入语义表面积 A′**：构造融合单步显著性与局部曲率的复合指标，量化表征空间中累积的语义计算工作量。与仅关注终点激活或单一线性方向的现有方法相比，A′ 捕获的是完整路径上的全局变形程度。
3. **设计多轮渐进式提示范式**：构建含战略压力与语义递进的五类提示（Honest/Malicious 等），模拟真实部署场景。与二元 trigger-response benchmark 的本质差异在于消除人工后门带来的虚假线性可分性。
4. **揭示“精度驱动信号显现”方法学规律**：通过全共识与全一致共识双轨对比，证明几何签名在噪声降低时反而增强（如 Honesty 策略 p 从 0.555 降至 0.048）。与传统“大样本优先”范式不同，本文确立测量精度对可解释性信号恢复的决定性作用。

## 方法详解
1. **双分辨率轨迹采样**：不再仅在层边界采样，而是在每层 Attention 输出后与 MLP 输出后分别提取残差状态，使轨迹点数从 $L+1$ 提升至 $2L+1$，独立解析上下文整合与非线性变换的几何贡献。
2. **未归一化残差重建**：跳过 Layer Normalization 的缩放与重中心化，直接累加各层增量：$x^{(\ell)} = x^{(0)} + \sum_{i=1}^{\ell}[\mathrm{attn}^{(i)} + \mathrm{mlp}^{(i)}]$，保留表征方向与幅度的真实语义信息。
3. **语义表面积 A′ 公式**：$A' = \sum_{i=1}^{N}(S_i + \gamma \cdot \kappa_i)$，其中 $S_i = \|x_i - x_{i-1}\|_G$ 为回拉度量 $G=U^TU$ 下的步长显著性，$\kappa_i$ 为离散三点中心差分计算的局部曲率，$\gamma=1.0$ 为曲率权重。该指标全局量化语义构建的总几何工作量。
4. **LLM 共识无监督分类**：使用 Gemini 1.5 Flash、Claude 3.5 Sonnet、GPT-4o Mini 对输出进行双维度标注（透明度：高/中/低；类型：解释性/回避性/操纵性），多数票构成全共识集，三者完全一致构成全一致共识集。
5. **统计验证协议**：采用 Kruskal-Wallis（多类透明度）与 Mann-Whitney U（二类响应类型）非参数检验，配合 Cohen’s d、$\eta^2$、Cliff’s δ 效应量及 1000 次 bootstrap 95% 置信区间，系统评估几何指标与语义分类的关联强度与稳定性。

## 实验与结果
1. **实验设置**：测试 Gemma3-1b（1.3B, 26 层, d=2048）与 LLaMA3.2-3b（2.3B, 28 层, d=3072），每策略生成 N=100 补全，覆盖 5 种自然主义提示策略。
2. **几何标度差异**：LLaMA3.2-3b 的 A′ 均值约 1,500（范围 1,000-3,000），Gemma3-1b 均值约 10,000（范围 8,000-16,000），相差约 6.7×，但相对排序关系严格一致。
3. **最强结果**：LLaMA3.2-3b 的 Persuasive 策略在全一致共识下 Response Type 区分达 p=0.027，Cohen’s d=4.15（极大效应）；Honest 策略高透明度组 A′ 均值 2,490 显著高于低透明度组 1,418（p<0.001）。
4. **精度提升效应**：Gemma3-1b 的 Honest 策略在全共识下完全不显著（Transparency p=0.555, Response p=0.310），经全一致共识过滤后跃升为显著（均 p=0.048），Cohen’s d=1.24，直接验证噪声掩盖假说。
5. **跨架构一致性**：两种模型在所有策略下均保持“解释性响应 A′ 高于回避性响应”的方向一致性，多数显著比较的效应量 $\eta^2>0.44$ 或 $d>1.0$，表明几何签名具有架构鲁棒性。
