# 论文速读：Curved-Inference-II-Sleeper-Agent-Geometry-Extending-Interpr

## 一句话总结
本文针对Anthropic Sleeper Agents研究中线性探针依赖人工后门可分性的局限，提出基于几何解释性的自然主义欺骗检测框架（CI02）；通过多轮语境模拟渐进式策略推理，利用残差流的曲率、显著性与新指标“语义表面积（A′）”，证明即使不存在人工线性边界，复杂推理仍会产生可区分的几何签名，且测量精度提升可使被噪声掩盖的模式显著显现。

## 研究问题与动机
- **核心问题**：现有Sleeper Agents等探测方法依赖线性探针与二元触发-响应模式，其高准确率可能仅是显式后门插入过程产生的artifact，难以泛化到自然训练中涌现的欺骗性对齐（deceptively aligned）行为。
- **现有方法不足**：线性探针只能提供二值激活边界，无法刻画渐进式、多语义维度交织的策略推理；且必须依赖标注数据与明确的位置假设，对无监督、连续分布的内在计算模式不敏感。
- **自然主义必要性**：真实部署场景中的欺骗往往通过多轮对话、渐进语义压力自然形成，而非简单开关式触发，需更贴合实际推理轨迹的检测手段。
- **几何检测优势**：几何度量提供连续信号，可捕捉多维语义空间中的轨迹弯曲与强度变化，且无需额外监督信号，适合无先验知识的自然涌现模式识别。

## 核心贡献（创新点）
1. **提出无后门、无监督的自然主义多轮欺骗检测范式**：设计五类渐进语义压力提示（Honest至Malicious），在不植入触发器、不依赖人工标签的情况下模拟真实部署中的策略推理，区别于传统Sleeper Agents的显式backdoor插入与线性探针套路。
2. **引入语义表面积（Semantic Surface Area, A′）作为综合几何指标**：将轨迹显著性（步长幅度）与曲率（方向变化）线性融合，量化模型在残差空间中完成语义表征所需的总“计算工作量”，区别于仅关注激活幅度或单一线性投影的传统解释性度量。
3. **扩展Curved Inference至CI02：双分辨率未归一化轨迹重构**：在每层attention与MLP子层边界同步采样，将轨迹点从$L+1$提升至$2L+1$，并绕过LayerNorm的缩放/中心化操作，保留原始幅值与方向信息，突破CI01在归一化空间与层边界采样的局限。
4. **揭示“测量精度放大几何信号”的方法学规律**：通过LLM三模型共识与完全一致同意（unanimous consensus）过滤，证明即使样本量减少40%–60%，几何模式的统计显著性与效应量反而显著提升（如Gemma3-1b的Honest策略从p=0.555跃升至p=0.048），验证内禀几何结构并非噪声产物。

## 方法详解
- **模型设置**：评估Gemma3-1b（1.3B, 26层, d=2048, RoPE）与LLaMA3.2-3b（2.3B, 28层, d=3072, RoPE）；仅前向推理，不更新权重。
- **提示设计与分类协议**：五类策略提示共享固定用户查询，前置模拟助手内部Thought行以诱导不同推理路径；使用Gemini 1.5 Flash、Claude 3.5 Sonnet、GPT-4o Mini独立评估透明度（High/Med/Low）与响应类型（Explanatory/Evasive/Manipulative），多数票为Full Consensus，完全一致为Unanimous Consensus。
- **轨迹提取与度量计算**：
  - 使用pullback度量 $G = U^T U$（U为unembedding矩阵），使距离反映logit空间的语义相似度。
  - 显著性：$S_i = \|x_i - x_{i-1}\|_G$，衡量步长幅度。
  - 曲率：$\kappa(i) = \frac{\sqrt{\|a(i)\|_G^2 \|v(i)\|_G^2 - \langle a(i), v(i)\rangle_G^2}}{\|v(i)\|_G^3}$，其中$v, a$为轨迹一阶/二阶导数。
  - 语义表面积：$A' = \sum_{i=1}^{N} (S_i + \gamma \cdot \kappa_i)$，本文取$\gamma = 1.0$。
- **统计与验证框架**：Shapiro-Wilk正态检验后统一采用非参数检验（Kruskal-Wallis多组、Mann-Whitney U二元对比）；报告Cohen's d、$\eta^2$、Cliff's delta效应量及95% bootstrap置信区间（1000次重采样）；跨架构验证以方向一致性、标准化效应量与显著性模式复用为核心标准。

## 实验与结果
- **数据集与基线**：每策略生成100条完成（共500条/模型）；基线对照为Full Consensus与Unanimous Consensus双轨分析，并与传统线性探针方法形成定位对比。
- **LLaMA3.2-3b结果**：表面面积均值约1,500（范围1,000–3,000）。unanimous过滤后全部5类策略保持高度显著（p < 0.001），效应量极大（Honest d=2.15, Malicious d=2.22, Persuasive d=4.15）；Deceptive策略透明度差异显著（p<0.001, $\eta^2=0.448$），低/中/高透明度均值分别为1,276、2,971、2,396。
- **Gemma3-1b结果**：表面面积均值约10,000（范围8,000–16,000），约为LLaMA的6.7倍。Honest策略从full共识的非显著（Trans p=0.555, Resp p=0.310）经unanimous过滤后跃升为显著（p=0.048, d=1.24）；Strategic响应类型显著（p=0.003, d=1.51）；Deceptive策略达成100%完全共识（61条全为low transparency/evasive），均值A′=9,769。
- **核心结论**：两种架构虽绝对量级差异巨大，但几何-语义方向关系高度一致（解释型 > 回避型）；提高分类精度可消除噪声，使原本被掩盖的几何签名显现，证明复杂推理的内禀几何结构真实存在且具备可检测性。

## 相关工作脉络
1. **Hubinger et al. (Anthropic) Sleeper Agents**：显式后门训练+线性探针检测（>98%）。本文定位其线性可分性可能是插入过程的artifact，提出无需触发器与监督标签的几何替代路径。
2. **Amnesic probing / causal tracing / supervised linear classifiers**：组件级干预与标注依赖型解释方法。本文定位不假设表征存储位置、不依赖标签，转而分析残差流轨迹的全局几何形状，提供连续无监督信号。
3. **Curved Inference (CI01, Manson 2025)**：前期工作证明语义关切偏移可诱导残差流曲率变化。本文定位将其从“关切敏感度”扩展至“自然主义欺骗检测”，并新增A′指标与双分辨率未归一化轨迹。
4. **Representation Flow / Belief-state Manifolds / trajectory divergence**：关注内部状态演变与扰动响应。本文定位提供更细粒度（子层级）、基于pullback度量的语义几何量化，并与外部行为分类直接对齐。
5. **输出层语言线索/矛盾检测**：符号或行为层面监控。本文定位绕过表层语言特征，直接观测意义构建的内在几何计算过程，补充机制解释性谱系。

## 局限性与未来方向
- **分类器依赖与选择偏差**：LLM共识仅为人类判断代理，unanimous过滤剔除模糊边界案例（样本量减少40%–60%），可能高估几何签名在边缘情境下的可靠性。
- **模型与提示覆盖有限**：仅测试两个小规模decoder-only模型，未验证于>70B参数、MoE/encoder-decoder架构或前沿闭源模型；提示策略较窄，缺乏对抗性设计与跨文化场景。
- **几何度量敏感性**：A′对有限差分估计、步长分辨率与激活噪声敏感，后期层微小偏差可能引起指标剧烈波动；虽按响应长度归一化，仍需平滑/多尺度分析以提升鲁棒性。
- **缺乏行为ground truth**：未验证真实危害行为或对齐风险，仅关联内部几何与共识分类标签；unanimous过滤可能进一步远离最具风险的边界案例。
- **未来方向**：扩展至多语言、大参数规模与指令微调模型；集成实时推理日志与对齐遥测；结合因果patching与混合探针/符号工具；探索高度复杂欺骗系统是否可能学会维持几何一致性以逃避检测。
