# 论文速读：Evaluating and Explaining Prompt Sensitivity of LLMs Using Interactions

## 一句话总结
本文提出基于神经交互（Interactions）的细粒度指标 IPS，用于量化与解释大语言模型对提示模板的敏感性；发现监督微调、增大模型规模、使用稠密架构及引入少样本学习均可显著降低敏感性，其底层共性机制在于主要稳定了原本就较稳定的低阶交互，而高阶交互的脆弱性仍未被解决。

## 研究问题与动机
1. **现有评估过于粗粒度**：当前 prompt 敏感性研究仅关注最终输出是否一致或准确率是否波动，无法解释模型内部逻辑为何发生偏移。
2. **输出相同不等于内部稳定**：细微且语义无关的格式改动（如 `Answer:` → `ANSWERS:`）即使未改变最终答案，也可能导致模型内部推理路径发生剧烈震荡，传统指标完全盲区。
3. **缺乏机制层面的归因**：不同模型因素（SFT、规模、架构、few-shot）如何影响敏感性尚不明确，难以指导更稳健的模型设计与部署。
4. **目标**：引入游戏博弈论框架下的交互分解方法，将 LLM 输出得分精确拆解为若干非线性输入组合效应，从而在推理层面细粒度衡量并解释 prompt 敏感性及其成因。

## 核心贡献（创新点）
1. **提出 IPS 细粒度度量**：通过计算两种等价 prompt 模板下显著交互效应的对称平均绝对百分比误差来量化敏感性，与传统输出一致性指标本质不同，能够捕捉“输出不变但内部逻辑已变”的潜在风险。
2. **系统解耦四大降敏因素**：在 50 个开源 LLM 上验证了监督微调、参数量增长、稠密架构、少样本学习均能系统性降低 prompt 敏感性，突破了以往仅靠单一对比实验的局限。
3. **揭示统一的底层作用机制**：发现所有降敏因素的核心共性是显著稳定低阶交互（涉及变量少的简单关系），而高阶交互（复杂组合）的敏感性依然居高不下，解释了模型鲁棒性提升的来源与天花板。

## 方法详解
- **交互分解理论**：基于通用匹配性质（Theorem 3.1），对输入词集合 $N=\{1,\dots,n\}$，任何随机掩码下的输出分 $v(\boldsymbol{x}_T)$ 均可由代理逻辑模型精确重构：$\phi(\boldsymbol{x}_T) = \phi(\boldsymbol{x}_\emptyset) + \sum_{S \subseteq N} \mathbb{1}(S\mid\boldsymbol{x}_T)\cdot I_S$，其中 $I_S$ 为 AND/OR 交互效应，$\mathbb{1}(\cdot)$ 为触发函数。
- **稀疏交互提取**：采用 LASSO-like 损失（$\min_{\{\gamma_T\}}\sum_S |I_S^{\text{AND}}|+|I_S^{\text{OR}}|$）从 $2^{n+1}$ 种候选交互中筛选出少量显著交互（salient interactions），满足 DNN 编码稀疏性的理论保证。
- **IPS 指标定义**：对每对等价模板 $(T,\hat{T})$，取两方显著交互集的并集 $\Omega_{\text{union}}$，计算归一化交互效应的对称平均绝对百分比误差（公式 3），再对数据集与模板对取期望，得到 $IPS \in \mathbb{R}^+$，值越低越稳定。
- **阶数分层分析**：按交互涉及变量数 $|S|$ 将显著交互划分为低阶（$1\le|S|\le\lfloor n/3\rfloor$）、中阶、高阶，分别计算 $IPS^{low}, IPS^{mid}, IPS^{high}$ 以定位不稳定性来源。
- **实验设置**：阈值 $\tau=0.1$ 用于过滤噪声（0.05–0.20 鲁棒性验证，Spearman $\rho=0.9905$）；输入掩码采用各模型专属 `[MASK]` token；生成配置为 greedy search（`do_sample=False`）以消除采样随机性。

## 实验与结果
- **数据集与模型**：ARC、MMLU（MCQ）及 Dolly-15k（开放生成）；50 个开源 LLM，涵盖 Llama、Mistral、Qwen、OLMo、InternLM 五大系列。
- **基线与对比**：输出一致性（output consistency）、最后一层隐状态余弦相似度与 $L_2$ 距离。
- **主要数值**：IPS 跨度为 1.268（Qwen2.5-72B-Instruct，最优）至 1.752（Mistral-7B-v0.3，最差）；IPS 与输出一致性呈显著负相关。
- **四因素结论**：
  1. Instruct/Chat 模型普遍低于对应 Base 模型；
  2. 同系列内参数量越大，IPS 系统下降；
  3. 稠密模型普遍优于 MoE（即使控制激活参数量相近，Table 7 仍成立，归因于门控路由差异）；
  4. Few-shot 较 0-shot 降幅最大集中在 0→1 shot，后续递增收益递减。
- **机制发现**：低阶交互本身最稳定（图 9），且四大因素对其相对改善幅度 $\Delta IPS^{low}$ 最大；高阶交互敏感性始终居高，降敏效果微弱。
- **鲁棒性验证**：开放任务（Dolly-15k）、复杂扰动（语义改写、指令重排）及不同 $\tau$ 下结论完全一致；表征级指标（余弦/$L_2$）出现矛盾趋势，进一步印证 IPS 的优越性。

## 相关工作脉络
1. **Prompt 敏感性评估**（Sclar et al., 2024; Chatterjee et al., 2024; Zhuo et al., 2024）：聚焦输出准确率或一致性波动，属粗粒度观测；本文首次从内部交互逻辑层面进行细粒度归因。
2. **神经网络的解释性方法**（Lundberg & Lee, 2017; Ancona et al., 2019）：Shapley/归因类方法缺乏对 DNN 推理过程的忠实性理论保证；本文采用经严格数学证明的 AND-OR 交互框架，具备通用匹配与稀疏性保证。
3. **稀疏交互提取与应用**（Li & Zhang, 2023; Ren et al., 2023a; Chen et al., 2024）：证明 DNN 仅编码少量显著交互；本文将该方法首次系统应用于 LLM prompt 敏感性研究，并验证其在多系列开源模型上的泛化性。
4. **MoE 与稠密架构对比**（Cai et al., 2025）：前人主要关注计算效率与性能扩展；本文补充了稳定性视角，指出 MoE 动态路由会引入更高敏感性。
5. **Prompt 扰动与鲁棒性**（Sun et al., 2024; Alzahrani et al., 2024）：多从对抗或格式扰动经验性观察；本文通过交互阶数分解给出可解释的内在机制，并为后续训练干预指明方向。

## 局限性与未来方向
1. **计算复杂度较高**：交互提取需对 $2^n$ 种掩码组合进行前向计算，直接应用于超长文本时开销巨大，目前主要依赖词选择与短语聚合进行近似。
2. **高阶交互稳定性仍未解决**：四大因素均未能有效压制高阶交互的敏感性，限制了整体鲁棒性的进一步提升。
3. **未来方向**：设计新型训练策略以增强模型对稳定低阶交互的依赖，或直接针对高阶交互的不稳定性进行正则化；引入高效稀疏交互近似算法（如 SPEX、ProxySPEX）以扩展至长文本生成场景。

## 研究启发与可借鉴点
1. **细粒度可解释指标的工程价值**：IPS 将“黑盒输出波动”转化为“可量化、可定位的交互不稳定性”，可直接迁移至模型上线前的敏感性筛查流程。
2. **控制变量解耦实验范式**：同家族、同训练范式下仅改变单一变量（SFT/规模/架构/shots）的对比策略，结论可信度高，值得在鲁棒性研究中广泛复用。
3. **长文本降维策略**：停用词剔除 + 短语级聚合的两步法在保持结论一致的前提下大幅削减计算负担，为交互分析应用于对话/检索长上下文提供了可行路径。
4. **机制驱动的模型改进思路**：发现“低阶易稳、高阶难控”的规律后，可将损失函数或微调数据针对性地偏向低阶语义组合，有望突破现有降敏天花板。

## 关键术语表
- **Interactions（交互）**：输入变量组合间的非线性协同效应，标量权重 $I_S$ 量化其对模型输出的贡献方向与幅度。
- **Salient Interactions（显著交互）**：绝对值超过阈值 $\tau$ 的交互，构成模型推理决策的核心逻辑单元。
- **Interaction-based Prompt Sensitivity (IPS)**：基于显著交互变化率的细粒度敏感性度量，对称平均绝对百分比误差形式，越低表示越稳定。
- **Low/Mid/High-order Interactions**：按参与输入变量数量 $|S|$ 划分的一阶至高阶交互，分别对应简单词组合、中等组合与全局复杂组合。
- **Universal Matching Property（通用匹配性质）**：理论定理，保证由交互权重重构的逻辑模型在任意掩码输入下输出与原始 DNN 完全一致。
- **Sparsity Property（稀疏性）**：实证与理论共同证明，DNN 实际依赖的显著交互仅占全部 $2^n$ 组合的极小比例。
- **MoE（Mixture of Experts）**：混合专家架构，通过门控动态激活部分子网络；本文揭示其路由机制会放大 prompt 格式扰动带来的内部不稳定性。

## 可复现要素
- **数据集**：ARC、MMLU、Dolly-15k 均为公开数据集；50 个开源 LLM 权重/代码均可在 HuggingFace 等平台获取。
- **代码与权重**：论文未提供独立 GitHub 仓库，但附录 E–L 详细公开了 prompt 模板、各模型掩码 token、生成配置（greedy）、硬件环境（4× NVIDIA Tesla V100-32G）及超参实验细节。
- **关键超参**：显著性阈值 $\tau=0.1$（0.05–0.20 区间验证稳定）；交互提取使用 LASSO-like 稀疏损失；评估基于 5 组等价 prompt 模板两两配对。
