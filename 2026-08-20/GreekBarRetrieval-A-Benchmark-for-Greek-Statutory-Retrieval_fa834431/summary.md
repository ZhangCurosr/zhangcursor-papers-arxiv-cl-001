# 论文速读：GreekBarRetrieval-A-Benchmark-for-Greek-Statutory-Retrieval

## 一句话总结
本文提出希腊语成文法检索基准 GreekBarRetrieval，基于律师资格考试题构建开放检索任务；实验表明原始密集检索召回优势明显，但引入 LLM 查询重写与多轮 REACT 式迭代后，BM25 在排序质量（nDCG/MAP）上达到所有方法最优。

## 研究问题与动机
- 法律问答系统依赖可验证的法条引用，检索质量直接决定答案的可解释性与准确性。
- 希腊语形态丰富，日常语言描述的案件事实与法条正式术语之间存在严重词汇鸿沟，传统稀疏检索难以精确匹配。
- 现有法律检索基准集中于英语或多国案例/合同语料，希腊语成文法（statutory）检索评测仍处于空白。
- 考试题目包含与具体法律问题无关的冗余事实，传统检索易受噪声干扰导致排名偏差。

## 核心贡献（创新点）
- 提出 GreekBarRetrieval 基准，首次为希腊语律师考试题构建开放法条检索任务。不同于 GreekBarBench 仅提供固定候选项的封闭问答设定，本文构建 6,308 篇候选池并剥离检索与推理环节。
- 系统评估 3 种希腊语 BM25 变体与 9 个密集 embedding 模型，确立希腊法律检索性能基线。区别于既往英语主导的评测，本文针对希腊语形态学与结构化法条编号设计专用预处理，量化稀疏/密集方法的适用边界。
- 验证 LLM 查询重写对稀疏与密集检索的协同增益。与传统词项扩展或跨语种翻译不同，重写策略显式对齐抽象法律概念并剔除无关事实，使 BM25 召回提升 0.24，效果远超其他增强手段。
- 设计 REACT-BM25 多轮迭代检索框架，通过规划器-观察者循环优化稀疏排序。现有迭代检索多绑定密集模型或生成式 ReAct 流程，本文将其迁移至传统倒排索引，证明多轮探索可显著提升 nDCG 与 MAP。

## 方法详解
- **数据构造**：保留 GreekBarBench 的问题与案件事实，将官方解答引用的法条转换为 `PREFIX::ARTICLE` 标识作为 gold；检索池涵盖 23 个法律源共 6,308 篇完整法条，过滤掉引用法条缺失或空集的 27 题，最终 283 查询。
- **稀疏基线**：使用 `rank_bm25` 实现 BM25，对比三种希腊语预处理：BM25-GREEKSTEMMER（Unicode 正则分词+去重音符+自定义希腊词干提取器）、BM25-SPACY（spaCy 希腊 pipeline 词形还原）、BM25-GR-NLP-TOOLKIT（保留标点无词干/词形处理）。默认超参 $k_1=1.5, b=0.75$。
- **密集基线**：部署 Gemini-001（API，输出维度 3072）、Qwen3-8B/4B/0.6B、Euler-Legal-V1、Jina-v5-small、Arctic-v2、EmbGemma-300M、Nomic-v1.5；统一 L2 归一化与精确 top-k 检索，未进行希腊法律语料微调。
- **LLM 查询重写**：使用 `gpt-oss-120b` 生成两类重写结果：稀疏侧输出紧凑法律关键词/短短语列表；密集侧输出法言法语摘要语句。提示词固定且未用评测结果调优。
- **PRF 增强**：稀疏侧采用 TF–IDF 项扩展（取首轮 Top-10 中得分最高的 30 个 term 追加到原查询）；密集侧采用正向反馈 Rocchio，新查询向量 $q_{\mathrm{PRF}} = \mathrm{norm}(\alpha q + \beta c)$，其中 $c$ 为 Top-10 文章嵌入质心，$\alpha=1.0, \beta=0.25$。
- **REACT-BM25 多轮循环**：规划器每轮基于历史查询与观察员保留的法条生成新关键词查询；观察员对 Top-100 结果做二值保留决策。最终排序主键为“被保留轮次频次”，次键为“首次保留轮次”，第三键为“历史最佳 BM25 排名”，上限 100 篇，最多运行 10 轮。
- **融合与翻译**：稀疏-密集采用 RRF（$k=60$）无需分数校准融合；全量英译基线使用 `openai/gpt-oss-120b` 翻译查询与法条，保留原始 ID 与相关性标注。

## 实验与结果
