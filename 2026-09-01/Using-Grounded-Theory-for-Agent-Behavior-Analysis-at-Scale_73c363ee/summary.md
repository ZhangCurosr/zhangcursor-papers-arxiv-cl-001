# 论文速读：Using-Grounded-Theory-for-Agent-Behavior-Analysis-at-Scale

## 一句话总结
本文提出 AutoTraceGT，首个将社会学定性方法“扎根理论”自动化应用于大规模 Agent 轨迹分析的端到端多智能体管道。该方法通过开放、轴向、理论三级编码的迭代循环直至理论饱和，自动生成可审计的行为分类法，在 7,500+ 条跨六数据集的轨迹上可恢复人类标注分类中 73–91% 的失败模式并揭示遗漏模式，且生成的代码本作为演绎特征空间在下游失败预测任务上显著优于少样本 LLM 基线。

## 研究问题与动机
- **现有分析方法的两难困境**：轻量级定量元数据（成功率、步数、工具调用计数等）虽易扩展但无法解释长轨迹中的求解过程；人工细粒度分析可解释但成本极高，难以处理成百上千步的 Agent 轨迹；预定义的分类器过于刚性，无法泛化到新任务与涌现行为。
- **方法论缺失**：ML 社区缺乏一种既能规模化处理数千条轨迹、又能保持归纳开放性与可审计性的行为分析框架，而社会科学早已发展出对应方法论（如扎根理论）来解决同类问题。
- **已有 LLM 辅助定性工具的不足**：现有工作（如 AcademiaOS、LOGOS）要么割裂了扎根理论的多阶段结构，用语义聚类替代轴向/选择编码，要么未经验证“理论饱和”这一核心终止准则，导致停止规则武断或概念广度不明确。

## 核心贡献（创新点）
1. **将扎根理论引入 ML 作为可规模化的 Agent 行为分析工具**：与预设分类器或单次归纳 prompting 的本质区别在于，该方法坚持“理论从数据中涌现”的归纳逻辑，并通过理论饱和提供 principled 的停止准则与从原始轨迹到理论主张的完整可审计链路。
2. **提出 AutoTraceGT 端到端自动化管道**：首次实现开放、轴向、理论三阶段编码的完整闭环，通过角色专业化的多智能体协同与代码本管理器（codebook manager）驱动迭代，所有中间产物均机器可读且可追溯，区别于仅做单次聚类或提示的既有管道。
3. **全面的实证验证**：在六个数据集、七千五百余条轨迹、四种骨干 LLM 上验证了过程的可靠性与产物的质量；不仅复现了人类分类法覆盖的失败模式（73–91%），还系统性地揭示了预定义分类法遗漏的模式，且将生成的代码本作为演绎特征空间用于下游失败预测，性能超越 Few-shot 基线。

## 方法详解
AutoTraceGT 包含四个智能体，在三个尺度上执行分层语义压缩，由 Manage 驱动迭代循环直至饱和（Algorithm 1）：
- **OpenCode（单条轨迹的开放编码）**：按 chunk 顺序处理轨迹消息序列，携带段级 memo 保持分析连续性。输出为 `(code, span, quote)` 记录，要求生成 2–5 词的概念性标签（描述行为模式而非表面动作），如 “persist through validation hurdles” 而非 “calls check tool”。
- **AxialCode（采样轮的轴向编码）**：对每轮采样的批量开放编码结果进行聚类，将概念码整合为高阶类别（category）与类别间关系，生成轴向 memo。每个类别附带文本定义、支持成员列表及状态标签 `status ∈ {succ, fail, both}`，保留从类别到原始片段的显式指针。
- **Manage（代码本管理/常数比较）**：维护带版本历史的代码本 $K_t$，每轮对新类别/关系执行 `{add, merge, split, flag}` / `{confirm, extend, add, contradict}` 操作并追加修订日志 $L_t$。采用“优先合并（merge-first）”策略对齐现有结构。定义每轮新增类别数 $a_t$，以连续 $W$ 轮内 $a_t < \epsilon$ 作为理论饱和的算法终止准则。
- **TheoreticalCode（全局理论编码）**：饱和后对稳定代码本进行综合分析，识别核心类别（core category）$c^*$，将其余类别组织为条件、语境、策略与后果，生成可证伪的理论叙述（narrative account）。该阶段仅依赖 $K_T$ 与修订日志 $L_T$，不引入新证据，保留未解张力。

## 实验与结果
- **数据集**：两类语料库共 7,500+ 轨迹。失败推理标注集：ALFWorld (100)、GAIA (50)、WebShop (50)；结果标签集：Tau-Bench (1,980)、Go-Browse (2,000)、SWE-Agent (2,000)。骨干模型包括 GPT-4.1-mini、GPT-5、GPT-5-mini、GPT-OSS-120B。
- **过程可靠性（RQ1）**：饱和诊断显示 `add` 操作占比下降、`merge`/`confirm` 上升，类别数与余弦相似度（趋近 1）均收敛。同配置三次独立运行代码本中位余弦相似度 0.929，显著高于跨配置零分布阈值 0.901（Mann–Whitney $p < 10^{-20}$）；固定数据集跨 LLM 的代码本覆盖率显著高于三种零分布基线（置换检验 $p < 0.001$），表明提取的是数据集特有的行为结构而非模型先验。
- **产物质量（RQ2）**：
  - **覆盖人类分类法**：AutoTraceGT 代码本在 ALFWorld、GAIA、WebShop 上分别恢复 75.0%、73.7%、90.9% 的人类失败模式（轨迹匹配率 82.4%、58.0%、87.9%），且召回率可高于精确率，揭示出预定义分类法系统性遗漏的模式
