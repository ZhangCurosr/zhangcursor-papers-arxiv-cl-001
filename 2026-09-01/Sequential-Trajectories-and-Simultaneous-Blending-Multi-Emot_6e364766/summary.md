# 论文速读：Sequential-Trajectories-and-Simultaneous-Blending-Multi-Emot

## 一句话总结
提出 HybridEmo 两阶段后训练框架，将监督微调与样本感知的混合奖励 GRPO 结合，首次在指令跟随 TTS 中显式建模顺序情感轨迹与并发情感融合任务，显著提升多情感生成的准确性与感知质量，同时保持语言保真度与说话人相似度。

## 研究问题与动机
1. **现有情感 TTS 仅建模话语级单情感**：主流系统（如 PromptTTS、EmoVoice 等）将情感视为全局静态标签，无法处理真实语音中常见的顺序演变（Trajectory）与并发混合（Blending）模式。
2. **SFT 缺乏显式情感结构监督**：Token 级交叉熵损失仅拟合目标语音序列，不评估生成结果是否满足规定的顺序或双情感共存分布，导致多情感控制能力有限。
3. **现有语音 RL 奖励无法匹配多情感结构**：GRPO/DPO 类方法多优化流利度、说话人相似性等全局指标；情感识别器仅提供单情感话语级分数，无法定位轨迹阶段的缺失/错序，也无法度量双情感是否真正并发。
4. **缺乏标准化的多情感评测基准**：现有评测多聚焦单情感或主观听感，缺少系统化覆盖轨迹长度（1-3 阶段）与情感融合对的客观/主观测试协议。

## 核心贡献（创新点）
1. **形式化多情感 TTS 控制任务并构建 MultiEmo-Test**：明确定义情感轨迹（顺序多阶段）与情感融合（并发双情感）两类任务，并提供配套评测集与评估协议。
2. **提出 HybridEmo 两阶段后训练框架**：SFT 初始化获得多情感生成基础能力后，通过样本感知的混合奖励 GRPO 进行结构化对齐，无需成对目标波形即可优化情感模式。
3. **设计分段对齐一致性奖励（R_consi）**：在无时间戳条件下按文本长度近似划分阶段，结合平均后验与最弱阶段分数，兼顾轨迹整体正确性与阶段完整性。
4. **提出 GMM 混合密度奖励（R_gmm）与较弱目标边距机制**：利用离线单情感 GMM 锚点评估帧级双情感密度 union，并引入边距惩罚抑制单边主导，实现并发情感的梯度协同优化。

## 方法详解
- **基础架构**：以 CosyVoice 3 (0.5B) 为底座，仅优化自回归语音 Token LLM；语音 tokenizer 与 flow-matching 声学生成器全程冻结，参考音色仅用于波形解码。
- **阶段一：SFT 初始化**：在多情感演示数据（轨迹 119,981 句、融合 4,115 句）上优化 token 级交叉熵 `L_SFT = -Σ log p_θ(z*_t | z*_<t, x, c_e)`，使模型获得初步多情感生成能力。
- **阶段二：GRPO 对齐**：每个输入采样 G=8 个 rollout，经固定声学生成器解码为波形后计算奖励；基于组内相对优势更新策略，并施加 KL 约束防止偏离 SFT 参考策略。
- **共享 ASR 奖励**：使用 SenseVoice 转录生成语音，计算归一化 WER `ε_wer`，通过 `R_asr = clip[0,1](1 - tanh(3ε_wer))` 限制分值范围，保障情感优化不损害内容清晰度。
- **轨迹一致性奖励**：按文本长度比例划分区间 `I_k`，利用 emotion2vec+ large 提取各段目标情感后验 `p_k`，计算均值 `p̄` 与最弱阶段 `p_min`，奖励为 `R_consi = βp̄ + (1-β)p_min`（β=0.7），避免高平均分掩盖单阶段失败。
- **GMM 混合密度奖励**：
  - **离线锚点构建**：用 CosyVoice 3 合成单情感语音，提取 frame-level 特征，经 LDA 降至 6 维、Isolation Forest 剔除 8% 离群帧后，拟合全协方差 GMM（M=3 组件）作为情感锚点分布。
  - **在线密度评分**：将生成帧投影后计算目标对 A/B 的帧级 log-density union `ℓ_mix = LSE(log p_A(u_t), log p_B(u_t))`。
  - **较弱目标边距**：计算每情感归一化贡献 `q_t,e`，取话语级最小值 `m`，当 `m < ρ` 时施加惩罚 `α·max(0, 1 - m/ρ)`（α=0.01, ρ=0.05），防止单一情感主导。
  - **标准化映射**：原始分数经指数滑动平均去量纲后通过 sigmoid 映射至 `[0,1]` 作为 `R_gmm`。
- **样本路由**：根据输入类型动态选择 `R_consi` 或 `R_gmm`，与共享 `R_asr` 加权组合（`w_asr=0.5, w_consi=0.5, w_gmm=0.3`）后输入 GRPO。

## 实验与结果
- **数据集**：SFT 语料 124,096 句（383.6h，Emilia 英文部分）；MultiEmo-RL 14,400 个纯文本-指令对；MultiEmo-Test 720 个样本（轨迹 600，融合 120，覆盖 12 对情感组合）。
- **基线模型**：CosyVoice 3 (0.5B)、EmoVoice-0.5B/1.5B、Qwen3-TTS-1.7B（外部参考，无语音提示）。
- **轨迹任务**：HybridEmo 宏平均正确率由 3.24 提升至 3.33（1E: 3.68→3.78，2E: 2.95→3.01，3E: 3.09→3.21）；自然度由 2.40 提升至 2.50；WER 仅 1.87%，UTMOS 3.21，说话人相似度基本持平。
- **融合任务**：强度由 3.47 提升至 3.71，自然度由 3.06 提升至 3.24，显著优于 EmoVoice 两档；强度与 Qwen3-TTS 持平，自然度仅落后 0.05；WER 降至 0.37%。
- **人类评估**：对比 CosyVoice 3 与 EmoVoice-0.5B，HybridEmo 胜率超负率 32pp；对比 Qwen3-TTS 呈均衡偏好（35%胜/29%平/36%负）。
- **消融结论**：跳过 SFT 直接 GRPO 提升有限且 WER 上升；专用单任务 GRPO 各自在对应任务上略优，但联合 HybridEmo 取得最佳综合性能；移除较弱目标边距使融合强度与自然度均值从 3.48 降至 3.36，验证防单边主导机制的有效性。
- **最强结果**：融合任务强度 3.71 / 自然度 3.24；轨迹任务宏平均正确率 3.33。
