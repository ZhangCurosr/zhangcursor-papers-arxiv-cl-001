# 论文速读：E-Commerce-Bench: Evaluating LLM Agents on Long-Horizon Autonomous Commerce

## 一句话总结
本文构建了 **E-Commerce-Bench**，一个持续 365 天的多商户电商模拟环境，用于系统评估 18 款主流 LLM 作为电商代理的长期自主运营能力，涵盖谈判、反欺诈、现金流管理、运营效率等七大维度，发现最强闭源模型（GPT-5.6 Sol）与开源模型（Qwen3.5-Plus）最终资产差距达 **1,264 倍**，且部分高成本模型反而以破产收场。

## 研究问题与动机
- **LLM Agent 在长周期复杂商业场景中的综合能力缺乏系统评测**：现有基准多为短 horizon 或单一任务，无法反映真实电商运营中谈判、库存、物流、财务等多环节耦合的长期决策挑战。
- **商业模拟环境难以同时支持多模型公平对比**：现有 work 往往只评测 1-2 个模型，且缺乏统一的七维评估框架与标准化环境。
- **开源模型在复杂长期决策中的表现未被充分量化**：闭源旗舰模型与开源 SOTA 之间的真实能力差距（包括稳定性、破产风险）缺乏大规模对照实验证据。
- **工具调用效率与最终盈利并无简单正相关**：部分模型调用次数少但利润高（Fable5），部分则反之，现有研究缺少对"效率-收益"权衡的细粒度分析。

## 核心贡献（创新点）
1. **提出 E-Commerce-Bench，一个 365 天、多商户、多工具链的电商代理评测基准**，填补了长 horizon 商业决策评测的空白，区别于以往短期或单任务的 agent benchmark。
2. **构建七维综合评估框架**（谈判质量 CSE⁺、欺诈防范 BadSpend%、现金流回撤 DD/Peak、运营效率¥/call、执行质量、长期学习、资产轨迹），首次实现对电商 agent 多维度能力的系统化量化对比。
3. **揭示大规模模型评测中的"幸存者偏差"与破产动力学**：指出 GPT-5.5 等模型均值曲线因破产样本被截断而虚线化上升，强调破产率是比平均收益更稳健的评估指标。
4. **发现工具调用分布的结构性非均衡性**：物流/推进/提现/库存占 71.8%，而供应商沟通仅 6.0%，调价类调用年均不足 3 次，揭示现有 agent 并未充分利用可改变价格的议价渠道。

## 方法详解
- **环境设计**：365 工作日模拟，Agent 扮演"Wang Wang"运营电商企业，目标为最大化年末总余额；初始资金 ¥100,000；最多同时开设 4 家门店（Beauty / Fashion / Appliance & Digital）。
- **资金三重桶结构**：Bank Account（银行）/ Platform Wallet（平台钱包）/ Escrow（托管，发货后 9 天结算），最早入账日为第 15 天，形成天然的现金流时序约束。
- **破产触发条件**：银行连续 10 个早晨余额为负即破产，该规则迫使模型必须维持最低运营缓冲。
- **七维评估指标**：
  - **CSE⁺（Buyer Surplus Retained）**：买方保留议价空间比例，衡量谈判质量。
  - **BadSpend%**：流向欺诈供应商的采购支出比例，衡量反欺诈能力。
  - **DD/Peak（Drawdown to Peak）**：峰值到谷底的最大回撤比例，衡量现金流稳健性。
  - **¥/tool call**：每工具调用产生的利润，衡量运营效率。
  - **Controllable pp / Natural pp / Realized % / On-time %**：分别衡量定价策略贡献、不可控退货因素、实际退货率、按时发货率。
- **记忆约束**：20 条目记忆存储，memory call 占约 2.1% 工具调用；系统消息 7,371 字符且不可 clear/evict，限制长期信息管理能力。
- **Counterpart 难度设置**：ExPRESIVE vs ADVERSARIAL 两种供应商类型，前者对中位 surplus 影响较小（差值 0.093），模型自身策略差异更大（0.215）。

## 实验与结果
- **数据集/评测规模**：18 个 LLM 模型 × 5 个独立 episode = 90 次完整运行（部分因破产提前截断）。
- **最强整体表现**：GPT-5.6 Sol 以最高均值资产领跑，但其与 Qwen3.5-Plus 差距达 **1,264 倍**。
- **破产模型**：90 局中共 **10 局破产**（6 局为闭源），其中 Qwen3.5-Plus 破产 4/5 局、GPT-5.5 破产 2/5 局、Claude Opus 4.6 破产 2/5 局、Gemini 3.1 Pro 破产 2/5 局，上述四者均损失超过峰值资产的 **一半**。
- **Qwen 代际跃迁**：Qwen3.7-Max 五年累计资产从 ¥6,290 飙升至 ¥358,790；其最差年度成绩仍低于所有 Qwen3.6-Plus 年度成绩。
- **谈判质量**：Claude Opus 4.7 CSE⁺ 最高（**0.811**），Kimi K2.6 最低（**0.596**）；12,060 局诚实会话中仅 73 局未成交，各模型成交率均 ≥96%，排名取决于成交额而非成交概率。
- **反欺诈**：Claude Opus 4.7 BadSpend 最优（欺诈支出仅 0.4±0.9 ¥k），Qwen3.5-Plus 最差；欺诈接触→下单转化率 Claude 仅 4.0%，GPT-5.6 Sol 为 31.7%。
- **现金流**：GLM 5.2 (high) 零透支、DD/Peak 最低（**0.127**）；Fable5 DD/Peak=0.141、DD 绝对值最小（¥114k）；Qwen3.5-Plus DD/Peak=**0.979**，最接近归零。
- **运营效率**：Fable5 每 tool call 赚 **¥479**，超越 GPT-5.6 Sol 的 ¥363，且调用量减少 **59.9%**；三款模型全年每调用亏损（最差 -¥92/call）。

## 相关工作脉络
- **与现有 Agent Benchmark 的关系**：本文区别于 WebArena、SWE-bench 等侧重短期任务完成的基准，聚焦**长 horizon（365 天）商业决策**，引入财务可持续性与破产风险作为核心评估维度。
- **与电商模拟研究的对比**：现有工作多关注单一供应链或定价任务，本文构建**多商户（4 店）、多品类（Beauty/Fashion/Digital）、多工具链**的综合环境，首次系统评测谈判-欺诈-现金流-运营的耦合效应。
- **与 LLM 多智能体经济评测的差异**：区别于仅评测对话能力或简单博弈的 work，本文引入**escrow 资金池机制**与**连续 10 天负余额破产规则**，使评测更接近真实商业约束。
- **与 OpenAI / Anthropic 内部评测的定位差异**：工业界常以单一财务指标（如 ROI）评测，本文提供**七维分解评估**，揭示"高效"（低调用）与"高利润"并非线性相关。
- **与记忆型 Agent 研究的关联**：本文固定 20 条目记忆上限与不可清除系统提示，为**长期记忆压缩策略**的研究提供了可复用的对比基线。

## 局限性与未来方向
- **仅覆盖中国电商平台语境**：环境规则（escrow 9 天、¥计价、Wang Wang 角色）反映特定平台生态，跨平台泛化性有待验证。
- **Counterpart 行为模式有限**：仅设 ExPRESIVE / ADVERSARIAL 两类供应商，缺乏更丰富的异构对手建模。
- **未评测工具调用成本**：当前工具调用无直接成本，与实际商业场景中 API 费用或人工成本脱钩。
- **破产截断带来的幸存者偏差**：部分模型因破产提前结束 episode，均值曲线虚线化可能高估其真实能力。
- **未来方向**：可扩展至多 Agent 竞争环境、引入动态市场价格波动、支持多平台跨域迁移评测。

## 研究启发与可借鉴点
- **七维评估框架可直接迁移**：CSE⁺（议价）、BadSpend%（风控）、DD/Peak（现金流）、¥/call（效率）四个量化指标可复用于其他商业 Agent 评测场景。
- **破产触发机制作为评估硬约束**：连续 N 天负余额破产的设计比单次收益均值更能揭示模型鲁棒性，值得引入金融 / 资源管理类 Agent 评测。
- **记忆上限约束模拟真实部署**：固定 20 条目记忆 + 不可清除系统提示的设置，为研究**长期记忆压缩与优先级管理**提供了可控实验条件。
- **工具调用分布分析揭示设计盲区**：调价类调用年均不足 3 次的发现，提示未来 agent 架构应强化议价工具的可用性与调度权重。
- **可与本团队方向结合**：若团队关注多智能体协同或供应链优化，可将本 benchmark 扩展为多 Agent 竞争环境，研究不同议价策略的纳什均衡。

## 关键术语表
- **E-Commerce-Bench**：论文提出的 365 天电商代理评测基准，支持 18+ 模型的多维度长期商业决策能力对比。
- **CSE⁺（Buyer Surplus Retained）**：买方保留议价空间的比例，衡量谈判质量的核心指标。
- **BadSpend%**：流向欺诈供应商的采购支出占总采购支出的比例，衡量反欺诈能力。
- **DD/Peak（Drawdown to Peak）**：资产从峰值到谷底的相对最大回撤比例，衡量现金流稳健性。
- **Escrow（托管资金）**：平台暂存的发货后资金，9 天结算期形成天然的现金流时序约束。
- **幸存者偏差（Survivorship Bias）**：破产 episode 被提前截断后，剩余 episode 均值虚高，导致模型真实能力被低估或高估的统计偏差。
- **Controllable pp / Natural pp**：分别指代理可直接调控的定价因素与不可控外部因素对利润的贡献百分点。
- **Wang Wang**：评测环境中 Agent 扮演的角色名，对应中国电商平台的典型商家身份。
