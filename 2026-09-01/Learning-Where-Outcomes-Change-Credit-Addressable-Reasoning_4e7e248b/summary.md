# 论文速读：Learning-Where-Outcomes-Change-Credit-Addressable-Reasoning

## 一句话总结
本文提出"信用可寻址推理"（credit-addressable reasoning）框架，通过Code-CoT将几何推理表示为可执行、行地址索引的代码事件，并结合CE-GRPO在共享前缀处分支采样，将终端结果差异转化为局部化优势信号，在九个几何基准上平均准确率达76.04，超越Qwen3-VL-8B基线8.09分。

## 研究问题与动机
1. **表征缺口（Representation Gap）**：自由形式推理轨迹中，决定性决策缺乏显式语义单元，关键视觉选择（如对象绑定、角度解读、辅助构造）被隐式处理。
2. **信用缺口（Credit Gap）**：轨迹级强化学习仅提供单一终端奖励信号，无法区分中间决策的个体贡献，导致错误假设难以被定位和纠正。
3. **现有方法局限**：程序辅助方法（如PAL、ToRA）暴露了推理结构但未将其作为优化单元；细粒度RL方法（如VinePPO、GPO）改进了更新位置，但仍依赖学习值或固定边界。
4. **代码作为共享语义单元的动机**：实验显示（Table 1），结合图像与外部生成代码（I+C） consistently优于单一模态，且自我生成代码差距达11.7–16.6分，表明可靠代码生成是关键瓶颈。

## 核心贡献（创新点）
1. **提出信用可寻址推理原则**：推理时暴露的语义单元直接定义优化时比较替代方案和分配信用的位置，实现了表征与优化的协同设计。
2. **Code-CoT表示框架**：将视觉感知表示为可执行Matplotlib代码，组织推理为四种类型事件（reference、auxiliary、coordinate、think），使每个事件既是可验证的几何操作，也是可寻址的信用单元。
3. **CE-GRPO局部化信用分配**：通过结构先验和类型归一化熵选择候选事件，在共享前缀处分支完整续写，将终端结果差异转化为事件条件优势，无需过程标注或辅助价值模型。
4. **系统级验证**：在九个几何基准上实现76.04平均准确率，相对轨迹级GRPO提升3.43分，且优势随中间事件数增加而扩大（每事件+3.77分，r=0.866）。

## 方法详解
**Code-CoT协议**（Section 4.2）：
- 响应结构：Y = [C, P, (e_l)_{l=1}^L, F]，其中C为行地址索引的可执行感知代码，P为解决方案计划，e_l为类型事件，F为最终答案。
- 四种事件类型：
  - **reference**：检索支持图示事实的代码行
  - **auxiliary**：扩展工作几何（添加线、点、圆等）
  - **coordinate**：建立可执行坐标系
  - **think**：对当前状态进行推理

**CE-GRPO算法**（Section 4.4）：
1. **候选事件选择**：结合结构先验（几何根植的think/action事件）与类型归一化熵 η(e) = (H̄(e) - μ_κ) / σ_κ，其中κ为事件类型。
2. **共享前缀分支**：对候选事件e_c，保留前缀z_c = y_{<s_c}，固定图像、问题和前缀，采样G个完整续写：u^(j) ~ π_θ(·|x, z_c)。
3. **局部优势计算**：A_{z_c}^{(j)} = (R(x, z_c ⊕ u^{(j)}) - R̄_{z_c}) / (σ_{R,z_c} + δ)，仅更新重生成事件及其下游后果。
4. **混合优化**：普通提示与共享前缀提示按1:1混合，共享相同程序化奖励和裁剪GRPO目标。

**程序化奖励函数**（Eq. 2）：
R(x,y) = clip(c(y) + 0.3·r_act(y) - Ω(y), -1, 1.3)，其中c(y)为答案正确性，r_act(y)为动作有效性比率，Ω(y)为重复和答案泄漏惩罚。

## 实验与结果
**数据集**：九个几何基准，涵盖：
- 视觉定位：MathVerse（5个子集）、VisOnlyQA-Syn/Real、MathVista-GPS
- 平面几何：Geometry3K、PGPS9K、GeoQA
- 辅助构造：GeoLaux-mini
- 过程级推理：MM-Math

**主要结果**（Table 2）：
- CE-GRPO平均准确率：**76.04**
- 超越Qwen3-VL-8B基线：**+8.09分**
- 超越Code-CoT SFT：**+6.49分**
- 超越轨迹级GRPO：**+3.43分**
- 在全部九个基准上均超过基线模型

**关键发现**：
- 依赖中间步骤的推理（GeoLaux-mini +15.16分，MM-Math +9.44分）获益最大
- 单模型调用超越两阶段系统GDP-4B-RL→Qwen3-VL-8B（+3.07分平均）
- 有效终止响应的准确度提升3.91分（Table 6），证明改善的是解质量而非协议合规性
- 视觉依赖变体（VO）提升15.10分，TD-VO差距从30.07降至14.09（Table 7）
- 选择器离线验证：结构选择比随机选择识别结果变化事件多30.2%（Table 14）

## 相关工作脉络
1. **程序辅助推理**（PAL、ToRA）：将推理表达为可执行程序，但未将代码作为优化单元；CE-GRPO将代码集成到策略优化中。
2. **形式几何系统**（AlphaGeometry、GeoTikzBridge）：将几何关系转换为形式语言，需要外部符号求解器；本文方法无需外部求解器，通过可执行代码实现验证。
3. **细粒度信用分配**（VinePPO、GPO、GRPO-MA）：估计中间状态/段的优势，但依赖学习值或固定边界；CE-GRPO通过事件边界和终端结果差异实现无标注信用分配。
4. **SRPO/CFPO**：利用自重置或反事实策略优化；本文的独特之处在于使用结构化事件边界而非启发式步骤检测器。
5. **多模态几何推理**（MathVerse、VisOnlyQA）：揭示VLMs在视觉感知上的弱点；本文通过代码-图像互补和训练缩小模态差距。

## 局限性与未来方向
1. **代码生成质量依赖**：自我生成代码仍落后于外部生成11.7–16.6分，代码生成可靠性是主要瓶颈。
2. **事件选择器的近似性**：当前使用熵和结构先验的启发式选择，非最优的事件定位。
3. **任务领域限制**：方法针对几何推理验证，在其他多模态推理任务（如科学图表、流程图）上的泛化性待验证。
4. **计算开销**：共享前缀分支需要多次完整续写采样，增加训练成本。
5. **未来方向**：可探索更通用的结构化表示、自适应事件选择策略、以及跨模态推理任务的迁移应用。

## 研究启发与可借鉴点
1. **表征-优化协同设计**：将推理时的语义单元直接映射为优化时的信用单元，为长程依赖推理提供了有效范式，可迁移至其他需要多步推理的任务（如代码生成、科学推理）。
2. **共享前缀分支技术**：无需过程标注即可实现局部化信用分配，通过固定前缀和采样续写比较终端结果，避免了额外价值模型的训练开销。
3. **程序化奖励设计**：结合答案正确性、动作有效性比率和行为惩罚的多维度奖励，比二元正确/错误信号提供更细粒度的学习信号。
4. **事件类型化协议**：将推理分解为可验证的类型化事件（reference/auxiliary/coordinate/think），增强了可解释性和可调试性。
5. **模态互补训练**：代码与图像互补而非替代的设计思路，以及通过训练缩小模态差距的策略，对多模态表示学习有借鉴价值。

## 关键术语表
**Credit-addressable reasoning**：推理时暴露的语义单元直接定义优化时比较替代方案和分配信用的位置，实现表征与优化的统一。
**Code-CoT**：将视觉感知表示为可执行、行地址索引的Matplotlib代码，并组织推理为类型化事件的推理框架。
**CE-GRPO**：Critical-Event Group Relative Policy Optimization，在共享事件前缀处分支采样完整续写，将终端结果差异转化为事件条件优势的强化学习算法。
**Programmatic reward**：基于程序化检查的奖励函数，综合答案正确性、动作有效性比率和行为惩罚，无需学习奖励模型。
**Type-normalized entropy**：对事件类型内的平均token熵进行标准化，用于在可比事件间分配分支预算。
**Shared-prefix branching**：固定图像、问题和完整前缀，从事件边界采样多个完整续写以评估局部决策质量的技术。
**Auxiliary construction**：在几何问题中添加辅助线、点或圆的构造操作，是几何推理中的关键步骤。
**Modality gap**：文本主导与纯视觉输入之间的性能差距，Code-CoT训练可显著缩小此差距。
