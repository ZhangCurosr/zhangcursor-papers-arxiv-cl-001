# 论文速读：Reactivating-Test-Time-Scaling-for-Plane-Geometry-Problem-So

## 一句话总结
本文针对多模态大语言模型（MLLM）在平面几何问题（PGP）求解中测试时扩展（TTS）效果不佳的问题，提出**多轨迹综合（MTS）**框架将符号程序转化为异构推理轨迹，并引入**感知增强（PA）训练**强化视觉到符号的映射；实验表明，该方案能显著激活 TTS 的收益，并在计算成本上取得更优的帕累托权衡。

## 研究问题与动机
1. **测试时扩展（TTS）在 PGP 求解中失效**：尽管自一致性（SC）在通用数学推理中表现优异，但在平面几何问题上，由于推理空间受限且缺乏显式视觉 grounding，采样轨迹难以汇聚多数共识，导致 TTS 收益有限。
2. **推理多样性不足**：现有 PGP 数据集严重依赖刚性符号程序（symbolic programs），缺乏自然语言推理所需的中步思维，难以探索多样化的解题路径。
3. **视觉感知到符号推理的鸿沟**：模型在符号化推理前往往误解图示（如将 $101°$ 误读为 $104°$），导致后续演绎错误，而现有方法缺乏明确的视觉解析步骤。
4. **计算效率瓶颈**：直接扩大采样预算会引入冗余，尤其对简单问题，缺乏自适应推理机制以实现精度与成本的平衡。

## 核心贡献（创新点）
1. **提出多轨迹综合（MTS）框架**：将刚性符号程序转化为可执行的 Python 脚本（PAL）及 CoT 增强变体，重新引入中间推理环节，从而激活 TTS 在 PGP 求解中的扩展效应。与仅依赖单一符号程序的现有方法本质不同，本工作通过异构轨迹混合大幅提升推理多样性。
2. **设计感知增强（PA）训练范式**：强制模型在推理前先解析图示为结构化语义子句（semantic clauses），实现视觉到符号的显式对齐。与直接程序预测方法相比，PA 训练显著降低了视觉误解引发的演绎错误。
3. **提出共识引导的多轨迹集成（CG-MTE）推理策略**：通过跨轨迹浅层共识检查实现自适应扩展预算，在无需额外超参数的情况下，以更低采样成本达到与高预算自一致性相当的精度。与标准多轨迹集成（MTE）相比，CG-MTE 更注重帕累托效率而非单纯追求精度上限。
4. **构建并开源 MTS-All 数据集与代码**：基于 PGPS9K、Geometry3K 和 GeoQA 三大基准，通过 MTS 框架构建了规模扩充的训练集（约 32.1K、33.7K、13.9K 样本），并将代码与数据公开，促进后续研究。

## 方法详解
- **多轨迹综合（MTS）**：从实例化后的符号程序出发，经过两条路径生成异构轨迹：
  - **程序到 PAL 转换**：采用基于规则的翻译（环境初始化、方程构建、方程求解、后处理）并结合执行验证（容差 $\epsilon=0.001$），生成可执行 Python 脚本（PAL）。
  - **CoT 增强**：对 PAL 和原始程序分别通过 MLLM 重写，生成带自然语言推理步骤的 **CoT-PAL**（生成-验证循环，最多 3 次）和 **CoT-Program**（仅语言解释，不可直接执行）。最终训练数据混合四种轨迹：Program、PAL、CoT-Program、CoT-PAL。
- **感知增强（PA）训练**：将求解过程建模为两阶段自回归生成：首先生成视觉语义子句 $S$，再基于 $S$ 生成推理轨迹 $T$。联合损失函数为：
  $$\mathcal{L} = -\log P_\theta(S|D,Q) - \log P_\theta(T|S,D,Q) = \mathcal{L}_{\text{perc}} + \mathcal{L}_{\text{reason}}$$
  其中 $\mathcal{L}_{\text{perc}}$ 优化视觉解析，$\mathcal{L}_{\text{reason}}$ 优化条件推理。
- **推理策略**：
  - **自一致性（SC）**：在统一模型上生成 $K$ 条候选轨迹，执行后取多数投票答案。
  - **多轨迹集成（MTE）**：对每种轨迹类型独立采样，分别生成 top-$D$ 候选，合并后投票。
  - **共识引导多轨迹集成（CG-MTE）**：从浅层深度 $d=1$ 开始逐步扩展，在各深度合并所有轨迹类型的 top-$d$ 答案并检查唯一众数；一旦达成共识则提前终止，否则继续扩展至 $d=D$；若仍无共识，回退到 CoT-PAL 的 top-1 输出。计算成本用平均采样数（ASN）衡量：$ASN_{\text{Std}}=VD$，$ASN_{\text{CG}}=\frac{V}{|\mathcal{T}|}\sum d_x$。

## 实验与结果
- **数据集**：PGPS9K（训练 8,021）、Geometry3K（训练 8,432）、GeoQA（训练 3,485）；经 MTS 扩展后训练集规模分别增至 32.1K、33.7K、13.9K。
- **评估基线**：通用 MLLMs（GPT‑4V、Claude 3.5 Sonnet、Qwen2.5‑VL‑7B/72B）、神经几何求解器（NGS、Geoformer、PGPSNet、LANS、GeoX）、神经符号求解器（InterGPS、GeoDRL、Pi‑GPS）。
- **主结果**：在 PGPS9K 上，微调后的 Qwen3‑VL‑8B（PA 训练于 MTS‑All）以贪心解码达到 **71.2%** 准确率，较直接程序预测基线（58.6%）提升 **+12.6%**；使用 beam search 自一致性（K=40）进一步提升至 **76.7%**。CG‑MTE 仅需平均 **4.89** 次采样即达到 **76.0%** 准确率，与高预算自一致性相当，但采样成本降低高达 **8×**。
- **跨模型规模一致性**：在 2B、3B、8B 模型上均获得稳定提升（PGPS9K 上绝对增益 7.4%–12.6%），且在内参 VL3.5 等外部模型上验证了框架泛化性。

## 相关工作脉络
1. **神经符号几何求解器**（如 InterGPS、GeoDRL、Pi‑GPS）：侧重将图示解析为形式语言后由符号引擎演绎，对解析误差敏感；本文聚焦通过多样化轨迹与自适应 TTS 提升 MLLM 的几何推理，不依赖外部符号求解器。
2. **神经几何求解器**（如 NGS、Geoformer、LANS、GeoX）：端到端从多模态输入预测解程序；本文在此基础上引入多轨迹混合与感知增强，弥补单一程序表示下的推理多样性不足。
3. **程序辅助推理**（PAL 范式）：将问题转化为可执行代码；本文将其扩展至几何领域，并进一步合成 CoT 增强版本，使轨迹兼具可执行性与自然语言可解释性。
4. **几何数据合成**（如 Alpha‑Geometry、GeoFM、GeoThought）：通过形式约束或教师模型生成新问题/新轨迹；本文**不合成新问题**，而是从已有验证过的形式程序出发，通过格式转换与论证增强派生异构轨迹，在保持形式严谨性的同时提升多样性。
5. **测试时扩展（TTS）**：包括自一致性、多轨迹集成等；本文揭示 TTS 在 PGP 领域失效的根本原因，并提出 MTS+CG‑MTE 的组合以重新激活 TTS 收益并优化计算效率。

## 局限性与未来方向
1. **依赖结构化标注**：MTS 需要可靠的形式化解程序，PA 训练需要语义子句标注，限制了方法在未标注数据上的直接应用。未来需探索替代性推理种子或更弱的结构化中间表示。
2. **局限于 2D 平面几何**：仅验证于 PGPS9K、Geometry3K、GeoQA 三个二维基准；扩展至 3D 几何、物理或其他多模态推理任务的有效性尚待检验。
3. **执行验证无法保证语言推理的语义忠实性**：CoT 增强的轨迹可能存在自然语言解释与形式步骤不对齐的情况（幻觉），需引入更严格的语义验证机制。

## 研究启发与可借鉴点
1. **轨迹混合促进测试时扩展**：将刚性符号程序转化为可执行代码及 CoT 增强变体，可有效增加推理空间多样性，该思路可迁移至其他符号密集型任务（如代数、逻辑推理）。
2. **感知先行两阶段训练**：通过显式视觉解析子句再推理的两阶段联合损失（PA 训练）可显著减少视觉误解引发的演绎错误，适用于任何需要图表理解的任务。
3. **共识引导的自适应推理**：CG‑MTE 通过浅层共识检查实现动态预算分配，避免了均匀采样的浪费，该自适应策略可推广至其他多轨迹集成场景。
4. **翻译‑重写‑验证流水线**：CoT‑PAL 采用“基于规则翻译→MLLM 重写→执行验证”三步流水线，兼顾轨迹的可执行性与语言丰富性，为合成高质量推理轨迹提供了可复用的工程范式。

## 关键术语表
- **测试时扩展（Test‑Time Scaling, TTS）**：在推理阶段通过增加采样预算（如多次采样并聚合）提升模型推理性能的技术。
- **平面几何问题（Plane Geometry Problem, PGP）**：要求同时理解几何图示与文本描述、进行多步演绎推理的数学问题。
- **多轨迹综合（Multi‑Trace Synthesis, MTS）**：将单个符号程序转换为多种异构推理轨迹（程序、Python 脚本、带 CoT 的版本）的数据增强框架。
- **感知增强训练（Perception‑Augmented Training, PA）**：强制模型首先生成结构化视觉语义子句，再以此条件生成推理轨迹的训练范式。
- **共识引导多轨迹集成（Consensus‑Guided Multi‑Trace Ensemble, CG‑MTE）**：按浅层到深层逐步检查跨轨迹共识，提前终止以减少冗余采样的自适应推理策略。
- **程序辅助语言（Program‑Aided Language, PAL）**：让模型生成可执行代码（通常为 Python）来求解问题的范式。

## 可复现要素
- **数据集**：PGPS9K、Geometry3K、GeoQA（均公开）；经 MTS 处理后的 MTS‑All 数据集已随代码开源。
- **代码与权重**：代码与数据已公开于 https://github.com/Jason8Kang/ReTTS-PGPS。
- **关键超参数**：学习率（2B/3B 模型 $2\times10^{-5}$，8B 模型 $5\times10^{-6}$）；训练轮数 10；最大序列长度 1024 tokens；CoT‑PAL 生成最多重试 3 次；验证容差 $\epsilon=0.001$；自一致性采样预算 $K=40$；多轨迹集成每种轨迹类型 top‑$D$ ($D=10$)。
