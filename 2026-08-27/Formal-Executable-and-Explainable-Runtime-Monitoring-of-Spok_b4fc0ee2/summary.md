# 论文速读：Formal-Executable-and-Explainable-Runtime-Monitoring-of-Spok

## 一句话总结
本文提出了一套形式化、可执行且可解释的空中交通管制（ATC）语音程序运行时监控框架。该框架将飞行员与管制员的无线电通话解析为实体关联的操作事件，与 ADS-B 监视数据融合为带时间戳的执行轨迹，并通过度量时序逻辑公式进行自动验证，最终输出与违规义务及支撑证据绑定的裁决结果。

## 研究问题与动机
- **核心问题**：ATC 安全依赖于管制员与飞行员的语音交互，但判断指令是否被执行不能仅凭 transcript，必须结合被指定航空器、其实时状态、系统观测及时序约束进行多源推理。
- **现有方法不足**：
  1. **监督类方法**（如轨迹合规监控）缺乏对语音交互的 grounding，无法识别指令级程序偏差，R1/R2 未覆盖。
  2. **语音类方法**（如回读错误检测）止步于字面比对，未延伸至实际飞行动作与状态一致性验证，R2/R3/R4 仅部分满足。
  3. **通用运行时验证（RV）方法**假设轨迹已给定，缺乏从异构数据自动构建轨迹的 pipeline，且裁决多为公式级证明，未与底层观测事实绑定提供可解释证据（R4 未满足）。
  4. **运营压力**：全球航班量持续增长而 staffing 受限，人工持续执行多源、时序、义务追踪检查已难以满足实时性要求。

## 核心贡献（创新点）
- **首个 ATC 义务度量时序逻辑形式化体系**：基于 ICAO Doc 4444 规范，将管制指令、飞行员回读、跑道授权、TCAS 警告等程序义务编码为带显式时间界限与优先级的 temporal 公式族，填补了控制器/飞行员义务形式化描述的空白。
- **端到端异构数据自动轨迹构建流水线**：打通“语音采集 → ASR 转录 → LLM 结构化解析 → 呼号消歧与状态解码 → 时序轨迹组装”的全链路，实现多源观测的自动对齐与融合。
- **支持三值语义的在线/离线双模验证框架**：在有限轨迹语义下引入 RV 的三值逻辑（true/false/inconclusive），保障开放轨迹下不提前误报，同时为每条违规返回触发位置与支撑命题，实现可解释裁决。
- **真实场景与历史空难的双重验证**：在真实航空气象数据上达到 F1=0.85，在 1,495 个合成违规场景上实现 100% 正确率；成功复现 Uberlingen（2002）与 Comair 5191（2006）两起历史事故中的程序偏差，并在撞击前 29~31 秒发出预警。
