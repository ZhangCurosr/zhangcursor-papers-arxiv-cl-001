# 论文速读：PlanSightRAG-A-Visual-First-Multimodal-RAG-for-Automating-Qu

## 一句话总结
本文提出 PlanSightRAG，一种视觉优先的多模态 RAG 框架，直接对土木工程标准图纸图像进行多向量检索与 VLM 推理，完全绕开 OCR；在五州 DOT 基准上实现 91.47% Recall@5，并首次演示了在不依赖人工注入规则的情况下，通过视觉检索与解析规范图集自动提取数值阈值完成合规性审计的闭环。

## 研究问题与动机
- 现有合规审查依赖工程师手动阅读老旧二维标准计划，传统 OCR/RAG 管线将图纸线性化为 token bag 后，会丢失尺寸链、几何布局、剖面符号与跨视图引用等核心语义，导致文本检索器召回率极低（如 BGE-M3+OCR 仅 36.79% Recall@5）。
- 通用 VLM 虽在自然图像与结构化文档上表现优异，但在密集、多视图、符号语义复杂的工程图纸上仍存在幻觉敏感、空间绑定错误与跨页推理断裂等问题，且现有工作多聚焦单图问答，缺乏面向大规模图纸档案的可扩展检索与可审计推理能力。
- 视觉优先检索（如 ColPali/ColNomic）虽能保留空间对齐，但尚未与下游推理层整合为端到端的工程合规审计流水线；同时领域内缺乏大规模、对抗性基准与可证伪的评估假设。
- 真实合规检查的难点不仅在于“找图”，更在于“确定哪条规则适用及其数值阈值”。现有系统通常假定规则库已人工数字化，无法处理从零散规范文集中自动发现并应用限制值的问题。

## 核心贡献（创新点）
1. **视觉优先的多向量检索框架与 Five-DOT 基准**：采用 ColNomic-3B 对图纸进行高分辨率瓦片化索引，零样本即达 91.47% Recall@5，从根本上绕开了 OCR 导致的几何信息丢失。*与已有工作本质区别：不同于传统文本/混合 RAG，检索层直接“看见”图纸，保留空间邻域与跨视图引用关系，而非将空间信号压缩为全局向量或 token 序列。*
2. **带证据溯源的 Agentic 合规审计管线**：设计 Planner–Retriever–Auditor–Synthesizer 四模块流水线，结合锐化
