# 论文速读：MathAdv-What-Theorem-Provers-Know-Reason-Formalize-and-Gener

## 一句话总结
论文提出了 MathAdv，一个涵盖13个本科/研究生数学领域、包含321道题的 Lean 4 形式化定理证明诊断基准，通过填空、多选与等价变换三类辅助任务解耦评估数学知识、非形式化推理、形式化构建与重表述鲁棒性，并系统揭示了当前定理证明模型存在的“形式化瓶颈”、领域表现极化、自然语言提示对专用模型的负迁移，以及对等价变换高度脆弱等关键局限性。

## 研究问题与动机
1. **聚合指标掩盖真实能力边界**：现有基准仅报告端到端证明通过率，无法区分失败源于知识盲区、推理缺陷还是将自然语言映射为 Lean 代码的形式化障碍。
2. **数学领域覆盖严重倾斜**：主流评测高度依赖竞赛数学（代数、数论），对拓扑、傅里叶分析、泛函分析、逻辑等高级领域几乎空白，难以刻画模型在广义数学推理上的能力。
3. **缺乏鲁棒性与泛化检验**：现有评测固定题面，无法判断模型是掌握底层数学结构，还是依赖表层词汇模式与训练集记忆，尤其在数据污染风险日益增高的背景下更为关键。
4. **形式化自动化翻译的可靠性瓶颈**：纯 LLM 难以同时保证 Lean 代码的类型正确性与数学语义忠实性，且 Mathlib 库在高阶领域存在结构性缺失，亟需可控的人机协作流水线。

## 核心贡献（创新点）
1. **构建多域多维度诊断基准 MathAdv**：覆盖13个数学分支，提供298个可编译 Lean 4 命题及配套的填空、多选、等价变换辅助任务，与以往单一 pass@K 指标的基准形成本质区别。
2. **提出组件级能力解耦评测框架**：将定理证明拆分为数学知识储备、非形式化求解、形式化构建、等价变换鲁棒性四个正交维度，使得 failure mode 定位从“黑盒通过率”转向“白盒归因”。
3. **设计“LLM草稿+编译器迭代纠错+双路语义验证+专家终审”的形式化流水线**：明确分工——编译器负责类型检查，LLM 负责语义对齐，专家负责库缺口决策，有效克服了纯自动生成不可靠的问题。
4. **首次系统性刻画当代定理证明器的能力图谱与失效规律**：实证揭示形式化翻译是主要瓶颈、领域表现极化、自然语言提示存在模型依赖性（对专用模型有害），以及等价变换鲁棒性普遍缺失四大规律。

## 方法详解
- **题目来源与分布**：321道题源自教材与领域专家贡献，覆盖 Number Theory(10), Linear Algebra(20), Abstract Algebra(12), Calculus(26), Real/Complex/Fourier/Functional Analysis, Probability(36), Topology(25), Geometry(25), Combinatorics(23), Logic(26)。其中298道完成 Lean 4 形式化，其余23道因 Mathlib 支持不足暂留作辅助评估。
- **三类辅助诊断任务**：
  - **直接回答/填空（Direct-answer）**：要求模型仅输出最终数值或表达式，隔离非形式化求解能力（共81道）。
  - **多项选择（Multiple-choice）**：考察题目背后的核心定理/证明策略，排除纯计算题后共293道。
  - **专家构造的等价变换（Transformed）**：共30道，保持底层数学结构不变但大幅改写表述，检验跨表征一致性。
- **人机协作形式化流水线**：
  1. *Initial Autoformalization*：LLM 按指定 Prompt 生成 Lean 4 草稿，强制优先引用 Mathlib 命名空间。
  2. *Syntax Correction*：将 Lean 编译器报错反馈给 LLM 循环迭代，直至通过类型检查。
  3. *Dual Semantic Verification*：独立 LLM 评估器与人类专家交叉核查形式化命题是否忠实于原题数学含义。
  4. *Final Expert Review*：第二位专家终审，针对 Mathlib 未覆盖概念评估可行编码方案，必要时延期形式化。
- **评测协议**：区分证明步生成模型（需与 Verifier 交互搜索）与全证明生成模型（pass@K 评估）。统一设置单轮最大 token 8192；交互实验采用最多 T 轮追加编译器错误信息，总预算 K=N×T（如 16×3）。

## 实验与结果
- **形式化证明性能（Table 1）**：整体准确率有限。Goedel-Prover-V2 以 **21.88%** 领先，其次为 DeepSeek-Prover-V1.5 RL + RMaxTS (**16.56%**)。Base 版仅 **1.25%**，经 SFT/RL 分别提升至 9.06%/11.25%，结合 RMaxTS 搜索后达 16.56%，印证 verifier 引导搜索在稀疏奖励环境中的核心价值。通用大模型（GPT-5.4 10.62%, DeepSeek-R1 10.94%）表现低于专用证明器。
- **领域分布差异**：模型在 Number Theory 与 Linear Algebra 表现最佳（Goedel-V2 分别达 70.0% 与 65.0%），但在 Topology 上所有模型均为 **0%**，反映训练语料偏向竞赛数学且高级领域 Mathlib 基础设施薄弱。
