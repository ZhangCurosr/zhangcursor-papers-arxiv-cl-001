# 论文速读：ℛ³: Training Robots to Reason in Natural Language via Reinforcement Learning

## 一句话总结
本文提出 ℛ³，一种两阶段后训练方法，将现成的视觉语言模型（VLM）转化为能在测试时为低层操作策略提供自由自然语言推理指导的机器人推理器；通过中期训练模仿专家推理风格，再利用基于 rubric 的单步强化学习从离线纯指令数据中进一步优化，显著提升了长视距操作任务的探索与泛化能力。

## 研究问题与动机
- 现有机器人操作策略多使用结构化中间表示（如边界框、子目标图像）或仅在训练时以推理作为辅助监督，但测试时并不生成自由语言推理，因而未将推理作为额外的测试时计算机制。
- 自由自然语言推理在视觉问答等静态任务上已被证明有助于分解、约束跟踪与预测，但在需要跟踪部分进展、推理物体关系、从错误恢复并引导含噪声低层策略的长视距机器人操作中，其作用与学习方法尚不明确。
- 现有方法要么依赖手工设计的中间表示，要么仅使用结构化思维链（CoT）作为训练信号，缺乏训练 VLM 直接生成自由语言推理来指导固定低层策略的通用后训练方案。
- 如何以可控的实验设置系统研究机器人推理的关键设计选择（数据收集、历史条件、初始化、RL 形式），并为开放世界操作提供可扩展的推理训练 recipe。

## 核心贡献（创新点）
1. **提出两阶段后训练 recipe（ℛ³）**：先用专家推理轨迹对现成 VLM 进行中训练以初始化推理风格，再用基于 rubric 的单步 RL 从仅含指令的离线数据中进一步优化；与仅使用结构化 CoT 作为辅助训练信号的工作本质不同，本文训练的是可用于测试时引导操作的自由语言推理。
2. **将自由自然语言推理作为测试时计算机制**：证明推理不仅改善表示学习，而且在推理阶段显式生成语言推理能带来额外的泛化收益；与仅把推理作为训练时监督信号的方法相比，推理在测试时的预算增加可因果提升任务成功率。
3. **设计基于 rubric 的 VLM-as-a-judge 单步 RL 奖励**：在不进行昂贵多轮机器人 rollout 的前提下，利用 VLM 裁判根据语义匹配与可行性规则给出标量奖励，并结合长度惩罚避免退化推理；区别于直接字符串匹配或需要多步在线 credit assignment 的方法。
4. **系统揭示机器人推理行为学习与设计选择**：通过消融与诊断表明，历史上下文显著提升推理质量，中训练对齐指令分布并稳定接口，单步 RL 在此基础上精炼为更审慎的行动导向规划；结构化 ECoT 元素在长视距闭环任务中并未带来额外收益。

## 方法详解
- **分层架构**：高层 VLM π_θ(z_t, u_t | x_t, g) 基于场景图像、长视距目标 g 与交互历史 x_t 生成自由语言推理 z_t 与短视距指令 u_t；固定低层策略 π_lo(a_t | s_t, u_t) 执行动作块。
- **Stage I 中训练（Mid-training）**：使用专家 reasoner（如 Gemini 3 Flash）在收集轨迹时同步生成的推理轨迹 z_t 与指令 u_t 构建目标序列 y_t = (z_t, u_t)，以标准 next-token prediction 进行 SFT：  
  L_SFT(θ) = −E[log p_θ(y_{t,i} | x_t, y_{t,<i})]。  
  训练包含成功与失败轨迹，以初始化跟踪进展、物体关系与纠错的推理风格。
- **Stage II 单步 RL（Rubric-based）**：在无推理标签的离线数据上，对同一上下文 x_t 采样 K 个响应 {(z_t^(k), u_t^(k))}，由 VLM 裁判根据 rubric 计算奖励 R^(k)，采用 Dr.GRPO 优化策略梯度损失：  
  L_GRPO(θ) = −E[min(ρ_t^(k)A^(k), clip(ρ_t^(k),1−ε,1+ε)A^(k))]，  
  其中 ρ 为重要性采样比，A^(k) 为组内归一化优势。奖励包含指令语义匹配分与长度惩罚（鼓励不低于 T 词）。
- **关键实现选择**：RL 阶段通过采样中训练模型的历史响应进行推理上下文补全；过滤重复指令以避免 reward shortcut；Language Table 使用 VLM 裁判（Qwen3.5-35B-A3B）进行语义匹配评分，杂货打包使用精确字符串匹配奖励。

## 实验与结果
- **数据集/环境**：Language Table（14 种长视距积木排列任务，6 个中训练任务 T_M、3 个 RL 任务 T_R、5 个 OOD 任务 T_O）与双臂模拟杂货打包任务（12 个未见配置）。
- **基线**：基础 VLM（Qwen3.5-4B）、指令仅模仿学习（IL mid only / IL）、仅中训练 ℛ³(mid only)、仅 RL ℛ³(RL only)、1/4 中训练 ℛ³(1/4th mid)、结构化 ECoT 变体等。
- **主要结果**：
  - Language Table：ℛ³ 在 T_M 与 T_R 任务上全面优于 IL 与基础模型，OOD 任务提升显著，如 diag_line +14.2%、mid +8.7%、iL +9.9%；group 达 65.8%（IL 64.7%）、iV 达 57.5%（IL 38.9%）。
  - 消融表明 RL  alone 即可提升，中训练提供更强先验并改善 OOD；仅 1/4 中训练数据在 OOD 上与全量相当。
  - 推理预算干预显示，截断或移除推理均显著降低成功率，证明测试时推理的贡献。
  - 杂货打包：ℛ³(RL only) 平均成功率 47.9%，高于 IL 的 38.0% 与基础 19.7%，归一化进度 73.1% vs 65.4%。
- **结论**：自由语言推理可作为有效的测试时计算机制，显著提升长视距操作与泛化；中训练初始化风格、单步 RL 精炼行为。

## 相关工作脉络
1. **Embodied CoT / ECoT**：使用视觉中心结构化 CoT（含边界框、坐标）作为推理监督；本文证明在长视距闭环任务中自由语言推理优于追加结构化元素，且推理在测试时的使用带来额外收益。
2. **训练时推理监督为主的方法**：如 Chen et al. 指出推理主要 benefit 来自训练时表示改进；本文通过预算干预与跨变体比较表明显式测试时推理具有因果贡献。
3. **高层语言/计划引导策略**（SayCan、Inner Monologue、SARL、SteerVLA）：多依赖符号分解、固定语义接口或在线 RL 学习语言策略；本文聚焦于 VLM 自由推理本身的训练与 test-time compute 机制。
4. **通用 VLA/机器人策略**（RT-2、Octo、OpenVLA、GR00T 等）：使用互联网预训练 VLM 骨干但缺乏显式推理；本文在此基础上引入后训练 pipeline 赋予推理能力。
5. ** hierarchical 操作与任务-运动规划**：传统方法使用手工结构、潜变量计划或预测性表示；本文保持低层策略冻结，通过语言推理高层引导，强调可解释性与泛化。
6. **Web/代码 agent 的在线推理与反思**：强调工具调用与反馈修正；本文借鉴单步 RL 思想但面向具身长视距操作，并使用 offline 数据与 rubric 奖励降低在线 rollout 成本。

## 局限性与未来方向
- **仿真局限**：实验仅在 Language Table 与模拟杂货打包两个仿真环境中进行，尚未在真实机器人上验证。
- **代理目标**：Stage I 依赖专家推理轨迹生成，Stage II 依赖 VLM 裁判作为语义奖励，优化的是最终任务成功的代理目标。
- **单步离线 RL**：当前避免多轮在线交互，credit assignment 受限；未来可扩展为多轮在线 RL，利用任务完成、中间进展与人类偏好信号。
- **高层-低层解耦**：固定低层策略可能引入意图与执行的错位；未来可联合训练推理与动作预测，并研究推理对低层动作生成的支持。
- **探索与适应**：当前主要利用离线数据；未来可利用自由推理支持更广泛的探索，适应新 embodiment、新物体与训练未见的失败模式。

## 研究启发与可借鉴点
- **两阶段后训练范式**：mid-training 初始化期望行为风格 + 单步 RL 精炼的策略，可迁移到需要测试时计算的视觉-语言-动作或其他分层决策系统中。
- **VLM-as-a-judge 的 rubric 奖励设计**：在缺乏精确环境回报但存在可判定的语义等价性时，可用结构化 rubric 的 VLM 裁判作为训练信号，减少对昂贵 rollouts 的依赖。
- **历史交互上下文的重要性**：将上一完整响应纳入上下文可显著提升长视距任务表现，提示在构建推理 agent 时应保留并显式利用交互历史。
- **推理预算的可控干预**：通过截断/延长推理 token 数量可直接衡量 test-time compute 的贡献，为后续研究测试时缩放提供诊断工具。
- **自由形式 vs 结构化 CoT 的权衡**：在需要闭环纠错与长期规划的具身任务中，自由语言推理可能比附加的视觉结构化标注更有效，可启发后续架构选择。

## 关键术语表
- **VLM（Vision-Language Model）**：融合视觉与语言能力的预训练模型，本文作为高层推理器生成自然语言推理与指令。
- **Chain-of-Thought（CoT）/ 自由语言推理**：模型在输出最终动作指令前生成的解释性文本；本文强调无需固定模板的自由形式推理。
- **Mid-training（中期训练）**：在预训练模型之后、RL 之前的监督微调阶段，用于注入特定领域推理风格与行为先验。
- **Rubric-based VLM judge**：根据预设评分规则（rubric）评估模型输出与参考指令之间语义匹配程度的大型 VLM 裁判。
- **Single-step RL**：在单个时间步上基于离线数据进行策略优化，避免长视距多步 online rollout 的高成本。
- **Dr.GRPO**：一种基于组内归一化优势的策略梯度优化算法，用于本文 RL 阶段的策略更新。
- **Test-time compute**：在推理阶段额外投入的计算资源（如生成长推理链），用于提升复杂问题的解决能力。
- **OOD（Out-of-Distribution）泛化**：模型在未见过的任务或场景上的表现能力，本文重点评估推理训练带来的分布外提升。
