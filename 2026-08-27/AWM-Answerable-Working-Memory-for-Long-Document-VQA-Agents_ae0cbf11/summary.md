# 论文速读：AWM-Answerable-Working-Memory-for-Long-Document-VQA-Agents

## 一句话总结
本文针对长文档VQA智能体“答案正确但终端工作记忆质量不足”的评估盲区，提出**记忆唯一可用性**诊断指标与**AWM-GRPO**奖励机制；该方法在不改变Agent架构与检索设置的前提下，将记忆可恢复性信号融入组相对策略优化，同步提升最终答案准确率与记忆内容质量。

## 研究问题与动机
1. **评估盲区**：现有长文档VQA评测仅检验最终答案正确性与证据页访问率，未验证终端工作记忆本身是否仍包含足以独立作答的证据。
2. **正确性≠记忆质量**：智能体可在最终步骤直接依赖原始页面上下文给出正确答案，却将泛化或缺失关键信息的发现写入记忆，导致记忆成为无效 artifact。
3. **盲点规模显著**：即使在提供黄金证据页（EP-given）的严格设置下，仍有 **42.5%** 的正确案例无法仅凭终端记忆被回答。
4. **优化的独立价值**：受控对比实验表明，固定页面访问条件并仅替换终端记忆内容，即可显著改善最终答案与记忆可读性，证明直接优化记忆本身具有独立收益。

## 核心贡献（创新点）
1. **提出记忆唯一可用性诊断**：通过冻结阅读器仅凭问题与终端记忆生成答案来量化记忆质量，区别于以往仅依赖最终答案或证据页访问率的粗粒度评估体系。
2. **设计AWM-GRPO四格奖励机制**：将记忆可用性信号嵌入GRPO组内优势排序，在严格保持“最终答案正确性优先”的门控约束下，对答案-记忆组合进行细粒度差异化奖励，区别于仅以最终答案正确性为标量奖励的Answer-only GRPO。
3. **验证记忆优化对端到端性能的独立提升**：在共享架构、检索与提示的严格对照实验中，证明仅通过调整RL奖励即可同步提升最终准确率与记忆可恢复性，区别于以往通过修改检索工具、记忆Schema或答案Prompt来改善性能的路线。

## 方法详解
- **Agent-Memory 循环**：智能体执行 retrieve-inspect-update 流程，最多15步；每次检索后必须追加一条带 `source_page` 引用的受限发现（≤40词），最终输出答案 $\hat{y}$ 与终端记忆 $M^{\text{term}}$。
- **四细胞诊断框架**：使用冻结的 Qwen3-14B Reader 仅接收 $(q, M^{\text{term}})$ 生成记忆答案，经官方 Judge 评分后得到二值变量 $s_{\text{ans}}$（最终答案正确性）与 $s_{\text{mem}}$（记忆唯一可用性）。由此划分四个结果细胞，核心失败模式为 **Memory-missing correct (MMC)**：$s_{\text{ans}}=1 \land s_{\text{mem}}=0$。定义条件比率 $P_{\text{mmc}} = \frac{\sum \mathbf{1}[s_{\text{ans}}=1 \land s_{\text{mem}}=0]}{\sum \mathbf{1}[s_{\text{ans}}=1]}$ 以消除答案错误对记忆评估的混淆。
