# 论文速读：Code-World-Model-Coding-Agent-as-World-Brain

## 一句话总结
提出 Code World Model 框架，将“世界演化”与“视觉渲染”解耦：由 Coding Agent 通过可执行代码维护持久化世界状态并推演因果后果，再经轻量 Proxy 编译器生成逐帧时空约束视频，最终由微调后的视频模型渲染高保真观测；证明了代码驱动的规则演化与视频生成先验结合可支持开放、连贯的世界模拟。

## 研究问题与动机
- 现有视频世界模型仅从视觉观测中学习动力学，只能看到世界演化的“结果”，无法直接获取底层规则、常识与因果机制，导致长期后果难以持续维持。
- 纯视觉表征下，实体状态变化往往发生在视野外或超出模型上下文窗口，因果链易断，难以支撑真正意义上的开放世界演化。
- 直接让语言模型逐帧执行状态更新计算代价极高且缺乏规则一致性与可重现性；而构建完整显式 3D 资产与渲染管线成本高昂，会过早限定视觉表现的天花板。
- 语言/Coding Agent 具备广博知识、常识推理与代码生成能力，视频模型具备高保真外观、运动与物理交互先验，两者结合有望同时满足“世界规则持久因果”与“开放视觉实现”。

## 核心贡献（创新点）
1. **提出世界演化与视觉实现解耦的框架**：以 Coding Agent 为“世界大脑”驱动可执行代码维护 $S_t^{\text{exe}}$，视频模型仅负责生成 $S_t^{\text{vis}}$；与现有完全依赖视觉历史/记忆模块的工作本质不同，将规则推理与状态更新外部化为可审查、可修改的代码。
2. **设计 Proxy 时空条件接口**：引入可编程的粗粒度代理表示（相机位姿、实体位置/姿态/轨迹、空间关系），经轻量确定性编译器渲染为 Proxy 视频，直接提供帧级时空约束；相比纯文本提示实现更精确的空间控制，相比完整 3D 管线大幅降低构建成本。
3. **构建游戏与真实视频双源对齐数据流水线**：游戏录屏同步提取运行时状态自动编译 Proxy-观察对；真实视频利用标定 3D 重建与物体标注离线生成对齐 Proxy，无需动作标签或相机轨迹人工标注，显著降低数据构建门槛。

## 方法详解
- **状态分解与演化公式**：将世界状态分解为 $S_t = (S_t^{\text{exe}}, S_t^{\text{vis}})$。演化分为两步：$S_{t+1}^{\text{exe}} = \mathcal{T}_{\text{AC}}(S_t^{\text{exe}}, A_t)$（Coding Agent 推理 + 代码高频确定性更新）与 $S_{t+1}^{\text{vis}} \sim G_\theta(S_t^{\text{vis}}, S_{t+1}^{\text{exe}})$（视频模型生成新视觉观测）。
- **Coding Agent 工作模式**：使用 GPT-5.6 Sol，处理稀疏但语义复杂的决策（解释事件、连接世界知识、规划长期后果、编写/修订机制代码）；高频重复更新（位置、碰撞、冷却、数值规则）交由代码自动执行，实现高层推理与底层执行的频率解耦。
- **Proxy 设计与编译**：Proxy 仅保留当前观测必须遵守的粗粒度时空结构，通过简单图元（胶囊骨架、线框、低多面体等）与边界框组合，沿目标视频相机轨迹进行确定性光栅化生成 Proxy 视频。空间分辨率为目标视频的 1/4，token 增量仅为 1/16；与结构化文本联合输入视频模型，文本负责外观/语义，Proxy 负责时空落位。
- **训练与推理设置**：基于 MiniMax-H3 Ref2VA 主干，使用 rank-128 LoRA 微调约 596M 参数；输入 124 帧 1344×768 @24FPS 视频，Proxy 序列取 11 个关键帧送入多模态编码器。长视频采用 124 帧滑动窗口（34 帧重叠），首帧由 GPT Image 2 生成外观锚点，后续窗口复用锚点并拼接前序 RGB 上下文以保证时序连续性。

## 实验与结果
- **数据集**：游戏数据来自 GTA V，共 157 个片段约 5.6 小时，采样 9,420 个 5 秒训练 clip；真实数据以 KITTI-360 为证明性案例，利用其标定相机位姿、语义 3D 重建与物体标注离线编译 Proxy。
- **评估基线**：定性对比现有动作/相机条件或纯文本条件的交互式视频世界模型（如 LingBot-World 2.0、WorldPlay、Matrix-Game 等）。
- **主要结果**：仅用 5 小时游戏数据微调后，视频模型能严格遵循 Proxy 指定的实体位置、动作轨迹、场景布局与相机运动，同时保留丰富的视觉细节与物理动态；相比仅靠文本或低维信号控制的方法，Proxy 在角色运动、镜头调度上提供同等现代 3D 游戏引擎级别的细粒度控制。
- **最强结果与提升幅度**：论文未报告数值指标，定性 Demo 展示了 Rubber-hose、Cel-shaded、写实等多种风格下的高保真生成与精确时空对齐，证明 Proxy 接口在不同视觉风格与复杂相机运动下的泛化可控性。

## 相关工作脉络
- **交互式视频世界模型**（Genie、LingBot-World 2.0、WorldPlay、Matrix-Game 等）：以视觉 rollout 为核心对象，依赖历史帧/记忆模块维持一致性；本文将其外部化，用代码+Proxy 接管状态演化，视频模型退居视觉渲染层。
- **生成式 3D 世界**（HY-World、HunyuanWorld、WorldGen 等）：追求显式几何、材质与完整渲染管线；本文 Proxy 仅为可编程的时空条件，不追求生产级资产，避免过早限制视觉天花板。
- **Coding Agent 与规则建模**（WorldCoder、GameDevBench、OpenGame 等）：多聚焦于生成可玩游戏工件或 POMDP 程序推导；本文将其定位为“世界大脑”，驱动开放世界持续演化并连接视频生成后端。
- **长程/流式视频生成**（MosaicMem、Infinite-World、MinWM、Causal Forcing 等）：侧重自回归一致性缓解与推理加速；本文通过状态外置与 Proxy 约束从根源降低长程漂移风险，提供另一种一致性保障路径。

## 局限性与未来方向
- **训练规模受限**：当前仅使用 5.6 小时游戏数据微调，生成质量与泛化边界仍受算力与数据量制约。
- **缺乏实时自回归生成**：当前为离线滑动窗口推理，未实现真正的流式/实时交互延迟优化。
- **Coding Agent 能力瓶颈**：现有模型尚难完全自主从零构建 AAA 级复杂机制与开放世界，原型仍依赖现有游戏引擎代码作为模板。
- **未来方向**：扩大多源对齐数据规模、引入更高级 Coding Agent 实现全自主世界构建、探索 Proxy 带宽的自适应切换（按需启用/调整）、向具身智能真实部署分布延伸。

## 研究启发与可借鉴点
- **状态-视觉解耦范式**：将“世界规则演化”与“高保真观测渲染”分离，可迁移至具身智能、仿真器构建等领域，允许代码层与生成层独立升级。
- **Proxy 作为可学习控制接口**：低分辨率时空条件视频配合结构化文本的控制设计，为视频模型的细粒度空间控制提供了简洁高效的训练目标，值得在长视频生成与视频编辑任务中复用。
