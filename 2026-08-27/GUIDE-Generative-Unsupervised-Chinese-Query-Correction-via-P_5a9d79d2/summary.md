# 论文速读：GUIDE-Generative-Unsupervised-Chinese-Query-Correction-via-P

## 一句话总结
本文提出 GUIDE，一种基于“混淆-澄清”范式的生成式无监督中文查询纠错框架。该方法通过音韵与视觉共享 ID 编码将易混淆汉字映射为聚类标识，训练 Transformer 编解码器从无标注查询流中重建原始序列，在 QSpell 250K 与内部 KwaiSearch 数据集上均显著优于现有基线，并在线上 A/B 测试中实现拼写错误率下降 80.1%。

## 研究问题与动机
1. **短上下文与意图漂移：** 搜索查询极短且缺乏语境，无约束的语言模型生成极易将模糊输入过度修正为高频通用短语，导致用户检索意图发生偏移。
2. **词汇快速演变：** 平台查询词库随热点事件、网红、新实体快速迭代，依赖人工标注的有监督方法维护成本极高且难以持续刷新。
3. **创意用字与错误的边界模糊：** 谐音有时是用户有意为之的创意表达（如“钱途”谐音“前途”），纠错系统必须区分“真实错误”与“合理变体”，避免过度编辑。
4. **高质量标注数据稀缺：** 大规模查询纠错对需要昂贵的领域专家标注，现有百万级标注数据仅覆盖极小部分的真实长尾错误分布。

## 核心贡献（创新点）
1. **提出“混淆-澄清”（Confuse-then-Clarify）生成范式：** 首次将音韵/视觉可混淆字符显式映射为共享 ID 作为编码器输入，为弱上下文下的受控纠错提供强归纳偏置，从根本上区别于自由形式重写。
2. **设计无监督共享 ID 重建机制：** 无需人工构建错误-正确配对，仅利用海量无标注查询日志流即可完成训练，将字符混淆结构本身转化为直接的学习信号。
3. **引入时间衰减与查询频率加权目标：** 提出 $w_i = \log(1+c_i) \cdot \exp(-\lambda \Delta t_i)$ 的加权 NLL 损失，使模型持续聚焦近期高频查询，自适应快速演变的搜索词库。
4. **发布 KwaiSearch 数据集并完成端到端线上验证：** 构建内部大规模搜索日志数据集，离线基准全面领先，线上部署使搜索拼写错误率从 2.01% 降至 0.40%，整体搜索 PV 提升 +0.122%。

## 方法详解
1. **字符聚类与共享 ID 编码：** 构建两种互补策略将原查询 $\boldsymbol{x}_i$ 映射为共享 ID 序列 $\tilde{\boldsymbol{x}}_i$。
   - **音韵聚类：** 去除拼音声调后按音节分组，多音字按搜索日志中的最高频读音分配 ID，精准覆盖拼音输入法导致的同音/近音替换。
   - **视觉聚类：** 使用 ViT 提取汉字图像特征，以余弦相似度结合阈值 $\tau$ 进行聚类，覆盖形近字混淆（如偏旁/部件相似）。
2. **编解码纠错架构：** 采用标准 Transformer encoder-decoder。编码器接收共享 ID 序列，学习对典型 IME 错误的容忍表示；解码器自回归生成原始字符 ID 序列。推理阶段使用 beam search（beam size=10，max length=输入长度）。
3. **多信号动态融合策略：** 音韵模型与视觉模型独立推理，对同一 query 分别输出 beam 候选及 token logits。融合时不引入显式错误分类器，而是计算两模型最优候选与原查询的归一化序列对数似然得分差距（Score Gap），保留差距更小（即改动更克制）的候选，有效抑制过度纠错。
4. **训练目标函数：** 
   $$\mathcal{L} = - \frac{1} {N} \sum_{i=1}^{N} w_{i} \sum_{j=1}^{m_{i}} \log p_{\theta} (x_{i,j} \mid \tilde{\boldsymbol{x}}_{i}, x_{i,<j})$$
   其中权重 $w_i = \log(1+c_i) \cdot \exp(-\lambda \Delta t_i)$，$\Delta t_i$ 以 90 天为单位，默认 $\lambda=0.0098$（基于年度约 60% 查询重合度的工程假设推导）。模型每周更新权重并重新采样，持续适应时效性热点。

## 实验与结果
1. **数据集与基线：** 在公开基准 QSpell 250K（20万训练/5万测试）与内部数据集 KwaiSearch（1.8亿训练/3万测试）上评估。对比基线涵盖有监督（BERT, MASKED-FT）与无监督/提示类（SIMPLE-CSC, LLM-ICL 0-shot/10-shot on Qwen3-0.6B/1.7B/4B）。
