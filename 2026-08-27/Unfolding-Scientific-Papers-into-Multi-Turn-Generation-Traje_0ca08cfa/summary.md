# 论文速读：Unfolding-Scientific-Papers-into-Multi-Turn-Generation-Traje

## 一句话总结
本文提出了一种将科学论文展开为多轮生成轨迹的流水线：通过逆向重建作者的写作意图、全局规划与分节构思，在保留原文段落不变的前提下合成思考过程，从而将约30B词元的论文文本扩展为约60B词元的继续预训练（CPT）语料；该方法同时衍生出指令微调（SFT）数据集与论文锚定写作基准 PAW-Bench，实验表明该轨迹数据能全面提升模型写作能力，且不损害推理性能。

## 研究问题与动机
1. **现有合成数据方法多基于短网页文本**：大多数现有工作操作于一两千词元的网页文档，仅能恢复局部思考，无法还原长文档的全局结构。
2. **现有方法分割机械、结构扁平**：通常按固定句子块或等分切割文本，将推理插入分割点；合成的思考仅作为附属于原文的单一评论块，未体现文档的内在结构。
3. **学术写作过程未被充分利用**：科学论文具有清晰、统一的体裁结构，且作者的实际写作过程包含全局规划与分节构思，为还原完整文档级写作过程提供了天然载体，但此前工作几乎未触及该方向。
4. **现有预训练数据易导致灾难性遗忘**：在单一学术域上继续预训练会拉大基础模型与原预训练分布的差异，而混合通用文本又难以直接带来写作能力的提升。

## 核心贡献（创新点）
1. **提出可缩放的论文展开流水线，将整篇论文转化为多轮生成轨迹**：通过逆向重建写作请求、全局计划与每节前的预写作 deliberation，在保留原文段落与摘要不变的前提下，将30B词元的论文文本扩展为约60B词元的CPT语料，中位数文档长度从11.2K提升至28–29K词元。
2. **将同一逆向构造扩展到指令微调数据与评估基准**：对单段文本应用该方法可生成约200K样本的SFT数据集；对 held-out 论文应用可生成 PAW-Bench（含2,940个任务，每个任务附带专属评分量规与检查清单）。
3. **在控制实验中隔离并验证了“展开构造”而非“论文内容本身”的价值**：使用相同论文纯文本作为对照，证明写作轨迹的展开结构能普遍提升写作表现，且提升效果在与不同SFT配方结合后仍能保持。
4. **揭示了生成器规模与训练损失、下游写作收益之间的非单调关系**：用较小生成器（4B）产出的轨迹虽然训练损失更高，但在写作与推理基准上取得了最优收益，表明合成数据的“难度”与风格多样性有助于提升模型泛化。

## 方法详解
**整体构造原则**：固定真实文本作为最终产物，逆向推导可能产生该文本的潜在上下文与思考过程。三个产品（CPT、SFT、PAW-Bench）共享同一预处理流水线，仅在源窗口、过滤严格度与生成模型上有所不同。

**CPT数据构建（四步展开）**：
1. **分节摘要**：对每节独立生成摘要，涵盖关键主张、方法与结论，用于后续步骤的紧凑输入。
2. **推导写作请求**：基于标题与所有节摘要，推断一个作者视角的自然写作请求，要求涵盖研究目标、核心方法与预期证据。
3. **推导全局计划与分节 pre-writing deliberation**：模型扮演作者，基于请求与摘要进行全局规划（章节顺序与功能）；对每一节，结合前后节摘要与原文，推导该节需确立的内容、证据与过渡决策。
4. **推导摘要 deliberation**：基于所有节摘要与原文摘要，推导如何将问题、贡献、证据与结论压缩至摘要中。

**轨迹结构**：
\[
q,\ p,\ c_1,\ s_1,\ c_2,\ s_2,\ \ldots,\ c_n,\ s_n,\ c_a,\ a
\]
其中 \(q\) 为写作请求，\(p\) 为全局计划，\(c_i\) 为第 \(i\) 节的预写作 deliberation，\(s_i\) 为原文第 \(i\) 节，\(c_a\) 为摘要 deliberation，\(a\) 为原文摘要。原文 \(s_i\) 与 \(a\) 保持不变，其余由生成模型合成。

**SFT数据构建**：
固定单段文本作为答案的事实核心，逆向推导能引出该答案的任务请求（含长度、格式等约束），再基于请求与材料生成前瞻性 deliberation。任务分为三类：改写（rewriting）、基于论文的问答/抽取（QA & extraction）、重组（reorganization）。每篇论文抽取三种不同任务类型，经确定性修复与语义评分（≥9分）后保留。

**PAW-Bench构建**：
对 held-out 论文生成任务与评分材料。每个任务包含加权量规维度（如内容覆盖、组织、 faithfulness）与检查清单（部分可代码验证）。任务按是否提供论文材料分为 prompt-only 与 paper-grounded 两类。

**生成设置**：CPT阶段使用 Qwen3.5-4B/9B/27B 作为生成器，temperature=1.0，每调用8,192词元预算；SFT阶段使用 Qwen3.6-27B，output budget 32,768词元。

## 实验与结果
**数据集与基线**：
- CPT语料：1.8M篇arXiv论文，经质量过滤后保留约1.8M（CPT）与356K（SFT）。
- 对照：纯 FineWeb-Edu（50B词元）、原始论文纯文本（30B词元）+ FineWeb-Edu（20B词元）。
- 主模型：Qwen2.5-7B 作为基础，分别进行 CPT 与 SFT。
- 评估基准：WritingBench、PAW-Bench、HelloBench、LongBench-Write（写作）；MMLU-Pro、GPQA-D、MATH-500、AIME 2025、LiveCodeBench v6（推理）；Qasper、QASA、LongBench v2（论文理解与长上下文）。

**主要结果**：
- **写作提升**：Our-Data-4B CPT + DeepWriting SFT 在 WritingBench Academic & Engineering 上达到53.9，较无CPT基线（49.8）提升+4.1；PAW-Bench Rubric 达59.47，较基线（55.42）提升+4.05；平均写作得分达54.34，较基线51.90提升+2.44（+4.7%）。
- **两阶段叠加效应**：使用 Our-Mixed SFT（替换10K DeepWriting样本）后，PAW-Bench Rubric 提升至63.73，Checklist通过率从0.529升至0.650；进一步结合轨迹CPT后，PAW-Bench达64.13，平均写作得分54.38，持续领先。
- **推理不受损**：Our-Data-4B CPT + OpenThoughts SFT 在推理基准平均得分46.82，高于直接 SFT（46.32），且显著优于仅 FineWeb-Edu CPT（44.30）。
- **论文理解与长上下文**：Our-Data-27B CPT 在 Qasper 上达43.01，较基线（39.82）提升+3.19；在 LongBench v2 ≤64K 上达40.22，较基线（36.96）提升+3.26，而 Plain-Paper CPT 在该设置下降5.06分。

## 相关工作脉络
1. **文本重建思考过程**：如 [12,32,35] 在网页文本上插入推理链，但仅处理短文档且结构扁平；本文将其推广至整篇科学论文，还原全局规划与分节构思。
2. **Megadocs**：[15] 将文档等分并在切割点插入推理，形成超长训练单元；本文按论文自身结构（节边界）分解，保留修辞与逻辑层次。
3. **REER**：[34] 在开放写作中寻找最佳解释已知答案的 deliberation；本文将其扩展至论文级多轮轨迹，且保留原文作为不可变答案。
4. **指令逆向合成**：[18,25,19] 从真实文本推导指令或大纲；本文在指令合成中同样保持答案事实核心来自论文，并生成前瞻性思考而非仅反向追溯。
5. **代码领域逆向工程**：[40] 从 GitHub 仓库还原开发轨迹；本文在自然语言学术写作中实现类似过程，且评估基准 PAW-Bench 附带可代码验证的检查清单。
6. **科学文献适应**：[17] 在清洁论文文本上训练；本文训练的是写作过程数据，而非仅表面文本，从而带来额外的写作能力提升。

## 局限性与未来方向
1. **继续预训练实验规模有限**：仅在一个基础模型（Qwen2.5-7B）与一种混合比例（30B轨迹+20B通用文本）上验证，较大模型或其他比例尚未测试。
2. **依赖LLM评分器**：写作指标基于 GPT-5.5 评分，虽经多轮自动检查与人工抽查，但仍可能存在与人类偏好的差距。
3. **论文理解与长上下文基准较小**：相关增益仅作为辅助证据，缺乏大规模人类评估支撑。
4. **轨迹为事后重建**：合成的思考过程不一定与作者实际写作时的 deliberation 完全一致。
5. **未来方向**：可将该方法推广至其他具有清晰结构的长文档（如技术报告、教科书章节），或探索不同学科领域的适用性。

## 研究启发与可借鉴点
1. **逆向构造范式可扩展**：固定真实文本作为答案、逆向推导前置上下文与思考过程的方法，适用于任何具有内在结构的长文档领域（如法律文件、工程报告）。
2. **生成器规模与数据“难度”的非单调关系**：较小生成器产出的轨迹虽训练损失更高，但可能因风格多样性与思考深度带来更好的下游泛化，为合成数据生成器的选择提供了新思路。
3. **训练损失可作为数据筛选的辅助信号**：本文发现损失最高的语料（4B生成）在写作与推理上表现最佳，提示在写作数据合成中可引入损失率进行多样性筛选。
4. **混合不同来源的SFT数据可叠加收益**：将本方法生成的写作SFT样本与公开写作数据集混合微调，能在保持广域写作能力的同时进一步提升学术写作质量。
5. **长上下文训练文档长度分布的重要性**：本文通过展开使中位数文档长度从11K提升至28K，有效扩展了长上下文训练覆盖，这对设计长文档预训练语料具有参考价值。

## 关键术语表
**Continued Pre-training (CPT)**：在已预训练模型基础上，使用新语料继续进行自回归预训练，以扩展领域知识或能力。
**Reverse Construction**：固定真实文本为答案，逆向推导可能产生该文本的用户请求、思考过程或评估标准。
**Deliberation**：在写作或推理过程中，模型内部或外显的思考链条，涵盖规划、论证、权衡等环节。
**PAW-Bench**：Paper-Anchored Writing Benchmark，一个以论文为锚点的学术写作基准，每个任务附带可代码验证的检查清单与量规。
**Trajectory**：指由写作请求、全局计划、分节 deliberation 与原文段落交错组成的多轮训练序列。
**Synthetic Data**：由模型生成而非人工标注的数据，此处特指通过逆向构造从真实论文衍生出的思考过程与任务数据。
**Catastrophic Forgetting**：模型在新增数据上继续训练时，原有能力（如推理）显著退化的现象。

## 可复现要素
- **数据集**：CPT与SFT源数据来自2006–2026年1月的arXiv论文（CPT约1.8M篇，SFT约218K篇）；PAW-Bench源数据来自2026年2–6月的论文（735篇）。论文未公开原始论文列表与处理后的完整语料，但提供了详细的预处理与过滤规则。
- **代码/权重**：论文未明确声明代码开源，但使用了 Qwen3.5-4B/9B/27B 与 Qwen2.5-7B 作为生成器与基础模型，这些模型为开源权重。
