# 论文速读：Skill-Issue-Are-Skills-Language-Invariant-in-LLMs

## 一句话总结
本文通过多语言自我对弈实验，首次系统量化了LLM在不同语言界面下的“技能表达不一致性”，发现同一模型在空间推理、战略决策与已知策略调用等维度会随交互语言产生显著差异；进一步证明将中间推理切换至更强语言可在部分游戏中恢复60%~90%的性能损失，表明语言敏感度作用于决策链的多个阶段而非仅输入理解。

## 研究问题与动机
- **核心问题**：现有研究多关注LLM跨语言的“知识可及性差异”（如事实检索不均），但对同一模型是否能在不同语言下平等调用推理、规划与决策等“技能”缺乏系统测量。
- **现有方法不足**：
  1. 静态基准（如MMLU、Belebele）仅评估单次问答准确率，无法捕捉多轮交互中状态跟踪、动作合法性校验与策略执行的动态一致性。
  2. 跨语言对比实验常混杂“知识储备差异”与“整体能力水位差异”，难以隔离语言接口本身的纯行为干扰。
  3. 缺乏支持多语言博弈轨迹细粒度拆解（失败轴线、卡牌条件决策、策略提及vs执行）的开放评测环境。

## 核心贡献（创新点）
1. **提出跨语言技能不一致性的独立量化框架**：通过固定游戏状态、规则与动作空间、仅变更语言接口的自我对弈设置，将语言对技能表达的影响从知识获取与基准性能中严格解耦。
2. **构建Multilingual TextArena开源资源**：提供65个游戏×193种语言的多层级翻译与验证管线（Tier A/B/C），填补了交互式多语言Agent评估的基础设施空白。
3. **揭示技能差异的多维行为表征**：不仅报告胜率落差，更深入刻画语言依赖的失败模式（如非拉丁语系在空间推理中更易忽略列/对角线）、风险偏好偏移（Kuhn Poker中bluff率跨语言差异>2×）以及已知算法策略的可及性断层（Nim最优解提及与执行率断崖下降）。
4. **验证中间推理语言干预的有效性**：证明在弱语言界面下强制模型以强语言进行内部推理，可在TicTacToe与Simple-Tak中恢复89.4%与60.5%的性能差距，定位了语言敏感度的可干预作用点。

## 方法详解
- **评估范式（Multilingual Self-Play）**：两个相同模型的实例在同一游戏环境 $E_g$ 中对战。Player 0 接收语言 $\ell_0$ 的观察与指令，Player 1 接收 $\ell_1$。棋盘符号、卡牌数值、合法动作语法（如 `[bet]`, `[1]`）与转移函数严格保持语言无关，从而将变量收敛为单一语言接口。
- **指标体系**：
  - **角色池化胜负差** $\Delta_{m,g}(A,B) = (W_{A,B} - L_{A,B}) / N_{A,B}$：兼顾 $(A,B)$ 与 $(B,A)$ 两种角色分配，消除先手/后手结构性优势，值域 $[-1,1]$。
  - **语言均值边际** $\mu_{m,g}(A) = \frac{1}{|\mathcal{L}|-1}\sum_{B\neq A}\Delta_{m,g}(A,B)$：衡量语言A在该游戏上的相对强度。
  - **模型级均值边际** $\bar{\mu}_m(A)$：跨游戏宏平均，用于全局语言排名与敏感性分析。
- **游戏覆盖**：6个双人对战文本游戏（TicTacToe, Nim, Colonel Blotto, Kuhn Poker, Simple-Tak, Iterated Prisoner’s Dilemma），分别测试空间推理、组合博弈、资源分配、非完美信息 bluffing、连接路径与重复社会互动。
- **翻译与验证管线**：Tier A（8语言）由 GPT-5.2 / Claude Opus 4.8 翻译并经母语者人工核验；Tier B 采用 Llama-3.1-405B / Qwen2.5-72B 自动翻译+回译+LLM一致性判决；Tier C/E 使用 NLLB-200 + 双模型直判。所有 `{placeholder}`、`[action token]` 与数值符号经 sentinel 替换确保结构保真。
- **推理语言干预实验**：保持界面语言固定为弱语言（如德语），通过系统提示强制模型在中间推理阶段使用强语言（英语），对比仅固定界面与“界面+推理双语分离”条件下的 $\mu$ 提升幅度，计算恢复率 $(\mu - \mu_{weak})/(\mu_{best} - \mu_{weak})$。

## 实验与结果
- **规模与模型**：Gemma-4-E4B-it、Qwen3-4B、Ministral3-3B-Instruct-2512；8种Tier A语言；每模型-游戏-语言对400局×双向角色，总计518,400局自我对弈（单任务约6 H200 GPU-hours）。
- **核心发现**：
  1. **强度分层显著**：英语在所有模型上平均最强，希伯来语最弱；Qwen3语言敏感性跨度最大（均值1.48在Blotto，0.32在TTT），Gemma最稳定（均值0.28）。
  2. **游戏间差异**：Colonel Blotto语言差距最大（三模型均值1.07），Kuhn Poker最小（均值0.13）；IPD对Gemma/Qwen稳定，对Ministral敏感。
  3. **技能差异细目**：TicTacToe中阿拉伯语/希伯来语界面对列/对角线防御显著弱于英语；Kuhn Poker中Qwen在最弱牌上bluff率跨语言差异超2倍；Nim最优策略提及在阿拉伯语/希伯来语下暴跌，且多数有效提及实为推理中途切回拉丁字母所致。
  4. **推理恢复**：德语界面+英语推理在TTT恢复89.4%，ST恢复60.5%；Kuhn Poker恢复有限且非线性（37.6%~49.3%），说明语言影响贯穿状态解释、推理与动作选择多阶段。
  5. **外部归因**：语言强度与Global-MMLU (r=0.73~0.92)、Belebele (r=0.71~0.79) 及FineWeb-2文本量 (r≈0.79) 均显著正相关；但基准平均分无法预测跨语言稳定性（Gemma均分最低但跨度最小）。马来语因拉丁脚本迁移效应优于希伯来语，中文则依赖模型内在能力而非单纯数据量。
- **最强结果**：英语界面下各模型综合表现最优；Gemma在TTT与Nim
