# 论文速读：Cross-Dataset-Stability-of-Expert-Informed-Skill-Prompting-a

## 一句话总结
论文在中文句子级隐喻识别任务上，首次在同一跨数据集评估中对比了专家启发式过程 Skill 提示与四种参数微调方法的跨数据集稳定性；结果表明，冻结的 Skill-ZS 虽不及微调模型在源数据集上的峰值精度，但具备最高的外部基准下限（82.64）和最窄的跨数据集性能范围（4.08 分），是一种可互补的更稳定知识供给路线。

## 研究问题与动机
- 现有隐喻识别系统在跨数据集迁移时表现波动大，仅报告源数据集最高分不足以反映真实可用性；外部性能下限和跨数据集变化幅度同样是关键评估维度。
- 监督微调将任务适配编码为模型参数，但参数对训练分布的依赖可能导致外部泛化不稳定；而以推理时注入的规则/程序性指导（Skill）则可能因显式语言学原则而降低分布绑定。
- 目前缺乏在同一跨数据集设置下，将专家启发的过程性 Skill 提示与任务特定微调进行对照的实验分析。
- 本文进一步希望从决策重新分配层面解释 Skill 如何改变预测倾向，从而形成更平稳的跨数据集性能轮廓。

## 核心贡献（创新点）
1. 首次在中文句子级隐喻识别的同一跨数据集评估中，对比专家启发式过程 Skill 与任务特定微调四条件，提出跨数据集稳定性与源对齐峰值性能的分离视角。
   - 与以往仅报告源数据性能的工作本质不同：本文同时报告外部均值、外部下限和跨数据集范围。
2. 提出适配句子级二分类的六步冻结 Skill，将 MIP/MIPVU 的核心判据操作化为推理程序，而无需新增标注或参数更新。
   - 与完整词级 MIPVU 流程或架构内嵌对比模块的本质区别在于：该 Skill 以可执行的指令形式在推理时供给，保留模型权重不变。
3. 通过配对零样本对照组揭示 Skill 带来的聚合决策迁移机制：在全部三个数据集上减少隐喻预测，降低 CCIME 误报但增加 CMRE/CMC 漏报。
   - 与仅报告整体分数的零样本工作不同：本文给出按数据集和类别分解的精度-召回权衡解释。
4. 建立一套包含跨数据集稳定性综合指标的评估框架，强调外部下限与范围应成为跨领域部署的系统设计约束。
   - 与单一源对齐评估或仅关注平均外部分数的基线相比：本文区分峰值性能与分布一致性两个独立目标。

## 方法详解
- 任务设定：中文句子级二元隐喻识别，标签空间固定；使用 CMRE 的训练/开发/测试分区，以及两个外部数据集 CCIME 和 CMC 的二元隐喻标签。
- 重叠与策略控制：在评估前移除与 CMRE Train/Dev 精确及归一化匹配的行，排除 38 行 CCIME 与 2 行 CMC；保留各视图内的重复行但保留独立标识；CMRE 将明喻视为隐喻，而 CCIME 将明喻与夸张划入非隐喻，构成标注策略偏移。
- 四种知识供给范式：
  - BERT-FT：使用 hfl/chinese-robertawwm-ext-large，双标签序列分类头，AdamW，学习率 2e-5，有效批次 16，最大序列长度 512，最多 5 个 epoch；在 CMRE Dev Macro-F1 上选 checkpoint，阈值固定 0.5，3 个种子均值。
  - LLM-FT：基于 Qwen/Qwen3.6-27B 文本模型，4-bit NF4 QLoRA，Rank 8，α=16，可训练参数 23.76M；Assistant-only target 且仅对目标 token 计算损失；AdamW，学习率 1e-4，有效批次 16，最大序列长度 256，最多 3 个 epoch；同用 3 个种子均值。
  - LLM-ZS：相同 Qwen 基础模型且不做参数更新，无示例输入，确定性解码与受限 JSON 标签格式。
  - Skill-ZS：在 LLM-ZS 之上注入冻结的六步专家 Skill，唯一差异项为 Skill 文本本身，其余基础模型、运行时、提示外壳、输出格式完全一致。
- Skill 构成：将隐喻判定的语言学原则操作化为六步推理：建立句子语境、识别候选映射、比较语境意义与基本意义、检验对比与类比、拒绝无支撑案例、聚合为单句标签；在 60 个 AI 辅助合成规范句上经 7 轮迭代修订，仅用于指令完善，未参与正式评估。
- 评估指标：以 Macro-F1 为主指标（因类别分布不均衡）；跨数据集稳定性由四个汇总量刻画：外部数据集均值、外部下限、源与外部均值之间的有符号差距、三个数据集的全局范围。

## 实验与结果
- 数据集：CMRE Train/Dev/Test 各 850 行，CCIME 1,162 行，CMC 698 行（已移除重叠行），均为二元句子级标注。
- 主要数值（Macro-F1）：
  - CMRE Test：BERT-FT 91.76，LLM-FT 91.17，LLM-ZS 81.87，Skill-ZS 79.12。
  - CCIME：BERT-FT 76.70，LLM-FT 76.78，LLM-ZS 66.74，Skill-ZS 82.64。
  - CMC：BERT-FT 84.68，LLM-FT 90.25，LLM-ZS 90.76，Skill-ZS 83.19。
- 跨数据集稳定性汇总（Macro-F1 点数，来自未舍入值）：
  - 外部均值：BERT-FT 80.69，LLM-FT 83.52，LLM-ZS 78.75，Skill-ZS 82.92。
  - 外部下限：BERT-FT 76.70，LLM-FT 76.78，LLM-ZS 66.74，Skill-ZS 82.64。
  - 源-外部均值差距：BERT-FT +11.07，LLM-FT +7.65，LLM-ZS +3.12，Skill-ZS −3.80（外部高于源）。
  - 跨三数据集范围：BERT-FT 15.06，LLM-FT 14.39，LLM-ZS 24.02，Skill-ZS 4.08。
- 最强结果与提升幅度：微调在源数据集取得最高峰值；外部均值最高为 LLM-FT 的 83.52，Skill-ZS 与之仅差 0.60 点；Skill-ZS 外部下限最高（82.64），较 LLM-FT 与 BERT-FT 分别高出 5.86 与 5.94 点；跨数据集范围最小为 Skill-ZS 的 4.08 点。
- 配对 Skill 效应：在所有数据集上 Skill-ZS 比 LLM-ZS 更少预测隐喻类；CCIME 误报从 319 降至 149，CMRE Test 与 CMC 误报亦下降但假阴性分别增加 50 与 57。Skill-ZS 在 CCIME 上相对 LLM-ZS 的 Macro-F1 提升约 15.90 点，是最显著的单数据集增幅。
- 不确定性说明：微调条件报告三种子均值与样本标准差，零样本为单次确定性运行，跨条件差异未作显著性声称。

## 相关工作脉络
- MIP/MIPVU 词级手动流程为系统性隐喻判定提供语言学依据，本文将其精简并操作化为句子级推理 Skill，而非直接在模型架构内嵌入完整流程。
- 序列隐喻识别、MelBERT 与 ContrastWSD 等工作通过模型结构、上下文交互或 sense 对比实现类似原则，但与本文在推理时注入冻结程序并对比微调的路径不同。
- 以往 LLM 隐喻研究评估零样本标签、MIPVU 启发式过程或规则脚本，本文在此基础上引入配对零样本对照与跨数据集稳定性综合指标。
- 跨语言与跨域泛化研究指出标注一致性与领域差异会改变性能，本文进一步区分"源对齐峰值"与"外部下限/范围"作为两项独立目标。
- RAG、提示工程与微调的比较研究聚焦全文隐喻识别，本文则聚焦中文句子级分类，并突出专家 Skill 在稳定性维度的定位。

## 局限性与未来方向
- 实验范围限于四种预设条件、一个基础 LLM、一个专家 Skill 与三个中文句子级数据集；两个外部数据集的结果不能外推至未见体裁、语言、标注方案或隐喻构式。
- CMRE 与 CCIME 标注策略不一致（明喻归属不同），导致对 CCIME 的迁移效果部分度量的是标注偏移适应，而非纯领域偏移。
- 微调条件提供三种子不确定度，零样本仅提供单次确定性运行，跨条件比较缺乏统一的不确定性估计。
- Skill 经由 60 条 AI 辅助合成句迭代修订，作者未保留具体模型标识，也未开展外部专家对每条规则的重审；当前混淆计数只能定位整段 Skill 的影响，不能分解到指令层因果。
- 评估为句子级二元分类，未定位具体隐喻词、未测量解释质量、程序遵从性或校准度，也缺乏人类可解释性评测。
- 未来可从以下方向推进：在更多体裁与语言上验证跨数据集稳定性；开展 Skill 组件消融以分离指令层效应；探索微调与程序性约束的混合范式；引入不确定度校准与结构化解释评估。

## 研究启发与可借鉴点
- 跨数据集评估应同时报告外部下限与跨数据集范围，避免仅以源对齐峰值掩盖部署风险；这一定量框架可直接迁移到其他 NLP 子任务的外部泛化研究。
- 在推理时注入冻结的程序性 Skill 提供了一种可审计的知识供给方式：当系统需要对标注边界做出稳定承诺时，可优先考虑此类零样本过程约束。
- 配对零样本对照（仅改变 Skill 有无）能有效隔离程序性知识的增量影响，其"同一基础模型+同一运行时+唯一干预变量"的设计可作为后续规则/流程类提示研究的通用实验模板。
- 本团队可在自身任务中复刻 Skill 构造流程：从公开发布的人工判例规范中提取步骤，经少量合成示例迭代修订后冻结为推理指令，再与微调条件在同一多数据集集合上进行稳定性对比。
- Skill 引起的预测倾向偏移揭示了精度-召回在不同数据集上的非对称变化，可启发未来设计针对分布偏移的场景化成本函数，将偏移敏感错误单独计费。

## 关键术语表
- **Skill**：一种可复用的冻结指令工件，将多步推理程序在推理时供给模型，不更新参数，区别于 In-Context 示例或学习适配器。
- **Macro-F1**：两个类别 F1 的未加权均值，作为跨数据集主指标以缓解类别分布不均。
- **外部下限**：所有外部数据集性能中的最低值，用于衡量最坏情况下的可用性能。
- **跨数据集范围**：源数据集与外部数据集之间 Macro-F1 的最大差值，衡量性能波动幅度。
- **QLoRA**：对量化 LLM 进行低秩自适应的微调技术，以较低显存开销实现参数高效适配。
- **MIP/MIPVU**：基于对比与语境-基本意义映射的手动隐喻识别语言学流程，本文将其原则抽象为句子级程序。
- **源-外部均值差距**：源测试 Macro-F1 减去外部均值，正值为源高负值为外部高，用于刻画分布偏移方向。
- **确定性零样本**：在给定冻结配置下单次运行得到固定输出，无随机采样或种子平均。

## 可复现要素
- 数据集：CMRE、CCIME、CMC 均为已有公开研究数据集，具体访问权限与重分发条件遵循原始发布条款；重叠移除记录、归一化规则与重复项处理在补充材料中提供。
- 代码与权重：补充材料将包含预处理记录、提示文本、冻结 Skill、运行时配置、实例级预测与评估代码，在允许重分发的范围内开源。
- 关键超参：
  - BERT-FT：学习率 2e-5，批次 16，序列长度 512，最多 5 epoch，固定阈值 0.5，3 个种子 42/43/44。
  - LLM-FT：4-bit NF4 QLoRA，Rank 8，α=16，可训练参数 23.76M，学习率 1e-4，批次 16，序列长度 256，最多 3 epoch，3 个种子 42/43/44。
  - LLM-ZS 与 Skill-ZS：确定性解码，受限 JSON 输出格式，基础模型 Qwen/Qwen3.6-27B，单次运行。
- Skill 开发：基于 60 条 AI 辅助合成规范句的七轮迭代修订，仅用于指令完善，不参与正式评估，具体作者模型标识未保留。
