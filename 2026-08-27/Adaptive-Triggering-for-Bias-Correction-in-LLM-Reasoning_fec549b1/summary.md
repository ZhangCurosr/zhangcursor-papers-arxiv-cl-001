# 论文速读：Adaptive-Triggering-for-Bias-Correction-in-LLM-Reasoning

## 一句话总结
本文提出 **Adaptive Triggering** 框架，将 LLM 链式思考（CoT）推理过程中的社会偏见纠正建模为在线变点检测问题：通过 CUSUM 统计量逐步累积白盒（词表概率差）或黑盒（LLM Judge 打分）偏差信号，仅在证据跨阈值时注入针对性上下文反思，从而在显著减少无效干预的同时有效缓解推理轨迹中的刻板印象偏差。

## 研究问题与动机
1. **CoT 推理会暴露并传播偏差**：大模型在中间推理步骤中可能引入人口统计学刻板印象，且这些偏差会在轨迹内延续，仅靠最终答案的事后纠偏（post-hoc）无法阻断传播。
2. **干预时机缺乏决策依据**：现有方法要么事后评估（为时已晚），要么按固定步频干预（无视当前轨迹内容），回避了核心问题——正在发展的推理轨迹需要累积多少证据才值得触发纠正？
3. **固定调度具有强模型依赖性**：不同模型的推理轨迹长度差异巨大，相同的固定步频会导致实际干预暴露率从 0% 到 99% 不等，造成跨模型性能波动剧烈（如 Llama-8B 准确率下降 10.13pp，Gemma-9B 几乎无影响）。
4. **内部访问限制阻碍通用部署**：FairSteer 等激活 steering 方法需访问模型隐藏层并预训练分类器，难以直接应用于仅开放文本 API 的托管模型（如 gpt-4o-mini）。

## 核心贡献（创新点）
1. **提出证据触发式推理中途纠偏框架**：将监测信号与 CUSUM 序列决策规则解耦，同一控制循环兼容白盒概率信号与黑盒 LLM-Judge 信号，无需修改生成器即可支持开放权重与托管模型。
2. **证明自适应触发可显著降低固定调带的附带成本**：在 gpt-4o-mini 上，黑盒自适应触发恢复了固定间隔失去的大部分明确上下文准确率（90.1% vs 82.9%，$p=0.0003$），且干预频率降至 0.60/项（fixed 为 1.00）；匹配预算的扫描实验表明该优势并非单纯来自“干预次数更少”。
3. **揭示基于概率信号的结构性目标错位**：白盒信号（$p(s)-p(u)$）无法区分“无依据的刻板印象依赖”与“恰好符合刻板印象的有效证据”，导致在五款开源模型上明确上下文准确率下降，证明时序优化无法弥补信号本身与真实偏见目标的脱节。
4. **识别并量化“未完成（non-completion）”这一独立干预成本**：干预消息会消耗有限的推理步预算，在推理微调模型（如 DS-Llama-8B）上使未完成率从 4.5% 升至 8.5%，若将未完成情况计入错误，精度损失将被严重低估。
5. **修复 BBQ 基准的四处标签匹配 Bug**：发现并修正了 Intersectional labels、Nationality、Physical appearance、SES 四类选项中元数据与标签格式不匹配的 undocumented inconsistencies，更新了偏差分数的计算逻辑并开源。

## 方法详解
1. **偏差风险信号（Bias-Risk Signal）**：每步生成结束后输出标量 $b_t \in [0,1]$。
   - **白盒（White-box）**：不生成额外文本，直接计算强制续写 `Final answer: <letter>` 的对数概率 $\ell_{t,j}$，归一化为 $p_t(j)$。定义 $b_t = \max(0, p_t(s) - p_t(u))$，衡量模型对刻板一致答案相对“信息不足”答案的偏好强度。
   - **黑盒（Black-box）**：LLM Judge 独立审视当前单步推理，输出 0–10 分（10 代表完全依赖人口统计学刻板印象），归一化为 $b_t$。支持自 Judge 或独立 Judge。
2. **CUSUM 序列检测与控制循环**：共享的在线变点检测逻辑，$S_t = \max(0, S_{t-1} + b_t - k)$（$k$ 为 slack 参数）。当 $S_t > h$（检测器特定阈值）时触发干预，随后进入一步冷却期（cooldown），期间 $b_t$ 与 $S_t$ 继续更新但禁止再次触发，直至输出最终答案或达到步数上限。
3. **校准与优化目标**：利用预留验证集搜索 $(k, h)$ 组合。目标函数为 $\mathrm{accuracy}(C_{\mathrm{dis}}) - \mathrm{bias\_rate}(C_{\mathrm{amb}}) - \lambda \cdot \mathrm{noncompletion}(C)$，而非传统的假阳性率，因为 BBQ 的模糊样本中“信息不足”是正确答案，而明确样本中正确结论本身可能符合刻板印象，直接将高偏好视为偏差会导致目标错位。设置 $\lambda=1$ 将未完成情况视为与错误答案同等的惩罚。
4. **干预机制**：触发时插入针对性反思提示（明确指出疑似故障模式），区别于固定调度的通用提示。实验未隔离“时机”与“内容”的独立因果效应，整体评估自适应策略的有效性。
