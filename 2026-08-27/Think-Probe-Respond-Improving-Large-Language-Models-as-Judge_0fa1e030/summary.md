# 论文速读：Think-Probe-Respond-Improving-Large-Language-Models-as-Judge

## 一句话总结
本文发现大语言模型在评估研究想法新颖性时存在严重的“中等新颖性”校准偏差：推理文本与人类专家高度一致，但最终数值评分却保守集中于中间类别。作者据此提出 Think-Probe-Respond (TPR) 框架，通过在思维链末尾从隐藏状态探测潜在新颖性判断，并以此条件化最终回复，使评估性能平均提升 22.30%，有效消除偏见且无需微调模型。

## 研究问题与动机
- **核心问题**：LLM 作为新颖性评委时，生成的论证依据（rationales）质量高且与人类一致，但输出的数值分数却系统性偏离内部推理与人类共识，存在“知行不一”的校准失效。
- **现有方法不足 1**：既往 LLM 新颖性评估研究多聚焦于提示词工程或多智能体流程优化，未深入诊断模型内部表征与最终输出之间的错配机制。
- **现有方法不足 2**：主流模型普遍表现出强烈的中间类偏向，极少预测 1 分（完全不新）或 5 分（高度创新），导致评估工具失去区分科研价值的能力。
- **现有方法不足 3**：简单的 Chain-of-Thought 提示无法修复该偏差，推理过程中实际已蕴含准确的新颖性信念，但未被模型显式捕获与利用。

## 核心贡献（创新点）
- **系统诊断并量化 LLM 新颖性判断的校准偏差**：首次明确界定“潜在信念（latent belief）”与“显式判断（expressed judgment）”的错配现象，指出偏差根源在于模型倾向于在输出层采取安全的中立策略。与以往仅观测表面性能的工作本质不同。
- **提出 TPR 轻量级推理时探测框架**：设计 Think-Probe-Respond 三阶段流水线，全程冻结 LLM 参数，仅训练一个逻辑回归探测头。相比全量微调或复杂多步提示，具备极低的计算与部署成本。
- **精确定位思维链末尾为最优探测时机**：通过跨时间步表征分析发现，新颖性信号在最后一个 think token ($t_n$) 处达到峰值且高度稳定；进入回复生成阶段后表征会被语言表层规划稀释。该发现为生成中途干预提供了明确的理论锚点。
- **证明小型开源模型+TPR 可超越大型闭源商业模型**：在统一开源模型族（Gemma-3、Llama-3.1、Qwen3、GPT-OSS）上验证 TPR 的模型无关性，最小模型（Gemma-3-4B）Macro-F1 达 24.4，显著击败 Gemini/Claude/GPT 旗舰模型的零样本上限（最高 17.1）。

## 方法详解
TPR 由三个顺序阶段构成，LLM 参数全程冻结，仅在推理阶段接入外部探针：
1. **Think（定性思考）**：向 LLM 输入研究想法及相关论文列表，要求模型基于新颖性类别的纯文本描述进行逐步推理。**关键设计**是刻意不提供 1–5 数值标签，迫使模型在内部表征中进行概念级对比，避免数值锚定污染隐藏状态。对原生支持 think token 的推理模型（如 Qwen3、GPT-OSS）直接触发内部推理；对非推理模型则显式附加 "Think step by step" 指令。
2. **Probe（表征探测）**：设 LLM 共 $L$ 层，思维序列为 $T = t_1, \ldots, t_n$。系统在生成完最后一个 think token $t_n$ 时暂停，提取最后一层隐藏状态 $h_{t_n}^{(L)}$ 作为特征向量，输入预训练的 logistic regression 分类器预测新颖性类别 $\hat{y} \in \{1,\dots,5\}$。
3. **Respond（条件生成）**：将 $\hat{y}$ 对应的类别文本描述拼接至已生成的思考内容之后，恢复自回归解码。模型在同时看见自身推理轨迹与探测所得显式类别的条件下，输出最终的结构化评估报告，确保数值结论与解释逻辑严格自洽。
- **训练与优化**：仅对逻辑回归分类器计算标准交叉熵损失并在 CPU 上训练；LLM 的 LoRA 微调对比实验采用 rank $r=16$、$\alpha=32$、dropout 0.1、lr $2\times10^{-4}$、2 epochs、bfloat16 精度，结果仍低于 TPR。

## 实验与结果
- **数据集**：RINoBench（1,381 个 ML 专家撰写研究想法，附相关工作、5 点 Likert 人工评分及专家论证）。
- **评估基线**：Zero-shot、Few-shot、CoT、Moose、ResearchAgent、AI Scientist、AI Researcher 提示方法、LoRA FineTune。
- **模型范围**：开源（Gemma-3 4B/12B/27B、Llama-3.1 8B/70B、Qwen3 4B/14B/32B、GPT-OSS-20B）vs. 闭源 SOTA（Gemini 2.5/3 Pro、Claude 4.5、GPT-5 mini/5.4）。
- **主要结果**：
  - TPR 在所有模型上平均超越最强基线 **22.30%**（Macro-F1），且显著优于计算代价更高的 FineTune。
  - 成功打破中等类偏向：闭源零样本几乎只输出 3/4 类，TPR 后各模型在 1 类和 5 类的 $F_1$ 显著提升（除 Qwen3 系列仍轻微回避 1 类）。
  - 模型规模非决定性因素：Gemma-3-4B (TPR) Macro-F1 = 24.4，Gemma-3-27B = 25.2；而 Llama-3.1-70B 仅排倒数第二，证明 TPR 弥补了小模型知识容量差距。
