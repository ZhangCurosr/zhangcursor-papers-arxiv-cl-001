# 论文速读：Select, Compress, Reinvest: A Controlled Study of Visual-Token Allocation in Long-Video MLLMs

## 一句话总结
本文对长视频多模态语言模型（MLLM）中的视觉 Token 分配问题进行了受控对照研究，在固定编码器、提示边界、帧预算和回答模型的前提下，依次干预**选择（Selection）**、**压缩（Compression）**和**再投资（Reinvestment）**三个决策，发现高质量帧选择是最大杠杆，而老算法 OMP 无调参即可匹敌多种专用选择器，且将压缩节省的预算再投资于更多关键帧可进一步提升 2–3 个点。

## 研究问题与动机
- **长视频无法逐帧处理：** 1fps 下 1 小时视频有 3600 帧，系统仅能保留少量关键帧，因此"选哪些帧"是管线中最紧的瓶颈，而非预处理细节。
- **已有对比缺乏控制变量：** 不同论文在选择器、编码器、提示边界、分辨率策略和回答模型上同时变化，无法归因单一决策的增益来源。
- **均匀采样是否仍是最优默认？** 均匀采样仍是事实默认策略，但其代价是否被低估、被高质量查询感知选择替代后的收益如何，缺乏系统化度量。
- **空间压缩与帧数扩展的收益如何分解？** 近年方法将帧选择和空间分辨率联合优化，但三者机制（更优时间戳、更优分辨率策略、更多帧数）难以分离。

## 核心贡献（创新点）
1. **第一个在统一评分器、提示、预算和回答模型下对 6 种免训练选择器进行成对比较的研究：** 所有规则共享同一 LongCLIP 缓存分数，消除了编码器差异带来的混淆；OMP 作为无视频定制机器的通用算法，与 LDDR-select 相差不到 1 个点。
2. **将"帧预算分配"分解为三个可独立干预的决策：** 选择（换时间戳）、压缩（缩分辨率）、再投资（用节省的 token 选更多帧），每个决策通过配对实验给出因果贡献，而非端到端黑箱对比。
3. **发现跨编码器排序的稳定性与实现误差的隐蔽性：** 将 LongCLIP 替换为 SigLIP 后 67%–84% 帧被替换但选择器排序不变；一个 AKS 实现的 padding bug 使 99.5% 帧被错误选中，却仅导致聚合准确率变化 0.07 个点，揭示了"跨实验比较"的脆弱性。
4. **提供了 OMP 在该嵌入空间中工作机制的观察性诊断：** LongCLIP 的文本查询与帧嵌入锥几乎正交，残差范数仅轻微下降，说明 OMP 在此并非做稀疏重构，而是做相关性+去重；后期选择补充了视觉新颖性但可能引入不相关噪声。

## 方法详解
- **实验单元（paired comparison）：** 每次比较在同一基准问题上执行两次，仅改变一个决策变量（选择/压缩/再投资），其余全部冻结。
- **共享编码器（LongCLIP）：** 所有候选帧与问题标题统一由 LongCLIP 编码一次，缓存后供所有选择器读取；答案选项不参与评分（遵循 AKS 官方实现）。
- **六个无训练选择器：**
  - **Uniform：** 均匀采样固定数量帧。
  - **Top-k：** 余弦相似度直接取 top-k。
  - **AKS（Tang et al., 2025）：** 递归分区保持时间覆盖。
  - **FOCUS\*（Zhu et al., 2025b）：** 在原发布调度下回放，但以密集 LongCLIP 向量替代原始 ITM 评分器（\*标记表示此为受控重放而非完整 FOCUS 流水线）。
  - **OMP（Pati et al., 1993）：** 经典稀疏近似算法，每一步选择与当前残差最相关的帧，然后投影消除已选方向：
    $$b_r = \arg\max_{i \notin B_{r-1}} e_i^\top q_{r-1}, \quad q_r = q_0 - \text{Proj}_{\text{span}\{e_j: j \in B_r\}}(q_0)$$
  - **LDDR-select（Chen et al., 2026a）：** 仅使用 Stage-1 的 Linear-DPP 选择器，不含动态分辨率流水线。
- **空间压缩干预：** 在固定时间戳下将每帧空间预算约减半（D@53 方案，均值约 0.53），使用 Qwen3-VL 的 smart-resize 规则进行实证 token 审计。
- **再投资干预：** 将压缩节省的 token 用于选择 k=16 个时间戳并施加约 50% 每帧上限；实际 token 消耗仅为原 k=8 全分辨率的 0.984–0.996 倍（LongVideoBench 审计）。
- **统计方法：** 配对 McNemar 检验；等价性声明采用双单侧检验（TOST）并报告 90% CI；跨基线比较使用重叠率检查。

## 实验与结果
- **数据集：** LongVideoBench（n=1337，分 15/60/600/3600s 四档），Video-MME（n=2700），LVBench（n=1549）。
- **主要回答模型：** Qwen3-VL-8B-Instruct（greedy，temperature=0，字幕关闭）；补充 InternVL3-2B/8B 与 GPT-5-mini。
- **核心结果（k=8，LongCLIP 评分）：**

| 方法 | LongVideoBench | Video-MME | LVBench |
|------|---------------|-----------|---------|
| Uniform | .5654 (−5.69) | .5637 (−5.85) | .3454 (−11.81) |
| Top-k | .6028 (−1.95) | .5704 (−5.18) | .4319 (−3.16) |
| OMP | **.6223** | **.6222** | **.4635** |
| AKS | .5916 (−3.07) | .6059 (−1.63) | .4287 (−3.48) |
| FOCUS\* | .5819 (−4.04) | .5578 (−6.44) | .3983 (−6.52) |
| LDDR-select | **.6320** (+0.97) | .6193 (−0.29) | **.4693** (+0.58) |

- **帧选择 vs. 帧数：** OMP 以 8 帧超越 Uniform 以 16 帧（LongVideoBench 3600s：+.6461 vs .4770，+6.9 pts，p=.0011）。
- **编码器交换（LongCLIP→SigLIP）：** 67%–84% 帧被替换，排序不变；OMP 优势在两个编码器下均显著。
- **压缩影响：** 压缩至约一半预算，准确率变化最多 ±0.44 pts（TOST ±3pt 等价区间，p=.0022）。
- **再投资收益：** k=8 全分辨率 → k=16 压缩，LongVideoBench +2.24 pts，LVBench +3.04 pts（p=.0009），Video-MME +1.56 pts，GPT-5-mini +2.39 pts。
- **InternVL3 泛化：** 在 InternVL3-8B 上同样复现选择增益（LongVideoBench +6.51，LVBench +10.14）；Video-MME 长视频上 8B 模型对 OMP 不敏感。
- **最强结果：** LDDR-select 在 LongVideoBench 上达 .6320；OMP 在 LVBench 上以 +11.81 pts 大幅领先 Uniform。

## 相关工作脉络
1. **AKS（Tang et al., 2025）：** 递归时间分区选择器，与 OMP 相比在 Video-MME 上差 1.63 pts，在 LVBench 上差 3.48 pts；两者均为无训练规则，但 AKS 有视频结构先验。
2. **FOCUS（Zhu et al., 2025b）：** 基于预算 bandit 的帧选择，本文以 LongCLIP 密集分数重放其调度（FOCUS\*），性能显著低于 OMP（LVBench −6.52 pts）。
3. **LDDR（Chen et al., 2026a）：** 线性 DPP 选择器 + Group-DPP 重要性动态分辨率；本文仅比较其 Stage-1 选择器部分，结果与 OMP 极为接近（LongVideoBench 差 0.97 pts）。
4. **Q-Frame（Zhang et al., 2025a）/ DAFS（Wang et al., 2026b）：** 联合优化帧选择与分辨率的端到端系统，本文将其增益分解为时间选择、分辨率策略和帧数三个独立机制，指出这些方法的联合收益来源不透明。
5. **MDP3（Sun et al., 2025）/ AdaRD-key（Zhang et al., 2025b）：** DPP 家族内的相关性-多样性权衡方法；本文附录 C 显示多种 DPP 变体未显著超越 OMP。
6. **AdaAlloc（An & Grauman, 2026）：** 同期工作直接研究全局上下文与高分辨率局部证据的预算分配，但当时无公开代码，本文从其项目页摘要描述，视为上游问题而非竞争方法。

## 局限性与未来方向
- **等价性 margin 为事后选择：** TOST 的 ±3pt 边界是在查看数据后选择的，非预注册，因此等价性声明偏向描述性而非确认性。
- **机制证据依赖特定编码器：** OMP 残差几何分析基于 LongCLIP 和 SigLIP（均为对比式 image-text 编码器），ITM 头或 MLLM attention 评分器的行为未测试。
- **部分辅助实验在第二计算环境运行：** 存在约 0.36–0.71 pts 的绝对精度漂移，但配对差异不受影响。
- **字幕关闭限制：** 所有实验关闭字幕，对依赖字幕的问题有系统性不利。
- **未来方向：** 引入"相关性下界"约束以减少无关新颖性干扰；探索事件边界约束的多样性选择器；测试更小模态间隙的评分器；将 OMP 残差范数作为快速 scorer 评估代理指标。

## 研究启发与可借鉴点
1. **成对配对 + 跨臂重叠率检查是检测实现 bug 的有效手段：** AKS 的 padding 错误通过 98.5% 重叠被捕获，建议所有选择器论文报告帧索引重叠率作为 sanity check。
2. **残差几何诊断可作为 scorer 快速评估工具：** OMP 的残差范数（0.972→0.967 仅轻微下降）揭示了 LongCLIP 的模态间隙问题，该方法可推广到其他 scorer 的快速诊断。
3. **"选择→压缩→再投资"三阶段分解框架可迁移：** 任何涉及多粒度资源分配的视觉任务（如图像 token 剪枝、多尺度特征融合）均可参照此框架进行因果归因。
4. **跨编码器排序验证增强结论可靠性：** 用 SigLIP 替换 LongCLIP 后排序保持稳定，表明核心发现不仅依赖单一编码器，可作为后续研究的基准验证步骤。
5. **OOS 算法（OMP）作为强 baseline 的价值：** 几十年的通用稀疏近似算法无调参即可匹敌专用设备，提示在提出新选择器时应与经典算法在同一设置下公平比较，而非仅与均匀采样对比。

## 关键术语表
- **OMP（Orthogonal Matching Pursuit）：** 1993 年提出的贪心稀疏近似算法，迭代选择与当前残差相关性最高的原子并正交投影消除已选方向。
- **LongVideoBench：** 包含 15s/60s/600s/3600s 多时长分层的长视频理解基准，本题使用该基准完整验证集（n=1337）。
- **TOST（Two One-Sided Tests）：** 用于等价性检验的统计方法，通过双单侧检验构建置信区间来证明两个条件差异在预设范围内。
- **DPP（Determinantal Point Process）：** 用于多样性子集选择的概率模型，通过行列式惩罚候选集内元素的冗余度。
- **FOCUS\*：** FOCUS 选择器在本文受控设置下的重放版本，以密集 LongCLIP 向量替代原始预算 ITM 评分器，仅测试调度有效性而非完整流水线。
- **Reinvestment：** 将空间压缩节省的视觉 token 预算重新分配给更多时间戳帧的决策策略。
- **Modality Gap（模态间隙）：** 对比学习模型中图像与文本嵌入空间之间的系统性偏差，本文观察到文本查询与帧嵌入锥近乎正交。
- **LDDR-select：** LDDR 系统的 Stage-1 Linear-DPP 选择器部分，不含动态分辨率流水线。

## 可复现要素
- **代码：** 已开源（https://github.com/codeprakhar25/omp-keyframe-sampling），含选择器实现、分析脚本、选定帧索引、跨实验重叠检查脚本及预注册文档。
- **权重：** 使用公开模型（Qwen3-VL-8B、InternVL3-2B/8B、LongCLIP、SigLIP-so400m）及 API 模型（GPT-5-mini）；不含训练。
- **数据集：** 三个公开基准（LongVideoBench、Video-MME、LVBench），基准视频文件未随代码发布。
- **关键超参：** 候选池 1fps，k=8（选择）/ k=16（再投资），压缩均值约 0.53（D@53），TOST margin ±2/±3 pts，McNemar 双侧检验，temperature=0，greedy decoding。
