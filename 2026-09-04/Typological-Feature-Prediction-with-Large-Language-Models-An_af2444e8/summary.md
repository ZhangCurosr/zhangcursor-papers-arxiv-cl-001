# 论文速读：Typological-Feature-Prediction-with-Large-Language-Models-An

## 一句话总结
本文探索大语言模型通过上下文学习（In-Context Learning）整合谱系、地理与类型学关联证据，完成 URIEL+ 类型学特征补全的任务；发现仅靠语言元数据的零样本提示无效，但加入锚点特征与邻居证据后，LLM 性能全面超越传统插补基线，且在低资源语言上表现稳定，同时能生成与给定证据基本一致的预测依据。

## 研究问题与动机
- 类型学特征数据库（如 URIEL+）稀疏度高达 87%，且缺失最严重的正是低资源语言，亟需可靠的自动化补全方法。
- 现有方法（kNN 插补、SoftImpute 低秩矩阵分解、随机森林等）跨语言资源层级与特征类型的性能差异未被充分评估，且输出通常缺乏可解释的预测依据。
- LLM 已展现出元语言推理能力与生成理由（rationale）的潜力，是否可用于类型学特征预测并提升方法的可解释性尚不明确。
- 如何设计合理的上下文提示，使 LLM 能有效整合结构化的语言学证据（谱系亲缘、地理邻近、统计关联）而非依赖外部平行语料？

## 核心贡献（创新点）
1. **提出多源证据结构化 ICL 框架**：将目标语言元数据、Phi 系数强关联锚点特征、谱系邻居与地理邻居组合为四模块 prompt，与依赖外部平行文本或大规模预训练特征的既往方法本质不同，仅利用库内生证据即可完成推理。
2. **揭示 LLM 在类型学预测上的性能边界与优势**：证明零样本元数据提示显著低于基线，但引入邻居证据后最佳配置（Llama-3.1-70B）整体 Macro F1 达 0.909，全面超越 SoftImpute（0.821），且在低资源语言上不仅未受损反而略优于高资源语言。
3. **引入人机对比注释协议评估可解释性**：在 180 个样本上开展两阶段人工标注，证实提示提供足够证据，LLM 预测与人类聚合高度一致（Cohen's κ=0.831），且约 79% 的 rationale 与给定证据一致，首次为类型学预测的可解释性提供实证支撑。
4. **设计控制变量严格的对照实验**：将 Random Forest 基线限制在与 LLM 完全相同的输入条件下训练，成功剥离“信息量”与“模型推理能力”的贡献，明确归因 LLM 优势源于逻辑整合而非单纯统计拟合。

## 方法详解
- **任务形式化**：将 URIEL+ 类型学矩阵中的缺失条目预测视为二元插补任务。令 $\mathbf{M} \in \{0,1,\bot\}^{N \times F}$ 为矩阵（$N{=}4{,}555$ 语言，$F{=}800$ 特征），对查询 $(\ell, f)$ 且 $\mathbf{M}[\ell,f]=\bot$ 时预测 $\hat{\nu} \in \{0,1\}$。
- **Prompt 四模块构建**：
  1. **目标语言元数据**：语言名称、Glottocode、ISO 639-3、语系谱系、宏观区域。
  2. **锚点特征（Anchor Features）**：基于训练集用 Phi 系数 $\phi(f_i,f_j)=\frac{n_{11}n_{00}-n_{10}n_{01}}{\sqrt{n_{1\cdot}n_{0\cdot}n_{\cdot1}n_{\cdot0}}}$ 预计算与目标特征最相关的 top-10 特征；为每个观测到的锚点提供条件支持计数 $P(f=1|a=\nu_a)$ 与全局对齐汇总。
  3. **谱系邻居**：以 $\ell$ 为根在 Glottolog 家系树上 BFS 构建上限 400 的候选池，贪心选取 5 个最大化覆盖目标与锚点特征的语言；输出各邻居的 $f$ 值、最多 3 个锚点值及邻近排名，汇总 yes/no/missing 票数，并强制包含支持 0 和 1 的最近对比邻居。
  4. **地理邻居**：构建逻辑同谱系邻居，候选池按 Glottolog 坐标的 Haversine 距离排序，距离以 km 报告。
- **输出约束与推理引导**：要求输出单行 minified JSON（`rationale`≤2句、`value`∈{"0","1"}、`confidence`∈{low,medium,high}），并附带 3 个示例；引导语强调综合权衡证据、近距离邻居权重可能高于远距离大量邻居、少数派若支持更充分可预测少数值。
- **基线对照设计**：Random / Majority / kNN-cosine(k=3) / SoftImpute / kNN
