# 论文速读：How-Perturbations-Propagate-A-Multi-Level-Analysis-of-Robust

## 一句话总结
本文在输出行为、隐藏状态几何与注意力头功能三个层面上，系统量化了六种自然/合成扰动在 Decoder-only LLM 中的传播轨迹；发现单一指标评估极易产生误导，只有当行为与内部指标多维收敛时（如对抗扰动），才能可靠判定模型的真实脆弱性。

## 研究问题与动机
- **输出行为无法完全刻画内部破坏**：现有鲁棒性评测多依赖 NLL 或生成文本相似度，但两种扰动可能产生相似的外部输出变化却破坏完全不同的内部表征或计算组件。
- **跨层级一致性未知**：扰动在层间几何（CKA、内在维度）与电路功能（注意力头分布）上的传播模式是否与行为指标对齐，尚未有系统性实验验证。
- **对抗扰动与自然扰动的本质差异待分离**：HotFlip 等梯度导向攻击常被简化为“高编辑率随机替换”，缺乏在严格匹配位置与速率条件下的多层面对照证据。
- **跨模型结论常受指标选择干扰**：GPT 与 Qwen 等架构在不同扰动下的表现差异，究竟是架构本质不同，还是评测指标（如 NLL vs Output Divergence）引入的假象，尚需解耦。

## 核心贡献（创新点）
1. **三层面联合量化扰动传播路径**。此前鲁棒性研究多聚焦单一输出指标，本文同步引入表示几何与注意力头功能诊断，揭示单指标结论的盲区与过拟合风险。
2. **建立头功能得分与激活补丁恢复的定量关联**。以往机制研究多停留于定性归类，本文证明 Copying 头得分可高效预测补丁修复效果，为黑盒功能定位提供可计算代理。
3. **提出位置严格匹配的对抗-随机对照框架**。现有攻击评估常混淆编辑率与优化目标，本文在同一编辑位点与比例下构建随机对照，首次在多层面上剥离出对抗搜索的独立破坏效应。
4. **确立“指标收敛性”作为鲁棒性验证的方法论标准**。不同于仅报告最优指标的做法，本文指出当行为与内部指标一致时结论才可靠，为跨架构泛化分析提供了可复用的诊断规范。

## 方法详解
- **输入与扰动构建**：基于 WikiText-2 Raw，固定 seed 采样长度 ≥128 的 300 条序列。设置六种扰动（char 均匀字符替换、typo QWERTY 邻键错误、token 均匀词表替换、word 单词级替换、synonym WordNet 同义词替换、shuffle 窗口内 token 乱序），强度 p ∈ {5%, 30%, 50%}。
- **行为指标**：负对数似然 (NLL) 衡量模型预测置信度下降；Output Divergence 采用归一化 Levenshtein 距离衡量生成序列差异。
- **表示几何指标**：
  - **CKA**：计算层间干净与扰动激活的余弦核相似度，预除去方差 Top-5 维度以降低离群敏感；仅对重分词后 token 数一致的扰动（token/shuffle）进行逐位置严格比较。
  - **TwoNN 内在维度**：基于 batch 内局部最近邻距离比 $d = N / \sum \ln(r_2^i / r_1^i)$ 估计激活流形复杂度，报告干净与扰动输入的 ΔID。
- **注意力头功能与扰动响应**：
  - 计算四类头得分（previous-token、duplicate、induction、copying），其中 Copying Score 基于 OV 电路矩阵 $C = E W_v^{(h)} W_o^{(h)} U$ 的 top-k 覆盖期望。
  - 测量 30% 扰动下归一化注意力熵的变化 $\Delta H$。
  - **激活补丁恢复**：将扰动输入的头部激活替换为干净输入对应激活，计算指标恢复率 $\Delta\%O = \frac{O(y_p) - O(\tilde{y})}{O(y) - O(\tilde{y})} \times 100$，仅保留 token/shuffle 等保持位置对应性的扰动。
- **对抗对比实验**：采用 HotFlip 梯度引导攻击（候选池 $|S|=50$），为每个被接受的对抗替换构建同位置、同比例的随机 token 控制，比较双方在 NLL、Output Divergence、CKA 与 ΔID 上的差异。

## 实验与结果
- **数据集与模型**：WikiText-2；GPT-2 系列（base/medium/large/xl）与 Qwen2.5-0.5B/1.5B。
- **行为分化**：Char 扰动产生最大 Output Divergence（50% 时 0.932），但 Token 替换在 30% 强度下 NLL 升至 8.569，显著高于 Word (7.376) 与 Synonym (5.427)，证明生成文本变化与预测置信度下降并非单调对齐。
- **几何指标独立信号**：CKA 显示 Char/Typo 破坏最强、Shuffle 保留较高相似度；TwoNN 显示 Char/Typo 降低早期层内在维度，而 Token 替换大幅提升内在维度，进一步验证行为-几何解耦。
- **头功能关联**：Induction 得分与熵增呈负相关（-0.271 ~ -0.609）；Copying 得分与补丁恢复强正相关（NLL 恢复：Token 0.726，Shuffle 0.622；Output Div 恢复：Token 0.652，Shuffle 0.348）。
- **跨模型一致性**：GPT 与 Qwen 在 NLL 与内在维度上呈现家族特异性差异（如 Token 替换 Qwen 内在维度增幅小于 GPT），但 Output Divergence 差异极小，表明架构影响高度依赖评测指标。
- **对抗 vs 随机**：HotFlip 在所有模型与强度下均显著高于匹配随机替换（GPT-2 30%：NLL 11.03 vs 8.52，Output Div 0.64 vs 0.57），且行为与内部指标全收敛，确认对抗优化带来真实的底层计算破坏。
