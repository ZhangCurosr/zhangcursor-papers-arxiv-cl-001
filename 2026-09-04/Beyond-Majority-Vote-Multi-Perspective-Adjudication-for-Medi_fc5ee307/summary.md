# 论文速读：Beyond Majority Vote: Multi-Perspective Adjudication for Medical Hallucination Detection

## 一句话总结
本文提出了**多视角注解流程**，结合初筛标注、LLM-as-a-Judge（LaJ）候选发现与医学专家/事实核查两种裁决方式，系统研究了医疗幻觉检测中标注流程对基准构建的影响，揭示了单次通过、单标注者幻觉基准普遍低估事实错误的现象，并开源了MDHJudgments数据集。

## 研究问题与动机
- **核心问题**：医疗聊天机器人长回答中的事实错误检测如何可靠地构建评测基准？
- 现有方法普遍采用**单次通过（single-pass）、单标注者**的标注范式，但长回答中错误往往隐藏于大量正确信息中，容易被遗漏。
- 多判断与裁决虽可提升完备性，但与大规模数据集构建目标存在张力；且医疗领域的正确性判断本身就依赖专业知识与证据，裁决者之间也可能产生分歧。
- 本研究旨在揭示标注流程选择对基准完备性及检测器评估结果的实质性影响。

## 核心贡献（创新点）
- **提出MDHJudgments多视角注解数据集**：首次结合初筛标注、LaJ候选发现与医学专家/事实核查两种裁决路径，构建了支持分析标注误差来源的基准。
- **将TREC风格集合评估（pooled assessment）引入幻觉检测**：初筛者与LaJ共同作为"系统"贡献候选，再由裁决者裁定，显著提升了候选发现的完备性。
- **揭示LaJ与人类初筛者的互补性**：LaJ能发现初筛遗漏的错误（召回率可达71–80%），但也会遗漏初筛者发现的错误，二者不可互相替代。
- **指出裁决者分歧揭示了标注任务的本质不确定性**：即使经过双重裁决，医学专家与事实核查者之间仍存在显著分歧（66%一致率），说明"has_error"并非完全客观的标签。
- **在MedExpert数据集上验证模式的普适性**：应用相同流程后，78% LaJ发现但MedExpert未注释的段落经裁决确认为错误，支持单次通过基准系统性低估事实错误的结论。

## 方法详解
**总体框架**：标注被视为"候选发现 + 裁决"的两阶段问题，而非单次判定。

1. **初筛标注（First-Pass Annotation, FP）**：
   - 标注者群体：医疗专业人员、医学训练学生、AI研究员（共20人）。
   - 两级判断：先对整段回答进行1-3级整体准确性判断；再对每段（section）进行细粒度判断，标记事实错误及属性错误（certainty/risk/urgency），最终简化为二元的`has_error`标签。
   - 回答含1–27个段落，平均每个回答8.1个段落，共4,377个段落。

2. **LLM-as-a-Judge（LaJ）候选发现**：
   - 使用GPT-5（temperature=1）提示模型对初筛者与LaJ存在分歧的段落进行事实错误检测。
   - 裁决池组成：402个初筛者分歧段落 + 389个初筛者与LaJ分歧段落 + 35个数据增强注入但被遗漏的段落（表2）。

3. **双重裁决**：
   - **医学专家裁决（Medical-Expert Adjudication）**：由Prolific认证的通用医疗领域专家（$130/hour，21人）基于自身知识判定，分为major/minor/no_error/needs_research四档，阅读初筛评论后可修正判断。
   - **事实核查裁决（Fact-Checking Adjudication）**：由具备事实核查技能的人员（$30/hour，156人）进行，需查找权威来源（如CDC、NIH、Mayo Clinic等），判定证据与段落及评论的关系（图4）。
   - 裁决结果同样简化为`has_error`用于基准构建。

4. **参考集构建**：三种构建方式：(1) FP:AG（初筛者全一致）；(2) FP+ME（添加医学专家裁决）；(3) FP+FC（添加工具人核查裁决）。

## 实验与结果
- **数据集**：MDHJudgments（541对问答，涉及囊性纤维化与儿科传染病学），代码与数据已开源（https://github.com/isi-vista/mdhjudgments）。
- **评估指标**：Krippendorff's α、跨组交叉复制可靠性（xRR）、Precision/Recall/F1。
- **一致性结果**：
  - 初筛者间一致率仅85%，α=0.15；医学专家一致率81%，α=0.05；事实核查一致率67%，α=0.07（表3）。
  - 跨组比较（表4）：FP与两类裁决的xRR仅0.01，LaJ与医学专家xRR=0.23，LaJ与事实核查xRR=0.40。
- **基准性能（表5）**：
  - 初筛标注者对FP+ME参考集的Recall仅21%，对FP+FC参考集Recall仅20%。
  - **LaJ表现显著更优**：FP+ME参考集上P=90%，R=71%，F1=80%；FP+FC参考集上P=90%，R=80%，F1=85%。
  - 若以不完整的FP:AG为参考（仅6个段落被 unanimously 标注为错误），LaJ的Precision骤降至2%，Recall为83%，说明缺少完备参考会严重扭曲检测器性能估计。
- **MedExpert验证**：78% LaJ发现但MedExpert未注释的段落经医学专家裁决后确认为错误（§5）。
- **核心结论**：单次通过的基准因初筛者漏检而系统性低估事实错误率；LaJ有效填补了候选缺口；但裁决分歧表明即使是多轮流程也无法达成完全客观的标注。

## 相关工作脉络
- **MedHallu**：基于PubMedQA构建，专注于合成注入幻觉的大规模数据集，无多视角注解流程。
- **MedExpert / MedVAL**：均为单次单视角注解，仅少量段落多标注用于计算一致性，缺乏裁决阶段；本文在LaJ引入和多源候选发现上与之区别。
- **MedHalu**：聚焦技术性较强的简短回答，本文覆盖面向患者的开放域长回答。
- **FELM**：具有多初筛者和裁决者，但未探索自动候选增强、响应级与段落级决策关系、及裁决间一致性分析。
- **HaluEval / FavaBench / SelfCheckGPT**：非医疗领域、无裁决流程的幻觉检测基准，可作为跨领域方法迁移的参照。
- 本文定位：填补了**医疗领域多视角幻觉标注流程的系统性分析**空白，强调基准构建过程本身对评测结论的影响。

## 局限性与未来方向
- 结果主要针对囊性纤维化与儿科传染病学两个领域，外推至其他医疗领域需谨慎；虽在MedExpert上做了验证，但未完整复现其标注指南。
- 裁决依赖分歧样本，对随机样本的裁决者一致率未知，可能存在选择偏差。
- LaJ仅使用单一模型（GPT-5）和单一提示，不同模型/提示组合可能产生不同候选池。
- 无法区分裁决分歧源于真实的专业判断差异还是简单失误（如疲劳、操作错误），需引入额外裁决层才能进一步分析。
- 所有标注者/裁决者均为美国背景，可能影响对事实性的判断标准。
- 未来方向：探索更多LLM视角的互补性、量化裁决分歧来源、拓展至更多医疗子领域、研究Holistic response-level judgment与section-level error率的关系。

## 研究启发与可借鉴点
- **TREC风格集合评估框架可直接迁移**：将多个检测器（包括不同配置的LLM）的输出汇集为候选池，再进行裁决，可显著提升基准的recall完备性，适用于任何幻觉检测评测场景。
- **LaJ作为候选发现机制而非最终标签来源**：本文证实LaJ能有效补充人类初筛者的遗漏，但自身精确率偏低，这一"互补而非替代"的关系为设计混合标注流程提供了实证依据。
- **响应级与段落级判断的关系值得深入研究**：本文发现响应级评分与段落错误率相关性仅-0.39（§4.5），高响应级评分的回答仍可能包含大量段落级错误，提示单一 holistic 指标不足以反映细粒度事实正确性。
- **裁决分歧本身的分析价值**：不应简单将裁决视为"纠错"终点，而应将分歧视为标注不确定性的信号来源，可用于指导标注指南迭代或评估标准的设计。
- **跨数据集验证方法论**：将相同流程应用于MedExpert等已有数据集进行"回溯性增强"，是验证方法普适性的有效策略，可为后续文献综述中的对比实验设计提供参考。

## 关键术语表
- **First-Pass Annotation (FP)**：初筛标注，由非统一背景的标注者对文本进行首轮事实性判断，通常作为候选发现的第一步。
- **LLM-as-a-Judge (LaJ)**：利用大语言模型作为自动化判断器，用于发现初筛标注可能遗漏的事实错误候选。
- **Adjudication（裁决）**：对初筛者之间或初筛者与LaJ之间的分歧进行最终判定，本文包含医学专家裁决与事实核查裁决两种形式。
- **has_error**：将多步细粒度判断简化为的二元标签，表示段落是否存在事实错误，是基准构建的核心目标变量。
- **Cross-Replication Reliability (xRR)**：扩展Cohen's κ至跨群体比较的指标，消除组内一致率和标注人数差异的混淆，用于评估不同标注范式的一致性。
- **TREC-style pooled assessment**：信息检索中的集合评估范式，将所有候选系统的检出结果汇集后再由评审员裁定，本文首次系统引入幻觉检测基准构建。
- **Holistic response-level judgment**：对整段回答的整体准确性判断（1-3级），与段落级细粒度判断形成对照，二者相关性仅-0.39。
