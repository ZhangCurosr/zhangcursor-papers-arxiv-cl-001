# 论文速读：Transfiver-Human-AI-Co-Inference-through-a-Shared-Editable-S

## 一句话总结
提出 **Transfiver** 架构，通过一个用户与模型共同维护的单一持久可编辑状态 $S_t$ 实现人机协同推理，解决长期交互中模型隐式更新状态导致用户修正无法生效的核心痛点，并以可证伪的“历史充分性”与“因果干预”契约验证其可行性。

## 研究问题与动机
- 长期人机交互中，指导推理的信息由模型隐式累积，用户无法直观检查或直接编辑，导致“旧事实仍被采信”或“修正不生效”。
- 现有记忆方案（RAG、Agent分层记忆、参数编辑 ROME/MEMIT、Supersede 等）普遍将“用户可见状态”与“模型实际计算状态”分离，存在隐藏计算路径。
- 记忆更新责任归属模糊：模型作为记忆看门人会自带偏差，而真正知道信息变更的是用户，用户操作应直接作用于模型计算所读的底层状态。
- 缺乏形式化、可审计的架构标准：需要明确界定何时一个系统真正满足“所见即所算”的共享状态要求。

## 核心贡献（创新点）
1. **提出共享可编辑状态模型与界面渲染规范**，明确状态必须保留身份、内容、时间、来源、生命周期等多维区分，而非仅靠词频或位置堆叠。
2. **形式化“历史充分性”与“因果干预”架构契约**，以数学条件约束“用户可见状态 = 模型唯一持久计算路径”，与记忆附件、事后解释或纯展示层划清界限。
3. **参数-状态分离范式与免梯度在线演化**，部署期冻结 $\theta$，仅通过前向 transition 或用户定向编辑更新 $S_t$，实现“单次事件学习”而不触发重训练。
4. **提供小型可运行实现与全套审计指标**（路径完整性、目标改变、局部性、回滚对称性），并在合成与真实多会话记录上验证契约可被满足。

## 方法详解
- **双轨状态演化**：`Stream Update`（模型根据新事件隐式判断归并或新建条目）与 `Directed Edit`（用户显式选址修改条目）作用于同一 $S_t$，二者失败模式不同，需分别评估。
- **状态代数结构**：$S_t = (\{s_{t,i}\}_{i=1}^{N_t}, R_t, \Gamma_t)$，单条 $s_{t,i}$ 含身份 $\kappa_i$、内容 $v_{t,i}$、占用 $o_{t,i}$、事件时间 $\tau_{t,i}$、地位 $w_{t,i}$、使用证据 $u_{t,i}$、来源 $p_{t,i}$、生命周期 $\sigma_{t,i}$；$R_t$ 存关系，$\Gamma_t$ 存关系/事件历史。
- **离线学习 vs 在线演化**：离线阶段 $S_{t+1} = T_\theta(S_t, z_t)$ 通过任务损失更新 $\theta$；部署阶段 $\theta$ 冻结，$S_{t+1} = T_\theta(S_t, z_t)$ 仅靠前向传递演化，用户编辑直接改写 $S_t$，均不触碰参数梯度。
- **历史充分性契约**：$S(H_t) = S(H'_t) \Longrightarrow \mathrm{Law}(F_\theta(H_t, c)) = \mathrm{Law}(F_\theta(H'_t, c))$，即任何隐藏缓存或独立历史路径都会破坏该等式。
- **测试模型实现**：采用 slot 结构 $(K, V, O, A)$，通过 $\bar{q}_t \cdot \bar{K}_i + \log(O_i+\epsilon)$ 计算注意力偏置，softmax 路由含学习到的 Unsupported Sentinel $\bot$；transition 用 straight-through estimator 学习“接入已有身份 vs 创建新身份”的离散决策。
- **审计度量**：路径完整性 $\epsilon_{\text{path}} = \|L_t - \hat{L}_t\|$；目标改变 $\mathrm{target}(i,q)$、局部性 $\mathrm{locality}(i,q)$、回滚距离 $\mathrm{rollback}(i,q)$；对称性要求状态置换仅 permute 输出分布而不改变行为。

## 实验与结果
- **合成测试（附录A）**：5个独立seed验证上下文隔离与多规则读取。4/5 seed 成功分离两上下文，context-conditioned accuracy 达 1.000，recency collapse 为 0.000，每episode创建条目稳定在 8 个；第2条件（上下文仅由header事件宣布）下5/5 seed 全部达成 1.000 准确率。
- **冻结状态多规则读取**：4种时序规则（most recent / earliest / as-of-section / nth value）共用 385 参数读出头，held-out 测试 5120 queries：准确率分别为 1.000 / 1.000 / 0.984 / 0.996；规则替换与编号替换控制实验表明模型真正读取了状态中的时间秩与关系标识，而非走捷径。
- **真实多会话交互记录**：44个含新旧值标注的用户-助手对话条目，对比 `prompt deletion` 与 `state retraction`。Retraction 策略下当前值准确率保持 0.659–0.705，旧条目次日返回次数为 0/44，且能恢复旧值（14–17/44）；Deletion 策略次日准确率骤降至 0.432–0.523，旧条目返回 31/44。保存-重载后状态张量完全一致，验证历史充分性。
- **最强结果**：state retraction 在真实记录上实现“修正即刻生效且不丢失历史追溯能力”，较 prompt deletion 在次日准确率上提升约 22%–27%（以 Mistral 为例 0.432→0.659）。

## 相关工作脉络
- **Neural Turing Machines / Fast Weights / Titans**：外部记忆或快速权重可在线变化，但未要求状态对用户透明且可定向编辑。
- **Transformer / Selective SSMs**：隐式压缩序列历史，缺乏地址化、可审计的持久交互状态。
- **Supersede [17]**：训练模型自我维护有界记忆以提升过时事实更新准确率，但未暴露状态供人工干预、回滚或跨会话审计。
- **RAG / kNN-LM / MemGPT / Larimar / Memory Layers at Scale**：检索或分层记忆作为外挂侧车，可见存储与计算模型存在分离，不满足“唯一持久计算路径”约束。
- **ROME / MEMIT**：直接编辑 Transformer 参数更新事实关联；Transfiver 保持参数冻结，改为编辑在线状态，避免梯度编辑带来的分布漂移。
- **Concept Bottleneck Models / Self-Explaining Networks**：允许用户干预概念层，但通常非跨交互持久状态；Transfiver 将“可干预对象”提升为架构核心的持久状态本体。

## 局限性与未来方向
- 当前仅为小型原型实现，扩展至自由文本、复杂关系网络与大尺度共享状态仍开放。
- 若人类不主动修正错误，可能引发身份错配、强制合并歧义条目、单义拆分、来源混淆、静默重要信息丢失等新失败模式。
- 隐私、安全与治理义务（来源追踪、删除、导出、访问控制、有害用户行为适配）需额外工程与设计，当前架构未覆盖。
- 需引入因果抽象（causal abstraction）标准进行严格测试，而非仅依赖解码准确率验证“所见即所算”。

## 研究启发与可借鉴点
- **形式化契约驱动架构设计**：用可证伪的数学条件（历史充分性、路径完整性、回滚对称性）替代黑盒记忆模块，为可解释 Agent 与长期交互系统提供可审计基准。
- **参数-状态分离 + 免梯度在线演化**：部署期冻结模型参数，仅通过前向 transition 或用户编辑更新状态，适合需要长期个性化、避免 catastrophic forgetting 的 assistant 场景。
- **可解释读出头设计**：用少量语义特征（时间秩、关系存在性、编号偏移）+ 极小网络替代端到端黑盒读取，便于诊断“答案是否真从可见状态产出”。
- **State Retraction 替代 Prompt Deletion**：在记忆管理系统中，标记条目为不可读而非物理删除，可同时支持“当前正确输出”与“历史追溯”，对审计与合规场景极具价值。
- **与团队方向结合机会**：可将此共享状态抽象为 LLM Agent 框架的统一记忆层，替代当前基于向量库+上下文窗口的割裂设计；或将其契约思想迁移至长视频/多模态持久记忆对齐任务。

## 关键术语表
- **Transfiver**：一种人机协同推理架构，通过单一持久可编辑状态 $S_t$ 绑定用户可见界面与模型计算路径，要求“所见即所算”。
- **History Sufficiency（历史充分性）**：若两个交互历史压缩后得到相同状态 $S_t$，则任意未来续接产生的输出分布必须相同，排除隐藏持久路径。
- **Directed Edit（定向编辑）**：用户显式选中状态中某个可寻址条目并替换其内容，要求修改立即生效、局部隔离且可精确回滚。
- **Stream Update（流式更新）**：模型隐式根据新到达事件判断是否归并至已有条目或新建条目，无需用户指定地址。
- **State Retraction（状态撤回）**：将条目标记为不可读而非物理删除，使模型停止基于该条目输出，同时保留历史记录供追溯或恢复。
- **Causal Intervention Contract（因果干预契约）**：编辑可见状态必须等价于编辑模型实际计算所用的状态，且修改具有目标局部性，不因无关输入产生副作用。
- **Straight-through Estimator**：用于离散写入决策（选择已存在身份 vs 创建新身份）的梯度近似方法，使反向传播可跨硬路由层。
- **LongMemEval**：评估聊天助手长期交互记忆能力的基准，涵盖提取、多会话推理、知识更新、拒答与时间感知等核心能力。
