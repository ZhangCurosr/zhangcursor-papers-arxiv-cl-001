# 论文速读：Contextual Tamil Spelling and Grammar Correction Using Progressively Fine-Tuned Sequence-to-Sequence Transformers

## 一句话总结
本文提出了一种端到端序列到序列的泰米尔语拼写与语法纠错方法，基于 mT5-small 和 mBART-50 在合成语料上执行四阶段渐进式微调，覆盖从表层噪声到跨词 sandhi 变化的十类错误；最佳模型 mBART-50 v5 在 1,000 句平衡诊断集上达到 69.3% 的 top-1 精确匹配准确率，沙迪类错误率达 87.5%。

## 研究问题与动机
- **泰米尔语的语言特性带来极高纠错难度**：泰米尔语为黏着语，拥有 247 个独立字母、丰富的动词形态变化及严格的 sandhi（音节连接音变）规则，拼写正确性与语法正确性深度交织，且高度依赖上下文。
- **现有方法仅处理表层错误，忽略上下文敏感错误**：已有的规则方法、统计 n-gram 模型及混合流水线多聚焦于同音字符替换等表层噪声，无法可靠处理主谓一致、时态一致性、跨词 sandhi 等需句子级理解的问题。
- **生成能力未被充分利用**：近期混合方法将 Transformer 仅用作候选重排序打分器，无法主动生成未在候选列表中出现的语法修正。
- **缺乏大规模标注语料，合成数据策略成为核心障碍**：泰米尔语缺乏真实标注的拼写错误语料，现有资源无法覆盖用户实际产生的错误多样性，特别是上下文层面的错误。

## 核心贡献（创新点）
- **端到端 Seq2Seq  formulation 替代重排序范式**：直接对 mT5-small 和 mBART-50 进行微调以将噪声句映射为干净句，而非将 Transformer 仅作为重排序器；本质区别在于释放了模型的生成能力，可修复候选生成器未覆盖的错误类型。
- **四阶段渐进式微调课程（v2→v5）**：每个阶段针对一类特定弱点——表层噪声、上下文语法、单点 sandhi、多点跨词 sandhi——分离了课程设计与架构差异的贡献；已有工作多采用单阶段端到端训练或仅覆盖单一错误类别。
- **构建 657,720 对合成训练数据的噪声注入流水线**：覆盖十类错误（含语料挖掘的一致性和跨词 sandhi 违反），并按 70/20/10 拆分，使用清洗句哈希确保无泄漏；此前泰米尔相关工作多仅针对单一混淆类别且训练/测试分布重合。
- **构建并公开验证的 1,000 句平衡诊断集**：每类 200 句，经精确匹配与 5-gram Jaccard 双重验证与训练数据无交集，并报告 top-1 精确匹配与复制基线（20.0%）；此前的上下文无关工作多用 top-k 准确率且无此类严格验证。
- **首次量化 sandhi 召回与身份准确率之间的单调权衡**：随 sandhi 召回上升，身份保持准确率单调下降；此前泰米尔拼写纠错文献未报告此类精度-召回权衡关系。

## 方法详解
- **骨干模型**：使用 mT5-small（300M 参数，span-corruption 预训练）和 mBART-50（610M 参数，去噪 seq2seq 预训练）。mT5 输入前缀 `"correct tamil: "` + 噪声句；mBART-50 在源句和目标句前均添加 `ta_IN` 语言 ID token。mT5 因 sentinel token 泄露问题，将 `decoder_start_token_id` 覆写为 pad token 并移除 `forced_bos_token_id`，使用 Adafactor 优化器以避免 bf16 下的 NaN loss；mBART-50 使用 AdamW。
- **四阶段渐进微调**：
  - **v2（表层噪声）**：在 500,000 对表层噪声数据上微调，处理插入、删除、替换、换位错误。
  - **v3（上下文增强）**：在 v2 基础上引入 75,000 对上下文错误（26.5% 主谓一致、15.1% 时态一致、10.4% 格标记等），加上 2,720 对主谓模板、30,000 对语音增强、20,000 对词内 sandhi、30,000 对身份样本，总计 657,720 对；降低学习率以防灾难性遗忘，cosine 调度，3% warmup，patience=3 早停。
  - **v4（单点 sandhi）**：从 v3 检查点恢复，使用 30,000 对单点 vallinam sandhi 错误数据训练 1 epoch，附 30,000 对 v3 回放样本。
  - **v5（多点跨词 sandhi）**：从 v3 恢复，使用 40,000 对多点 sandhi 数据（32,425 对单点、6,608 对两点、967 对三点）训练 2 epoch，附 20,000 对回放样本。
- **推理**：beam search（4 束），`no_repeat_ngram_size=3`，length penalty=1.0，early stopping，最大生成长度 128 token；mBART-50 设置 `forced_bos_token_id` 为 `ta_IN`。每个句子仅需一次前向传播。
- **损失与评估**：训练使用 label smoothing=0.1；验证集通过 token-F1 选择检查点；主指标为句子级 top-1 exact-match accuracy，辅以 token-F1 和 character error rate。

## 实验与结果
- **数据集**：基于 Tamil Wikipedia（约 170 万词，处理后约 120 万句），合成噪声对总计 657,720 对；诊断集为 1,000 句平衡集（每类 200 句），经哈希和 5-gram Jaccard 验证与训练数据无交集。
- **评估基线**：复制基线（Copy，返回输入不变，20.0%）、Tamil-LLaMA-7B-Instruct（zero-shot 19.0%、3-shot 24.7%，4-bit NF4 量化）。
- **主要结果**：
  - **最佳模型 mBART-50 v5**：总体 **69.3%** top-1 精确匹配，沙迪类 **87.5%**，主谓一致 **43.5%**，语音混淆 **69.5%**，Pulli 遗漏 **72.0%**，身份保持 **74.0%**。
  - mT5-small v5：63.1%，比 mBART-50 v5 低 6.2pp。
  - 各阶段增益：主谓一致从 v2 的 1.0% → v3 的 52.5%；沙迪从 v2/v3 的 0% → v4 的 63.0% → v5 的 87.5%（mBART-50 v5）。
  - Tamil-LLaMA-7B-Instruct zero-shot 19.0% 与复制基线 20.0% 无统计显著差异（p=0.59）。
- **关键结论**：课程设计的贡献大于架构差异；sandhi 召回以身份准确率为代价单调递增；提示大模型无法替代任务特定的监督微调。

## 相关工作脉络
- **TamilMayangoliSpell（Yazhmozhi VM et al., 2026）**：同样微调多语言 seq2seq 模型，报告 93.50% 精确匹配，但仅针对单一 mayangoli 音近字符混淆类别，排除 sandhi 和上下文错误；本文覆盖十类错误并报告与训练集验证不相交的诊断集结果。
- **Parthasarathi et al.（2003）及规则/统计方法**：基于形态分析的拼写检查器或 bigram/n-gram 模型，上下文窗口仅 2 词，无法处理跨度更长的语法依赖；本文彻底转向端到端生成式方法。
- **Sampath & Shanmugavel（2023）混合方法**：结合编辑距离、Soundex、规则与 LSTM 打分，仅输出候选排名；本文直接使用 Transformer 生成能力，无需候选生成+重排序两步。
- **Rajalakshmi et al.（2023）RoBERTa 拼写检查器**：对预枚举候选进行判断而非生成；本文与之本质区别在于端到端生成式句子级修正。
- **Tamil-LLaMA-7B-Instruct（Balachandran, 2023）**：泰米尔适配的大语言模型；本文首次在其上评估专注拼写纠错任务，发现零样本提示与复制基线无显著差异，说明通用 LLM 不经微调难以迁移到专用正字法纠错。
- **Sharma & Bhattacharyya（2025）Hi-GEC**：低资源印地语语法纠错的比较研究（直接噪声注入/往返翻译/神经错误生成）；本文沿袭合成数据策略但扩展到泰米尔语的多类别语法错误场景。

## 局限性与未来方向
- **sandhi 覆盖不完整**：失败集中在特定句法模式（如与格的名词后接某些动词），鼻音同化等罕见现象完全未覆盖，87.5% 仅涵盖 vallinam 类型。
- **维基语料偏差**：训练和诊断数据均来自 Tamil Wikipedia，与即时通讯、搜索、学生写作等真实场景存在体裁差异。
- **回放策略有待优化**：v4/v5 的回放样本从 v3 语料中均匀采样，可能导致主谓一致能力部分遗忘（mT5 v3→v5 从 52.5% 降至 40.0%）。
- **可选 sandhi 的规范争议**：部分被标记为"身份错误"的修改实际上是规范性语法中存在争议的选择，需母语者仲裁。
- **未来方向**：对回放样本按类别加权；扩展至 TamilCorp 等体裁平衡语料；对 Tamil-LLaMA 进行 LoRA 微调以分离架构与监督的影响；加入 NLLB 验证课程泛化性；从社交媒体和学生写作中获取真实错误。

## 研究启发与可借鉴点
- **渐进式课程设计的可迁移性**：将复杂纠错任务分解为逐层增强的阶段（表层→上下文→特定语言现象），每阶段只引入一类新错误并配合回放防遗忘，该策略可迁移至其他低资源语言的 GEC 任务。
- **身份样本（identity pairs）作为负样本的必要性**：将 20% 训练数据设为无需修改的干净句对，迫使模型学会"不修改"，这对防止过度纠错具有通用价值，值得在其他正字法任务中采用。
- **precision-recall 权衡的系统性量化**：通过分类平衡的诊断集揭示单指标会掩盖的 trade-off（sandhi 召回 vs 身份保持），为部署决策提供依据——建议类场景用高 recall 模型，自动修正类场景用保守模型。
- **大语言模型提示在专门任务上的局限**：Tamil-LLaMA 的零样本/少样本结果接近复制基线，说明通用 LLM 在低资源语言的专用纠错任务上需要任务特定微调而非仅靠提示；这一结论对其他低资源语言的大模型应用具有警示价值。
- **诊断集构建方法**：哈希+5-gram Jaccard 双重验证确保诊断集与训练集严格分离，该验证流程可直接复用于其他合成数据驱动的 NLP 任务评估。

## 关键术语表
- **Sandhi（桑迪/连音规则）**：泰米尔语等印度语言中词边界的语音变化规则，相邻词的音节相互影响产生拼写变化，是本文核心纠错目标之一。
- **Vallinam**：泰米尔语法中的硬辅音类别（克、戳、特、扑），其触发的 sandhi 变化需插入辅音后缀，是本文 sandhi 纠错的重点类型。
- **Pulli（ Pulloid 省略）**：泰米尔语元音标记符（◌்）的遗漏错误，属于表层字符级错误。
- **Mayangoli 混淆**：泰米尔语中音近字符（如 ல/ள/ழ, ர/ற, ந/ன/ண）的混淆错误，是泰米尔语特有的高频表层错误类型。
- **Top-1 exact-match accuracy**：句子级精确匹配准确率，要求模型输出与标准答案完全一致，本文主要评估指标。
- **渐进式微调（Progressive Fine-tuning）**：多阶段训练策略，每阶段在前一阶段检查点基础上引入新数据类别，逐步扩展模型能力。
- **Catastrophic forgetting（灾难性遗忘）**：神经网络在新任务上训练时丢失已有知识的现象，本文通过回放样本缓解。
- **Span-corruption**：mT5 的预训练目标，随机掩码输入中的连续片段并要求模型重建，区别于 mBART 的去噪序列重建目标。
