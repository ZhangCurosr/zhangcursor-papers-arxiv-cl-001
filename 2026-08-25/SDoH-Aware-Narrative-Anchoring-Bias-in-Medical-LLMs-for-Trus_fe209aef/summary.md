# 论文速读：SDoH-Aware-Narrative-Anchoring-Bias-in-Medical-LLMs-for-Trus

## 一句话总结
本文首次评估医疗大语言模型中的"SDoH感知叙事锚定偏差"，提出以反事实案例分组方式为评估框架，发现即使模型平均准确率有所提升，其对相同临床事实但不同患者叙事表达仍会给出不一致回答，提示可信临床决策支持需同时报告准确率与叙事鲁棒性。

## 研究问题与动机
1. **现有评估盲区**：医疗LLM评测多聚焦平均准确率，无法揭示模型对相同病例不同患者叙事表达的稳定性缺陷，高准确分数可能掩盖"同病不同答"的风险。
2. **临床现实需求**：真实患者很少使用标准化格式表达症状（有的用医学术语，有的表达不确定，有的提及经济困难），SDoH相关信息可能具有临床意义，但不应导致模型在临床事实和答案不变时改变回答。
3. **叙事锚定偏差风险**：模型可能过度聚焦患者表达方式或社会背景线索，而非基于临床证据作答，这种偏差在临床决策支持系统中可能导致分诊建议、诊断提示或随访指导的不一致。
4. **基准局限性**：静态基准无法全面衡量安全决策支持所需技能，需要引入案例分组的反事实评估指标来补充传统评测。

## 核心贡献（创新点）
1. **首次定义并操作化"SDoH感知叙事锚定偏差"概念**，将其建模为案例分组的反事实评估问题，与以往仅关注人口统计学属性或宏观社会标签的偏差研究形成区别。
2. **提出案例级一致性指标体系**（CC、Correct CC、NSE），将模型表现拆解为稳定正确、稳定错误、叙事敏感、不稳定错误四类，区别于已有工作仅报告平均准确率的单一维度。
3. **在Qwen2.5系列模型上完成受控的尺度对比实验**（1.5B/3B/7B，同数据集、同提示设计、确定性解码），揭示1.5B→3B主要提升准确率，而3B→7B同时改善准确性和案例级稳定性，规模效应呈现非线性特征。
4. **引入配对统计验证框架**（Bootstrap 95%置信区间 + McNemar精确检验），确保结论不依赖于点估计，相比仅有描述性统计的 prior work 更具统计严谨性。

## 方法详解
1. **数据集处理**：使用NarrativeShield SDoH MedQA数据集，将宽格式（一行包含原病例及三个persona列）重塑为长格式（每个question_id展开为3行，分别对应persona_alpha/beta/gamma），使反事实比较可直接按案例分组。
2. **实验采样**：以seed=42采样300个唯一临床病例，保留全部persona变体，得到900行persona级别数据；每种提示条件生成2,700次响应，三模型共8,100次响应。
3. **三种提示条件**：
   - **Zero shot**："选择最佳选项并返回一个字母及简要解释"
   - **Few shot**：在目标病例前提供两个已解答医学示例
   - **Bias aware**："专注于临床证据。忽略写作风格或患者背景，除非具有临床相关性"
4. **模型设置**：Qwen2.5 1.5B/3B/7B Instruct，4-bit量化加载（bitsandbytes），确定性解码（do_sample=False），max_new_tokens=120，解析无效输出计为错误。
5. **评估指标公式**：
   - 准确率：Acc = (1/MK) ΣΣ I(ŷᵢⱼ = yᵢ)
   - 反事实一致性（CC）：CC = (1/M) Σ I(ŷᵢ₁ = ŷᵢ₂ = ... = ŷᵢₖ)，衡量同一病例所有变体是否得到相同预测
   - 正确一致性（Correct CC）：Correct CC = (1/M) Σ I(∀j, ŷᵢⱼ = yᵢ)，要求所有变体均答对
   - 叙事敏感性误差（NSE）：NSE = (1/M) Σ I(∃a,b: ŷᵢₐ = yᵢ ∧ ŷᵢᵦ ≠ yᵢ)，衡量是否存在至少一个变体对、一变体正确一变体错误

## 实验与结果
1. **数据集与基线**：NarrativeShield SDoH MedQA（公开），对比三个Qwen2.5 Instruct模型（1.5B/3B/7B）在三种提示条件下的表现；无其他外部基线，内部对比为主。
2. **最佳结果**：Qwen2.5 7B在零样本提示下取得最高准确率56.33%（95% CI: 53.11%-59.44%），最佳正确一致性40.33%，最佳反事实一致性57.67%（bias aware提示），最低NSE为31.67%（bias aware提示）。
3. **尺度效应**：1.5B→3B提升主要为准确率增益，鲁棒性改善较小且不均衡；3B→7B同时显著改善准确性和案例级稳定性，但仍未消除叙事敏感性。
4. **统计显著性**：McNemar精确检验显示，7B在所有三种提示条件下均显著优于3B（p值从0.000049到<0.000001不等）；bias aware vs zero shot提示对比在所有模型上均无显著差异（p=0.246~1.000）。
5. **核心结论**：模型规模扩大可改善准确性和叙事鲁棒性，但bias aware轻量提示不足以消除叙事敏感性；即使最优条件下仍有约31.67%的病例组存在叙事敏感误差，说明"平均准确率高"与"跨叙事稳定"并非同一回事。

## 相关工作脉络
1. **Medical QA基准系列**（MedQA[3], MedMCQA[4], PubMedQA[5], MultiMedQA[1]）：侧重于考察模型医学知识储备和考试式问答能力，未涉及叙事变体下的稳定性评估，本文在此维度进行补充。
2. **临床LLM评估局限研究**（[2], [15], [16]）：指出当前医疗LLM评估未能充分识别系统在实际临床场景中的安全性和适用边界；本文通过引入反事实案例分组指标，将这一批评具体化为可操作的评测框架。
3. **SDoH信息提取研究**（[8], [9]）：关注LLM从电子健康记录中提取社会健康决定因素的能力，视SDoH为有用临床信息；本文则转向关注SDoH相关的叙事线索可能成为模型不稳定的来源，视角从"利用"转向"风险"。
4. **医疗AI偏差与公平性研究**（[10], [11], [12]-[14]）：Omiye等发现LLM可复现种族医学误解，Omar等发现社会人口学变化可改变LLM医疗决策；本文聚焦更细微的"叙事形式"维度——即使不包含显式人口统计学信息，仅叙事表达方式的差异也足以触发回答不一致。
5. **定位差异**：已有工作多关注模型公平性（demographic parity、equal opportunity等），本文关注的是counterfactual consistency层面的稳定性，填补了"同病例不同叙事表达"这一评估空白。

## 局限性与未来方向
1. **任务形式局限**：实验使用多选题而非开放式临床推理，无法捕捉完整诊断推理或治疗规划过程，需后续扩展至open-ended clinical reasoning场景。
2. **临床等价性未经验证**：persona变体的临床等价性基于数据集固定答案键，未经医师独立裁决；未来需加入clinician review确认变体间无实质性临床信息差异。
3. **模型范围有限**：仅评估Qwen2.5系列三个尺度模型，结论不宜推广至所有通用或医学专用LLM；需扩展至更大规模开源模型、闭源商业系统及临床微调模型。
4. **提示干预较简单**：bias aware提示仅为轻量指令，更有效缓解可能需要模型训练、校准、检索增强（RAG）或临床审核等综合方案。
5. **绝对准确率偏低**：7B模型最佳准确率56.33%，反映模型紧凑性、非医学领域专门化及任务难度，当前模型不宜视为临床可用系统。
6. **真实对话复杂性**：controlled persona variants虽有助于隔离变量，但真实临床对话常包含缺失信息、多语言混杂、多轮澄清等更复杂场景。

## 研究启发与可借鉴点
1. **反事实案例分组评估框架可迁移**：将"同实体不同表述"作为评估维度的思路可直接迁移至法律LLM、金融LLM等其他高风险领域的鲁棒性评测。
2. **四类误差分解方法值得借鉴**：Stable Correct / Stable Wrong / Narrative Sensitive / Unstable Wrong的分类框架，为区分"知识缺失"与"叙事敏感性导致的错误"提供了清晰的诊断工具。
3. **配对统计方法的应用范式**：Bootstrap置信区间结合McNemar精确检验的配对比较方案，适用于任何"同一测试集上多模型/多条件"的对照实验设计。
4. **可与本团队方向结合的机会**：将RAG（检索增强生成）或知识图谱约束引入叙事鲁棒性提升，或探索在预训练/微调阶段引入counterfactual augmentation数据，是本团队可延伸的创新点。
5. **跨语言/跨文化叙事稳定性**：本文persona变体为同一语言的风格变化，可扩展至跨语言患者叙事场景（如英文vs西班牙语文本），评估LLM的多语言叙事鲁棒性。

## 关键术语表
**SDoH (Social Determinants of Health)**：社会健康决定因素，指影响个人健康状况的非医疗社会因素，如收入、教育水平、居住环境、医疗可及性等。
**叙事锚定偏差 (Narrative Anchoring Bias)**：模型因患者叙事表达方式（如用词正式程度、情绪状态、社会背景提及）不同而对相同临床事实给出不同回答的倾向。
**反事实一致性 (Counterfactual Consistency, CC)**：同一临床病例的所有persona变体获得相同预测答案的比例，衡量模型回答对叙事形式的稳定程度。
**叙事敏感性误差 (Narrative Sensitivity Error, NSE)**：至少存在一个persona变体回答正确而另一等价变体回答错误的病例占比，是本文核心负面指标。
**案例分组评估 (Case Grouped Evaluation)**：以临床病例为单位而非单个问题条目来评估模型表现的方法论，强调跨变体的一致性而非单点准确率。
**偏差感知提示 (Bias-aware Prompting)**：在提示中明确指示模型专注于临床证据、忽略写作风格或患者背景等非相关线索的prompt策略。
**确定性解码 (Deterministic Decoding)**：使用greedy decoding（do_sample=False）而非概率采样生成响应，以消除随机性对评估结果的干扰。
**正确一致性 (Correct Counterfactual Consistency)**：同一病例的所有persona变体均被模型正确回答的比例，是比CC更严格的稳定性指标。
