# 论文速读：DELISTBENCH-Evaluating-Search-Enabled-LLMs-for-Auditable-Cor

## 一句话总结
本文提出 SEARCH-TO-RECORD（S2R）数据库保障任务与 DELISTBENCH 基准（1,200 条退市公告记录），用于评估搜索增强型 LLM 能否基于公开来源独立重构金融机构自定义的公司事件记录。

## 研究问题与动机
- 金融机构持有从 vendors 购买的证券主数据库与公司事件历史，但面临记录缺失、过时、分类错误、与内部定义不一致等审计风险。
- 独立的人工公共来源审计成本高（需定位交易所公告、区分正式行动与警示、识别公告日期而非生效日期、保留证据链）。
- 现有事件抽取工作假设已提供文档（DCFEE、FinReason），而非从开放网络检索并结构化输出数据库就绪记录；现有 RAG/搜索增强工作多面向开放问答，而非限定安全范围与历史截止的闭集重建。
- 检索增强本身不足以可靠完成日期/理由/列表边界判定，且经济型系统能否逼近最强系统仍不清楚。

## 核心贡献（创新点）
1. **形式化 SEARCH-TO-RECORD（S2R）任务**：将检索增强的 LLM 评测从“回答问题”转向“重建机构定义的事件记录”，强调闭集、可审计、证据导向的数据库保障视角。
2. **构建并发布 DELISTBENCH 基准（1,200 条记录）**：引入三条诊断层（A 正样本/ B 未来负样本/ C 仍在市负样本）与发行国家不交划分，便于区分不同失败模式。
3. **成对封闭/联网五模型系统性评测**：在同一记录结构与公开 API 定价下比较 GPT-5.6 Luna、DeepSeek V4 Pro/Flash、Gemini 3.6 Flash/3.5 Flash-Lite 的决策、日期、理由、成本与延迟，给出部署路线图。
4. **基于风险分层（L2 正则逻辑回归）的接受/审核路由协议**：在 5% 实证校准误差目标下分离低风险负样本自动通过、高风险正样本人工复核的工作流。
5. **成本-性能前沿分析**：发现经济系统（DeepSeek V4 Flash、Gemini 3.5 Flash-Lite）以 4.5%–6.6% 的最贵系统 API 成本达到 75.9%–78.3% 的联合精度，证明低成本替代可行。

## 方法详解
- **S2R 输入/输出形式化**：输入为 $(e_i, s_i, v_i, c_i, z_i, T_i)$（发行人、证券、目标交易所、国家、可选稳定 ID、历史截止 $T_i$）；输出为 $(q_i, d_i, r_i, E_i, u_i)$（状态 yes/no/unknown、正式公告日期、标准化理由、声明级证据、不确定性），仅当 $q_i=$ yes 时日期/理由有效。
- **退市公告定义**：要求公开正式决定/获批申请/交易所判定/撤回申请/已完成退市行动；警示、宽限期、可能退市、停牌、最后交易日、无正式披露的生效日、针对其他上市地的行动均不满足。
- **DELISTBENCH 三分层设计**：Stratum A=400 截止前已公告的合格退市；Stratum B=400 截止前未公告、截止后出现的“未来公告”负样本；Stratum C=400 截至 2026-08-06 在任何时间对同一标的无合格退市的仍在市控制样本。B/C 虽同为 no，但代表不同的失败模式（前瞻误判 vs 仍存活误判）。
- **评估指标**：整体联合正确率（所有 1,200 条）、A-only 日期 $\pm 7$ 天与宽泛理由正确率、A-联合 $\pm 7$、整体联合 $\pm 7$；无效输出与弃权计为错误；单独报告证据质量、成本、延迟。
- **成本度量**：基于 2026-08-11 观测的公开 API 使用与列表价（按 1,000 条计费），不含工程/基础设施/人工审核。
- **风险接受路由**：以模型置信度、模式有效性、弃权、引用数、延迟、回答长度、提供商搜索请求数为特征训练 L2 正则逻辑回归；在 300 条校准集上选最大阈值使经验接受误差 $\le 5\%$，并在 300 条测试集上不变应用；无效输出与弃权强制送入人工审核。

## 实验与结果
- **数据集**：DELISTBENCH，1,200 条，覆盖 59 个发行人国家（美加 38.2%、亚太 26.3%、欧洲 26.3%、非洲/中东 4.8%、拉美/加勒比 4.4%）；截止 2020-12-31，两侧各 180 天排除缓冲；发行商家族不交分层划分（600 训练/300 校准/300 锁定测试）。
- **模型与条件**：5 个模型系列各 2 种条件（封闭/联网），共 10 个配置；联网条件下使用各自官方搜索工具。
- **关键数字**：联网使 $\pm 7$ 天日期精度提升 34.0–48.0 pp、事件状态精度提升约 2.8–21.7 pp；最佳系统 Gemini 3.6 Flash 联网整体联合精度达 81.5%，A-only 日期 $\pm 7$ 天为 58.2%、理由 71.8%、A 联合 $\pm 7$ 为 45.2%。
- **经济系统逼近**：DeepSeek V4 Flash 联网 A-联合 $\pm 7$ 为 79.0%（低于 GPT-5.6 Luna 1.2 pp）、成本仅为 GPT-5.6 Luna 的 6.6%；Gemini 3.5 Flash-Lite 联网 A-联合 $\pm 7$ 为 75.9%、成本仅为 4.5%，延迟最低。
- **风险接受表现**：Gemini 3.6 Flash 接受 72.7% 样本、误差 3.7%；DeepSeek V4 Pro 接受 65.7%、误差 2.5%；GPT-5.6 Luna 达 6.8% 误差（高于 5% 校准目标），说明实证校准并非测试集保证。
- **失败模式**：日期仅偏差占 41.4%、错过公告占 19.8%、日期+理由偏差占 19.0%、B 类前瞻投影占 8.1%；证据审计显示 yes 预测仅有 52.8% 通过，no 预测 88.3% 通过。

## 相关工作脉络
- **DCFEE / FinReason**：文档级/细粒度金融事件抽取工作，假设已提供文档，而 S2R 包含检索、列表解析与数据库就绪输出。
- **WebGPT / ReAct**：浏览器辅助问答与工具交错使用基线；S2R 固定目标身份与历史截止，聚焦事件记录重建而非开放 QA。
- **FreshLLMs / RealTime QA**：动态事实检索研究；本工作在受限证券宇宙、明确截止的闭集设定下评估。
- **ALCE / LongFact**：引用质量与分声明验证；S2R 的证据审计用于判定 URL 可达性、列表身份、截止相关性、支持程度。
- **Selective Classification / Risk-controlling Prediction Sets**：选择性预测与风险约束理论；S2R 采用经验校准集阈值，非形式测试集保证。
- **FinDeepForecast / FinDeepResearch**：近期金融深度研究与预测基准；本文转向数据库保障与可审计事件记录重建，而非行情预测。

## 局限性与未来方向
- **平衡分布不代表真实 prevalence**：基准设定 $\pi_A=\pi_B=\pi_C=1/3$ 暴露罕见但关键的失败，生产环境的正样本比例更低，因此基准报告的风险估计未被重加权。
- **使用当前公开网络重建历史事件**，而非封存的历史索引；未评估实时检测延迟；黄金日期仅为构建时发现的“首个合格公开披露”，未必是最早披露。
- **C 类仅表示截至 2026-08-06 未识别合格行动**，并不证明其不存在。
- **国家字段为发行人地理**而非上市市场，且缺少越南等低资源市场的记录，限制对动机场景的结论外推。
- **证据审计由 Codex 辅助完成**，两样本人机 agreement 为 78%，完整 750 包未双重编码；可重复性需归档 prompts、访问日期、配置与原始输出。
- **未来方向**：更强的正样本联合完成能力、市场感知部署校准、风险触发式机器升级（官方源二次检索/确定性时间线检查/独立验证器/更强模型）、以及小规模人工审核尾段。

## 研究启发与可借鉴点
- **任务定义层面的启示**：将检索增强 LLM 从“生成文本”转向“生成数据库就绪记录 + 证据链”，适合需要审计轨迹的金融/合规场景。
- **分层设计可迁移**：A/B/C 三分层清晰区分“真实正样本/前瞻误判/仍在市误判”三类失败模式，值得复用到其他事件抽取基准（并购、财报、监管处罚）以揭示隐藏错误结构。
- **成对封闭/联网评估范式**：固定模型设置、仅开放检索权限的 paired design，能干净估计检索对各项指标的真实增益，建议作为工具型 LLM 报告的标配。
- **风险-接受阈值与部署 prevalence 分离讨论**：给出 $R_{dep}(t)=\sum \pi_s^{dep} r_s(t)$ 公式，提示在基准上观察到的最低 27.3% 审核率不可直接外推至生产。
- **成本-性能前沿图与 ready-yield 指标**：同时报告每 1,000 条成本、延迟与 A-only ready yield，便于机构按预算权衡模型选择。

## 关键术语表
- **SEARCH-TO-RECORD（S2R）**：搜索增强型 LLM 从公开来源重建机构定义事件记录的数据库保障任务。
- **DELISTBENCH**：1,200 条退市公告记录组成的闭集基准，含 A/B/C 三层诊断分布。
- **Stratum A/B/C**：A=截止前已公告的合格退市；B=截止前未公告但在截止后发布的“未来公告”负样本；C=截至观测日对同一标的仍无合格退市的仍在市控制样本。
- **Joint $\pm 7$ accuracy**：状态正确、公告日期在 $\pm 7$ 天范围内、且宽泛理由正确的联合指标（仅应用于 A 或全量记录）。
- **Risk-based acceptance routing**：以模型置信度等为特征训练 L2 正则逻辑回归，选阈值在经验接受误差 $\le 5\%$ 下最大化接受覆盖，强制无效/弃权送入人工审核。
- **Economy web system**：以最高价系统 4.5%–6.6% API 成本运行、仍能达成 75.9%–78.3% 联合精度的联网模型。
- **Prevalence effect**：生产环境中正事件比例远低于基准 1/3 时，整体审核负载显著降低的现象。
- **Ready yield**：在所有测试记录中既被自动接受又 joint-exact 正确的比例（用于衡量 A 类可自动放行产出）。
