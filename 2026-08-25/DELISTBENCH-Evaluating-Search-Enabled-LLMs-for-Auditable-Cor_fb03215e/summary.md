# 论文速读：DELISTBENCH-Evaluating-Search-Enabled-LLMs-for-Auditable-Cor

## 一句话总结
本文提出了 **SEARCH-TO-RECORD（S2R）** 数据库保障任务与 **DELISTBENCH** 基准（1,200 条退市公告记录），系统评测了五种主流大模型在开放网络检索辅助下重建机构定义的公司事件记录的能力；结果表明，接入网络后公告日期±7天准确率提升 34.0–48.0pp，最佳系统整体联合准确率（±7天）达 81.5%，而低成本经济型系统在仅占最高成本 4.5–6.6% 的情况下可逼近最优精度。

## 研究问题与动机
1. **金融机构的数据库审计需求**：金融机枃依赖外部数据商的公司事件历史库，但核心痛点不是"有哪些公司"，而是事件库是否完整、准确、及时且符合机构自身定义。
2. **独立公共源审计成本高昂**：传统人工审计需逐条查找交易所/发行人公告、区分正式行动与预警、映射公告日期而非生效日期，工作量大。
3. **网络检索 LLM 的 fluent 输出≠数据库就绪**：模型可能检索到正确公司但错误listing、将未来事件投影至历史截止期前、返回有合理日期但无法由引用支撑的判断。
4. **现有事件抽取工作假设文档已提供**：DCFEE、FinReason 等工作均基于已知文档，而 S2R 还需检索、listing 解析，并返回可直接入库的结构化记录。

## 核心贡献（创新点）
1. **提出 SEARCH-TO-RECORD 可审计数据库保障任务**：将目标身份和截止期固定、事件状态开放的条件设定形式化，与现有闭卷事件抽取任务本质不同。
2. **构建并公开 DELISTBENCH 基准**：1,200 条记录平衡分为三大诊断层（A正样本/ B未来事件负样本/ C仍上市对照组），使用发行人家族不相交拆分，公开证据可由第三方复核。
3. **设计风险自适应分流框架**：通过 L2 正则逻辑回归预测每条记录的出错风险，在平衡校准集上选择误差≤5% 的最大阈值并冻结至测试集，实现"低误码自动接受、高误码送审"的分层流程。
4. **系统评测五种模型族在配对闭卷/联网条件下的完整表现**：揭示网络检索是时效性提升的主因，低成本模型可接近最强系统，但未解决正样本日期/原因的精确恢复瓶颈。

## 方法详解
1. **S2R 任务形式化**：输入 $x_i = (e_i, s_i, v_i, c_i, z_i, T_i)$，其中 $e_i$ 发行人、$s_i$ 证券、$v_i$ 目标交易所、$c_i$ 国家、$z_i$ 可选标识符、$T_i$ 截止期；输出 $\hat{y}_i = (q_i, d_i, r_i, E_i, u_i)$，$q_i \in \{\text{yes}, \text{no}, \text{unknown}\}$ 为截止期前事件状态，$d_i$ 正式公告日期，$r_i$ 规范化原因，$E_i$ 声明级证据，$u_i$ 不确定性。
2. **退市事件定义**：阳性需满足"公开发布的正式决定/批准申请/交易所裁定/已提交撤回/已完成退市行动"且针对指定证券和交易所； deficiency warning、暂停交易、最后交易日、不含合格披露的生效日等均不构成阳性；后续反转不影响历史有效记录。
3. **DELISTBENCH 构建**：1,200 条均分三层，Stratum A=400 正样本（截止前已有合格公告），Stratum B=400 未来负样本（截止后才有合格公告），Stratum C=400 活跃控制（截至 2026-08-06 无任何合格退市行动且仍在交易）。覆盖 59 个发行人国家，38.2% 来自美加，26.3% 亚太，26.3% 欧洲。截止期 2020-12-31，两侧 180 天排除缓冲区。按 600/300/300 进行发行人家族不相交分层拆分。
4. **评估协议**：决策准确率在所有 1,200 条上评估；日期和宽泛原因准确率在 400 条 A 类上评估；联合正确性要求每条记录决策正确且 A 类满足日期容差与原因正确；无效输出和弃权计为错误。证据质量、成本、延迟单独评估不进入层级正确性。
5. **风险基接受与分流**：对每条记录，使用模型置信度、schema 有效性、弃权、引用数、延迟、回答长度、提供商搜索请求数等特征训练 L2 正则逻辑回归；在 300 条校准集上选择经验接受集误差≤5% 的最大阈值并冻结至测试集；无效输出和弃权一律送审。
6. **部署校准**：引入 prevalence 效应，生产环境 review 负载为 $R_{\text{dep}}(t) = \sum_s \pi_s^{\text{dep}} r_s(t)$，并通过约束条件 $R_{\text{dep}} \leq 5\%$、$\text{Recall}_A \geq \gamma$、$\text{Err}_{\text{accept}} \leq \delta$ 联合选择策略，防止以漏报阳性换取低 review 率。

## 实验与结果
1. **数据集与模型**：DELISTBENCH（1,200 条），评测模型 5 族 × 2 条件 = 10 个系统：GPT-5.6 Luna、DeepSeek V4 Pro、Gemini 3.6 Flash、DeepSeek V4 Flash、Gemini 3.5 Flash-Lite。
2. **状态准确率**：所有联网系统在 Macro-F1 上全面优于闭卷；最佳系统 **Gemini 3.6 Flash Web** 准确率达 97.3%，Macro-F1 97.0%，A-precision 99.2%，A-recall 92.8%。DeepSeek V4 Pro 闭卷 A-recall 高达 89.8% 但在 Web 下降至 85.0%（−4.8pp）。
3. **日期与原因完成**：A-date-±7 提升 **34.0–48.0pp**，A-joint-±7 提升 **24.8–35.3pp**；但 Gemini 3.6 Flash Web 仅能精确日期化 46.0% 的 A 记录，联合完成（决策+日期±7天+宽泛原因）仅 **45.2%**。
4. **整体联合准确率（±7天）**：最佳系统 Gemini 3.6 Flash Web 达 **81.5%**；经济型 DeepSeek V4 Flash Web 79.0%（成本仅 GPT-5.6 Luna 的 6.6%）；Gemini 3.5 Flash-Lite Web 75.9%（成本仅 4.5%）。
5. **错误分析**（Table 4）：日期仅错误占 41.4%，遗漏公告 19.8%，日期+原因 19.0%，未来投影错误（B 类）8.1%，C 类假阳性 3.7%，弃权 3.1%；主要瓶颈非 JSON 格式，而是识别正式事件阶段、绑定目标 listing、遵守截止期。
6. **证据审计**：52.8% 的 yes 预测证据包通过协议，88.3% 的 no 预测通过；Codex 与人工标注精确一致率 78.0%，排除不可评估后一致性 89.4%。
7. **风险分流**（Table 6）：Gemini 3.6 Flash Web 接受 72.7% 记录、误差 3.7%、review 率 27.3%；DeepSeek V4 Pro Web 接受 65.7%、误差 2.5%；但 A 类阳性自动接受率仅 2.1–18.9%，条件接受误差仍高达 44.4–70.6%。

## 相关工作脉络
1. **DCFEE / FinReason（金融事件抽取）**：假设文档已提供，聚焦单一文档内的事件抽取与原因提取；S2R 额外要求检索、listing 解析并返回可直接入库的机构定义记录。
2. **WebGPT / ReAct（搜索增强 LLM）**：开放域问答与工具交互范式；本文固定目标身份和事件定义，在已知证券 universe 内做截止期感知的事件重建，与通用 QA 场景不同。
3. **FreshLLMs / RealTime QA（动态事实检索）**：关注实时问答；本文关注历史事件数据库的独立审计，强调截止期纪律和证据追溯。
4. **ALCE / LongFact（引用与声明级验证）**：评估引用质量和声明分解验证；本文在此基础上增加了结构性输出的数据库可用性要求和风险自适应分流。
5. **FinDeepResearch / FinDeepForecast（金融深度研究基准）**：聚焦公司分析与预测；本文任务更贴近运营保障（database assurance）而非预测，强调可审计性和 deployment calibration。
6. **Selective Classification / Risk-Control Prediction Sets**：理论选择性分类与风险可控预测集提供有限样本保证；本文采用经验校准阈值，明确说明非测试集保证。

## 局限性与未来方向
1. **平衡基准不反映真实事件发生率**：$\pi_A = \pi_B = \pi_C = 1/3$ 是诊断性设计，生产环境中阳性比例通常低得多，review 负载会被 prevalence 效应稀释。
2. **未使用时间密封历史索引**：用当前公开网页重建历史事件，可能引入后见之明偏差；活检测试延迟也未被评估。
3. **Category C 仅表示"未发现"而非"证明不存在"**：通过 2026-08-06 未发现合格退市行动，但Listing 当时仍在交易。
4. **证据审计为 Codex 辅助**：仅 200 个样本经双人人工验证，750 个全量包未双编码；验证一致率 78.0% 留有余地。
5. **国家层面结果为描述性异质性诊断**：国家与语言、来源可及性、交易所覆盖、标识符质量高度相关，非因果国别排名。
6. **未包含越南等低资源市场数据**： motivative 的低资源市场设置因样本缺失而无法直接结论。

## 研究启发与可借鉴点
1. **"闭卷 vs 联网"配对设计**：同一模型在固定推理策略下仅开放/关闭检索，干净估计检索增益，适合多数检索增强系统的消融设计。
2. **三层诊断性分层（正/未来负/活跃控制）**：将负面样本细分为"后续发生"和"始终未发生"，有效暴露投影错误，值得类比到其它时序事件基准。
3. **风险自适应分流 + 5% 校准误差目标的冻结阈值策略**：用校准集选阈值并冻结至测试集，同时要求 recall 约束，兼顾覆盖率与可靠性，可用于生产部署参考。
4. **证据审计协议（Pass/Fail/Unverifiable 三分法）**：针对 yes/no 预测设计不对称证据要求，量化模型引用质量，为下游可审计系统提供可复用评测范式。
5. **Prevalence 效应与部署校准框架**：将平衡基准的 review 率通过 $\pi_s^{\text{dep}} / \pi_s^{\text{bench}}$ 权重校正至目标市场，避免直接外推导致的低估，是基准→生产的标准桥接方法。

## 关键术语表
- **SEARCH-TO-RECORD（S2R）**：一种数据库保障任务，给定已知证券集合与历史截止期，由系统从公开来源独立重建机构定义的公司事件记录。
- **DELISTBENCH**：本文构建的 1,200 条退市公告基准，按 A/B/C 三层平衡采样并公开证据与拆分，用于评估搜索增强 LLM 的事件重建能力。
- **Category A / B / C**：A 为截止前有合格退市公告的正样本；B 为截止后才公告的负样本（暴露投影错误）；C 为至今无合格行动的仍上市对照样本。
- **Joint accuracy（±7天）**：要求对每条记录给出正确决策，A 类还需公告日期在±7天内且宽泛原因正确，B/C 类仅需正确否定决策。
- **Future-event projection**：模型将截止期后发生的退市公告错误判断为截止前已存在，是 B 类独有的典型错误模式。
- **Risk-based acceptance**：通过风险评分模型对每条记录预测出错概率，在经验校准集上选择阈值，低于阈值的记录自动接受，否则送人工审核。
- **Evidence protocol (Pass/Fail/Unverifiable)**：审计系统提交的 URL 是否满足可访问性、listing 匹配、截止期相关性及对预测的支撑四个维度。
- **Prevalence effect**：生产环境中阳性事件占比远低于基准平衡设计时，整体 review 负载会显著降低，但阳性记录本身的误差率不受影响。
