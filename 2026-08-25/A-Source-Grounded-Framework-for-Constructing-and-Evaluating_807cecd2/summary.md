# 论文速读：A-Source-Grounded-Framework-for-Constructing-and-Evaluating

## 一句话总结
本文提出一种基于源文本（source-grounded）的框架，将PMC临床病例报告转化为分阶段披露证据的多模态诊断对话，并设计了一套结合原子项对齐与案例级FVCU质量评分的评估策略，用于在隔离自主选检行为的前提下，精准检验MLLM在渐进式多模态证据解释与整合阶段的诊断推理能力。

## 研究问题与动机
- 临床诊断需渐进式整合病史、查体、常规化验、影像及关键检验结果，但现有医疗多模态基准多停留在固定输入问答或终点答案预测，缺乏对“时序证据整合”过程的刻画。
- 完全交互式的诊断智能体同时耦合证据选择、解释与整合，诊断失败难以归因至具体认知环节；需要可控设定将“解释/整合”与“自主提问/检查选择”解耦。
- 直接复用原始病例报告易发生信息泄露（如图片说明、确诊段落提前暴露），且仅凭最终诊断准确率无法区分“推理完整、证据扎根”与“仅靠关键词猜测”的差异。
- 现有基于清单或整体流畅度的评测方法难以定位具体证据缺失、幻觉或临床无效推断；需要细粒度对齐与多维度质量评分相结合的评估体系。

## 核心贡献（创新点）
1. 提出了source-grounded框架，将PMC病例报告转换为计算机可解释的结构化表示与分阶段多模态诊断对话，严格锚定源文本证据。**与直接调用固定VQA数据集或端到端自由对话Agent的工作不同，该框架以文献原文为唯一证据源，并通过分阶段披露协议将证据解读环节从自主决策中剥离。**
2. 设计了受真实临床工作流启发的渐进式证据披露协议，按“病史→查体/常规化验→影像逐张→关键诊断性检验→最终综合”顺序推进。**与AMIE、3MDBench等交互式基准相比，本协议固定证据呈现节奏，避免模型因提前看到确诊信息或自主选择检查路径而产生评测偏差。**
3. 提出原子项对齐（atomic item alignment）与案例级FVCU（Factuality, Validity, Coherence, Utility）评分相结合的双层评估体系。**不同于传统仅依赖最终答案匹配或整体文本质量打分的方法，该体系能精确定位具体证据的缺失/多余/矛盾，同时从临床效用层面判定整体推理质量。**
4. 基于24例内部医学病例完成框架可靠性验证与o4-mini、Claude Haiku 4.5的基线评测，揭示当前前沿MLLM“流畅≠证据扎根”的诊断推理缺陷。**填补了医疗多模态评测在“渐进式证据整合”这一细分场景的基准空白，为后续自适应诊断代理开发提供可控测试床。**

## 方法详解
- **输入与数据源**：采用JATS XML格式的PMC开放获取全文，要求满足四项条件：可解析XML、≥1张可检索图像、可提取最终诊断、含足以支持渐进对话的完整临床记录。多图病例严格保留原文发表顺序，确保图文叙事对齐。
- **计算机可解释表示抽取**：基于CARE病例报告清单，使用LLM提取器将文章划分为三类字段：
  1. `Clinical case elements`：人口学、主诉、既往/个人/家族史、查体、常规化验、关键诊断性发现（免疫组化/分子/微生物/病理等）、检查名称与时间线；明确排除最终诊断与图像推导结论。
  2. `Figure-linked evidence`：图像模态、源文本明确描述的影像学/病理学发现、以及文章所述诊断意义；禁止像素级推断。
  3. `Diagnostic assessment references`：文章报告最终诊断 + 支撑该诊断的源文本推理链。
  抽取Prompt强制要求“仅提取源文本显式陈述内容，未提及留空，不推断/改写/泛化”。
- **渐进式对话构建**：首轮仅注入临床病史与常规化验；关键诊断性检验被刻意 withholding 以防剧透；随后按序展示原始医学图像及非诊断元数据（标识符/模态），要求模型区分客观观察与推断并使用谨慎措辞；最后一轮披露关键检验，模型基于全部信息进行最终推理与诊断。参考对话由结构化抽取内容经约束改写生成。
- **原子项评估（Atomic Item Evaluation）**：将参考与模型输出拆解为诊断/推理/影像目标特有的原子单元，一对一匹配并统计TP/FN/FP。
  - **Strict匹配**：保留临床必要修饰语（病因、解剖位点、亚型、严重度等），用于最终诊断Precision/Recall/F1。
  - **Lenient匹配**：允许措辞或粒度差异但核心证据一致，用于推理与影像发现的Precision/Recall/F1。
  - **Contradiction**：仅当出现直接临床不相容时判定，模糊重叠或需外部推理的不自动归类为矛盾。
- **案例级FVCU评分**：将原子项匹配摘要（匹配/缺失/多余/矛盾）输入LLM裁判，按1-5分评估四维度：Factuality（声明是否被可用证据支持）、Validity（推断是否临床合理）、Coherence（内部逻辑一致性）、Utility（是否覆盖与综合了支持诊断路径的关键证据）。总体推理质量分为独立 holistic 评分，非四维度算术平均；重大事实/有效性错误或关键证据遗漏直接降级。

## 实验与结果
- **数据集**：24篇公开内部医学PMC病例报告；图像模态覆盖放射/血管造影、病理/细胞学、内镜、眼科、超声心动图、心电图；中位图像数3.5张/例（范围1-8）。
- **实现设置**：GPT-4.1负责抽取、参考对话生成与原子项分解；GPT-5.1负责语义匹配与FVCU评分；待评测MLLM为o4-mini与Claude Haiku 4.5，遵循完全相同的分阶段提示与披露节奏。
- **参考对话保真度**：最终诊断Strict P/R/F1 = 0.99/1.00/0.99；推理Lenient F1 = 0.69，影像发现Lenient F1 = 0.67；总体FVCU = 4.79/5.00，证明框架转换高度保留原文诊断信息。
- **MLLM性能**：
  - 最终诊断Strict F1：o4-mini **0.35**，Claude **0.25**（Precision仅0.32/0.20）。
  - 推理Lenient F1：o4-mini **0.28**，Claude **0.24**；影像发现Lenient F1：o4-mini **0.17**，Claude **0.11**（Claude影像Precision低至0.06）。
  - 共性与差距：两模型Coherence较高（4.54/4.29），但Factuality/Validity/Utility及Overall（2.75/2.50）显著落后参考。Utility差距最大（2.29/2.12 vs 4.25），表明流畅叙述不足以替代证据扎根的临床推理。
- **错误模式**：参考对话的低F1主要来自改写引入的粒度/附加解释项（推理多余率35%，影像38%）；MLLM影像多余生成率高达89%（o4-mini）与94%（Claude），低F1主要由大量无源文本支撑的视觉主张造成。

## 相关工作脉络
1. **VQA-RAD / SLAKE / LLaVA-Med / Med-Flamingo**：聚焦固定输入下的医学图像问答或开放生成，缺乏对临床时序证据整合过程的建模与评测。
2. **AMIE / multimodal AMIE / MMD-Eval / 3MDBench**：推进至交互式诊断对话，但证据选择、解释与整合能力高度耦合，失败归因困难；本文以固定披露协议与之区分，专注
