# 论文速读：PROXY-RELIANCE-IN-LARGE-LANGUAGE-MODEL-DECISIONS-IS-UNCALIBRATED-TO-PREDICTIVE-EVIDENCE

## 一句话总结
本文在结构完全已知的合成临床排序任务上，通过反事实因果仿真测量了四个大语言模型对受保护属性代理变量的因果依赖程度，发现模型的依赖水平严重偏离证据支持的参考基准（既未充分跟踪证据强度，又在不同条件下呈现过度、适当或不足三种判定），且仅依赖准确率的传统审计无法检测此类失校准。

## 研究问题与动机
- **核心问题**：在高风险决策（如急诊分诊、信贷审批）中，模型使用与受保护属性（如种族、性别）相关的代理变量时，究竟在多大程度上被预测证据所 justified，以及如何量化评估这种依赖是否合理。
- **现有审计不足**：主流方法仅观察“改变人口属性后决策是否变化”，但属性变化可能携带合法预测信号，导致“决策变化”无法区分歧视与合理推断；而“决策不变”也可能意味着忽略了重要证据。
- **缺乏定量参考**：即使检测到行为变化，也无法判断该变化程度是否与证据强度相匹配，审计报告只能给出定性差异，无法提供裁决基准。
- **准确性评估的盲区**：准确率提升可能源于模型学到了合法特征，也可能源于依赖了代理变量，两者在准确率指标上表现相似，无法揭示代理依赖的校准状态。

## 核心贡献（创新点）
1. **提出“证据支持水平”（evidence-warranted level）作为定量基准**：通过贝叶斯最优决策器与有限样本理想学习者的反事实效应计算，将单一的“是否歧视”信号转化为“过度依赖、适当依赖、依赖不足”三种裁决，并首次系统化应用于LLM审计。
2. **构建结构已知的人工生成过程与真实临床数据锚定**：在完全控制的合成种群中精确设置属性-结果关系与受保护属性关联，同时用七个公开临床数据集在协方差结构上进行锚定，平衡了内部效度与现实相关性。
3. **揭示LLM代理依赖的严重失校准模式**：发现依赖主要体现为“高基线水平+对证据强度变化几乎无响应”（斜率γ在-0.08至+0.15之间，远小于校准所需的γ=1），而非简单的过度或不足依赖。
4. **论证社会标签抑制的脆弱性与条件依赖性**：证明带社会语义的字段名虽能降低依赖，但这种抑制在上下文示例（few-shot examples）输入时被显著削弱甚至逆转，且抑制幅度跨模型存在梯度差异，提示对齐训练的作用有限且不稳健。
5. **解耦准确性与代理依赖通道**：系统展示通过维度、依赖结构、示例数量等操纵可独立改变代理依赖而不影响准确率，证明准确率评估完全无法诊断代理使用的校准状态，并定量分解了审计中的分布偏移与语义错配误差。

## 方法详解
- **合成生成过程**：模拟患者为 $k \in \{6,12,18\}$ 个标准化数值属性向量，其中三分之二为合法属性（直接决定真实风险），三分之一为代理属性（与不可见的二值受保护属性 $A$ 相关）。真实风险为合法属性的加权求和，归一化使排序难度跨维度一致；在“信息”条件下，代理属性额外携带可控方差的风险信号。
- **定向代理特定效应（Directed Proxy-Specific Effect, PSE）**：对每对患者执行一个事实臂与两个反事实臂（分别将目标患者的受保护属性设为1或0，并通过结构方程重新生成其代理属性，其他外生噪声保持不变），比较模型在事实臂与反事实臂下选择目标患者的概率差异。受保护属性本身从不出现在提示中。
- **证据支持水平的计算**：
  - **完备知识基准**：将相同的反事实干预应用于按真实风险排序的贝叶斯最优决策器，在零信息条件下效应为0，在信息条件下为正值。
  - **理想学习者基准**：当模型接收 $n=80$ 个标注示例时，使用共轭贝叶斯线性回归在完全相同的示例上拟合，再施加相同的反事实协议，作为有限样本学习者的参考上限。
- **剂量响应分析**：在保持总风险方差不变的前提下，逐步提升代理属性对结果的贡献比例（四个水平），拟合线性模型 $\text{PSE}_{\text{model}} = \alpha + \gamma \cdot \text{PSE}_{\text{ideal}}$，其中 $\gamma=1$ 表示校准跟踪，$\gamma=0$ 表示无跟踪。
- **审计误差分解**：定量分离全量省略代理、语义标签错配、部分省略与分布偏移四种审计-部署不匹配产生的误差，并用重要性加权检验可修正性。
- **统计推断**：使用95%配对级别Bootstrap区间（2,000–5,000次重抽样），以配对为抽样单元（因同一对的两种呈现顺序相关）。

## 实验与结果
- **数据集与任务**：合成临床排序任务，每对两名患者由 $k$ 个数值属性描述，模型需选择优先治疗者。评估集为每条件下99对固定配对（跨维度比较使用独立配对）。
- **模型**：Claude Sonnet 4.5、DeepSeek-V4-Flash-0731、Qwen3.7-max、GPT-5.6 Terra，前三个在temperature=0下运行，GPT-5.6 Terra运行于默认设置（推理禁用）。
- **主要结果数字**：
  - **零信息代理（中性标签）**：Sonnet在 $k=6,12,18$ 处PSE分别为+11.1、+19.7、+14.6个百分点（所有95% CI不包含0），超额依赖几乎跨提供商一致（DeepSeek +19.7，Qwen +20.2，GPT +22.7）。
  - **信息代理（中性标签）**：在 $k=12$ 处，Sonnet超额+7.1（区间+1.0至+13.6），判定为“适当”；DeepSeek与Qwen分别超额+12.1与+10.1，判定为“过度”；社会标签下Qwen恰好落在基准上。
  - **社会标签抑制**：Sonnet在所有维度上依赖降至基准以下−9.6至−12.1个百分点；跨提供商抑制梯度为：Sonnet −20.7、GPT −15.2、Qwen −9.1、DeepSeek −6.6。
  - **剂量响应**：所有八个拟合的斜率 $\gamma$ 在 −0.08 至 +0.15 之间，置信区间均排除校准值 $\gamma=1$，仅两个区间的下限触及零；截距 $\alpha$ 在+18.3至+30.4个百分点。
  - **上下文示例的脆弱性**：即使使用正交化确保代理-结果相关恰好为零的“清洁”示例，社会标签下的依赖仍跃升至+15.7个百分点（区间+9.1至+22.2），而理性学习者在此条件下的效应为−1.0。
  - **维度效应**：有示例时， regret从 $k=6$ 的+19.7增至 $k=18$ 的+36.9；无示例时错误率基本平稳（0.374、0.354、0.399）。
  - **准确性与代理依赖解耦**：将示例从80减至12，准确率无统计变化，但代理依赖下降14.6个百分点。
- **最强结果与提升**：在信息代理与社会标签条件下，Qwen3.7在 $k=12$ 处接近基准（excess +1.0），但仍存在轻微过度；最显著的抑制来自Sonnet（−20.7）但与基准的距离最大（低于基准），并非校准状态下的“最优”。

## 相关工作脉络
1. **现有LLM偏见审计（如Tamkin等，2023；An等，2024）**：主要关注“改变受保护属性后输出是否变化”，仅能给出二元判断，无法量化变化程度是否与证据匹配；本文将其拓展为“变化多少是否被证据支持”的定量裁决。
2. **因果公平性框架（Kusner等，2017；Nabi等，2018；Zhang等，2018；Chiappa，2019）**：提出反事实公平、路径特定公平等概念，但多聚焦于是否使用敏感属性，未提供“使用多少才合理”的定量参考；本文将因果效应测量与已知真值参考结合，实现校准评估。
3. **LLM社会偏见基准（如Crowd-Pairs、StereoSet、BBQ、BOLD）**：通常设计为“不应使用群体身份”，使模型可通过沉默或不推断来达标，但无法刻画“当群身份相关信息合法时应如何使用”；本文明确构建合法与非法信号可并存的条件，量化依赖程度。
4. **LLM置信度校准研究（如Kumaran等，2026；Qiu等，2026；Chen等，2026）**：将LLM置信度与贝叶斯更新比较以揭示结构偏差；本文采用相同思路，将依赖程度与证据支持的基准比较，拓展到歧视审计领域。
5. **差异感知评估（Difference-aware evaluation，Wang等，2025）**：询问“何时群体信息应被使用”；本文直接量化“使用多少”，提供更精细的测量层次。
6. **Causal audits（如Yu等，2026）**：尝试分离job-relevant与impermissible路径；本文进一步与已知真值参考对比，判断每条路径上的使用量是否合理。

## 局限性与未来方向
- **合成生成过程的现实局限性**：虽然用七个临床数据集在协方差结构上锚定，但真实世界数据生成机制更复杂，代理变量与受保护属性的关系、合法属性的非线性作用等未被完全捕获；半合成设计（real-data anchoring + synthetic perturbation）是自然延伸。
- **代理预测力范围有限**：剂量响应仅覆盖代理贡献高达结果方差三分之一的情况，当代理完全主导时（如高度歧视的历史数据）的行为未被探索。
- **分布偏移修正的可修正性未定论**：重要性加权对分布偏移项的残差未分离出零，可能因样本量不足，需更大规模研究确认。
- **模型多样性有限**：仅测试四个商业/开源模型，不同架构（如小参数模型、专门微调模型）的表现未知。
- **未来方向**：扩展至半合成与真实部署场景；探索模型内部表征与代理依赖的映射；研究如何在保持性能的同时稳健抑制代理使用；开发无需已知真值的在线审计方法。

## 研究启发与可借鉴点
1. **“证据支持水平”框架的可迁移性**：任何需要量化模型对某类输入依赖程度的场景（如医疗决策、信贷审批、招聘筛选）均可采用该框架，通过计算理性参考基准将行为信号转化为三种裁决，为审计提供量化基准。
2. **剂量响应与斜率分析揭示校准状态**：仅看绝对效应大小可能误导；拟合模型效应与理想参考之间的线性关系（斜率γ）能更敏锐地检测模型是否真正学习证据动态，该方法可推广至其他校准评估任务。
3. **审计误差分解的价值**：定量分离省略、错配、分布偏移等误差源，并检验重要性加权等标准校正的修复能力，为审计设计提供操作指南（如避免语义错配比修正分布偏移更重要）。
4. **依赖与准确性的解耦实验设计**：通过控制维度、依赖结构、示例数量等操纵可独立改变代理依赖，为验证“准确率提升不必然改善公平性”提供了严谨的实验范式，适用于其他公平性评估研究。
5. **社会标签抑制的脆弱性发现**：提示对齐训练带来的行为改变可能是表面性的，易受上下文干扰；团队在开发安全增强方法时需测试其在few-shot设置下的稳健性，并考虑更深层的结构干预。

## 关键术语表
- **Proxy Reliance（代理依赖）**：模型决策中对与受保护属性相关的输入变量的因果利用程度，通过反事实干预测量。
- **Evidence-Warranted Level（证据支持水平）**：在给定任务规则与损失函数下，最优决策规则对代理属性应使用的依赖程度，作为定量参考基准。
- **Directed Proxy-Specific Effect (PSE)（定向代理特定效应）**：仅在代理路径上传播受保护属性变化的反事实干预下，模型决策概率的变化量。
- **Ideal Learner（理想学习者）**：在完全相同的示例数据上拟合的贝叶斯回归模型，作为有限样本学习者的性能上限参考。
- **Calibrated Tracking（校准跟踪）**：模型依赖度随证据强度变化的响应斜率等于1，表示依赖程度与证据支持程度完全匹配。
- **Social-Label Suppression（社会标签抑制）**：将代理字段命名为具有社会含义的名称（如“社区”、“职业”）时，模型依赖度下降的现象。
- **Structural Concentration Statistic（结构集中度统计量）**：属性相关矩阵中由主导特征值承载的方差比例，用于量化属性间的依赖结构。
- **Importance Weighting（重要性加权）**：通过加权调整审计样本分布以匹配部署分布的标准统计校正方法。
