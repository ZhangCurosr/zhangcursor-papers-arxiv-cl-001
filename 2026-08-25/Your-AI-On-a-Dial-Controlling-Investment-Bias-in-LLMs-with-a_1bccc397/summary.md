# 论文速读：Your-AI-On-a-Dial-Controlling-Investment-Bias-in-LLMs-with-a-Single-Neuron

## 一句话总结
本文提出了一种仅通过对单个 MLP 神经元坐标施加加法偏移的推理时干预方法（"投资偏差旋钮"），可在不修改提示词或模型参数的情况下，连续、单调地控制大语言模型的整体投资倾向（买入/卖出偏置），并能校准至目标立场（包括中性）。

## 研究问题与动机
- LLM 在投资决策支持中展现出系统性、模型特异的投资偏好（如对特定行业、市值、动量维度的偏向），这些偏置会干扰分析结论。
- 现有调节手段（提示词工程、微调）存在明显缺陷：提示词对措辞敏感且效果跨模型不稳定；微调则固定于单一目标，需反复重训。
- 缺乏一种无需改动参数或提示、可在推理时连续调节模型整体投资立场的方法，使不同投资者的委托需求得以适配。
- 核心研究问题：单个神经元能否提供单调控制？能否校准至目标立场（含中性）？干预效果是否能传播至下游工作流（检索、长上下文、组合构建）？

## 核心贡献（创新点）
1. **提出"投资偏差旋钮"机制**：通过单个 MLP 坐标的加法干预连续控制 LLM 整体投资立场，与提示词/微调/密集激活引导的本质区别在于其极简的局部干预方式与零参数更新。
2. **建立两阶段旋钮选择流程**：先用梯度敏感度筛选与买卖决策相关的候选坐标，再用留置校准误差（RMSE）评估跨证券的可迁移性，与已有激活引导方法（如 CAA、RepE）相比干预足迹极小（仅 1 个坐标）。
3. **实证验证多场景扩展效应**：在代理检索设置中改变信息搜索与证据选择；在长上下文下保持比提示词更稳定的立场控制；在探索性回测中传播至证券排序与投资组合构成。
4. **系统性能力保持评估**：在 5 个通用基准和 2 个金融专用基准上证明，校准后的模型未出现统计显著的性能退化（经 BH 校正后无显著下降）。

## 方法详解
- **投资偏差度量**：采用 Lee et al. [18] 的平衡证据框架，对 427 个股票代码逐一呈现等量看涨/看跌证据，令模型输出 buy/sell 决策； TICKER 级别偏差分数为 $\pi_s = (N_{buy}^{(s)} - N_{sell}^{(s)}) / (N_{buy}^{(s)} + N_{sell}^{(s)})$，模型级别聚合为 $\pi$。
- **单神经元干预**：对每个解码器块的 MLP 下投影输入 $\mathbf{h}_{\ell,t}$ 的第 $n$ 个坐标施加加法偏移 $\tilde{h}_{\ell,t}[n] = h_{\ell,t}[n] + \Delta$，在自回归生成过程中对所有 token 位置生效，不修改模型参数或提示词。
- **旋钮选择算法（Algorithm 1）**：
  1. 计算所有 MLP 坐标的梯度敏感度 $G_c = |\frac{1}{|S|}\sum_s \sum_p \frac{\partial(z_{buy}^{(s)} - z_{sell}^{(s)})}{\partial x_{\ell,p}^{(s)}[n]}|$，筛选决策相关候选。
  2. 将证券全集划分为不相交子集 $S_A$（校准集）和 $S_B$（验证集）。
  3. 对每个候选 $c$，在 $S_A$ 上测量响应曲线 $\pi_{c,A}(\Delta)$，反演得到各目标先验 $t \in \mathcal{T}$ 对应的干预系数 $\widehat{\Delta}_{c,A}(t)$。
  4. 将同一 $\widehat{\Delta}$ 应用于 $S_B$，以 RMSE 衡量目标复现精度：$\mathrm{RMSE}(c) = \sqrt{\frac{1}{|\mathcal{T}|}\sum_t [\pi_{c,B}(\widehat{\Delta}_{c,A}(t)) - t]^2}$。
  5. 选取 RMSE 最低的可行候选作为最终旋钮坐标 $c^*$，并在完整全集上重新估计校准设置。
- **能力保持评估**：在 MMLU、GSM8K、ARC-Challenge、TruthfulQA、RACE、FinQA、Financial PhraseBank 七个基准上进行 zero-shot 评测，使用配对 McNemar 检验，报告单边 95% 置信下界。

## 实验与结果
- **模型与数据集**：五个开源 LLM（Qwen3-8B、Llama-4-Scout-17B、DeepSeek-R1-Distill-Qwen-14B、Gemma-4-12B-it、Mistral-Small-24B），427 个 S&P 500 股票代码的平衡证据评测集。
- **单调性（RQ1）**：所有五模型的偏差分数 $\pi$ 随干预强度 $\Delta$ 单调变化；selected coordinates 位于网络中段至尾段。Qwen3-8B 最优候选为 L23/F4099（RMSE=0.038，覆盖完整 [-1,1] 范围）。
- **校准（RQ2）**：
  - Qwen3-8B：基线 $\pi=+0.575$，校准至中性需 $\Delta^*=-11.44$，29.6% 决策改变。
  - Llama-4-Scout：基线 $\pi=+0.623$，$\Delta^*=-4.43$，32.5% 决策改变。
  - DeepSeek-R1-14B：基线 $\pi=+0.095$，$\Delta^*=+3.55$（方向相反），21.1% 决策改变。
  - Gemma-4-12B 和 Mistral-24B 基线已近中性，无需干预。
- **能力保持**：最大绝对变化为 1.60 个百分点；经 BH 校正后无任何基准出现统计显著的退化。
- **代理行为（RQ3a）**：在 BM25 检索设置中，中性校准使看跌强调在搜索查询中提升 88%，打开的证据中提升 41%，备忘录引文中提升 74%。
- **长上下文鲁棒性（RQ3b）**：上下文从约 550 扩展到 16,025 token 时，匹配的系统提示词效果逐渐衰减，而旋钮保持稳定看跌立场。
- **投资组合构建（RQ3c）**：2025.8.4–2026.2.20 的周度回测显示，旋钮分散了 $\Delta=0$ 时聚集在 Score ceiling 的股票，Top-100 组合的 Sharpe 比率在强设置下超过 500 个随机组合的 95th 分位。
- **对比密集激活引导（Appendix E）**：Dial 与 CAA、RepE 均能单调控制且均有零交叉点，但 Dial 仅编辑 1 个激活/token，FDR 能力损失为 0/105，显著优于 CAA（4/105）和 RepE（2/105）。

## 相关工作脉络
1. **Lee et al. [18]**：引入受控证据冲突框架度量 LLM 潜伏投资偏好，本文在此框架基础上进一步研究如何连续调节偏差，而非仅识别和刻画。
2. **Dimino et al. [9,10]**：发现 Qwen 模型中的位置偏差和对 firm-size/valuation/risk 的系统性偏好；本文的定位是通过局部干预而非重新训练来调节此类偏差。
3. **InfTime [20] / CAA [27] / RepE [32]**：密集激活引导方法通过完整方向向量干预多个层；本文的单坐标干预与其本质区别在于干预足迹极小、无需构造对比样本。
4. **FairSteer [21]**：检测社会偏差激活并条件性施加 debiasing 向量；本文聚焦金融投资偏好而非社会偏差，且采用持续可调而非二值开关方式。
5. **Neuron-level 干预 [8,15,24]**：先前工作定位事实知识神经元或社会偏差神经元并进行抑制；本文首次将单神经元干预用于连续校准投资偏好而非简单抑制。
6. **Prompt-based 偏差缓解 [3]**：行为经济学提示可减少某些认知偏差；本文在 Appendix C 对比显示提示词干预跨模型效果差异大（如 Disclosure 对 Qwen3-8B 仅部分减少 bias，对 Llama-4-Scout 过度纠正，对 Gemma-4-12B/Mistral-24B 反而引入正偏差）。

## 局限性与未来方向
- 旋钮仅控制模型的整体看涨/看跌倾向，无法针对特定公司、行业或资产类别进行定向控制，也不处理其他形式的金融偏差（如确认偏误）。
- 所有结果仅在评测设定内经验性成立；校准得到的 $\Delta$ 值针对二元 buy-sell 判断且平衡证据结构，迁移至不同输出空间或推理需求的任务需重新校准。
- 干预需要访问模型内部激活，仅适用于开放权重模型；模型权重、架构、分词器或推理实现的变更需重新估计坐标和系数。
- 投资组合回测为探索性，未覆盖交易成本、滑点和执行延迟，不能证明投资 alpha。
- 未超出测量干预范围的结果外推需谨慎，跨未测试任务/模型变体/市场条件的持续性未验证。

## 研究启发与可借鉴点
1. **单坐标干预的简洁性与高效性**：相比密集激活引导，单 MLP 坐标干预在保持等效控制力的同时几乎消除了能力退化，可作为其他连续行为控制任务的参考范式。
2. **两阶段选择流程（敏感度筛选 + 留置 RMSE 校准）**：将候选坐标的"决策相关性"与"跨样本可迁移性"解耦评估，方法论可直接迁移到其他需要定位因果特征的研究。
3. **长上下文稳定性优势**：在长上下文场景中，神经元级干预比提示词指令更稳定，对需要长期一致性立场的金融/法律代理系统具有实用价值。
4. **偏差调控与能力保持的解耦验证**：系统性地用配对 McNemar 检验和 BH 校正评估能力影响，为后续工作提供了可复用的评估协议。
5. **从决策输出到信息行为的传播分析**：不仅评测最终决策变化，还追踪了搜索查询、证据选择和论证强调的级联效应，这一多层评估思路可推广至其他行为干预研究。

## 关键术语表
**Investment-bias dial（投资偏差旋钮）**：一种推理时干预机制，通过对单个 MLP 神经元坐标施加加法偏移，连续调节 LLM 整体买入/卖出倾向，无需修改提示词或模型参数。
**Decision prior（决策先验）**：模型在做具体决策前对买入或卖出方向的总体倾向性，旋钮调控的就是这一聚合层面的先验而非具体证券的选择。
**Gradient sensitivity $G_c$（梯度敏感度）**：衡量某神经元坐标对 buy-sell 对数几率差值的偏导绝对值，用于筛选与投资决策最相关的候选坐标。
**RMSE calibration error（RMSE 校准误差）**：在留置验证集上衡量候选坐标复现目标先验网格的精度，值越低表示跨证券的可迁移控制能力越强。
**Valid-decision rate（有效决策率）**：模型输出能被成功解析为 buy 或 sell 的比例，反映干预不破坏输出格式的能力。
**Agentic retrieval setting（代理检索设置）**：模拟研究代理通过生成搜索查询、BM25 检索、选择性阅读证据片段并最终产出买入/卖出建议和投资备忘录的多阶段工作流。
**Sharpe ratio（夏普比率）**：投资组合风险调整收益指标，本文在探索性周度回测中用它衡量旋钮干预对下游组合绩效的影响。
**FDR losses（错误发现率损失）**：经 BH 校正后仍保持统计显著的能力退化数量，用于量化干预对非目标任务的副作用。

## 可复现要素
- **数据集**：427 个 S&P 500 股票代码的平衡看涨/看跌证据（合成/结构化），评测协议见 Appendix A.1；代码未明确提及开源链接，但论文提供了完整的 prompt 和评估协议描述。
- **代码/权重**：使用五个开源权重模型（Qwen3-8B、Llama-4-Scout-17B、DeepSeek-R1-Distill-Qwen-14B、Gemma-4-12B-it、Mistral-Small-24B）；论文未明确声明提供独立代码仓库，干预通过 HuggingFace Transformers 5.9.0 的 prehook 实现。
- **关键超参**：干预强度 $\Delta$ 为连续实数；$S_A/S_B$ 划分用于校准与验证；DeepSeek-R1-14B 使用 2,048 token 生成预算，其余模型使用 1,024 token；MMLU 使用固定 1,000 项样本，其余基准使用完整评测集；目标先验网格 $\mathcal{T}$ 包含 $\{-0.3, 0, +0.3\}$。
