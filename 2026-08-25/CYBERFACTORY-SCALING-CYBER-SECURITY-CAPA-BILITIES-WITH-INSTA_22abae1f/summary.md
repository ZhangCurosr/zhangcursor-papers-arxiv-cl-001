# 论文速读：CYBERFACTORY-SCALING-CYBER-SECURITY-CAPA-BILITIES-WITH-INSTA

## 一句话总结
本文提出 CyberFactory，一个统一开源框架，将真实世界的 CVE 漏洞 artifact 转化为可执行、可验证的代理任务实例，并通过可复用的“漏洞分析技能”引导教师模型合成 agentic 训练轨迹。最终训练的 OpenAegis 模型在推理时无需技能即可内化该域优先验工作流，在 CyberGym 上以较少参数达到 52.4% Pass@1，大幅超越基座及更大规模的通用模型。

## 研究问题与动机
- 闭源 LLM（如 Mythos）在网络安全任务上已展现较强能力，但开源前沿模型缺乏可复现的训练方案，仅发布权重无法保证能力可复现。
- 现有开源努力多聚焦孤立任务（如 CTF），数据管道分散，缺乏可扩展的 agentic 训练数据与统一的多任务训练流水线。
- 单纯依赖简单 prompt 的随机 rollout 效率低下，扩展此类模型必须注入强领域先验，并结合执行反馈进行交互式修正。
- 核心问题：如何构建统一、开源、可扩展的训练方案，将碎片化的真实漏洞证据转化为可验证的代理监督信号，并安全地迁移至模型参数中？

## 核心贡献（创新点）
- **提出端到端开源训练配方**：打通数据构建、轨迹合成与 SFT 训练的统一流水线。与现有仅发布权重或孤立 CTF 解法的做法不同，本文首次实现从真实 CVE 到可执行监督信号的完整可复现闭环。
- **设计技能引导的轨迹合成管道**：将专家安全分析流程编码为任务无关的“漏洞分析技能”，仅用于教师模型数据合成。与依赖无约束 rollout 或推理时注入 prompt 的方法不同，该技能在 SFT 后完全内化，推理零依赖。
- **发布 OpenAegis 多任务模型**：基于 Qwen 3.5-397B-A17B 训练，覆盖 PoC 生成、漏洞修复与 CyberQA。与更大参数量的基座模型（GLM 5.2、Kimi K2.7）相比，本文证明高质量的域引导轨迹与差分预言机监督足以实现参数层面的反超。
- **提出阈值上下文压缩机制**：在 90% token 水位触发结构化压缩，保留关键证据与待办状态。与简单截断或全量保留历史不同，该策略显著降低长 horizion 安全 agent 的上下文耗尽率并提升成功率。

## 方法详解
- **实例构建（Instance Creation）**：数据来源于 ARVO、OSS-Fuzz 与野生 CVE。保留含 CWE 类型的 CVE，通过软件版本范围定位 fix commit，得到 pre-patch 与 post-patch Docker 镜像；使用额外元信息（CWE 类型、crash 信息）过滤模型可直接解答的简单样本，保留挑战性实例。描述由 LLM 对 commit message 进行分类/重写生成。
- **补丁生成与 QA 数据**：补丁生成沿用 CVE-Factory 的漏洞-修复对照思路；QA 采用“答案优先”策略，答案严格源自可信源（崩溃位置、函数调用图、权威报告），经 LLM Judge 验证答案可追溯、问题唯一且未泄露答案。
- **技能引导的轨迹合成**：提供任务无关的“漏洞分析技能”，指导模型按固定流程执行：源码与环境检查 → 域优先验探索 → 基于证据的验证 → 迭代修正。
