# 论文速读：ConvergeFlow: Language Flow with Provable Convergence to Token Embeddings

## 一句话总结
ConvergeFlow 是一种嵌入空间流匹配语言模型，通过将数据预测器约束为词嵌入的凸组合并仅用 MSE 目标训练，首次证明了采样轨迹可严格收敛至合法 token 嵌入，从而无需额外 CE 解码器即可直接输出离散词元；在 OpenWebText 上以 130M 参数达到 Gen. PPL 33.17（熵 5.44），显著优于现有连续与离散扩散语言模型。

## 研究问题与动机
- 现有连续流/扩散语言模型（如 LangFlow、ELF、FLM）的采样轨迹无法保证终止于有效 token 嵌入，预测器误差会使终态落在词表嵌入之间。
- 为弥合该间隙，现有方法仍需引入离散的交叉熵（CE）监督训练独立终端解码器，这与流模型的纯连续性质不一致，限制了理论完备性与范式统一性。
- 核心科学问题：能否设计一种纯连续训练框架，使流匹配采样轨迹可证明地收敛至离散 token 嵌入，从而实现端到端无 CE 依赖的直接 token 预测？
- 动机：提供具有严格收敛保证的连续生成范式，消除混合监督带来的训练-推理不一致，并验证流匹配在语言建模中的完整潜力。

## 核心贡献（创新点）
- **提出首个具备 token 嵌入收敛保证的流匹配语言模型**：通过嵌入加权参数化将预测器约束在词嵌入凸包内，并在对数 Lipschitz 正则性条件下给出采样轨迹依概率收敛至离散 token 嵌入的理论证明。与 LangFlow/ELF 的本质区别在于：本文完全消除终端 CE 解码器，而前者仍需依赖离散监督或独立投影模块。
- **纯 MSE 训练结合高斯核因子化先验**：利用 Proposition 1 揭示的后验乘性结构，将凸权重参数化为“可学习基权重 × 已知高斯腐蚀核”，仅用流匹配诱导的 MSE 损失优化。与 LangFlow（直接学习后验分布并用 CE 优化）的本质区别在于：因子化仅作架构先验，预测器全程由连续 MSE 驱动，不引入任何 token 级离散交叉熵项。
- **设计三种时间自适应采样引导机制**：提出自条件引导、迭代自条件细化与无条件引导，并将强度调度设计为随信噪比升高而增强的时间自适应形式，在固定 NFE 预算下实现 Gen. PPL 与熵的显式可控权衡。与现有连续/离散扩散模型仅依赖单一 CFG 或掩码策略的本质区别在于：本文提供了可解耦调节质量与多样性的统一推理接口。
- **系统性实验验证与理论-实证闭环**：在 OpenWebText 上以 130M 参数实现 Gen. PPL 33.17（熵 5.44），超越所有对比基线；通过消融实验验证 MSE 优于 CE、两种解码规则一致性 >99%，以及嵌入加权结构对轨迹收敛的决定性作用。
