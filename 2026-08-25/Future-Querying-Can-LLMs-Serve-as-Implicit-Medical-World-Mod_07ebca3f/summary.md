# 论文速读：Future-Querying: Can LLMs Serve as Implicit Medical World Models?

## 一句话总结
论文提出了“未来查询”（Future Querying）新范式，通过评估大语言模型能否基于患者历史轨迹回答时间索引的临床问题，来探究LLM是否能作为隐式医学世界模型；实验表明，经过简单微调的小参数开源模型即可在合成医学数据和真实ICU记录上达到与头部商业闭源模型相媲美的性能。

## 研究问题与动机
- **核心问题**：大型语言模型（LLMs）在海量文本上预训练后，是否隐含地学习到了类似“医学世界模型”的动态演变知识？能否直接用于灵活地预测患者未来状态？
- **现有方法不足**：
    1. 传统临床预测模型依赖任务特定的管道和人工筛选的结构化特征，开发维护成本高，难以扩展。
    2. 现有模型通常针对预设目标（如院内死亡率、再入院风险）和固定时间窗进行训练，无法灵活回答多样化的开放式问题。
    3. 临床中大量有价值的非结构化文本信息（如病程记录、医学报告）未被充分利用，或需要昂贵的专门提取管线。

## 核心贡献（创新点）
1. **提出“未来查询”范式**：将预测任务重构为基于患者历史轨迹回答自然语言时间索引查询的问题，为评估LLM的隐式世界模型能力提供了一个统一框架。与仅评估通用推理或特定事实记忆的现有工作不同，本文聚焦于动态临床轨迹预测。
2. **开发从观测数据构建训练集的自动化方法**：利用LLM从纵向患者历史中自动抽取谓词、划分时间戳、生成查询-答案对，从而无需人工标注即可为未来查询任务创建大规模训练数据。
3. **证明小模型微调可达商业模型水平**：发现经过简单监督微调（LoRA），小型开源模型（如MedGemma-1.5-4B-IT）在医学未来查询任务上可以匹配甚至超越规模大得多的专用生物医学模型，且性能接近顶尖闭源模型，凸显了任务特定微调和开放模型的价值。
4. **构建并开源两个评估基准**：提出了一个新的合成医学报告数据集（覆盖广泛常见病）和基于真实MIMIC-IV ICU记录的基准，用于系统评估不同规模、类型模型的未来查询能力。
5. **强调隐私与部署实用性**：研究证明了在本地硬件上微调小型开放权重的可行性，为符合医疗数据隐私要求的部署场景提供了可行路径。

## 方法详解
- **任务公式化**：患者$p$被表示为按时间排序的医学报告序列$\{(t_1, r_1), ..., (t_n, r_n)\}$，其中$t_i \leq T$（当前时间$T$）。查询$q$由两部分组成：时间无关的文本谓词$x$（询问什么）和时间戳$t \geq T$（询问何时）。模型目标是学习条件分布$P(a | p, q)$，即基于患者历史$p$和查询$q$生成答案$a$。
- **无特征工程**：模型直接作用于原始的非结构化临床文本（医学报告），无需进行任何结构化预处理或手动特征选择。
- **任务无关的训练策略**：采用标准的监督微调（SFT）最大似然目标 $\theta^* = \arg\max_\theta \frac{1}{N} \sum_{k=1}^{N} \log f(a_k | p_k, q_k; \theta)$，通过标准LLM训练流程即可优化，无需为不同临床任务单独设计模型。
- **数据集构建算法**：
    1. **谓词抽取**：从患者时间线中随机抽取报告$r_i$，利用LLM生成关于其中事件或发现的文本谓词问题$x$及对应答案$a$。
    2. **时间分区**：为每个谓词随机选择一个参考时间点$\hat{T}$，满足$t_1 \leq \hat{T} < t_i$，将报告$i$置于“未来”。
    3. **历史-查询-答案生成与过滤**：组合历史上下文、查询$q(x,t)$和答案$a$，过滤掉答案仅从历史上下文即可明显得出的情况，保留真正的未来预测样本。

## 实验与结果
- **数据集**：
    - **合成医学报告**：3,226名患者，53,612个查询，由Gemini 2.5 Flash自回归生成。
    - **MIMIC-IV ICU记录**：9,733名患者，164,911个查询，为真实脱敏临床笔记。
- **评估基线**：
    - **现成LLMs**：包括通用开源模型（Gemma系列、Mistral系列）、领域适应的生物医学模型（MedGemma-1.5-4B-IT, BioMistral-7B）以及大型闭源模型（Gemini, GPT, Claude, DeepSeek, GLM）。
    - **微调后模型**：在小型开源模型上使用LoRA（rank=16）和全参数微调。
- **主要结果与结论**：
    - **现成模型**：大型闭源模型表现最佳。在合成数据上，四个前沿模型准确率超过50%，显著领先其他基线。在真实MIMIC-IV数据上，仅Claude Sonnet 5和GLM-5.2勉强超过50%。有趣的是，专用生物医学模型（如BioMistral-7B, MedGemma）性能不及通用模型，表明预训练任务与未来查询任务存在不匹配。
    - **微调效果**：LoRA微调带来显著提升，在MIMIC和合成数据上分别提高11.7-21.5个百分点和12.4-19.6个百分点。原表现最差的MedGemma-1.5-4B-IT微调后获益最大，最终性能与更大的Gemma3-12B-IT相当。微调后各小模型性能趋于收敛（MIMIC上43-46%，合成数据上46-51%），表明训练信号比模型容量更重要。
    - **最强结果**：Claude Sonnet 5在合成医学报告基准上达到最高准确率（>50%）。经微调的MedGemma-1.5-4B-IT模型在MIMIC-IV上达到46%的准确率，媲美远大于它的商业模型。

## 相关工作脉络
1.  **与Foresight[18]、TransformerEHR[35]等对比**：此类工作同样使用transformer架构建模患者时间线，但通常依赖结构化电子健康记录（EHR）数据，并针对特定预后终点（如死亡率、再入院）进行训练。本文方法直接处理非结构化文本，且任务无关。
2.  **与BioMistral[20]、MedGemma[11]等生物医学LLM对比**：这些模型在医学文本上进行领域适应预训练。本文结果表明，在本次未来查询任务上，这些专用模型的零样本性能反而弱于通用大模型，提示预训练目标与动态轨迹预测任务可能存在差异。
3.  **与EHR2Path[29]等多模态轨迹建模对比**：EHR2Path等工作利用多模态EHR数据预测患者路径。本文方法专注于单模态非结构化文本，但强调了其无需特征工程、可灵活回答查询的优势。
4.  **与“LLM作为世界模型”的探针研究对比**：如[22]通过状态抽象探针评估LLM的内部世界表征，[34]评估生成模型中的隐式世界模型。本文从应用角度切入，通过具体的未来查询任务来实证检验LLM是否具备捕捉临床动态的能力。

## 局限性与未来方向
- **局限性**：
    1.  评估使用的“合成医学报告”数据集虽然规模大，但其对真实临床复杂性的模拟程度有待验证。
    2.  评估指标“LLM-as-a-judge”存在主观性，且未来临床结果本身具有多义性，非100%准确。
    3.  研究未深入区分模型表现是源于真正的“世界模型”能力还是基于统计模式的“联想”。
    4.  当前实验主要在文本模态内进行，未整合多模态临床数据。
- **未来方向**（论文提及及可推断）：
    1.  与临床专家合作进行真实性验证，并确定人类临床医生的性能上限。
    2.  引入一致性检查或反事实探测等机制，以区分世界建模与模式匹配。
    3.  扩展到多模态数据集成，提升预测的全面性。
    4.  研究不确定性估计和鲁棒性分析，以支持安全可靠的临床部署。

## 研究启发与可借鉴点
1.  **未来查询范式**可将LLM的预测能力从一个固定的分类/回归任务，转化为一个更通用、更灵活的问答接口，这一思想可迁移至其他序列预测领域（如金融、气象）。
2.  **从观测序列自动生成训练数据的方法**（谓词抽取+时间戳划分+过滤）是一个高效的数据工程技巧，可用于其他需要构造“历史-未来”问答对的时序任务。
3.  **小模型微调的经济性与有效性**：本研究强有力地证明了，针对特定下游任务进行轻量级微调（如LoRA），可以让中小规模开源模型达到与超大闭源模型相近的性能，这对计算资源受限的研究团队具有重要指导意义。
4.  **直接使用非结构化文本**避免了复杂的数据清洗和特征工程管线，简化了pipeline，这一原则在医疗AI等数据异构性强的领域具有普适价值。

## 关键术语表
- **未来查询 (Future Querying)**：一种新范式，要求模型基于患者的历史轨迹，回答关于其未来状态的自然语言、时间索引的查询。
- **隐式医学世界模型 (Implicit Medical World Model)**：指大语言模型在预训练过程中可能无意识地学习到的、关于疾病发展和治疗反应等医学动态的内部表征。
- **无特征工程 (Feature-agnostic)**：指模型直接处理原始非结构化输入（如文本），无需人工设计或提取结构化特征。
- **任务无关 (Task-agnostic)**：指同一个模型无需为不同临床预测目标（如死亡率、并发症）重新训练或调整，即可回答多样化的查询。
- **时间戳划分 (Temporal Partitioning)**：构建训练数据的关键步骤，在患者时间线中选择一个虚拟的“现在”时间点$\hat{T}$，将未来的报告视为待预测的目标。
- **LLM-as-a-Judge**：使用另一个大型语言模型来评估和判断预测答案与参考答案之间语义等价性的自动化评估方法。
