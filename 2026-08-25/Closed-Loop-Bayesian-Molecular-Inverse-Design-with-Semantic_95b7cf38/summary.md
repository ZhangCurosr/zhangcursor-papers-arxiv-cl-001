# 论文速读：Closed-Loop-Bayesian-Molecular-Inverse-Design-with-Semantic

## 一句话总结
提出 **BoMolLLM**，一种将冻结大语言模型作为语义代理的闭环分子逆向设计框架；在有限 Oracle 预算下，通过直接读取 SMILES 历史、任务指令与评分反馈进行 Top-k 引用选择与可选指导文本生成，替代传统高斯过程在压缩潜空间中的搜索，显著提升候选池富集效率并提供自然语言可解释的优化轨迹。

## 研究问题与动机
- 分子逆向设计在实践中是**闭环候选池富集**问题，需在有限 Oracle 调用预算内持续提升匹配目标性质的分子比例，而非单次生成单一最优样本。
- 现有基于高斯过程（GP）的贝叶斯优化（BO）依赖压缩连续嵌入空间，导致分子子结构特征、参考相似度及任务级语义在降维过程中丢失。
- 当前 LLM 分子设计研究多采用单次提示（one-shot），缺乏利用 Oracle 反馈动态修正搜索轨迹的显式迭代机制。
- 分子优化历史本质上是离散文本与结构对象的序列，直接利用 LLM 的语义理解能力进行代理决策可在保留 BO 探索-开发平衡的同时实现全过程可解释。

## 核心贡献（创新点）
- **代理层解耦的闭环框架**：将分子逆向设计抽象为可替换代理的迭代闭环，使框架兼容 GP 与 LLM 两类代理，隔离决策层作为核心设计变量。
- **语义 LLM 代理机制**：用冻结 LLM 直接消费原始 SMILES、Oracle 得分与任务上下文，以上下文学习替代数值后验更新，以显式引用选择替代采集函数优化。
- **跨骨干一致性验证与可解释分析**：在 3 种 LLM 骨干与 6 个分子任务上证明该方法优于单次生成、匹敌或超越 GP-BO，并通过轨迹分析揭示自发的探索-开发转换行为。

## 方法详解
- **统一对齐得分**：定义 $a_\tau(s; y_\tau^\star) \in [0,1]$ 将不同 Oracle 输出标准化。药物任务按目标标签决定是否取反分类概率；材料任务在 log 空间计算预测值与目标值的指数衰减距离，确保高分恒对应强目标契合。
- **三模块闭环结构**：系统由冻结生成器 $\mathcal{M}$（Llamole，指令 LLM + 图扩散 Transformer）、任务 Oracle ${\mathcal{O}}_\tau$ 与冻结代理 LLM $\mathcal{L}$ 组成，运行 $T$ 轮独立优化。
