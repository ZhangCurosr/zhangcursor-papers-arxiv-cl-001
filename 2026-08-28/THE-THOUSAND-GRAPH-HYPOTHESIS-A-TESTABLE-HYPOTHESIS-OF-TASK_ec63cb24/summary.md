# 论文速读：THE THOUSAND GRAPH HYPOTHESIS: A TESTABLE HYPOTHESIS OF TASK-CONDITIONED RELATION MATERIALIZATION IN REPOSITORY-LEVEL CODE REASONING

## 一句话总结
该论文提出“千图假说”，主张仓库级代码推理无需预构建并维护外部关系图；借助两层实体索引，让大模型在推理时通过自注意力动态实例化任务特定的隐式关系图。在 SWE-bench Verified 上使用 DeepSeek-V4-Flash 的控制实验中，两层索引在零预建边条件下取得 95.6% 成功率，优于基础系统的一层索引。

## 研究问题与动机
- 现代软件仓库规模远超模型单次上下文容量，且仓库持续演化；如何在不过度训练模型、也不依赖长期外部关系维护的前提下支持仓库级代码推理，仍缺乏有效范式。
- 主流路线各有短板：把仓库知识训练进模型成本高且易过时；按需检索灵活但可能遗漏跨文件关键依赖；显式外部代码图精确却带来持续的抽取、同步和一致性维护开销。
- RepoCoder/Repoformer/Agentless 等更侧重“检索到哪里”，但未回答“相关实体进入上下文后是否还需要预建关系”这一核心机制问题。
- 明确可证伪的假说仍缺失：不同任务在同一仓库上是否会诱导不同的隐式任务图，以及零外部边的设置是否仍可实现仓库级修复。

## 核心贡献（创新点）
- 提出可证伪的“千图假说”，将仓库知识建模为持久实体+推理时任务条件关系实例化的动态机制，而不是依赖固定的外部图结构。
- 设计零外部持久边的接口假设，用 $E_{\mathrm{input}}^{\mathrm{rel}}=\emptyset$ 的形式化表达，与显式关系抽取方案形成本质区别。
- 提出两层仓库实体索引，分离全局模块级定位与局部实体详情选择，使得实体集合可在有界上下文中被压缩和组装。
- 在统一约束下进行端到端控制实验，证明在零预建边的条件下，两层索引仍能获得最高的仓库级修复成功率。
- 给出可审计的长期部署记录与当前可审计子集的对照，区分全量使用证据与可复核证据，强调假说适配性与可复现路径。

## 方法详解
- 外部状态只保留实体及其索引，不存储或预建关系边：每个实体 $v_i = (\mathrm{id}_i, x_i, m_i)$ 携带内容/摘要与元数据；关系在推理阶段由模型隐式组织。
- 两层索引的工作流：第一层基于全局索引 $I^{(1)}(R)$ 按任务定位候选模块集合 $\mathcal{D}_q = \mathrm{Locate}(q, I^{(1)}(R))$；第二层在候选域内按任务选择局部实体 $V_q = \mathrm{Select}(q, \mathcal{D}_q, I^{(2)}(R))$；最终上下文 $C_q = \mathrm{Serialize}(q, V_q)$ 不含预建关系。
- 假说下的隐式任务图：以自注意力为例，$A_q^{(\ell, h)} = \mathrm{softmax}((Q K^\top)/\sqrt{d})$，并按实体 token 集合聚合跨层/头强度，定义 $w_{ij}(q) = \Phi(\{A_q^{(\ell, h)}[a,b]\})$，从而得到 $G_q = (V_q, W_q)$；该图是用于表述假说的行为量，并不作为外部可存储/可查询的关系图输出。
- 体系与显式图边界对比：显式图需要实体、边、模式和图数据库并在仓库变更时重算边；本工作仅更新实体和索引，任务适配在推理时的注意力中发生。
- 从假说导出的可检验预测：任务敏感性、零边可行性、覆盖度效应；实验直接检验第二点，并通过层次消融间接反映第三点。

## 实验与结果
- 数据集：SWE-bench Verified，使用 DeepSeek-V4-Flash 作为基础模型。
- 三种受控条件均不含预建实体关系边：base system、one-layer index、two-layer index。
- 主要结果：base system 成功率 92.1%，one-layer 达 94.2%，two-layer 达 95.6%；两层相较 base 绝对提升 3.5pp，相较 one-layer 提升 1.4pp；误差由 7.9% 降至 4.4%。
- 最强结果为两层索引的 95.6%，表明在零外部边约束下仍可完成仓库级修复；结果与“任务条件关系实例化”假说兼容，但不构成对模型内部隐式图的直接因果证明。
- 长期实践报告提供使用规模证据：半年以上、200+ 项目、多次 GitHub 修复；可审计快照为 6 个仓库、52 个验证产物，并在一个公开仓库中观察到 29 个合入 PR（27 个含明确修复提交）。

## 相关工作脉络
- RepoCoder/Repoformer/Agentless：通过迭代检索、选择性检索与结构定位提升仓库级可达性，仍主要解决“去哪里读”；本文进一步追问“读进来之后是否仍需预建关系”。
- GraphCoder/CodexGraph/RepoGraph/LocAgent：构建基于图导航或检索的外部结构，提供强确定性查询，但与本文的关键差异在于是否持久存储并维护关系边。
- GRACE/RepoScope/CoCo：多视图图与结构化上下文检索，RepoScope 还引入任务条件链预测；它们与本文定位差异在于外部图维护成本与任务适配方式。
- RLCoder：以补全为导向的仓库级检索，但训练数据仍依赖依赖抽象；本文强调在推理阶段不依赖持久图关系。
- RPG-Encoder/CodexGraph：涉及图增量更新或全扫描与持久化，代表显式图路线的维护负担；本文以仅更新实体与索引来规避此类成本。
- RIG/Codebase-Memory：关注仓库变更后边的失效、重连与一致性；本文的方案通过不持久边来规避这类生命周期问题，但代价是关系变为隐式且需依赖推理组织。

## 局限性与未来方向
- 实验仅在单一模型 DeepSeek-V4-Flash 和单一公开基准 SWE-bench Verified 上验证，跨模型与跨基准泛化性未证实。
- 报告的是与假说一致的行为结果，而非对模型内部隐式图 $G_q$ 的直接因果观测或可解释证据。
- 长期实践部分区分了作者报告规模与可审计子集，前者不足以作为严谨的因果证明，后者规模仍有限。
- 两层索引的自动化程度、选择函数 $\mathrm{Select}$ 的具体实现、$\Phi$ 的可计算代理并未在当前报告中完全展开。
- 未来可从模型内部注意力模式反推 $G_q$ 的可解释分析、扩展至多模型与更大基准，并量化覆盖度效应与错误结构的对应关系。

## 研究启发与可借鉴点
- 将“关系是否必须外部持久化”转化为可证伪假说，并用控制实验比较不同索引层次，值得在其它长上下文或仓库推理任务中复用。
- 两层索引的全局路由-局部选择分解，为在有限上下文内组织大型实体集提供了可实现的工程范式。
- 用统一零边约束进行对比，有助于剥离检索能力与关系先验的贡献，是评估仓库级系统的健康对照设计。
- 将“可审计子集”与“全量部署记录”分开报告，为长期系统提供透明度与可复核路径，适用于工业场景验证。
- 本团队可结合注意力可视化或中间层聚合统计，构造对 $w_{ij}(q)$ 的可计算代理，从而把行为改进与隐式图机制联系起来。

## 关键术语表
- **千图假说**：同一仓库在不同任务下会通过模型注意力形成不同的隐式任务图，关系在推理时临时实例化。
- **隐式关系实例化假说**：外部系统只需持久化实体，推理阶段的任务条件上下文足以组织所需关系。
- **两层仓库实体索引**：第一层做全局定位，第二层在候选域内做局部实体选择，避免一次性输入全量仓库。
- **零外部持久边**：外部接口不存储预建关系，$E_{\mathrm{input}}^{\mathrm{rel}}=\emptyset$，以减少维护和更新成本。
- **隐式任务图**：基于注意力强度聚合得到的 $G_q=(V_q, W_q)$，用于刻画任务条件下的关系组织，并非外部可存图。
- **可证伪预测**：包括任务敏感性、零边可行性和覆盖度效应，用于指导对照实验与消融。
- **SWE-bench Verified**：基于真实 GitHub 任务的仓库级修复评测基准，用于端到端能力评估。
- **可审计子集**：与全量部署记录区分开的、可复核的实验与日志切片，用于保证结果透明度。
