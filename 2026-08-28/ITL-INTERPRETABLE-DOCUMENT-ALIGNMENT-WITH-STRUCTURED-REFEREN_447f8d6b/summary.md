# 论文速读：ITL: INTERPRETABLE DOCUMENT ALIGNMENT WITH STRUCTURED REFERENCE FRAMEWORKS

## 一句话总结
本文提出ITL（Intelligent Target Locator），一种领域无关、语言便携的方法，用于量化目标文档与结构化参考文档（SRD）中各概念之间的概念对齐程度；其核心创新是设计了可追溯至具体术语证据的"亲和度"度量，输出每个(文本单元, 概念)对的分级对齐值。

## 研究问题与动机
1. **现有方法缺乏概念级可追溯证据**：主流检索与分类方法返回成对相似性分数或离散标签，无法提供可直接追溯至支持证据的概念级分数，难以审计与解释。
2. **手动评估成本高且不可复现**：面对海量异质文档（尤其非结构化PDF），人工对照参考框架评估对齐程度成本高昂、依赖专家判断且难以保持一致性。
3. **概念关系具有分散性与语义性**：文档与参考框架之间的关系是概念性而非严格词汇性的，对齐证据往往分散于文本不同位置，传统词匹配方法难以捕获。
4. **需要跨文档可比、粒度灵活的量化度量**：对齐度量应支持在文档、段落、句子等不同粒度上进行分析与可视化，并能被外部审计。

## 核心贡献（创新点）
1. **形式化了"亲和度"度量**：提出一个基于加权术语匹配的多层级亲和度函数，每个(文本单元, 概念)对的得分均可追溯至支撑该得分的具体术语及其权重。
2. **提出通用两阶段方法论**：参考模型归纳阶段直接从SRD诱导带权重的术语画像；文档对齐阶段复用同一语言处理核心计算目标文档与各概念的亲和度；两阶段均由SRD驱动，不依赖特定领域或训练数据。
3. **设计了四项多维权重指标**：综合术语的判别力（跨概念分布熵补）、特异性（按术语类型计算的语义约束度）、相关性（概念内成员过滤）与重要性（前两指标的乘积），替代单一词频或嵌入相似度。
4. **引入了参考亲和度与相对亲和度**：以概念描述符自身的亲和度作为解释锚点，使绝对亲和度被归一化为相对亲和度，支持跨概念、跨文档的可比性分析。
5. **统一了四种术语类型的处理框架**：将独立词、二元组、三元组、共现项（固定窗口内非相邻词对）统一到多重集表示下，并通过词性标签区分独立词的身份、共复合术语仅用词干的方式防止模式碎片化。
