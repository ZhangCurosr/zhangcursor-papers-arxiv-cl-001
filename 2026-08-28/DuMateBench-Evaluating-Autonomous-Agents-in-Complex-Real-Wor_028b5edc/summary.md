# 论文速读：DuMateBench-Evaluating-Autonomous-Agents-in-Complex-Real-Wor

## 一句话总结
本文提出了 **DuMateBench**，一个从大规模生产型 Agent 平台真实用户会话中提取并重构的基准测试，旨在系统评估自主智能体在需协调多能力（编程、检索、文档处理、内容生成等）的端到端工作流中，面对资源受限、网络/工具瞬断及工作区噪声等现实环境扰动时的任务完成度、鲁棒性与效率权衡。

## 研究问题与动机
- **跨能力工作流组合性严重不足**：现有基准（如 OfficeBench、OdysseyBench、APEX-Agents）通常按单一应用或预定义能力划分任务，缺乏对需跨工具、跨模态协同的复杂工作流的覆盖，无法反映真实用户请求中多能力编排的共性挑战。
- **环境现实性与会话工作流割裂**：鲁棒性导向基准（如 ToolSandbox、SetupBench、ComplexMCP）将缺失依赖、网络抖动等扰动孤立评估，未与需交付异构 artifact 的真实多轮交互工作流结合，导致评测结果难以外推至生产场景。
- **评估标准在客观约束与语义质量间难以兼顾**：真实任务往往存在多种有效解法，纯确定性规则易误拒合理变体，而纯人工评估成本高且易受主观偏差影响；亟需一套可自动化、可审计的混合评估协议。
- **真实上下文与持久化状态缺失**：多数基准从零初始化环境，忽略了生产环境中普遍存在的历史交互记录、配置文件与工作区状态，使得 Agent 的上下文利用与状态管理能力无法被客观衡量。

## 核心贡献（创新点）
1. **首个基于真实会话的组合型工作流基准**：从 DuMate 生产平台清洗、重构出 200 个可执行任务，覆盖 8 大粗场景与 17 种细粒度能力，79.5% 的任务需跨至少两个场景协同完成，首次系统性量化 Agent 在多能力编排下的真实水平。
2. **可复现的三维环境复杂度建模**：在隔离 Docker 容器中显式注入 Insufficient（缺失依赖/资源限制）、Unstable（瞬断网络/工具故障）与 Noisy（干扰文件/噪声数据）三类扰动，将环境难度从黑盒容器转化为可控、可审计的评测组件。
3. **混合确定性清单与 LLM-as-Judge 的评估协议**：结合原子级客观检查（存在性、格式、公式、内容约束）与模态特定的人工审核 Rubric，以 $F_t = 0.3 P_t + 0.7 J_t$ 融合任务硬性完成度与异构产物质量，兼顾可复现性与语义评估覆盖面。
4. **Agent-Model 交互诊断与质量-效率三角分析**：系统评测 5 类 Agent 框架 × 4 款 SOTA LLM 的 20 种配置，首次揭示“环境扰动下的性能由底层模型能力与上层 Agent 框架协同决定”，并提供时间、Token 消耗与成功率的全维度权衡图谱。
