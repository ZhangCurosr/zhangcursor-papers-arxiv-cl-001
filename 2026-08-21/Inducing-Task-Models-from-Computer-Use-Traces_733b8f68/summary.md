# 论文速读：Inducing-Task-Models-from-Computer-Use-Traces

## 一句话总结
本文提出了 TASK MODEL INDUCTION (TMI)，一种从无约束的计算机使用痕迹中联合发现潜在多任务并诱导结构化任务模型的方法。该方法将原始屏幕截图和输入事件转换为语义活动，解耦交织的多线程工作流，并为每个任务生成配对目标层次结构与程序控制流的统一任务模型，显著提升了下游智能体技能生成的准确率（相对最强基线提升 30.0%）。

## 研究问题与动机
1. **自然主义痕迹的价值与建模困难**：被动录制的计算机使用痕迹（截图+鼠标/键盘事件）蕴含丰富的专家知识和工作流程，但目前大多数从未被记录，专业知识仍处于隐性状态。将其转化为显式的、可审计的、可复用的模型对于人机协同和智能体学习至关重要。
2. **现有方法的不足**：LLM 摘要方法会将并发任务混合并丢弃目标层次和控制流；工作流诱导方法假设整个记录是单一连续工作流，无法处理交织任务，且子目标被扁平化，迭代和分支表达受限；现有的轨迹分析方法通常预先给定根任务，无法扩展到包含潜在多样任务的会话。
3. **信号-意图鸿沟**：原始事件（如光标移动、按键）语义含义极低，需要跨越多模态感知才能 bridging 到语义意图。
4. **多线程工作的结构性挑战**：真实工作场景是多线程的（用户在同一会话中切换无关目标），且同一任务内存在交织的子目标，现有方法缺乏对非连续任务跨度（non-contiguous task spans）的建模能力。

## 核心贡献（创新点）
1. **形式化定义了"任务模型"概念**：首次将任务模型定义为配对目标层次结构（recursive goal decomposition）与程序控制流（sequencing/iteration operators）的显式表示，根植于计算思维和结构化编程定理。
2. **提出 TMI 三阶段流水线**：设计了事件接地与活动分割（bridging low-level signal to local intent）、潜在任务诱导（untangling multi-threaded activity stream，无需预定义任务集）、任务模型构建与调和（独立诱导目标/程序模型后在形式有效性约束下调和为统一模型）的完整框架。
3. **调和机制（Reconciliation）解决互补性失败模式**：证明了目标模型和程序模型各自具有独立证据但存在互补性盲区（目标模型常错误拆分迭代单元，程序模型常丢失底层目的），调和步骤使两者边界互修正（64.5% 的目标节点边界被程序模型修正，21.9% 的程序节点边界被目标模型修正）。
4. **内在与外在双重评估验证有效性**：内在评估在合成交错轨迹上达到 ARI=0.974，步骤重建率达 74.9%（最强基线仅 30.3%）；外在评估在 SkillLearnBench 上用诱导任务模型生成可复用技能，相对最强基线将保留任务准确率提升 30.0%。

## 方法详解
TMI 由三个串联阶段构成：

**阶段一：事件接地与活动分割 (§3.1)**
- **事件接地 (Grounding)**：使用视觉语言模型接收截图对 $(s_i, s_{i+1})$ 和记录的操作 $a_i$，推断事件含义（做什么、作用对象、应用），OCR 转录可见屏幕内容。接地严格约束在截图可见证据内。
- **两层次分割**：
  - 语义动作 (Semantic action)：将连续事件归组为产生一次有意义状态变化的单元，**向后**分割（backward），因为动作结束于artifact达到新状态时。
  - 活动 (Activity)：将语义动作归组为由单一局部目标解释的单元，**向前**分割（forward），因为活动始于目标被采纳时。

**阶段二：潜在任务诱导 (§3.2)**
- **增量分配**：活动按时间顺序处理，每个活动 $e_k$ 与现有任务档案（summary + identifiers）比较，分配到语义最接近的任务或开启新任务。
- **标识符 (Identifiers)**：维持任务一致性，跨应用/artifact/naming 变化保持任务连贯（如 "study-frontend" 仓库与 "review-trial.web.app" URL 指向同一任务）。
- **全局合并**：增量分配可能因目标漂移或长中断而分裂任务，最终通过全局合并阶段合并追求相同目标的任务。

**阶段三：任务模型构建与调和 (§3.3)**
- **目标模型 $O_t$**：递归分解（recursive decomposition）生成层次结构，根为任务目标，叶为活动 $E_t$，内部节点为潜在子目标。每个节点表示预期结果（抽象过具体策略）。有效性约束：每个活动恰好出现在一个叶节点，单活动节点必须为叶，内部节点必须陈述期望结果而非接口操作。
- **程序模型 $P_t$**：基于结构化编程定理，使用可观测操作符（sequence、for-each、while）构建控制流树：
  - SEQ：步骤按时间顺序枚举
  - FOR-EACH：至少两次对齐出现的相同活动模式，主要差异在命名artifact或实体
  - WHILE：重复发生直到满足目标状态条件
- **调和 (Reconciliation)**：从 $O_t$ 根节点向下扩展 $M_t$，每层控制流算子取自 $P_t$，子目标取自 $O_t$。分歧时分裂/合并/重挂载节点直到目标范围与控制流一致。形式有效性约束保证完整性与非重叠。

**实现细节 (§3.4)**：所有阶段使用 gpt-5.4 (temperature=1.0)，评估使用 gpt-5.5 和 claude-sonnet-5 作为独立judge。

## 实验与结果
**数据集**：
- HumanWork：38 个真实人类工作会话，15 个任务，5 个专业领域，42.8 小时录制，48.7K 原始事件
- SkillsBench：86 个软件工程任务，195 次运行，24.1K agent 步骤

**内在评估结果 (§4)**：
- **任务诱导鲁棒性 (Table 1)**：整体 ARI = 0.974 ± 0.028，MAE = 0.48 ± 0.54；即使密集交错（d=4）仍保持 0.968 ARI
- **任务诱导稳定性 (Table 2)**：HumanWork 匹配率 94.74%（gpt-5.5），SkillsBench 成功率 93.24%
- **任务模型保真度 (Table 4)**：
  - 步骤描述准确率：**74.9%** vs Workflow summary 30.3% vs Direct gen. N/A
  - 操作符正确率：**88.5%** vs 52.7%
  - 调和消融证明：单独目标模型仅 63.2% 描述准确率，单独程序模型无操作符，联合诱导节点数仅为 TMI 一半

**外在评估结果 (§5, Table 5)**：
- 使用诱导任务模型生成可复用智能体技能
- 保留任务准确率：**18.57%** vs Workflow summary 14.29%，**相对提升 30.0%**
- 可执行性：67.65% vs 59.35%
- 人类策展技能覆盖率最高(93.59%)但准确率仅10.00%，说明覆盖率与准确性不单调相关

## 相关工作脉络
1. **过程挖掘 (Process Mining)**：Van Der Aalst et al. (2011) 从已包含类型化活动和案例标识的事件日志中发现过程模型；TMI 无需预定义任务/边界，直接从原始截图表征工作。
2. **计划识别 (Plan Recognition)**：Kautz et al. (1986) 基于预设计划库推断目标；TMI 无先验任务集，联合发现隐式任务。
3. **计算机使用轨迹分析**：Wang et al. (2025) 的工作流总结产出阶段化叙事，缺乏正式模式和控制流；TMI 显式建模目标层次与 for-each/while 结构。
4. **多任务与认知研究**：González & Mark (2004), Mark et al. (2008) 证明知识工作者持续交错目标；TMI 利用 event segmentation theory (Zacks & Tversky, 2001) 将非连续任务跨度纳入建模。
5. **Agent 轨迹预训练**：Lu et al. (2025), Song et al. (2026) 在演示数据上预训练；TMI 提供显式、可审计、可复用的中间表示而非黑盒训练。
6. **UI  grounding 方法**：Shaw et al. (2023), Yang et al. (2023) 将像素映射为 UI 操作；TMI 在此基础上进一步抽象为活动、任务和任务模型三层语义结构。

## 局限性与未来方向
1. **隐私风险**：TMI 处理可能包含个人 identifiable information (PII) 的自然主义痕迹，需考虑在诱导前对截图和键盘事件进行隐私脱敏，且脱敏对诱导质量的影响留待未来研究。
2. **错误传播**：pipeline 早期错误（接地误差约影响 9% 目标节点、5% 程序节点；分割误差约 6%）会向上传播，后续阶段不重新分割轨迹。
3. **评估依赖 LLM judge**：尽管使用两个模型家族交叉验证，自动评估可能仍有家庭偏见。
4. **跨任务工作空间共享**：同一领域多任务共享工具/artifact 时（如两个数据分析任务均编辑 Jupyter notebook），区分难度增加。

## 研究启发与可借鉴点
1. **独立诱导+调和架构值得迁移**：目标模型与程序模型分别捕捉不同证据维度，调和步骤解决互补性失败的模式可推广至其他多视图结构化表示学习任务。
2. **标识符机制处理跨域一致性**：用 referential identifiers（artifact 名称、实体）而非纯语义 summary 维持任务连贯性，可有效应对 surface variation（应用/naming 变化），对多模态轨迹关联任务具有借鉴价值。
3. **操作符选择准则可复用**：for-each 要求"至少两次对齐出现且主要差异为命名实体"、while 要求"条件满足前重复"，这种基于证据的类型化控制流判定规则可直接应用于其他程序合成场景。
4. **非连续任务跨度建模**：放弃"任务占据连续时间跨度"的假设，允许 task span 分散在整个轨迹中，更贴近真实工作场景，可启发智能体 memory 系统的稀疏关联设计。

## 关键术语表
**Task Model**：配对目标层次结构与程序控制流的显式树状表示，每个节点携带一个目标和一个控制流算子（SEQ/FOR/WHILE）。
**Event Grounding**：利用截图对 $(s_i, s_{i+1})$ 和记录操作的视觉上下文推断原始事件的语义含义。
**Semantic Action**：产生一次有意义状态变化的连续事件序列，是比 raw event 更高一层的抽象单元。
**Activity**：由单一局部目标解释的语义动作序列，是用户意图可被推断的最小单位。
**Latent Task Induction**：从无约束痕迹中动态发现并分配活动到隐式任务的增量-合并过程。
**Reconciliation**：调和目标模型与控制流模型分歧、融合为统一任务模型的步骤。
**Structured Programming Theorem**：任何程序均可仅用顺序、选择、迭代三种算子表达，本文取可观测的前两者加迭代变体。
**Adjusted Rand Index (ARI)**：衡量预测分区与真实分区之间一致性的指标，范围 [-1,1]，越高越好，已校正随机期望。
