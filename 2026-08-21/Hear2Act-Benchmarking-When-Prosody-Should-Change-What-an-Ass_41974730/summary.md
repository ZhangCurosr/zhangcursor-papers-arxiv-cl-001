# 论文速读：Hear2Act: Benchmarking When Prosody Should Change What an Assistant Does

## 一句话总结
本文提出了 HEAR2ACT，一个统一的评估协议，用于测试在任务导向对话中，语音韵律线索（prosody）在什么条件下能够改变助手的决策。研究发现：当词汇证据不足时，韵律确实具有决策价值，但当前音频大模型无法直接将音频信息转化为行动，需要通过显式的中间文本表示才能实现有效利用。

## 研究问题与动机
1. **任务导向对话中的韵律信息价值未被系统评估**：现有 benchmark 要么评估任务对话成功（如 MultiWOZ），要么评估韵律感知（如 Paralinguistic benchmarks），但缺乏将韵律证据与下游任务决策相连的统一协议。
2. **"听到"与"做到"之间的鸿沟**：即使模型能感知韵律线索（如犹豫、不满意的语调），也不代表能将这些信息用于改善多轮对话的后续行动（如继续追问还是过早推荐）。
3. **韵律 vs. 词汇证据的互补关系不明**：需要量化在什么条件下韵律提供额外信息（词汇不足时），以及在什么条件下韵律贡献有限（词汇已明确时）。
4. **评估方法的局限性**：现有工作缺乏同时控制词汇内容与韵律变化、保持任务与用户需求固定的匹配式对比实验。

## 核心贡献（创新点）
1. **提出 HEAR2ACT 统一评估协议**：构建 480 个受控场景，固定任务与用户需求，仅改变关注点是通过词汇还是韵律表达，首次支持文本与语音助手的对比评测。*本质区别：不同于仅评估单轮响应恰当性或情感理解的基准，本文追踪韵律证据在多轮任务决策中的完整影响链。*
2. **揭示"感知-行动"鸿沟（perception-action gap）**：发现 Qwen2.5-Omni 能以 0.85 准确率感知韵律线索，但直接将音频输入决策时最优解率仅提升 0.7 个百分点（14.6%→15.3%）。*本质区别：此前工作（如 LISTEN、ParaBridge）指出类似现象，但本文为首个在任务导向对话中量化这一鸿沟的基准。*
3. **提出两阶段干预方案并验证有效性**：让模型先从音频推断关注状态（resolved/unresolved）并以文本形式表示，再用于决策，最优解率提升至 39.6%，接近 ground-truth 的 40.7%。*本质区别：证明显式中间表示是弥合感知-行动鸿沟的有效手段，为后续方法设计提供新思路。*
4. **设计精细的控制实验与诊断指标**：包含匹配式 rollout、label-fidelity 干预（全正/全负/打乱标签）、以及 ASK/CLARIFY/RECOMMEND/CONFIRM 行为分解，分离"问得更多"与"问得更准"的区别。*本质区别：超越简单准确率指标，提供对话策略变化的精细诊断。*

## 方法详解
**场景构造**：
- 从 SGD 数据集的 48 个服务领域抽取种子，每领域 10 个场景，共 480 场景
- 每场景包含：初始请求（可见需求）、三层隐藏关注点（L1 硬约束、L2 强偏好、L3 中度偏好）、11 个候选选项
- 候选选项覆盖 8 种满足模式（3层关注点的组合）+ 1 安全选项 + 2 违反显式需求的选项

**交互引擎**：
- 确定性用户引擎：给定场景、对话历史、助手动作，决定剩余未解决关注点、可披露信息、用户响应
- 两种反馈实现：
  - **Explicit lexical feedback**：关注点在词汇中明确陈述
  - **Prosody-mediated feedback**：硬约束违规仍明确，软关注点通过韵律传递"推荐未解决"信号

**评估条件**（ spoken 助手）：
- T（仅转写）：baseline
- A（仅音频）：测试纯音频感知
- A+T（音频+转写）：测试直接融合
- T+S（转写+ground-truth状态）：oracle 参考
- T+Ŝ（转写+音频推断状态）：两阶段干预
- SER baselines：HuBERT/SpeechBrain 通用情感标签

**文本模型条件**：
- T（仅转写）vs. T+S（转写+ground-truth状态）：隔离关注点信息的决策价值

**指标**：
- 1st%：最终选择最优选项的比例
- OptSat%：推荐后非负面接受的比率
- SvcSat%：交互满意比率
- 行为诊断：ASK/CLARIFY/RECOMMEND/CONFIRM 比例、隐藏关注点披露率、过早终止率

**语音渲染**：
- Qwen3-TTS（主）与 VoxCPM2（鲁棒性）
- 关注状态映射到 delivery labels：resolved→satisfied/warm/enthusiastic；unresolved→hesitant/underwhelmed/concerned/frustrated

## 实验与结果
**数据集与规模**：
- 480 个场景，960 个基础 episode
- 54,240 个评估 rollout（含 5 个文本 LLM × 2 条件 × 480 场景 + 2 个语音 LLM × 5 条件 × 480 场景等）
- 领域覆盖：旅行、住房、医疗、金融等 8 个服务家族

**主要结果**（Qwen3-TTS 渲染，Prosody-mediated feedback）：

| 条件 | Qwen2.5-Omni 1st% | Qwen2-Audio 1st% | 平均 1st% |
|------|-------------------|-------------------|-----------|
| T（仅转写） | 15.4 | 13.7 | **14.6** |
| A+T（音频+转写） | 15.9 | 14.7 | **15.3** |
| T+Ŝ（音频推断状态） | 43.0 | 36.2 | **39.6** |
| T+S（ground-truth状态） | 44.5 | 36.9 | **40.7** |

**关键发现**：
1. **韵律的决策价值**：Prosody-mediated feedback 下，ground-truth 状态使 5 个文本 LLM 平均 1st% 提升 **+36.7pp**（26.9%→63.5%），而 Explicit lexical feedback 下仅提升 **+6.4pp**
2. **感知-行动鸿沟**：Qwen2.5-Omni 在感知任务上达 0.85 准确率（Qwen3-TTS）/ 0.76 准确率（VoxCPM2），但直接音频输入对决策几乎无帮助（14.6%→15.3%）
3. **两阶段干预有效**：T+Ŝ 达到 39.6%，接近 oracle 的 40.7%，差距仅 1.1pp
4. **通用情感识别部分有效**：HuBERT（32.6%）和 SpeechBrain（29.2%）优于直接音频但仍低于任务对齐的 T+Ŝ（39.6%）
5. **行为变化**：正确关注信息使 ASK/CLARIFY 从平均 1.8 次增至 4.4 次，全部关注点披露率从 3% 提升至 30%，过早终止率从 69.7% 降至 26.7%
6. **渲染器鲁棒性**：VoxCPM2 结果与 Qwen3-TTS 模式一致，per-cell 差异平均 1.5pp

## 相关工作脉络
1. **MultiWOZ/SGD**（Budzianowski et al., 2018; Rastogi et al., 2020）：多域任务对话基准，有结构化状态和可验证成功，但**不隔离韵律线索对顺序决策的影响**。
2. **SpokenWOZ**（Si et al., 2023）：扩展至语音场景，但仍**缺乏隐藏用户需求的控制与韵律-决策链路评估**。
3. **StyleTalk/ParaS2S**（Lin et al., 2024; Yang et al., 2026）：控制词汇内容评估响应恰当性，但**仅评估单轮响应而非多轮任务轨迹**。
4. **MULTI-Bench/HumDial-EIBench**（Deng et al., 2025; Wang et al., 2026b）：评估情感理解与多轮交互，但**缺乏候选选项驱动的客观结果验证**。
5. **LISTEN**（Chen et al., 2026）：发现词汇主导和声学线索利用不足，但**未追踪多轮任务决策**。
6. **ParaBridge**（Wang et al., 2026c）：识别感知-行为鸿沟并通过 scaffolding 改进，但**本文在受控基准上提供更精确的因果测量**。

## 局限性与未来方向
1. **韵律功能的单一性**：仅评估"推荐是否未解决"这一种决策相关功能，未覆盖更广泛的偏好结构或其他韵律功能（如强调、讽刺等）。
2. **合成语音的限制**：用户 utterance 和语音均由结构化状态合成，虽经人类验证（0.92 准确率）但仍无法捕捉自然语音的完整变异性。
3. **Ground-truth 状态的诊断性质**：T+S 条件是诊断性参考而非部署设置，实际系统中需依赖模型推断。
4. **T+Ŝ 干预的双重性**：同时引入显式表示和额外推理步骤，未能完全隔离机制（是表示形式的作用还是推理过程的作用？）。
5. **未来方向**：扩展至更多韵律功能、自然语音数据、端到端感知-行动联合训练、动态关注状态建模。

## 研究启发与可借鉴点
1. **匹配式 rollout 设计**：固定场景与用户需求，仅改变证据类型（词汇/韵律/状态），实现干净的因果对比——可直接迁移至其他多模态决策评估。
2. **两阶段干预范式**："感知→显式表示→决策"的解耦策略，为弥合感知-行动鸿沟提供可复用的方法论，尤其适用于多模态大模型的中间表示学习。
3. **Label-fidelity 干预实验**：通过全正/全负/打乱标签控制，分离"正确时序信息"与"仅统计分布"的贡献——值得在时序预测任务中借鉴。
4. **行为诊断指标体系**：区分"问得更多"与"问得更准"、"过早终止"与"有效探索"——为对话系统评估提供细粒度分析框架。
5. **任务-韵律联合建模机会**：本文证明任务相关的关注状态推断（T+Ŝ）显著优于通用情感识别（HuBERT/SpeechBrain），提示未来可探索**任务条件化的韵律表征学习**。

## 关键术语表
**HEAR2ACT**：本文提出的统一评估协议，用于衡量韵律线索何时改变任务导向对话中助手的决策。
**Prosody-mediated feedback**：关注点主要通过语音韵律（语调、节奏等）而非词汇内容传达的反馈条件。
**Explicit lexical feedback**：关注点在用户 utterance 的词汇层面明确陈述的反馈条件。
**Optimal-solution rate (1st%)**：多轮对话结束后选择最优候选选项的 rollout 比例。
**Perception-action gap**：模型能感知韵律线索但未能将其转化为更好决策的现象。
**Audio-inferred state (Ŝ)**：模型从音频推断的关注状态（resolved/unresolved）并以文本形式表示。
**Label-fidelity intervention**：用全正、全负或打乱的关注状态标签替换真实标签，测试增益是否依赖正确时序信息。
**Deterministic user engine**：根据场景、对话历史和助手动作，确定用户响应、状态转移和信息披露的规则引擎。
