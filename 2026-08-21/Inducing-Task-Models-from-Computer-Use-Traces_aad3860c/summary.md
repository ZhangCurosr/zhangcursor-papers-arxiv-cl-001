# 论文速读：Inducing-Task-Models-from-Computer-Use-Traces

## 一句话总结
论文提出 TASK MODEL INDUCTION (TMI)，从被动记录的自然计算机使用轨迹中自动发现潜在任务、解纠缠并发活动，并为每个任务构建将目标层次分解与控制流结构相结合的任务模型，显著优于现有工作流归纳基线。

## 研究问题与动机
- 自然计算机使用轨迹（被动记录的截图和鼠标/键盘事件）蕴含大量日常工作如何完成的信息，但这类知识多为隐式、从未被文档化，AI 智能体进入真实工作环境后需要学习任务的实际执行方式，组织也需要审计和复用这些知识。
- 现有方法仅部分解决该问题：LLM 摘要会将并发任务混合、丢弃目标层次；直接生成任务模型能恢复 schema 但无法恢复执行结构；工作流归纳将所有活动视为单一连续工作流，无法处理交错的并发任务，且子目标被扁平化、迭代与分支未被表达。
- 真实工作具有多线程特征——用户在会话中切换多个不相关目标，任务内部也存在交错的子目标；现有 trace 分析方法假设根任务预先给定，无法扩展到包含潜在多样任务的会话。
- 从信号到结构三重挑战：原始事件的语义含义低、需视觉上下文桥接；天然工作多线程且目标交错；轨迹仅记录执行路径，不直接揭示目标层次或组织执行的 control flow。

## 核心贡献（创新点）
- **形式化任务模型表示**：将目标层次递归分解与由顺序/迭代算子构成的程序控制流配对，每个节点携带目标与控制流算子；本质区别在于既保留意图层次又显式表达执行结构，而非仅生成步骤列表或自由文本摘要。
- **提出 TMI 三阶段方法**：事件接地与活动分割 → 潜在任务发现与分配 → 目标/程序模型独立诱导后在形式有效性约束下调和；与已有方法的区别在于多任务无需预定义、非连续活动可归属同一任务、目标与程序视图互补而非单_pass 联合生成。
- **结构一致性调和机制**：分别以目标和程序证据独立诱导两棵树，再按规则分裂/合并/重父节点使目标范围与控制流一致，能恢复单一模型各自丢失的步骤；区别于直接生成的单 Pass 尝试，避免粒度损失与幻觉增加。
- **内在/外在双重评估**：内在指标用 ARI/MAE/步骤描述准确度验证轨迹还原质量，外在指标用 SkillLearnBench 下游智能体技能生成验证迁移效果；相比先前工作仅评估摘要质量，本文证明任务模型可显著提升智能体准确率 30.0%。

## 方法详解
- **事件接地与活动分割**：视觉语言模型接收前后截图对 $(s_i, s_{i+1})$ 与操作 $a_i$，推断事件语义、目标产物与应用；基于视觉差异做局部解释而非回溯归因。语义动作由连续事件组成、产生一次有意义的状态变化；活动由单一局部目标解释。分割方向遵循证据：语义动作反向分割（直到状态被确认），活动正向分割（前序上下文表明目标采纳）。
- **潜在任务诱导**：维护每个任务的任务档案（摘要 + 引用标识符如产物名/命名实体），活动时序分配给语义最接近的任务或开启新任务；标识符跨应用/产物/命名漂移保持任务连贯，避免碎片化为虚假子任务；全局合并阶段对目标趋同的任务进行最终合并。
- **目标模型诱导**：从任务目标出发递归分解为子目标树，叶子对应活动，内部节点为无法直接追求、需用子目标联合解释的中间目标；节点描述期望产出而非界面操作。
- **程序模型诱导**：基于可观测的控制流算子——sequence、for-each（至少两次对齐重复且仅命名产物/实体不同）、while（重复直至目标状态条件满足）；排除 selection（trace 通常仅展示 enacted 策略）；重复步骤必须在对齐出现中被接地为活动 episode。
- **模型调和**：从任务目标向下展开，控制流算子取自程序模型、子目标取自目标模型；分歧时按规则分裂/合并/重父节点，例如程序模型读为 for-each 但目标模型拆分为每用户子目标时，保留单一循环并将子目标嵌套为其语义细化；每节点最终携带目标与控制流算子，叶子接地到活动。
- **形式有效性约束**：目标树要求完整不重叠、单活动节点必须为叶、内部节点必须是期望产出；程序树要求每活动至少被一个节点覆盖、算子属于封闭原语集、for-each 必须绑定显式枚举集合、while 必须有目标状态退出条件；违反时由确定性验证器反馈并触发定向修复。

## 实验与结果
- **数据集**：HumanWork（38 个真实人类会话，15 项任务，5 个专业领域，共 42.8 小时/48.7K 原始事件）；SkillsBench（86 个软件工程任务，选取高平均动作数 15 个任务，195 次运行/24.1K 代理步骤）。
- **内在评估**：合成多任务轨迹实验（$K \in [2,15]$ 任务数，$d \in [2,4]$ 交错难度），ARI 总体 0.974，MAE 0.48；跨两种 LLM judge（gpt-5.5 / claude-sonnet-5）的潜在任务身份匹配率：HumanWork 94.74%/89.47%，SkillsBench 93.24%/98.65%。
- **任务模型保真度**：TMI 步骤描述准确度 74.9%（最强基线 workflow summary 仅 30.3%）；算子正确率 88.5%（基线 52.7%）；目标覆盖与一致性优于/持平 direct generation。消融显示 w/o 目标模型步骤描述降至 63.2%，w/o 调和 procedure hallucination 翻倍。
- **外在评估（SkillLearnBench）**：以 induced task model 作为 skill 来源，held-out 任务准确率 18.57%，相比最强基线 workflow summary 的 14.29% 提升 30.0%；可执行性从 59.35% 提升至 67.65%。人工专家技能覆盖率最高（93.59%）但准确率仅 10.00%，说明覆盖率与实际迁移能力正负相关。
- **非线性和平执行影响**：错误纠正占 89% 会话，探索性搜索 87%；尽管 step description 下降至 66.7%，仍远超基线 30.3%，parent-child 一致性无系统性下降。

## 相关工作脉络
- **Plan recognition（Kautz et al., 1986）**：从观测动作推断目标，但预设有计划库或领域理论；TMI 无需预定义任务集，直接从 raw trace 联合恢复语义动作与潜在任务。
- **Process mining（Van Der Aalst et al., 2011）**：从含类型化活动与 case identifier 的事件日志发现程序模型；TMI 处理未标注的原始屏幕/输入事件序列，不依赖 typed activities。
- **Computer-use trace grounding（Shaw et al., 2023; Yang et al., 2023; You et al., 2024; Zheng et al., 2024）**：将像素接地到 UI 操作；TMI 在此基础上进一步从接地事件恢复活动、任务和层次结构。
- **Workflow summarization（Wang et al., 2025）**：产生阶段式自由文本摘要；TMI 输出结构化任务模型，保留目标层次与控制流算子，避免并发任务混合。
- **Agent skill learning from demonstrations（Lu et al., 2025; Song et al., 2026）**：预训练代理从演示中学习；TMI 提供可审计、可复用的符号化 skill 源，提升 held-out 任务准确率 30%。
- **Task analysis under known root task（Wang et al., 2024; Grohs et al., 2024）**：假设根任务已知；TMI 在无任务边界和描述的 unconstrained session 中联合发现 latent tasks。

## 局限性与未来方向
- TMI 处理包含个人可识别信息的自然轨迹，未来部署需考虑在诱导前对截图和键盘事件进行隐私脱敏，并研究脱敏对诱导质量的影响。
- 当前 pipeline 全部依赖 gpt-5.4/gpt-5-mini/gpt-5.5/claude-sonnet-5，成本和可访问性受限；未讨论轻量化替代或本地部署方案。
- SkillsBench 转换中将 agent 的 tool call/result 直接映射为活动，绕过了底层接地阶段，尚未在纯 agent 轨迹上验证完整 pipeline。
- 跨领域泛化（如移动设备、VR/AR 环境）和多语言场景未评估，任务标识符漂移鲁棒性在高重叠应用占比（96.7% 共享应用）下仍需谨慎。

## 研究启发与可借鉴点
- **目标与程序双视图调和思路**：分别从意图和执行角度独立诱导互补模型，再通过形式约束调和，可迁移至视频轨迹、机器人操作轨迹等多模态行为理解任务。
- **合成交错轨迹评估设计**：通过采样 K 会话切分 d 段重排构造不同并发度和交错密度条件，系统化评估鲁棒性；可作为多任务学习/轨迹理解工作的标准压力测试范式。
- **标识符跨漂移保持任务连贯**：引用 artifact/named entity 作为任务档案的稳定锚点，适用于跨应用/跨命名变异的长期活动追踪或日志关联分析。
- **消融定位互补失败模式**：w/o objective model、w/o procedure model、w/o reconciliation 三种消融揭示"目标视图忽略过程结构、程序视图忽略意图、单 Pass 粒度损失"三类不同失败，为后续改进提供明确诊断维度。
- **下游 skill 迁移量化**：将 induced model 作为 skill 来源，在 SkillLearnBench 验证准确率相对提升 30%，为结构化的行为表示提供端到端效用证明，可参考其"学习源对比"实验设计。

## 关键术语表
**Task Model**：将任务的目标层次递归分解与执行过程的 control-flow 算子（sequence/for-each/while）配对的树形表示，每个节点同时携带目标与算子。
**Event Grounding**：利用前后截图对的视觉上下文，将原始鼠标/键盘事件推断为带有语义意图、目标产物与应用信息的 grounded event。
**Semantic Action**：由连续接地事件组成、共同产生一次有意义状态变化的原子单元。
**Activity**：由单一局部目标解释的语义动作集合，标志着一段可识别的意图执行段。
**Latent Task**：会话中未被预定义的潜在目标任务，其边界与归属在活动轨迹中隐含，需由系统发现与分配。
**Objective Model**：以任务目标为根的递归分解树，内部节点为中间子目标，叶子为活动，解释"为什么执行"。
**Procedure Model**：由 sequence/for-each/while 算子构成的执行组织树，基于可观测的时序与重复模式诱导，解释"如何执行"。
**Model Reconciliation**：在形式有效性约束下，将目标模型与程序模型的分歧通过分裂/合并/重父节点调和为一致任务模型的过程。
