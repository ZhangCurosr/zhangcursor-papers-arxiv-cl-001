# 论文速读：TASK-COEVOLVE-EFFICIENT-HARNESS-OPTIMIZA-TION-VIA-ADAPTIVE-V

## 一句话总结
提出 Task-CoEvolve，通过方差加权动态选择高区分度验证任务，并结合包含概率感知的全量分数估计，在仅需 20% 评估预算下即可匹配甚至超越全量验证集搜索的 Agent harness 优化效果，同时将搜索成本降低 67–80%。

## 研究问题与动机
- **评估成本过高**：现有自动化 harness 优化方法（如 Meta-Harness）每轮迭代均对固定全量验证集进行完整评估，在长程终端任务（单次执行耗时数十分钟）场景下，评估成为整个优化循环的主要瓶颈。
- **验证集静态退化**：随着 harness 持续进化，原本具有区分度的任务会迅速变成“全对”或“全错”，继续消耗评估预算却无法提供有效的排序信号。
- **子集轮换导致不可比**：若简单每轮随机重采样子集以避免过拟合，则不同轮次的原始子集得分受任务难度波动影响，无法直接横向比较与最终择优。
- **核心诉求**：在严格有限的评估预算下，动态聚焦最有判别力的任务，同时保证跨迭代评估结果落在统一标度上。

## 核心贡献（创新点）
- **协同演化范式**：首次将“验证任务选择”显式纳入 harness 自动优化闭环，与仅优化候选生成/选择的既有工作形成正交互补。
- **方差加权任务选择**：提出基于历史成功率伯努利方差的采样权重设计，使评估预算自动聚焦于候选群体表现分歧最大（$\bar{p}_t \approx 0.5$）的能力前沿任务，并辅以不确定性奖励防止早期样本偏差。
- **双模式抽样感知估计**：针对验证集分布形态自适应选用 Hajek 估计或锚点差值估计，通过包含概率逆加权消除子集难度波动，实现跨迭代公平比较。
- **实证验证**：在在线文本分类与 Terminal-Bench 2.1 上系统证明，7% 预算即可逼近全量搜索，20% 预算可超越全量搜索，同时削减 67–80% 的 token 消耗与近半运行时间。

## 方法详解
- **Phase 0 初始化**：在搜索启动前，用两个预设初始 harness（zero-shot 与 few-shot）在全量验证集 $\mathcal{T}$ 上各运行一次，记录每个任务的历史成功率 $\bar{p}_t$ 与观测次数 $n_t$，作为后续采样的先验。
- **Phase 1 方差加权任务选择**：第 $k$ 轮为任务 $t$ 计算权重 $w_t = \max(\bar{p}_t(1-\bar{p}_t), \ell_t) + \lambda/\sqrt{n_t}$。第一项为伯努利方差，刻画候选间的分歧程度；第二项 $\lambda/\sqrt{n_t}$ 为不确定性 bonus，缓解早期统计噪声；$\ell_t$ 为未解决任务的下界常数。按权重采样大小为 $m = \lceil \rho N \rceil$ 的子集 $S_k$，评估候选后更新历史统计。
- **Phase 2 抽样感知全量估计**：为避免固定/随机子集带来的估计偏差，利用 Monte Carlo 估算每个任务在本次抽样中的包含概率 $\pi_t = \Pr[t \in S_k]$，并据此估计全量得分 $\hat{S}(h)$：
