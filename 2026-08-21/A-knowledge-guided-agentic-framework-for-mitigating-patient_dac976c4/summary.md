# 论文速读：A knowledge-guided agentic framework for mitigating patient-context ambiguity in health queries

## 一句话总结
论文提出了一种**知识图谱引导的智能体框架**，在患者与下游语言模型之间作为一个独立中间层，主动识别并获取缺失的患者特定上下文（症状、用药、过敏史等），再将澄清后的提示词传递给下游LLM生成最终回答。在症状诊断检索和饮食安全分类两个任务上，该方法相比直接回答和单纯重述，显著提升了准确率并降低了预测不确定性。

## 研究问题与动机
- **患者查询的 underspecified 本质**：患者向医疗聊天机器人提交的查询往往简短且缺少关键的个人健康上下文（症状、诊断、用药、过敏、饮食限制等），导致同一查询可对应多种合理回答，但均无充分依据。
- **区别于已有歧义类型**：与词汇歧义、知识歧义、意图歧义不同，"患者上下文歧义"（patient-context ambiguity）的缺失信息存在于患者自身，无法从模型参数或外部语料库中检索获得，必须通过交互主动获取。
- **现有方法不足**：纯参数化知识增强、检索增强生成（RAG）、知识图谱 grounding 都无法获取未披露的患者变量；单纯重述（Rephrase-and-Respond）保留了原始查询的信息量，不能引入新事实；现有澄清研究（如CLAM、CLAMBER）多针对开放域QA，而非患者特定的临床上下文。

## 核心贡献（创新点）
1. **形式化"患者上下文歧义"为独立问题**：将缺失个人健康信息与词汇歧义、知识缺口、意图不明明确区分，提出需通过交互获取而非推理解决的澄清范式。
2. **知识图谱引导的智能体中间层**：在患者与**不修改的**下游LLM之间引入一个确定性控制器+LLM的编排器，利用任务特定知识图谱（DxSxKG / FoodSafetyKG）构建假设集、计算期望信息增益、选择最优澄清问题，无需对下游模型进行微调。
3. **两个受控基准验证"获取新信息 vs 重述现有信息"**：在症状诊断检索（1,034实例）和饮食安全分类（487实例）上，证明主动获取患者上下文相比仅重述查询能产生质的性能提升。
4. **跨模型一致性与不确定性分析**：澄清后不仅平均准确率提高，且不同下游LLM之间的性能差异显著缩小，重复生成时的预测熵大幅下降。

## 方法详解
**框架架构**：分为三层——Interface（信息交换）、Orchestrator（澄清工作流）、外部知识源（Neo4j 知识图谱）。底层LLM（GPT-5.5）负责语义解析与问题表述，确定性控制器负责假设管理、问题选择和停止决策。

**候选构建**：将查询中的可见症状/食物词映射到知识图谱实体；若初始检索到的候选假设少于3个或临床不一致，内层LLM可进行一次扩展（最多提议3个额外术语），扩展结果经图谱匹配后参与候选构建但不作为澄清问题。

**假设初始化与权重分配**：设初始假设集为 $\mathcal{H}_0 = \{h_1, \ldots, h_K\}$，每个假设赋予等权初值 $b_0(h) = 1/|\mathcal{H}_0|$。

**问题选择策略（期望信息增益）**：在第 $t$ 轮，控制器遍历所有未询问的二元澄清变量 $v \in \mathcal{V}_t$，选择最大化熵减的变量：
$$v_t^* = \arg\max_{v \in \mathcal{V}_t}\left\{ H(b_t) - \sum_{a\in\{0,1\}} P(a|v,b_t)\,H(b_t|a,v) \right\}$$
其中 $H(b_t)$ 为当前假设分布的香农熵。

**假设更新**：收到答案 $a_t$ 后，剔除不相容假设并重新归一化：
$$b_{t+1}(h) = \frac{\mathbf{1}[h \in \mathcal{H}_t(v_t^*, a_t)]\,b_t(h)}{\sum_{h'\in\mathcal{H}_t}\mathbf{1}[h' \in \mathcal{H}_t(v_t^*, a_t)]\,b_t(h')}$$

**停止条件**：①某假设后验概率 > 0.95；②无进一步有信息增益的问题；③达到交互上限（诊断任务最多5轮）。若到达极限仍无法收敛，搜索共同上级类别（IS A 祖先），若覆盖 $\geq \lceil|\mathcal{H}_0|/2\rceil$ 则输出 PARTIAL，否则 ABSTAIN。

**知识图谱**：诊断任务使用 DxSxKG（129,815 诊断节点、340,842 症状节点，源自 UMLS 2025AA）；饮食安全任务使用 FoodSafetyKG（208万食物节点、60营养属性节点，整合 USDA FoodData Central + 14部临床实践指南）。

## 实验与结果
**数据集**：
- 诊断检索：Synthea 合成记录，1,034 实例，32 个诊断标签，平均每个病例含 8.22 个症状，约 50.5% 可见、49.5% 隐藏。
- 饮食安全分类：487 实例，38 种患者健康背景，301 OK / 186 NOT OK（正类为 NOT OK）。

**评估基线**：BASIC（直接回答）、Rephrase-and-Respond（RAR，仅重述不获取新信息）、AGENT（主动澄清后回答）。

**诊断检索结果**：
- **精确 Top-1 准确率**：Agent 57.7%–71.1%，远超 BASIC（0.6%–11.0%）和 RAR（0.8%–10.0%）；相对提升至少 **57.1 pp**。
- **精确 Recall@5**：Agent 90.6%–90.9%，远超 BASIC（2.0%–16.2%）和 RAR（2.2%–15.7%）；相对提升至少 **77.7 pp**。
- **ICD 级别 Top-1**：Agent 78.8%–80.6%，BASIC/RAR 为 27.2%–45.9%。
- Agent 在 1,034 例中 abstain 35 例（3.4%），选择性结果与整体结果差异很小，说明提升非因大量排除困难案例。

**饮食安全分类结果**：
- Agent 在 **4/5 个模型上取得最高 MCC**（GPT-5.5: 0.783、Claude Opus 4.8: 0.837、LLaMA 3.3 70B: 0.750、Mistral Large: 0.741）。
- Agent 在 GPT-5.5 和 Claude Opus 4.8 上大幅降低 false negative 率（漏判 unsafe food）；对 Gemini 3.1 Pro 的 MCC 略低于 BASIC，但 accuracy 和 precision 更高。

**跨模型一致性**：Agent 配置在所有指标上均呈现**更高的均值 + 更小的标准差**，表明澄清后下游模型选择的敏感性显著降低。

**重复生成不确定性分析**：在 2 个诊断探针各 500 次重复中，Agent 的类别级熵均值仅 **0.017 bits**，而 BASIC/RAR 分别为 0.320/0.338 bits；饮食安全探针中 Agent 全部 1,000 次输出完全一致（熵=0）。

## 相关工作脉络
1. **Rephrase-and-Respond (RAR, Deng et al., 2024)**：仅对查询进行重述，不引入新信息；本文证明对"患者上下文歧义"场景效果有限，因为信息缺失是结构性而非表述性。
2. **CLAM / CLAMBER**（Kuhn et al., 2023; Zhang et al., 2024）：LLM驱动的开放式澄清问答；本文指出 MediQ 基准上单纯 prompt 方式并不稳定地提升澄清质量，需知识图谱结构化约束。
3. **CLEAR-KGQA (Wen et al., 2025)**：知识图谱辅助的消歧；主要针对事实/实体歧义，而非患者特定上下文（后者需从用户处获取，无法从外部知识库检索）。
4. **Retrieval-Augmented Generation (Lewis et al., 2020) & 医疗RAG综述**：通过外部检索补充模型知识；但无法检索未披露的过敏史、用药等患者变量，本文的工作正是弥补这一缺口。
5. **Synthea 合成数据 + UMLS 知识图谱**：诊断基准的构建参考 Synthea 合成记录生成规范 [21,22] 及 UMLS 术语体系 [23]，确保候选假设与澄清问题的知识基础具有临床有效性。

## 局限性与未来方向
- **合成数据局限**：诊断基准来自 Synthea 合成记录，未涵盖真实临床中的合并症、文档变异、不完整病史和患者自然语言；需在真实临床数据上验证。
- **知识图谱覆盖不全**：缺失或不正确的图谱关系可能导致假设检索失败或问题选择受限；UMLS 和临床指南的关系并非完整。
- **Oracle 模拟答案**：澄清答案由模拟 oracle 从完整病例中提供，现实中患者可能误解问题、给出不确定/不完整答案或使用非标准术语。
- **仅评估两个任务和五个模型**：泛化到其他临床领域、人群或部署场景需谨慎推断。
- **动态/纵向上下文未覆盖**：当前框架仅获取患者可主动陈述的稳定属性（诊断、用药、过敏等），无法获取 hydration status、sleep、physical activity 等动态变量，也未整合电子健康记录等纵向数据。
- **不确定性分析仅2个探针**：重复采样实验仅覆盖了两个诊断查询和两个饮食查询，无法代表整个评估分布的不确定性特征。

## 研究启发与可借鉴点
1. **上下文获取与生成解耦**：将"获取缺失信息"与"生成最终回答"分离，由确定性控制器基于知识图谱做结构化决策，LLM 仅负责语义映射与表述，这种设计可迁移到医疗、法律、金融等高风险问答场景。
2. **基于期望信息增益的主动澄清策略**：用 Shannon 熵衡量假设分布的不确定性，以最大化预期信息增益为目标选择问题，是一种通用且可复用的多轮澄清决策框架，不限于医疗领域。
3. **知识图谱作为假设约束器而非生成器**：图谱仅限定假设空间和候选问题，不生成最终回答；这一设计使系统行为更可解释、可审计，同时避免了 LLM 幻觉对澄清流程的污染。
4. **Ambiguity Injection Module (AIM)**：论文附录提供的 AIM 工具可通过规则遮蔽、词汇泛化、LLM persona 重写等方式自动生成 underspecified 查询对，可用于构建面向消歧训练/评测的数据集，值得借鉴于其他领域的模糊性研究。
5. **跨模型一致性作为评估维度**：将"不同下游模型之间的性能方差"纳入评估，揭示澄清对下游模型选择的鲁棒性增益，为系统评估提供了超越单一准确率的新视角。

## 关键术语表
- **患者上下文歧义（Patient-context ambiguity）**：查询本身语义清晰但缺少患者特定健康信息（症状、用药、过敏等），导致多个回答均合理但均无充分依据的歧义类型。
- **知识图谱引导的消歧（KG-guided ambiguity mitigation）**：利用结构化领域知识图谱构建候选假设集，并通过确定性算法选择最具区分力的澄清问题。
- **期望信息增益（Expected information gain）**：以香农熵减量衡量某个澄清变量对降低假设不确定性的预期贡献，作为问题选择的最优标准。
- **Rephrase-and-Respond（RAR）**：先将模糊查询重述为更清晰的表述再回答，但不获取任何新信息的基线方法。
- **Matthews 相关系数（MCC）**：综合考虑 TP/TN/FP/FN 的二分类评估指标，适合类别不平衡场景，本文饮食安全任务的主要评估度量。
- **预测熵（Predictive entropy）**：对重复生成输出的多样性度量，熵越低表示模型输出越一致，但不等于输出正确。
- **Synthea**：开源的合成电子健康记录生成器，基于流行病学模型生成虚拟患者记录，本文用于构建受控的诊断基准。
- **Ambiguity Injection Module（AIM）**：将完整查询转换为 underspecified 版本的自动化工具，通过遮蔽、泛化、LLM重写等手段生成消歧评测数据。

## 可复现要素
- **数据集**：诊断基准（Synthea 合成记录，1,034 实例，未在公开数据集上）；饮食安全基准（487 实例，作者构建，未在公开数据集上）。论文声明"frozen benchmark inputs and row-level predictions will be made available with the peer-review release"。
- **代码**：论文声明"Source code for constructing the knowledge graphs, running the ambiguity experiments and reproducing the reported metrics will be available in the versioned project release"，包含 pinned Python environment、SHA-256 manifests 和 offline reproduction command。
- **模型**：无微调；底层澄清模型为 GPT-5.5（OpenAI API），下游模型面板：GPT-5.5、Claude Opus 4.8、Gemini 3.1 Pro、LLaMA 3.3 70B、Mistral Large。商业模型调用无法 byte-for-byte 复现，但提供冻结输出供离线验证。
- **关键超参**：诊断任务最多 5 轮澄清；后验概率阈值 0.95；假设扩展最多 3 个额外术语；知识图谱节点数：DxSxKG 共约 47 万个节点/关系，FoodSafetyKG 约 2,085 万食物节点 + 2,700 万关系。
