# 论文速读：How Output Format Confounds Data Quality and Capability in Instruction Tuning

## 一句话总结
本文系统揭示了指令微调中输出接口格式如何同时混淆数据质量评估与模型能力测量：谱统计量对接口旋转不变因而无法识别语义损坏，而模型学到的技能被"锁入"训练接口，更换评估格式可使微调在GSM8K上的效应从正增益翻转为大幅损失。

## 研究问题与动机
- **双重判断依赖同一输出接口**：指令微调依赖两个核心判断——选哪些数据学习、微调是否产出了能力——两者均通过输出接口（纯答案、JSON字段、标签跨度等）测量，接口变化本身即可移动未训练基座模型在ARC-C上最高70分的准确率。
- **谱统计量质量指标存在构念效度缺陷**：新兴的基于有效秩、核范数等谱统计量的数据质量度量被证明对接口旋转不变（Theorem 1），理论上无法分离仅通过接口交互项差异的内容，实证上在清洁vs语义损坏分类中落在[0.35, 0.65]盲区。
- **能力测量受接口与评估协议双重制约**：跨接口迁移实验显示，同一技能在不同接口下准确率差异可达40+分；单次生成预算修正即可翻转GSM8K微调效应的符号，表明报告的"能力增益"可能属于协议而非模型。

## 核心贡献（创新点）
1. **提出接口条件梯度签名的生成模型与谱盲定理**：将归一化梯度签名分解为共享方向、内容成分、接口偏移与接口-内容交互四部分，严格证明任何仅依赖奇异值谱的泛函对正交接口旋转不变，奠定谱度量无效的数学基础。
2. **证明接口残差携带目标特定语义结构**：在三个模型族（Qwen3.5-4B/9B、Mistral-7B）上，共识去中心化后的残差对齐以1.00命中率将每个清洁样本指向其目标任务，拒绝"异方差噪声"解释，确立交互项Γ的实际存在。
3. **构建跨架构能力锁入图谱与协议审计**：展示技能按训练接口存储、跨格式迁移率近零的现象，并揭示单点评估预算（192 vs 768 token）可翻转GSM8K微调效应符号（从+13分到−58分），质疑当前评测报告的可信度。
4. **提供预注册的否定边界划定**：预注册干预表明移除接口子空间无法因果解锁跨接口迁移，预训练几何也无法预测锁定位置，明确标出梯度几何作为诊断工具的有效范围上限。

## 方法详解
- **梯度签名建模**：对低秩适配器在指令单元x与接口k下的累加梯度取方向 $u_k(x) = g_k(x)/\|g_k(x)\|$，建模为 $u_k(x) \propto g_0 + s(x) + \delta_k + \Gamma_k(x) + \varepsilon_k$，满足 $\sum_k \Gamma_k(x) \approx 0$ 的零和约束。
- **共识与残差**：跨接口平均得共识方向 $\hat{g}_{sem}(x)$，接口敏感性 $S(x) = 1 - \|m(x)\|$ 度量接口旋转幅度；去中心化残差 $r_k(x) = u_k(x) - m(x)$ 捕获接口-内容交互。
- **残差对齐RA**：通过Frobenius内积比较两单元的接口变化结构 $\mathrm{RA}(x,t) = \langle R(x), R(t) \rangle_F / (\|R(x)\|_F \|R(t)\|_F)$，在纯加法接口假设下退化为常数，非退化即证 $\Gamma_k$ 携带内容。
- **能力锁入指数**：$\mathrm{Lock}_T(j) = 1 - \mathrm{mean}_{k \neq j} \Delta_T(j \to k) / \max(\Delta_T(j \to j), \epsilon)$，对角增益≥10分且跨接口转移比<0.2即判定为锁定。
- **谱盲定理（Theorem 1）**：接口变化近似为 $G \mapsto c_k R_k G Q_k^\top$，任何仅依赖奇异值谱的泛函满足 $\varphi(c_k R_k G Q_k^\top) = \varphi(c_k G)$，正交因子被消去，仅保留尺度 $c_k$，故有效秩与核范数对接口旋转不变。
- **预注册因果干预**：将LoRA-B更新投影到接口偏移子空间 $\{\delta_k\}$ 的正交补上（rank-3，全层应用），以+5分为Go阈值检验是否能解锁跨接口迁移，操纵检查确认移除6.5%更新能量但行为无变化。

## 实验与结果
- **数据集与任务**：12个分类与多项选择任务（sst2、yelp、rte、qnli、boolq、copa、piqa、hellaswag、winogrande、arc_challenge、commonsense_qa、ag_news），覆盖情感、NLI、QA与常识推理；4种训练接口（plain、raw span、JSON、task tag）+2种持有接口（natural、bracket）。
- **模型族**：Qwen3.5-4B、Qwen3.5-9B、Mistral-7B-v0.3，均使用rank-8 LoRA适配器，从o_proj与down_proj的lora_B因子提取64组参数梯度。
- **谱盲实证**：有效秩与核范数在三个模型族上AUC均在[0.35, 0.65]盲区内（4B: 0.415/0.468；9B: 0.545/0.517；Mistral: 0.588/0.399）；残差对齐在4B达0.789，Mistral达0.670，9B为0.579（落入盲区边缘）。
- **残差特异性**：清洁样本的own-target argmax命中率在三个架构上均为1.00（chance ≈ 0.083，permutation p < 10⁻⁴），最强可迁移正向结果。
- **能力锁入**：跨4张地图共找到14-24个对角增益≥10分的单元格，其中5-7个完全锁定；qnli/raw在所有四张地图中均锁定（跨越3架构、2 seed）；rte/raw在3/4张地图锁定。
- **接口门控效应**：COPA在raw接口训练提升43分而plain接口仅4分；ARC在raw接口提升66分而JSON接口反降1.3分。
- **评估预算翻转**：GSM8K在192 token预算下9B微调显示+13分增益（1.0→14.0），修正至768 token后变为−9.5分（24.0→14.5），4B模型更从78.0降至19.5（−58.5分）；原因系基座模型长推理被截断， tuned模型提前EOS终止不受影响。
- **干预失败**：移除rank-3接口子空间后rte|raw仅+0.25分（CI [−2.65, 2.65]）、qnli|raw仅+1.05分（CI [0.0, 2.75]），远低于+5分阈值。

## 相关工作脉络
- **LESS及梯度相似性数据选择**（Xia et al., 2024; Zhao et al., 2025; Yao et al., 2026; Min et al., 2026; Li et al., 2025）：本文形式化将梯度拆分为共享/内容/接口三部分，检验已有方法利用的相似性信号追踪的是内容还是输出表面。
- **谱统一质量度量**（Li et al., 2026）：以有效秩统一数据质量信号，本文审计其构念效度，证明任何谱泛函对接口旋转不变，单标量谱度量无法分离仅通过交互项差异的内容。
- **输出格式敏感性**（Sclar et al., 2024; Do et al., 2025）：已有工作发现等价格式可在推理时移动few-shot准确率最高76分，本文将其分析移至训练数据与梯度层面，分离接口偏移δ与交互Γ。
- **数据估值与可识别性**（Ghorbani & Zou, 2019; Ilyas et al., 2022; Bilodeau et al., 2024）：争议单标量是否足以衡量数据价值，本文类比指出内容仅可识别到 nuisance 变换等价类，接口即为此类变换。
- **概念擦除**（Ravfogel et al., 2020, 2022; Belrose et al., 2023）：本文尝试将同一子空间投影操作从表征空间移至训练更新空间，但预注册结果为空。
- **格式专用适配**（Wang et al., 2024; Ramé et al., 2022）：格式专项微调与跨环境梯度统计为最接近的前作，但均未形式化输出接口为同时塑造质量测量与能力测量的混淆轴。

## 局限性与未来方向
- 实验仅限分类与短程推理任务及低秩适配器，扩展至长程生成与全参数微调尚未进行。
- 语义损坏家族虽含模型生成 paraphrase 与自然 dirty pool，仍无法覆盖真实数据损坏的全部方式。
- 计算资源限制使研究止步于十亿参以下三个模型族，更大规模可能改变效应幅度但方向可能不变。
- 预注册干预（移除接口子空间）失败表明锁定机制位于 LoRA-B 池级接口子空间之外，定位锁入存储位置仍是开放问题。
- 方向性度量（残差对齐）在自然 dirty pool 上外推失败（AUC 0.56），需发展更 robust 的开放质量度量。

## 研究启发与可借鉴点
- **多接口梯度签名设计**：对同一内容构建4种接口表达并计算跨接口共识与残差，可作为标准诊断协议验证新数据选择方法是否真正读取语义而非包装。
- **残差对齐作为新质量信号**：RA指标在构造损坏轴上优于谱统计量，未来可探索将其嵌入LESS类选择器以提升跨格式鲁棒性。
- **评估协议审计标准化**：单点预算修正翻转效应的发现提示GSM8K等推理任务评测需报告多预算曲线，避免截断偏差伪装为能力增益。
- **接口锁入可作为正则化目标**：若锁定反映接口特定过拟合，可在训练中引入跨接口一致性正则（如约束不同接口的残差方向相近）以增强泛化。
- **预注册因果干预框架**：本文在方法设计前冻结Go阈值与决策规则，将"干预失败"作为边界贡献而非负面结果，为可重复性研究提供方法论示范。

## 关键术语表
- **Gradient Signature（梯度签名）**：归一化的低秩适配器单步梯度方向向量，编码数据将使模型参数朝哪个方向移动。
- **Interface（接口）**：同一语义内容的表面输出格式，如纯文本答案、JSON字段、标签跨度等，本文设K=4种训练接口+2种持有接口。
- **Residual Alignment（残差对齐 RA）**：去除跨接口共识后的残差向量间的Frobenius内积相似度，度量接口变化结构的配对特异性。
- **Capability Lock-in（能力锁入）**：技能仅在被训练的接口格式下可读出、跨格式迁移率近零的现象，用Lock指数量化。
- **Spectral Blindness（谱盲）**：定理保证的有效秩、核范数等谱泛函对接口正交旋转不变，无法分离仅通过交互项差异的内容。
- **Semantic Selectivity（语义选择性）**：质量度量区分清洁数据与纯语义损坏数据的AUC，定义为 $\operatorname{sel}(M) = \operatorname{AUC}(\text{clean vs. semantic-corrupt}; M)$。
- **Consensus Direction（共识方向）**：跨所有接口梯度的平均并归一化，理论上抵消接口偏移δ与交互Γ的零和项，保留共享与内容成分。
- **Bridge Score（桥接分数）**：结合接口子空间能量与交互耦合的预测分数，预注册用于预测哪些任务-接口组合将发生锁定，实证预测失败。
