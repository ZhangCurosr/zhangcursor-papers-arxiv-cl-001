# 论文速读：CoMerge: Conflict-Driven Preference Optimization for Multi-Task Model Merging

## 一句话总结
CoMerge 将多任务模型合并重构为自监督偏好优化问题，利用朴素合并（Task Arithmetic）输出的缺陷作为硬负样本构建偏好对，通过优化张量级合并系数显式缓解参数干扰；在 MergeBench 上取得平均归一化性能 0.9968，超越所有数据自由与数据驱动基线，并在指令跟随、安全等冲突敏感任务上显著提升。

## 研究问题与动机
1. **参数干扰导致合并性能下降**：直接将多个专家模型的任务向量相加聚合时，不同任务在共享参数坐标上可能产生冲突方向，引起性能退化。
2. **现有方法缺乏行为级负反馈**：数据自由方法（如 TIES-Merging、DARE）依赖静态启发式规则，数据驱动方法（如 AdaMerging、RegMean）虽通过校准数据集优化系数，但未直接利用朴素合并输出的失败模式作为负信号。
3. **外部标注成本高**：依赖人工偏好标注或外部奖励模型构建偏好对，在实际多任务合并场景中难以获得。
4. **需要兼顾效率与细粒度控制**：全参数微调可达到较高性能，但计算开销巨大；需在参数空间显式合并与轻量优化之间取得平衡。

## 核心贡献（创新点）
1. **框架创新**：提出 CoMerge，将模型合并形式化为自监督偏好优化问题，通过冲突驱动的负样本合成显式缓解参数干扰，与现有方法仅依赖正样本或静态规则形成本质区别。
2. **负样本构建策略**：利用朴素 Task Arithmetic 合并输出的缺陷（如幻觉、逻辑不一致、风格错配）作为硬负样本，无需任何人工标注或外部奖励模型，自动构造偏好对。
3. **参数高效张量级优化**：引入每任务‑每可合并张量独立的可学习系数 Λ，仅优化 1,445 个标量系数即可达到接近 Full‑DPO 的性能，大幅降低计算资源需求。
4. **全面实验验证**：在 MergeBench（12 个数据集、5 类能力）上取得平均归一化性能 0.9968，超越所有基线；在指令跟随、安全等冲突敏感任务上提升显著，并在多架构、多规模模型上验证泛化性。

## 方法详解
- **任务向量提取与压缩**：对每个专家模型的任务向量 τ_i = θ^i_ft − θ_pre，先进行全局幅度剪枝（保留绝对值最大的 10% 参数），再对投影矩阵选择性应用低秩 SVD 近似（目标秩 k_max = 1500，当因子化后存储量小于原矩阵时执行），得到预处理后的任务向量 τ̂_i。
- **自监督偏好对合成**：给定输入 x，以专家模型输出 y_w ∼ π_θ^i_ft(·|x) 作为正样本（chosen），以朴素 Task Arithmetic 模型（固定缩放系数 α = 0.4）的输出 y_l 作为负样本（rejected），构建偏好对 (x, y_w, y_l)，形成数据集 D_pref = {(x, y_w, y_l)}。
- **张量级合并参数化**：合并后参数定义为 θ_{Λ,p} = θ_{pre,p} + Σ_i λ_{p,i}·τ̂_{i,p}，其中 p 遍历所有可合并张量（注意力、MLP、归一化层），λ_{p,i} 为待学习的标量系数，初始值设为 0.4。
- **偏好优化损失**：采用 DPO 损失，以初始合并模型作为固定参考策略 π_ref：
  L_pref(Λ) = −E_{(x,y_w,y_l)~D_pref}[log σ(β log(π_θΛ(y_w|x)/π_ref(y_w|x)) − β log(π_θΛ(y_l|x)/π_ref(y_l|x)))].
- **训练细节**：使用 AdamW 优化，学习率 1e‑2，β = 0.1，λ_init = 0.4，有效 batch size = 16，训练 280 步；偏好数据由每个专家训练集随机采样 1k 样本生成。

## 实验与结果
- **数据集与基准**：基于 MergeBench 协议，在 Llama‑3.1‑8B‑Instruct、Llama‑3.2‑3B‑Instruct、Gemma‑2‑2b‑it 三个模型上评估，涵盖 12 个数据集（指令跟随 IFEval、数学 GSM8K & MATH、多语言 M‑MMLU/M‑ARC/M‑HellaSwag、编码 HumanEval+ & MBPP+、安全 WildGuardTest/HarmBench/DoAnything‑Now/XSTest）。
- **对比基线**：数据自由方法（Model Soup、Task Arithmetic、TIES‑Merging、DARE、Dataless Localize‑and‑Stitch）与数据驱动方法（RegMean、RegMean++、Localize‑and‑Stitch、AdaMerging (Gen.)）。
- **主结果**：CoMerge 在 Llama‑3.1‑8B‑Instruct 上平均归一化性能（Avg. NP）达 **0.9968**，超过最强数据自由方法 Task Arithmetic（0.9538，+0.0430）与最佳数据驱动方法 AdaMerging (Gen.)（0.9788，+0.0180）。指令跟随（0.9952 vs 0.8687）与安全性（1.0340）提升尤为显著。
- **跨模型泛化**：在 Llama‑3.2‑3B‑Instruct 上获得 0.9699 ± 0.0032，超过所有种子下的 Dataless L&S（0.9649）；在 Gemma‑2‑2b‑it 上获得 0.9321 ± 0.0014，与 RegMean++（0.9324）相当。
- **计算效率**：CoMerge 仅优化 1,445 个系数，在单张 NVIDIA H20 GPU 上耗时 38.3 GPU‑分钟；Full‑DPO 需 4 张 H20 共 95.9 GPU‑分钟，资源节约 **60.1%**，而性能仅相差 0.0015（0.9983 vs 0.9968）。

## 相关工作脉络
1. **数据自由合并**（TIES‑Merging、DARE、DELLA）：通过符号解析、随机剪枝或幅度采样缓解冲突，属静态规则；CoMerge 动态学习系数并利用行为负反馈，灵活性更强。
2. **数据驱动合并**（AdaMerging、Localize‑and‑Stitch、RegMean/++）：依赖校准数据集优化系数或掩码；CoMerge 无需外部标签，直接以朴素合并缺陷为负样本，降低数据依赖。
3. **偏好优化用于模型融合**（WRPO、InfiFPO）：通过输出/分布对齐隐式蒸馏，常需外部奖励模型；CoMerge 将 PO 应用于显式参数空间合并，且完全自监督。
4. **Task Arithmetic**：作为基础合并范式的线性求和，CoMerge 在其输出缺陷上构造负样本，针对性地修正参数冲突。
5. **Full‑parameter fine‑tuning**（Full‑DPO）：达到更高上限但计算昂贵；CoMerge 证明轻量化系数优化可逼近全参数微调，提供高效替代方案。

## 局限性与未来方向
- **标签噪声风险**：假设专家输出总是优于朴素合并输出并不绝对成立，个别样本可能存在专家错误而合并输出仍可接受，引入噪声弱化偏好信号。
- **超参数固定**：剪枝比例（10%）、SVD 最大秩（1500）、初始缩放系数（α = 0.4）在所有 backbone 上统一设定，未经系统敏感性分析。
- **负样本构造单一**：仅使用 Task Arithmetic 作为负样本来源，未探索迭代生成、软权重或其他冲突特定裁判。
- **未来方向**：开发冲突特异性裁判或置信度加权机制；系统性研究剪枝、秩、缩放超参数；探索迭代偏好数据混合策略；结合更先进的任务向量稀疏化技术。

## 研究启发与可借鉴点
1. **自监督负样本合成思路**：利用基线方法的内在缺陷自动生成硬负样本，避免昂贵的人工标注，可迁移至模型压缩、蒸馏、微调等需要对比信号的场景。
2. **张量级细粒度系数优化**：将全局/任务级系数推广至张量级，提升合并过程的表达力与冲突分辨能力，同时保持参数量极低，适合高效适配多任务场景。
3. **偏好优化在显式合并中的应用**：将 DPO 等偏好优化范式从输出对齐延伸至参数空间合并，为模型集成提供新的理论视角与实用工具。
4. **冲突敏感任务评估设计**：在安全性、指令跟随等对参数干扰高度敏感的维度上验证方法有效性，为合并研究提供更全面的评测基准。
5. **资源效率量化对比**：通过 GPU‑minutes 与可训练参数数量直观展示轻量化优势，为后续工作提供可复用的效率评估范式。

## 关键术语表
- **CoMerge**：冲突驱动的偏好优化框架，通过将模型合并重构为自监督偏好学习任务来缓解参数干扰。
- **Task Arithmetic**：基于任务向量（微调后参数减去预训练参数）线性组合实现模型合并的基础方法。
- **Preference Optimization**：利用正负样本对直接优化模型策略的学习范式，如 DPO，无需显式奖励模型。
- **Normalized Performance (NP)**：合并模型性能相对于各专家模型性能的归一化比值，1.0 表示完美保留。
- **Parameter Interference**：不同任务向量在共享参数坐标上产生冲突更新，导致合并后性能下降的现象。
- **Tensor‑wise Coefficients**：为每个可合并张量独立学习的标量系数，实现细粒度的任务贡献控制。
