# 论文速读：NS-Copilot-An-LLM-Driven-Agent-System-for-Autonomous-Neurosc

## 一句话总结
论文提出了NS-Copilot，一个基于LLM的多智能体系统，仅需原始神经数据与自然语言任务描述即可自动完成端到端神经科学分析；通过统一编排9个跨EEG与胞外尖峰模态的预训练基础模型，并结合自动化模型选择与闭环优化机制，在阿尔茨海默病、帕金森病与工作记忆解码基准上均显著超越现有强基线。

## 研究问题与动机
1. **原始数据与模型输入的接口鸿沟**：现有预训练神经模型对采样率、通道布局、张量形状等有严格且异构的约束，非专家用户难以将原始记录适配到目标模型。
2. **跨任务的最优模型选择难题**：无单一架构能通吃所有数据条件（模态、通道数、记录范式、分类目标）；通用AutoML系统未覆盖领域专用预训练模型，现有EEG基准仍需手动逐模型配参。
3. **执行结果的自适应工作流优化缺失**：即便数据格式正确、模型选定，超参错配或特征工程不当仍会导致次优结果；现有自修复方法仅处理语法/运行时错误，缺乏基于执行指标的根因诊断与策略级路由能力。
4. **学科交叉壁垒导致潜力未释放**：神经科学实验室普遍缺乏AI工程能力，而现有科学Agent多依赖通用代码生成或单一模态工具链，无法灵活调度异构预训练神经模型。

## 核心贡献（创新点）
1. **统一预训练模型编排框架**：首次将9个跨EEG与 spike 模态的领域预训练模型接入单一自然语言接口，实现无需数据集特定启发式规则的端到端自动化分析。*与已有工作的本质区别在于将异构模型抽象为无状态前向推理端点，并通过声明式工具规格彻底屏蔽底层架构差异。*
2. **自动化模型选择协议（Auto Model Selection）**：Planner根据数据集元数据动态确定主评估指标，构建优先级候选队列，并引入独立参考分数作为性能阈值以实现早停。*区别于通用AutoML仅搜索传统ML模型，本文直接针对领域预训练基础模型进行特征对齐与动态排序。*
3. **闭环诊断与显式 Modify-vs-Replan 路由**：Controller基于执行指标进行深度语义调试，明确区分局部算法调整（Modify，由Coder打补丁）与方法论根本缺陷（Replan，由Planner重新生成策略）两种优化路径。*突破了现有LLM自修复仅处理代码级错误的能力边界，首次在神经数据分析闭环中采用策略路由机制。*
4. **多范式基准的系统性验证**：在AD、PD和WM三个跨疾病/跨模态基准上完成评估，主指标均超越全部基线；消融证实性能增益主要来自预训练模型的特征迁移与闭环择优，而非编排本身。

## 方法详解
- **整体架构**：由四个LLM智能体协同驱动：Planner（规划）、Coder（代码生成）、Controller（闭环优化）、Interpreter（结果解释）。输入为原始数据+自然语言提示；输出为综合分析报告。
- **Planner**：解析数据集配置文件（模态、通道数、采样率、类别分布），自动选定主指标（如不平衡数据用Balanced Accuracy，多分类用Macro F1）。独立LLM编程代理（GPT-5.2-Codex）生成参考性能阈值，Planner本身不感知该分数以消除指标选择偏差。为队列中每个候选模型生成JSON格式的分析计划。
- **Coder**：接收分析计划与工具规格（Tool Specification，声明各模型支持的模态、通道数、目标采样率等约束），自动生成完整Python脚本：读取原始文件→预处理（重采样/通道过滤）→调用模型前向推理提取特征→构建下游分类器→评估。代码在Docker沙箱中执行，单次限制300s，超时记为失败并计入零分。
- **Controller**：若初始队列所有模型未达阈值，激活闭环优化。重新排列搜索队列（提升潜力模型优先级），接收完整执行轨迹（代码、指标、历史计划、元数据、原始提示），诊断性能异常（如准确率趋近随机、类别召回严重失衡）。根据诊断显式路由：
  - **Modify模式**：高层逻辑合理但需局部调整（更换分类器、调正则化、改特征窗口），绕过Planner，直接将补丁指令传给Coder。
  - **Replan模式**：方法论存在根本缺陷（如特征提取范式完全不适用），将反馈回Planner从头合成新策略。
  默认最多2轮重试，每轮一旦达标即触发早停。
- **Interpreter**：接收最终执行结果（Accuracy、Balanced Accuracy、Macro F1、AUROC、逐类Recall、混淆矩阵、可视化），生成包含指标解读、关键发现、局限性与后续建议的综合报告。

## 实验与结果
- **数据集**：AD EEG (OpenNeuro ds004504, 88受试者, 19通道10-20, 3分类 AD/FTD/Healthy), PD EEG (OpenNeuro ds004584, 149受试者, 64通道10-10, 2分类), WM Spikes (DANDI 000006, 79单元, 256次试验, 左右舔液二进制解码)。
- **基线**：AutoML-Agent, LAMBDA, AutoGen, SciAgents, Claude-Sonnet-4.5, GPT-5.2-Codex。
- **主要结果（8次独立试验均值±std）**：
  - **AD EEG (Macro F1)**：NS-Copilot **57.16±5.71%** vs 最强基线Codex 51.01±2.52%，提升约+6.15pp。
  - **PD EEG (Bal. Acc.)**：NS-Copilot **71.32±2.97%** vs Codex 65.52±7.98%，提升约+5.80pp。
  - **WM Spikes (Bal. Acc.)**：NS-Copilot **74.43±3.18%** vs Codex 72.58±1.68%，提升约+1.85pp。
- **最强结果与提升幅度**：在三个基准的主指标上均夺冠。AD任务提升最大（较Codex +6.15pp，较Vanilla初轮 +7.36pp）。
- **消融结论**：Controller的Value主要在于“保留每轮最优结果”而非强制探索（平均 ∆(returned) = +3.80pp， ∆(exploration) = -0.11pp）。预训练模型相比手工特征（Vanilla）在AD上带来+13.34pp收益，在WM上带来+6.82pp收益，证实领域知识迁移的核心价值。
