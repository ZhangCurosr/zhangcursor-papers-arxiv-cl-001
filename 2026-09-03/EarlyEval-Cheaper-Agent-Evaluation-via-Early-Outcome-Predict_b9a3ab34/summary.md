# 论文速读：EarlyEval-Cheaper-Agent-Evaluation-via-Early-Outcome-Predict

## 一句话总结
本文提出 **EarlyEval**，一种基于早期结果预测的 Agent 评测加速框架。其核心洞察是：智能体的最终成败往往在轨迹中途就已隐含于行为模式中，通过训练成功/失败双分类器实时监测，可在保证榜单保真度的前提下提前终止冗余执行步骤，显著降低单任务评测成本。

## 研究问题与动机
- **评测经济账不可持续**：前沿模型在复杂 Agent Benchmark（如 SWE-bench Verified）上单轮评测成本已达数百至数千美元，且随迭代调参循环被反复支付，形成资源壁垒。
- **既有降本路径存在盲区**：主流工作集中于 Benchmark Distillation（缩减任务数量），但已保留任务的单次执行开销丝毫未减，缺乏“任务内”维度的效率优化。
- **早期可预测性具备客观基础**：智能体轨迹常在自然结束前已暴露确定信号（如已写入正确修复代码、或陷入对相同报错的重复重试），提前判定最终结果具备可行性。
- **缺少系统化早停评测方法**：Agent 领域尚无针对第三方批量评测场景的轨迹早停框架，亟需探索如何在执行过程中安全“截断”以换取算力节省。

## 核心贡献（创新点）
1. **提出 Early Outcome Prediction 新范式**。与 Benchmark Distillation 仅削减任务数量的思路本质不同，本文从单次任务内部执行轨迹维度切入，通过中途早停直接压缩计算开销，与既有工作形成互补轴。
2. **设计 EarlyEval 双分类器轻量框架**。区别于 LLM-as-Judge 等高延迟方案，本文采用 LightGBM 树集成配合 Platt 概率校准与双阈值门控，实现亚毫秒级步态推理，彻底消除预测器自身的计算负担。
3. **构建三维多模态轨迹特征体系**。突破单一文本或日志特征的局限，系统融合行为动力学、自然语言上下文与参考解结构重叠度，在保留高预测精度的同时支持无参考解场景的平滑降级。
4. **建立严格防泄漏的跨基准评测协议**。采用 Leave-One-Agent-Out 并拆解模型/脚手架维度的隔离设置，首次系统量化了早停判定对榜单排名保真度与解决率偏差的影响边界。

## 方法详解
- **问题定义**：给定智能体 $A$ 在任务 $t$ 上的部分轨迹 $\tau_{:k} = (e_1, \dots, e_k)$，预测最终二值结果 $y \in \{0,1\}$；若置信度达标则早停并记录预测值，否则继续执行至自然结束。
- **特征工程 $\phi(\tau_{:k}) \in \mathbb{R}^d$**（三大族）：
  - *Behavioral Features*：累计活动计数（37）、最近一步属性（11）、关键事件时序（18）、工作模式/停滞信号（32）、错误与测试状态流（17）。
  - *Textual Features*：任务 Prompt（64维 SVD）、完整/最近 Action 文本（各128维 SVD）、环境 Feedback 文本（各128维 SVD），独立分块向量化保留语义边界。
  - *Reference-Solution Features*（仅含 Gold Patch 的 Benchmark）：补丁元信息（28）与前缀-黄金解结构重叠度（54，Jaccard/命中数）。
- **双预测器架构**：分别训练成功预测器 $h_+$ 与失败预测器 $h_-$，共享同一特征输入但目标标签取反（$y=1$ vs $y=0$），使正负证据独立积累，并显式保留“双方置信度均低”的 Continue 区间。
- **概率校准与决策规则**：原始树模型输出经 Platt scaling 映射为校准概率 $p_+, p_-$；预设成功阈值 $s$ 与失败阈值 $f$，首步满足 $p_+ \geq s$ 或 $p_- \geq f$ 时触发早停，同时触发时按首次跨越时间优先。
- **训练规范**：按 Task 划分训练/验证集防泄漏；轨迹内所有前缀严格归属同侧；前缀样本权重设为 $1/(T+1)$ 消除长轨迹主导；LightGBM 超参固定（lr=0.03, leaves=31, max_depth=6, subsample=0.75/0.70, reg=0.5/10.0）。
