## Abstract

Pruned language models are judged almost entirely by accuracy and perplexity, which assumes that preserved output behaviour implies preserved internal computation. We test this assumption with a factorial pruning study on GPT-2, crossing two importance criteria (magnitude, random), two component types (attention heads, MLP neurons) and three sparsity levels (30%, 50%, 70%). Using the fully characterised indirect object identification (IOI) circuit as ground truth, we measure circuit integrity with activation patching, path patching and direct logit attribution. We find two qualitatively distinct failure modes. Magnitude head pruning (≥50%) zeroes the circuit: outputfacing heads are removed, and the model falls to near-chance. Magnitude neuron pruning at 30% inverts it: all 26 circuit heads remain intact, but Name Mover contributions flip sign, and the model systematically prefers the wrong name (17.7% accuracy). Perplexity ranks it as less damaged than random head pruning (74.6 vs 140.1). A replication of the Greater-Than circuit shows that the critical component type depends on the circuit’s architecture. These results show that output metrics and structural checks can both miss mechanistic damage, motivating circuit-level causal analysis as a complementary evaluation of compressed language models.

## 1 Introduction

Compression is now a default step in the language model deployment pipeline: pruning, quantisation, and distillation are routinely applied to reduce memory footprint and inference cost, often as a black-box post-processing stage after training (Ding et al., 2023; Bai et al., 2024). Because these methods are judged almost entirely by their effect on downstream benchmarks, accuracy and perplexity, they are treated as behaviourally neutral whenever those numbers hold up. This paper asks whether that judgment is safe to make. The concern is not merely academic. A model can produce a correct answer for the wrong reason, and the pathways that mechanistic interpretability has isolated in unpruned models, such as the IOI circuit (Wang et al., 2022), give a concrete setting in which "correct reason" can actually be checked, rather than assumed. If pruning is capable of severing or inverting the specific components responsible for a behaviour while leaving redundant computation to paper over the loss at the output layer, then accuracy-based compression audits are measuring the wrong thing, and models cleared for deployment on that basis may carry mechanistic damage that only surfaces under distribution shift, adversarial input, or further fine-tuning. This risk is what our factorial pruning study is designed to expose. Rather than treating pruning as a single method to be validated once, we vary both what is removed (attention heads vs. MLP neurons) and how it is selected (magnitudebased vs. random), across a range of sparsities, and ask whether these choices leave distinguishable fingerprints on a well-characterised circuit’s internal structure, independent of whatever the accuracy metric reports.

Our contributions are twofold. First, we identify two qualitatively distinct mechanistic failure modes of structured pruning in Transformer language models: circuit zeroing and circuit inversion. We show that MLP-neuron pruning can invert an otherwise structurally intact circuit, transforming a functioning circuit into an actively misleading circuit that produces systematic rather than random errors. Second, we demonstrate that standard behavioural and structural pruning evaluations can miss such mechanistic failures: for example, perplexity may rank an inverted model as less damaged, while checking whether circuit components remain present can falsely suggest that the circuit is intact. Our results therefore motivate circuit-level causal analysis as a complementary evaluation of compressed language models.

In the following sections, we review related work, outline our experimental setup, present our results, and conclude with a discussion and conclusion.

## 2 Background and Related Work

## 2.1 Mechanistic Interpretability and Circuit Analysis

Mechanistic interpretability reverse-engineers neural networks by identifying circuits, interpretable components that implement human-understandable algorithms (Bereska and Gavves, 2024; Cammarata et al., 2020). In transformers, circuit analysis decomposes the residual stream into attention-head and MLP contributions, then uses causal interventions to test which are necessary and sufficient for a behaviour (Wang et al., 2022; Meng et al., 2022; Geiger et al., 2021). The Indirect Object Identification (IOI) task requires completing sentences such as “When Mary and John went to the store, John gave a drink $t o \_ ,$ with the indirect object (IO, Mary) rather than the subject (S, John). Wang et al. (2022) identified a 26-head circuit in GPT-2: Previous Token (PT) heads copy token positions; Duplicate Token (DT) and Induction (IND) heads detect repeated names; S-Inhibition (S-INH) heads suppress the subject; Name Mover (NM) heads copy the IO to the output; Negative Name Mover (NNM) heads suppress the IO signal as a self-correcting brake; and Backup Name Mover (BNM) heads compensate when NM heads fail. This gives a well-characterised ground truth against which compression-induced changes can be measured.

We use two complementary tools: activation patching, which replaces a head’s activations with those from a corrupted run to measure causal necessity, and Direct Logit Attribution (DLA), a noninterventional decomposition of the logit difference into per-head contributions that measures direct contribution (Goldowsky-Dill et al., 2023; Wang et al., 2022).

## 2.2 Weight Pruning

Pruning assumes that many parameters are redundant: unstructured pruning removes individual weights, while structured pruning removes entire neurons, filters, or attention heads (Ding et al., 2023; Bai et al., 2024). Magnitude-based pruning, the most widely used criterion, removes lowmagnitude weights (Han et al., 2015); random pruning serves as a controlled baseline. From an interpretability perspective, the key distinction is between attention heads, which implement relational computation across token positions, and MLP neurons, which store features, knowledge and positionsensitive representations that downstream heads depend on (Geva et al., 2021; Rai et al., 2024). This motivates our $2 \times 2$ factorial design.

## 2.3 Pruning and Circuit Integrity: Prior Work

Attribution-guided pruning (Layer-wise Relevance Propagation, Integrated Gradients, gradient-based attribution) preferentially retains task-relevant subgraphs (Hatefi et al., 2025; Chhabra and Khalili, 2025), and Attribution-based Parameter Decomposition shows that interpretable circuit components can survive substantial size reduction (Braun et al., 2024). In safety-aligned models, pruning may disproportionately erode safety-relevant circuits (Chhabra and Khalili, 2025). However, no prior work has characterised whether different pruning strategies produce qualitatively distinct circuit failures or shown that these failures are invisible to accuracy evaluation. We address both gaps.

## 3 Experimental Setup

## 3.1 Base Model

All experiments use GPT-2 (Radford et al., 2019): 117M parameters, 12 transformer layers, 12 attention heads per layer, and a hidden dimension of 768. GPT-2 is selected because it is the canonical platform for mechanistic interpretability research, with a fully characterised IOI circuit providing a groundtruth benchmark. All compressed variants are derived from a single pre-trained checkpoint with no weight updates after pruning, ensuring crossvariant comparisons are made at matched starting conditions. All experiments are implemented using TransformerLens (Nanda and Bloom, 2022), which provides hook-based access to residual stream activations, attention head outputs, and MLP intermediate states.

## 3.2 Pruning Variants

Twelve pruned variants are created by crossing two importance criteria (magnitude, random), two component types (attention heads, MLP neurons), and three sparsity levels (30%, 50%, 70%), yielding a $2 \times 2 \times 3$ factorial design.

Attention head pruning. Heads are pruned by zeroing all weight slices corresponding to a given head in the c\_attn projection matrix (Q, K, and V columns) and the corresponding rows of the c\_proj output projection. For magnitude pruning, each head is scored by the L2-norm of its Q-weight slice, and the k lowest-scoring heads across the entire model are removed. Random pruning assigns importance scores uniformly at random and removes a fixed proportion of heads per layer.

MLP neuron pruning. Neurons are pruned by zeroing the corresponding columns of the first weight matrix $( W _ { \mathrm { i n } } )$ and rows of the second weight matrix $( W _ { \mathrm { o u t } } )$ within each MLP sub-layer. For magnitude pruning, neurons are scored by the L2 norm of their $W _ { \mathrm { i n } }$ column and the lowest-scoring neurons are removed globally. Random pruning removes a uniformly sampled fraction of neurons from each layer independently.

## 3.3 Evaluation Datasets and Tasks

Sentences follow the ABB/ABC design of (Wang et al., 2022), built from 15 templates , 14 objects and 28 single-token names, and each is paired with a corrupted counterpart in which the second subject is replaced by a foil name to support activation patching. The primary metric is the mean logit difference $l d = \ell _ { \mathrm { I O } } - \ell _ { \mathrm { S } } \mathrm { : }$ the difference in logprobability between the indirect object name and the subject name at the prediction position. Positive values indicate correct IO prediction; negative values indicate the model assigns a higher probability to the subject. Circuit analysis uses activation patching across all 26 IOI circuit heads and DLA decomposed by functional class. General language modelling performance is evaluated on TinyStories (Li and Eldan, 2023) via perplexity over 1000 sequences.

## 3.4 Implementation Details

All experiments use Python 3.10 with Transformer-Lens (Nanda and Bloom, 2022) and HuggingFace Transformers (Wolf et al., 2020). LayerNorm folding is explicitly disabled (fold\_ln=False) to preserve activation scales. DLA is computed using a linear approximation of the final LayerNorm centred on the full residual stream, ensuring component contributions sum to the observed logit difference within numerical precision. Sparsity fractions are verified after TransformerLens conversion to ensure zero-valued entries are correctly propagated.

All experiments are run on an NVIDIA L4/T4 GPU (Google Colab) with fixed random seed 42.

## 4.2 Failure Mode I: Zeroing

Magnitude attention head pruning at 50% and 70% sparsity physically eliminates the output-facing heads of the IOI circuit. At 50% sparsity, DLA scores for all four major circuit classes, NM, NNM, S-INH, and BNM, fall to exactly zero (Table 2). Weight norm verification confirms that circuit heads have been physically removed: pruned circuit heads collapse to uniform attention patterns (IO\_attn = 0.067, S\_attn = 0.133). At 30% sparsity, 10 of 26 circuit heads are removed; the surviving NM heads (L9H6 and L9H9) retain partial IO-preferring attention (L9H9: IO\_attn = 0.536, S\_attn = 0.083), explaining the partial 9.2% NM retention at this sparsity. Despite the elimination of the circuit, the model retains 45.7%–47.9% IOI accuracy at 50%–70% sparsity. This residual accuracy derives from non-circuit computation: earlycircuit heads and MLP layers are not targeted by magnitude attention head pruning (which removes lower-norm output-facing heads first), and their intact language-modelling signal incidentally favours the IO token over the S token on most sentences. Zeroing is the most interpretable and, from a safety perspective, the least dangerous failure mode: the circuit has been structurally removed, the cause of degraded performance is straightforwardly attributable to physical elimination of circuit components, and the model makes near-chance predictions rather than actively misdirecting.

The result is a mean IOI logit difference of −2.475 and accuracy of 17.7%: the model is actively and confidently predicting the wrong name. The mechanism is context poisoning. Magnitude pruning preferentially removes the largest MLP neurons, which implement the position-specific representations and name-identity encodings that attention heads depend on to locate the correct indirect object. The NM heads remain functional as copying mechanisms, but the corrupted residual stream directs them to the wrong entity. Attention pattern analysis confirms this: L9H6 shows IO\_attn = 0.051, S\_attn = 0.650; L9H9 shows IO\_attn = 0.123, S\_attn = 0.600. The heads are operational but pointed at the subject. At 30% sparsity, the residual stream is corrupted enough to invert the NM signal while still providing sufficient discriminability for consistent (though wrong) predictions. At 70% sparsity, the residual stream is so broadly degraded that attention patterns lose discriminability, weakening both correct and inverted signals and moving the logit difference back towards zero. The 30% model is strongly wrong; the 70% model is weakly wrong, a pattern invisible to accuracy evaluation, which shows only modestly reduced accuracy at 30% relative to the catastrophic underlying circuit failure.

## 4.4 High-Sparsity Limit of Inversion

Random neuron pruning at 70% sparsity produces the weakest circuit signature in the study. No class shows a strong sign flip: NM (−1.2%), NNM $( - 0 . 0 \% )$ and BNM (−1.3%) are indistinguishable from zero, and S-Inhibition retains only 6.9% of its baseline contribution (Table 2). Accuracy (47.9%) and mean logit difference (−0.038) match the zeroing profile at equivalent sparsity (Table 1), but the cause differs: neuron pruning does not touch the attention heads, so the circuit is not absent; its directional signal has faded. Activation patching shows a partial exception: S-Inhibition retains a moderate causal effect $( d = 0 . 2 7 0 )$ , whereas NNM retains its paradoxical negative effect $( d = - 0 . 3 2 9 )$ . The same trajectory appears across sparsity levels, with the logit difference decreasing from −0.896 at 30% to −0.502 and −0.038 at 50% and 70%, respectively. We therefore treat this regime as the terminal, noise-dominated end of inversion, in which context corruption is so broad that both the correct and the inverted signals fade, rather than as an independent mechanism.

Perplexity does not track circuit damage. Magnitude attention head pruning has the lowest perplexity at every sparsity (23.37 at 30%, against 140.10 for random attention heads at the same sparsity), and neuron pruning is far more damaging than head pruning at matched sparsity, with magnitude neurons at 70% reaching a perplexity of 18,934. The most strongly inverted circuit, therefore, belongs to a model that a perplexity audit would rank as the less damaged of the two.

Component type and depth. Representational fidelity separates component types more sharply than selection criteria. At 70% sparsity, magnitude attention head pruning retains a CKA of 0.851, the highest of any pruned model at that sparsity, whereas magnitude neuron pruning retains only 0.500. For neuron pruning, cosine similarity (0.703) and CKA (0.500) diverge at 70%, indicating that the principal axes of variation in the MLP output space collapse while mean activation directions are partially preserved. All strategies preserve early layers (CKA ≥ 0.900 in every condition) while late-layer CKA never exceeds 0.848 and falls as low as 0.260, so the representational bottleneck under pruning is a late-layer phenomenon, which is where the IOI output-stage heads sit.

Criterion reversal for neurons. For attention heads, magnitude selection preserves more structure than random selection (CKA 0.917 against 0.817 at 50%). For neurons, the ordering reverses at low sparsity: random pruning at 30% reaches a CKA of 0.825 against 0.698 for magnitude pruning. This is consistent with the contextpoisoning account in Inversion: magnitude selection removes the highest-weight neurons, creating localised representational voids, whereas random selection spreads the damage more evenly.

## 4.6 Attention Diffusion and Sharpening

We track head-averaged attention statistics (entropy, effective support, first-token mass, and head cosine similarity to the base model; full results in Table 8.

Head pruning diffuses attention. Pruning entire heads produces systematic attention diffusion under both criteria. At 70% sparsity, entropy rises monotonically from 2.013 nats to 3.561 (magnitude) and 3.536 (random), effective support grows from 11.4 to roughly 51 tokens (a 4.5-fold increase), and first-token attention collapses from 0.421 to 0.098 (magnitude) and 0.146 (random), destroying the attention sink. This is a structural consequence of zeroing a head’s weights, which yields near-uniform softmax outputs regardless of how the head was selected, and it matches the uniform IO and S attention measured on the eliminated circuit heads (IO\_attn = 0.067, S\_attn = 0.133). Head cosine similarity falls heterogeneously $( \bar { s } = 0 . 5 2 4$ and 0.482 at 70%), reflecting damage concentrated in the removed heads.

Neuron pruning does not diffuse attention. Neuron pruning leaves attention heads untouched, and its signature is opposite or weak. Random neuron pruning sharpens attention: entropy is below base at 30% and 70% (1.638 and 1.478 nats), effective support falls to 9.25 and 7.80 tokens, and first-token attention rises to 0.521 and 0.552. The 50% condition (2.050 nats) interrupts this trend and is likely a stochastic or threshold effect. Magnitude neuron pruning produces only a mild entropy increase $( \Delta H = + 0 . 1 7 3 ~ \mathrm { t o } ~ + 0 . 3 9 4 )$ . A plausible mechanism is a compensatory collapse of the residual stream: with fewer MLP neurons, hidden states become less diverse and attention concentrates on contextually dominant positions. At matched sparsity, random neuron pruning also preserves head routing better than random head pruning (s¯ = 0.894 vs. 0.704 at 30%; 0.819 vs. 0.482 at 70%).

Implication for detection. Zeroing is visible in aggregate attention statistics, whereas the inverted model at 30% magnitude neuron pruning $( \Delta H = + 0 . 1 7 3 )$ looks comparatively intact, even though its Name Mover heads attend sharply to the wrong token (S\_attn = 0.650 for L9H6). Aggregate entropy cannot distinguish a head that attends correctly from one that attends confidently to the subject, which is why head-level causal analysis is needed.

## 4.7 Greater-Than Circuit Replication

To test whether the taxonomy is specific to IOI, we apply the same twelve pruned variants to the Greater-Than (GT) circuit of Hanna et al. (2023). Each prompt has the form “The noun lasted from the year XXYY to the year XX” and requires a completion YY<sup>′</sup> >YY. The circuit comprises six heads in four classes: year encoding (L0H1, L1H5), year difference (L9H1), comparison (L10H7), and output computation (L11H0, L11H10). Unlike IOI, the GT computation is MLP-dominant: the largest direct logit attributions in GPT-2 come from the layer 9, 10 and 8 MLPs (0.867, 0.863 and 0.557), with L9H1 (0.551) the first attention component. The metric is the GT logit difference $\Delta G T$ , the mean logit of valid completions minus the mean logit of invalid ones. The base model achieves $\Delta G T = 2 . 8 5 5 \pm 1 . 9 4 2$ and an argmax accuracy of 94.0%.

Neuron pruning is the most destructive. Magnitude neuron pruning inverts ∆GT at every sparsity level, with accuracy at or below 0.2%. Random neuron pruning retains a small positive logit difference at 30% (0.421, 33.8% accuracy) but inverts at 50% and 70%, and accuracy reaches exactly 0.0% by 50% under both criteria. Because the GT circuit relies on distributed MLP computation, the surviving attention heads cannot compensate for it. Magnitude selection is again more damaging than random selection for neurons at 30% (degradation 120.3% against 85.3%), plausibly because it removes the highest-activating neurons most likely to carry the ordinal comparison signal.

Attention head pruning degrades gradually. Magnitude attention head pruning retains meaningful performance (accuracies of 66.1%, 53.5%, and 17.7%) and crosses the zero logit difference only at 70%. Random attention head pruning degrades more sharply, with accuracy falling to 1.0% at 50%, and the gap between the two criteria widens with sparsity (degradation 58.1% against 62.6% at 30%, and 67.7% against 92.5% at 50%).

Circuit-level evidence. Head-level activation patching shows that L10H7 (comparison) and L11H0 and L11H10 (output) are the heads most affected by attention pruning. L9H1 (year difference) shows increased patching scores in pruned models, consistent with compensation as output heads fail and L9H1 absorbs a larger causal load, whereas in neuron-pruned models, the same heads show negative effect sizes because no recoverable signal is computed. Path patching (Table 5) shows CMP→OUT and YE→YD as the most consistently damaged paths. At 70% random attention pruning, all four paths degrade by more than 100%, indicating complete circuit dissolution, whereas under magnitude attention pruning at 70%, YD→CMP (−90.2%) and YD→OUT (−32.4%) show negative degradation, reflecting compensatory re-routing as the output heads fail.

Relation to the IOI taxonomy. GT reproduces the asymmetry between component types, but with the roles reversed. Which component type is critical, therefore, depends on the circuit’s architecture, but in both circuits, the choice of component type, rather than sparsity, determines the failure.

## 5 Discussion

## 5.1 Component Type and Selection Criterion Jointly Determine Failure Mode

Component type matters more than sparsity. Magnitude attention pruning at 70% (zeroing) retains 47.9% IOI accuracy, whereas magnitude neuron pruning at 30% (inversion) retains only 17.7%, despite zeroing far fewer parameters. Within a component type, however, the selection criterion changes the failure signature (Table 2). At 30% sparsity, magnitude attention pruning gives the expected zeroing profile (S-INH 17.6%, NM 9.2%, NNM ≈ 0, BNM −2.2%). Random attention pruning at the same sparsity instead flips NM (−8.9%), NNM (−11.5%) and especially BNM (−59.8%), a partial-inversion signature otherwise associated with neuron pruning. Path patching suggests why (Table 7). Low-norm heads are disproportionately the circuit’s own late-layer output heads, so magnitude selection is close to surgical: S-INH→NM degrades most (87.4% vs. 36.6– 66.5% upstream). Random selection also removes upstream PT, DT and IND heads that feed the surviving Name Movers, and degrades all four pathways (PT→IND 201.3%, DT→S-INH 122.0%, IND→NM 143.2%, S-INH→NM 91.2%). Inversion thus arises whenever the context Name Movers read is damaged while the Name Movers survive, whether via neurons or via randomly removed upstream heads. A practitioner choosing between magnitude and random head pruning is therefore choosing between a self-announcing failure and a silent one, even though the pruned component type is identical. One caveat: for neuron pruning, patching effect sizes fall with sparsity (magnitude: $d \ : = \ : 0 . 1 3 5$ at 30% to 0.059 at 70%) while performance worsens, indicating global disruption in which patching loses sensitivity, so d should not be read as damage magnitude across sparsity levels.

## 5.2 Why Inversion Is the Most Dangerous Failure Mode

A zeroed model fails transparently: at 70% magnitude attention pruning every DLA class is exactly zero and attention over IO and S is near-uniform (0.067 vs. 0.133), so the residual accuracy comes from non-circuit computation. Inversion leaves no such structural trace. Under 30% magnitude neuron pruning, all 26 circuit heads remain intact (weight norms > 25), so an audit checking whether the circuit still exists would pass it. Yet the output mechanism has been redirected: NM contribution falls from +3.576 to −1.102, BNM from +0.427 to −0.511 (−119.9%, the most extreme inversion in the study), and S-INH retains 21.2%. The mean logit difference is −2.475 with 17.7% accuracy, the worst of all twelve variants, which is a systematic preference for the subject rather than undirected guessing. Perplexity misranks this model: at 30% sparsity it scores 74.61 against 140.10 for random attention pruning, yet its logit difference is far worse (−2.475 vs. −0.706). Degradation is also non-monotonic in sparsity (184.1% at 30%, 123.5% at 70%), because heavier pruning degrades the residual stream until attention no longer discriminates between candidates. The model is thus most misdirected at the sparsity practitioners are most likely to consider conservative. Structural checks miss behavioural inversion, while accuracy and perplexity cannot distinguish uncertainty from systematic error. For safety mechanisms, the pruning method could determine whether failure merely reduces capability or reverses the intended behaviour.

## 5.3 Structural Weak Points

Two components are disrupted across conditions. The S-INH→NM pathway is degraded in every condition we report (path-patching d = 0.102– 0.365; Table 7), even under random neuron pruning at 30%, where all other pathways show reorganisation rather than damage. Because S-Inhibition is distributed across the MLP and attention components at layers 7–8, it is exposed to any pruning strategy, regardless of the target. NNM heads show negative patching d in all twelve conditions (−0.205 to −0.539; Table 9), i.e. their suppressive role is decoupled or inverted rather than merely weakened. We hypothesise that this reflects the precision NNM heads need to target the subject token specifically, compared with the more distributed IO-copying signal of NM heads; we do not test this directly.

## 6 Conclusion

We demonstrate that weight pruning disrupts transformer circuits through two distinct failure modes, driven primarily by component type rather than sparsity level. Magnitude attention head pruning eliminates output-facing heads outright, producing undirected, near-chance failure. Magnitude neuron pruning instead corrupts the MLP context that attention heads depend on, producing confident misdirection that accuracy metrics obscure. At high sparsity, random neuron pruning shows both correct- and incorrect-sign contributions fading toward zero together, a terminal, noise-dominated regime rather than a stable, independently characterisable third mechanism.

## Limitations

Model and scale. All experiments use GPT-2 small (117M parameters). Larger models have more numerous heads and more distributed, redundant circuits, so the failure modes we report may not transfer directly, and replication at larger scales (e.g. GPT-2 Medium/Large or Pythia) is the most immediate extension.

Circuit coverage and data. We analyse two circuits, IOI and Greater-Than, on synthetically generated prompts (300 IOI sentences). Synthetic data is standard in circuit analysis but limits ecological validity, and we do not test whether circuit damage affects natural-language tasks that reuse the same computation. The failure-mode taxonomy and the component-type asymmetry should therefore be read as hypotheses to be tested on other circuits (e.g. factual recall, syntactic parsing), not as general principles.

Pruning protocol. We prune whole attention heads and MLP neurons by zeroing their weights, with no weight updates afterwards, and score importance with simple criteria (the L2 norm of a head’s Q-weight slice, or of a neuron’s $W _ { \mathrm { i n } }$ column). We do not study weight-level unstructured pruning, removal of entire layers or blocks, gradient- or attribution-based criteria, or postpruning fine-tuning, any of which may change or repair the failure modes we observe.

Safety implications. GPT-2 small has no safety fine-tuning, so our remarks on refusal- or harmavoidance mechanisms are an extrapolation from the S-Inhibition and Negative Name Mover circuits, not a measured result.

Feature-level analysis. Our SAE analysis (Appendix A.6) uses a SAE trained on the base model, so high reconstruction error shows only that activations leave the base model’s feature manifold, not what features the pruned model has. Layer 11 is excluded because the base model’s own reconstruction error exceeds the validity threshold.

## A.1 Logit-Lens Divergence

We track layer-wise next-token accuracy through the logit lens on 500 TinyStories prompts, normalised by the base model’s accuracy at each layer. A model is said to diverge at the first layer where the accuracy drop is significant (Bonferronicorrected paired t-test, $p < 0 . 0 5 )$ and exceeds 5 percentage points. Eight of the twelve pruned models diverge at L6 and none diverges earlier. Magnitude attention pruning diverges latest: at L9 for 30% and 50% sparsity (relative accuracy above 0.89) and at L7 for 70% (relative accuracy 0.883). All three magnitude neuron models diverge at L6, with mean relative accuracy 0.670 at 30%, whereas random neuron pruning at 30% reaches 0.881, the same criterion reversal seen in CKA (Table 3).

## A.2 Base Model DLA Reference Profile

Table 6 establishes the base GPT2 DLA profile used to compute all retention percentages reported in Table 2 of the main text. NM heads dominate the positive contribution; NNM heads make a large correct-sign negative contribution, acting as a selfcorrecting brake. Early-circuit classes (PT, DT, IND) have near-zero direct contributions $\mathrm { ( | D L A | < }$ 0.09), consistent with their role as upstream signal processors rather than direct output contributors. The retention percentage in Table 2 is defined as:

$$
\mathrm { R e t e n t i o n } ( \% ) = \frac { \mathrm { D L A } _ { \mathrm { c l a s s } } ^ { \mathrm { c o m p r e s s e d } } } { \mathrm { D L A } _ { \mathrm { c l a s s } } ^ { \mathrm { b a s e } } } \times 1 0 0
$$

Negative retention values indicate the class has flipped sign relative to base and is actively harming correct IO prediction. Because NNM has a negative base DLA (−2.094), a positive compressed NNM DLA produces a negative retention value, which is the inversion signature reported in Section 4.3 of the main text.
