# 论文速读：From-Entity-Mentions-to-Tone-An-LLM-Based-Pipeline-for-Media

## 一句话总结
本文提出了一套基于本地开源大语言模型（Gemma 4）的端到端媒体偏见与框架分析流水线，通过对阿尔巴尼亚语新闻进行话题/事件聚类、命名实体识别与情感分析，实现从源级别、人物级别到事件级别的多维偏见检测，并在低资源语言场景下验证了其可行性。

## 研究问题与动机
- **媒体偏见监测缺乏可持续工具**：传统依靠传播学专家人工审查的方式成本高、主观性强、难以大规模持续运行；而现有机器学习方法又依赖大量高质量标注数据，在低资源语言中更难落地。
- **阿尔巴尼亚语NLP资源匮乏**：该语言缺乏成熟的NER工具与情感分析资源，已有的工作多为小规模人工标注数据集或针对特定任务的微调实验，难以支撑大规模新闻监测。
- **单一指标无法刻画偏见全貌**：媒体偏见不仅体现在情感倾向（tone），还涉及选题选择（selection）、报道深度（depth）、来源声誉（reporting/source）等多个维度，需要多层面信号共同支撑判断。
- **推荐系统加剧信息茧房风险**：社交媒体和新闻聚合平台中的推荐算法会放大特定内容，使读者容易受到选择性呈现和虚假信息的误导，需要客观、自动化的偏见评估工具辅助决策。

## 核心贡献（创新点）
1. **端到端低资源媒体偏见流水线**：基于 Kedro 框架与本地 Gemma 4 模型实现了涵盖话题聚类、事件检测、NER、情感分析与偏见度量的完整流程，无需领域适配即可在阿尔巴尼亚语上运行——与以往依赖大型预训练微调模型的方法相比，本工作证明开源通用模型可直接作为起点。
2. **系统对比两种提示策略的工程权衡**：首次在同一任务中严格比较含严格校验规则的 Prompt v2 与更简洁的 Prompt v1，揭示了"一致性-覆盖率-执行效率"三方权衡，指出简单提示结合后处理清洗更适合持续监控场景——不同于此前工作往往只关注准确率提升而忽视工程可行性。
3. **与 GDELT 标注的系统性对标**：在无黄金标准数据集的情况下，以 GDELT 自动化标注为参考系评估 LLM 输出质量，发现 LLM 能恢复 GDELT 遗漏的大量人物提及，这对后续源级别/人物级别情感对比尤为关键——为低资源场景提供了一个可操作的评估范式。
4. **三层偏见分析框架的工程实现**：分别提供源级框架画像、人物级语调差异、事件级守门指标，并展示了三者如何组合支撑新闻聚合工具的可解释可视化——将理论上的偏见分类转化为可直接用于产品层的结构化输出。

## 方法详解
- **话题与事件聚类**：对 8,358 篇阿尔巴尼亚语新闻按 TF-IDF + k-means 聚类为 50 个话题簇，再结合 TF-IDF 余弦相似度与时间窗口识别出 3,551 个事件簇，其中 1,340 个事件有多源覆盖。
- **NER 与情感联合提取**：使用本地部署的 Gemma 4 模型，通过两个版本的 prompt 从全文同时抽取 PER/ORG/LOC 实体（包含原文形式与英文规范形式）及情感标签-分数对（score 范围 [-1, 1]）。Prompt v1 无强制校验规则；Prompt v2 增加了显式一致性约束（如 score < -0.3 必须标为 negative）。
- **源级框架画像**：统计每个新闻源在正/中/负情感文章中的占比，计算平均情感分数与 "Avg. bias"（各话题正向率减负向率后再取平均），并与语料基线（-0.192）比较得出 "Bias vs. corpus"。
- **人物级语调差异**：对每位公众人物统计其在各源中的提及文章数、平均情感分数及 "Tone balance"（= 正向率 − 负向率，范围 [−1, +1]），用于跨源对比同一人物的报道差异。
- **事件级守门与覆盖指标**：计算每个事件的 "Gatekeeping Score = 1 − 覆盖源数 / 总活跃源数"，分数越高表示传播越集中；同时记录事件级 "Framing Polarity"（正向率 − 负向率）。
- **评估策略**：以 GDELT 自动化标注为参照，报告情感标签一致率、NER 宏平均一致率（分别从 LLM 侧与 GDELT 侧）、以及精确率/召回率/F1。

## 实验与结果
- **数据集**：来自 GDELT 的 8,358 篇阿尔巴尼亚新闻（2026年4月），覆盖 124 个独立新闻源；话题簇 50 个、事件簇 3,551 个、多源事件 1,340 个。
- **Prompt 对比**：
  - Prompt v1 情感标注覆盖率 51.75%，NER 覆盖率 39.97%，不一致率 8.53%；
  - Prompt v2 情感覆盖率降至 37.20%，NER 覆盖率 27.20%，不一致率 0.0%；
  - v2 执行时间为 v1 的两倍，最终选用 v1 并辅以规则清洗。
- **情感对齐 GDELT**：
  - Prompt v1：可比较文章 3,612 篇，标签一致率 58.72%；
  - Prompt v2：可比较文章 3,109 篇，标签一致率 62.34%。
- **人物 NER 对齐 GDELT**（仅比较双方均标注的 URL-实体对）：
  - Prompt v1：LLM 宏一致率 36.83%，GDELT 宏一致率 71.46%，平衡分 45.30%；精确率 30.2%，召回率 70.3%，F1 42.3%。
  - Prompt v2：LLM 宏一致率 36.12%，GDELT 宏一致率 70.41%，平衡分 44.44%；精确率 29.8%，召回率 69.6%，F1 41.7%。
- **结论**：LLM 能回收 GDELT 遗漏的大量人物提及（高召回、低精确），与 GDELT 存在中等程度重叠但覆盖不同文本区域；Prompt v1 以更高覆盖率和更低延迟成为实际选择。

## 相关工作脉络
- **Wang et al. [3]（Media Bias Detector）**：构建了可视化仪表盘展示语气/主题/政治倾向指标，使用 LLM 量化分类；本文在其基础上进一步下沉到具体新闻源与公众人物的细粒度对比，并强调低资源场景适用性。
- **Kumar et al. [4]（Sentinel）**：支持并列比较单篇报道的框架差异；本文与其定位相似但聚焦于阿尔巴尼亚语等低资源语言，且采用本地模型而非云端 API。
- **Ye & Skiena [12]（MediaRank）**：对全球 5 万新闻源做综合排名（含报道偏见、同行声誉、社交热度）；本文的源级框架画像与之互补——MediaRank 给出全局排名，本文提供可解释的细粒度信号。
- **Rönnback et al. [10]**：基于 GDELT 大规模分类新闻源的长期偏见；本文与其不同点在于用本地 LLM 而非非 LLM 神经网络，并额外引入人物级与事件级分析。
- **Elbouanani et al. [11]**：揭示 LLM 对同一短语因政治目标替换产生不同情感分类的偏差，并提出用虚构名替换作为缓解策略；本文在讨论中明确引用该工作，承认自身模型同样可能携带此类偏差并建议未来引入匿名化。
- **Tohidi et al. [9]**：证明生成性偏见新闻可影响公众舆论；本文在此基础上提供自动化工具用于检测而非生成偏见内容。

## 局限性与未来方向
- **评估基准非人工标注**：以 GDELT 自动化标注作为参照并非黄金标准，两者均为自动推断，因此一致率仅能反映方法间重叠而非绝对正确性。
- **人物 NER 精确率偏低（~30%）**：LLM 识别出的许多人物实体需人工校验，存在较高假阳性风险。
- **Prompt v2 覆盖率损失**：严格校验规则导致可用标注article 减少约 30%，限制了后续分析的样本基础。
- **模型偏见传导风险**：Gemma 4 本身可能对特定政治人物携带先验偏见，影响人物级语调比较的可信度。
- **未来方向**：① 用 LLM 标注数据训练轻量级专用模型以提升效率；② 引入人名匿名化等偏差缓解策略；③ 接入 MCP server 实现与新闻聚合系统的持续集成；④ 为争议性实体与语调分配引入人工编辑校验环节。

## 研究启发与可借鉴点
- **低资源语言可采用"通用开源LLM + 提示工程"作为快速启动方案**，无需等待领域专用模型训练——这对资源受限语言的研究具有直接参考价值。
- **Prompt 设计中的"一致性校验 vs. 覆盖率"权衡应被显式报告**：本研究给出了清晰的定量对比，为后续工作提供了工程决策范式。
- **多层级偏见分析框架（源级 / 人物级 / 事件级）可迁移到其他语言或平台**，只需替换底层 NLP 组件即可复用整套指标定义与可视化逻辑。
- **以 GDELT 自动化标注为中间基准的评估思路**，在无黄金标准数据时提供了一种务实的质量验证路径。
- **LLM 在 messy 多语种新闻文本上的"隐式清洗"能力**（统一人名变体、纠正拼写错误）可被纳入后续 pipeline 设计中，降低预处理成本。

## 关键术语表
- **Media Bias（媒体偏见）**：新闻报道偏离中立立场的现象，包括选择、语气、深度、来源等多维表现。
- **Media Framing（媒体框架）**：新闻在已被选中报道后，通过叙事结构、语气、强调等手段组织信息的方式。
- **Gatekeeping（守门机制）**：新闻源对哪些事件/人物予以报道或省略的结构性选择行为。
- **Tone Balance（语调平衡）**：针对特定人物在某源中的所有提及，计算正向率减去负向率得到的 [−1, +1] 区间指标。
- **Prompt v1 / v2**：两种不同严格程度的 NER+情感联合抽取提示模板，v2 增加标签-分数一致性强制校验规则。
- **Macro Agreement Rate（宏平均一致率）**：分别从 LLM 和 GDELT 视角计算实体匹配一致性的平均值，再取二者平均得到平衡分。
- **Framing Polarity（框架极性）**：事件级别的正向率与负向率之差，反映整体报道倾向。
- **GDELT**：Global Database of Events, Language, and Tone，一个大规模多语言事件与情感自动化标注数据集。
