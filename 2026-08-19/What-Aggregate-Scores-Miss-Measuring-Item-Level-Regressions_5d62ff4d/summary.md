# 论文速读：What-Aggregate-Scores-Miss-Measuring-Item-Level-Regressions

## 一句话总结
论文通过在 GPT-5.4→GPT-5.5→GPT-5.6 Sol 产品序列的三次配对升级中，对 900 个公共基准项目进行 50 次重复采样并校准排列零模型，揭示仅依赖聚合基准分数的迁移决策会系统性掩盖双向项目级变化。

## 研究问题与动机
- 商业 LLM API 已成为生产系统的核心外部依赖，供应商按退役时间表强制下线旧模型，下游消费者必须迁移；但迁移安全性取决于向后兼容性，而现有评估仅报告聚合分数的净变化。
- 聚合分数的压缩会混淆"统一改进"与"部分项目改进、部分项目退步"的混合场景，导致迁移决策误判（例如 +7.3pp 的聚合增益可能伴随 8.3% 项目的可靠退步）。
- LLM 输出的随机性使单次采样无法可靠检测项目级变化：Ma et al. [2] 指出非确定性是 LLM API 回归测试的三大根本障碍之一；[6] 在 open-weight 模型上发现单次采样遗漏 42% 的真实变化项目、误报 25% 的无变化项目。
- 现有前作存在局限：[7] 纵向研究因使用单样本估计导致概率变化同向；[8] Toloka 评估仅在 K=5 下使用 Holm 校正，分辨率较低；开放权重模型的结论尚未在前线商业模型上验证。

## 核心贡献（创新点）
1. **首次在前线商业 API 迁移中实现项目级向后兼容性测量**：在 GPT-5.4 到 GPT-5.6 Sol 的三次配对升级中对 900 个公共基准项目进行 K=50 重复采样，并通过排列零模型校准完整分类流程——区别于 [7] 的单样本 IRT 拟合和 [8] 的 K=5+Holm 校正，本文在商业模型上实现更高统计分辨率的双向变化检测。
2. **揭示聚合增益下仍存在的可靠退步现象**：在所有九个迁移-基准单元中，可靠改进与可靠退步共存；聚合增益最高达 +7.3pp 的边仍包含 8.3% 可靠退步项目，聚合损失边仍包含 10.7% 可靠改进项目——打破了"净增益即安全"的直觉假设。
3. **量化严格评分与宽松评分的迁移分歧**：在 IFBench 上，最新迁移使严格-宽松评分差距扩大 3.9pp（严格评分下 -3.9pp 的回归在宽松评分下缩至 -0.04pp），表明部分回归集中在格式合规性而非任务能力，为下游系统的设计提供分层风险评估视角。
4. **发布完整的响应级档案与逐项评分输出**：提供请求参数、原始响应、模型标识符、使用元数据和时间戳的完整归档，支持在不重新查询可变商业 API 的前提下进行验证与替代重评分——填补了可复现性研究的资源空白。

## 方法详解
- **比较单位与迁移边**：以"迁移边"为基本比较单位，测量三条边：连续旗舰升级 5.4→5.5、5.5→Sol，以及供应商支持的直接升级 5.4→Sol；模型 API 标识符分别为 `gpt-5.4`、`gpt-5.5`、`gpt-5.6-sol`。
- **控制变量与采样设计**：所有请求参数在模型间保持恒定（仅更换模型标识符），推理努力设为 medium，不启用 temperature，不设输出长度上限；每个项目对每个模型独立查询 K=50 次。
- **基准筛选**：先对 11 个候选基准进行预筛选（每基准 30 个项目、3 个模型、K=10），保留至少 35% 项目存在模型准确率 ∈[0.1, 0.9] 的候选，最终选定 SuperGPQA（知识，500 项）、Omni-MATH hard（数学，100 项）、IFBench（指令遵循，300 项），合计 900 项。
- **评分方案**：响应归入六类互斥类别（语义正确、语义错误、格式失败、拒绝、截断、API 错误）；知识与数学项通过两阶段解析器提取最终行答案并与参考答案精确匹配+符号归一化比对；IFBench 使用官方验证器，提供严格与宽松两种读数（宽松读数在表面格式标准化后重应用验证函数）。
- **统计检验与分类**：对每个项目 i 在模型 m 下计算观测准确率 p̂_{m,i}；对每条边 s→t，使用 Fisher 精确检验配合 Benjamini-Hochberg FDR 控制在 5% 水平确立统计显著性，辅以实际显著性阈值 ε=0.2（通过率变化 ≥20pp）确立最小效应量；同时满足两者且 p̂_{t,i}−p̂_{s,i}≥ε 判为可靠改进，≤−ε 判为可靠退步；95% CI 完全落入 (−ε, ε) 判为实际等效，其余为不确定。
- **排列零模型校准**：对每条边，将 2K 个结果合并后随机重分配版本标签（每侧 K 个），重跑完整分类流程，1000 次重复得到 P⁺、P⁻、P_chg 的零分布；报告值与零分布的 95th 百分位并列呈现，确保声明的可靠变化严格高于噪声基线。
- **严格-宽松差异分析**：定义 R_m 为模型 m 在 IFBench 上宽松与严格验证器得分的均值差，每条边报告 ΔR = R_t − R_s，量化格式合规性退化的幅度。

## 实验与结果
- **数据集**：SuperGPQA（500 项）、Omni-MATH hard（100 项）、IFBench（300 项），共 900 项；数据采集于 2026 年 7 月 30 日至 8 月 13 日，请求并发度固定为 36，瞬态 API 错误以指数退避重试。
- **基线对比**：与 [6]（open-weight 7–8B 模型，K=10，可靠变化 21–28%）、[8]（Toloka，GPT-5.5 vs GPT-5.6，711 企业工作流，K=5+Holm 校正）形成对照。
- **核心数值（Table 1）**：
  - 5.4→5.5：SuperGPQA Δ=+2.3pp（P⁺=8.2%, P⁻=5.0%, P_chg=13.2%）；Omni-MATH hard Δ=+7.3pp（P⁺=17.0%, P⁻=6.0%, P_chg=23.0%）；IFBench Δ=+1.9pp（P⁺=11.3%, P⁻=8.3%, P_chg=19.7%）。
  - 5.5→Sol：SuperGPQA Δ=+1.4pp（P⁺=7.6%, P⁻=4.4%, P_chg=12.0%）；Omni-MATH hard Δ=−4.1pp（P⁺=9.0%, P⁻=15.0%, P_chg=24.0%）；IFBench Δ=−3.9pp（P⁺=6.7%, P⁻=13.3%, P_chg=20.0%）。
  - 5.4→Sol：SuperGPQA Δ=+3.8pp（P⁺=10.8%, P⁻=4.8%, P_chg=15.6%）；Omni-MATH hard Δ=+3.2pp（P⁺=10.0%, P⁻=5.0%, P_chg=15.0%）；IFBench Δ=−2.0pp（P⁺=10.7%, P⁻=13.3%, P_chg=24.0%）。
- **排列零模型校准结果**：所有九个迁移-基准单元中，零分布的 P_chg 95th 百分位均为 0.0%，表明 Fisher/BH/ε 标准在 K=50 下无假阳性，所有报告变化严格高于噪声基线。
- **严格-宽松评分差距（Section 4.3）**：IFBench 上 GPT-5.4/5.5/Sol 的 R_m 分别为 6.3pp、5.1pp、9.0pp；5.4→5.5 的 ΔR=−1.2pp，5.5→Sol 的 ΔR=+3.9pp，5.4→Sol 的 ΔR=+2.7pp；最新迁移下严格评分显示 −3.9pp 回归，而宽松评分仅 −0.04pp，退化集中于格式合规性。
- **最强结果**：Omni-MATH hard 上 5.4→5.5 的聚合增益最大（+7.3pp），同时可靠变化比例最高（P_chg=23.0%），但 6.0% 项目仍可靠退步；5.4→Sol 在 IFBench 上可靠变化比例达 24.0%，为九组中最高。
- **补充分析**：附录 B 显示单次采样（K=1）在 2700 个 item-edge 对上未能检测出任何可靠变化，而 K=50 共检测出 457 个；附录 D/E/F 报告 token 消耗分布、六类别响应分解及难度分层结果。

## 局限性与未来方向
- 基准筛选步骤仅选择模型保留"表现空间"的基准，因此报告的可靠变化比例是信息性基准上的估计值，而非任意生产负载的普适率——需在未来工作中扩展到真实企业工作流验证。
- 研究仅覆盖单一供应商（OpenAI）的 GPT-5.4 至 GPT-5.6 Sol 产品线和三个公共基准，其他供应商、任务类型及生产负载的模式待检验。
- 实际显著性阈值 ε=0.2 与试验次数 K=50 共同决定可检测变化范围，更小的真实变化被归入"不确定"类别——未来可探索自适应阈值或贝叶斯分层模型以细化检测边界。

## 研究启发与可借鉴点
- **K=50 重复采样 + 排列零模型校准的完整 pipeline 可迁移**：适用于任何需要区分真实模型差异与采样噪声的商业 LLM 评估场景，尤其是发布前后对比、A/B 测试或供应商切换决策。
- **严格-宽松评分分层报告机制**：IFBench 的实验证明格式合规性与任务能力的退化可能不同步，建议在指令遵循类任务的评估中同时报告两种读数，以区分功能性退化与格式敏感退化。
- **与团队方向的结合机会**：若团队涉及 LLM API 依赖管理或模型版本治理，可将本文报告的可靠变化比例（12–24%）作为接受测试设计的参考基线；亦可将重复采样方法集成至 CI/CD 管道中以持续监控 API 变更。
- **响应级档案的可复用价值**：完整归档支持离线重评分，避免了商业 API 的不可控性与成本——建议在同类研究中强制发布交互轨迹，以提升可复现性与二次分析潜力。

## 关键术语表
- **Item-level regression（项目级退步）**：在模型版本升级过程中，特定测试项目在统计上可靠地从正确变为错误的现象，区别于聚合分数的单向表述。
- **Permutation null（排列零模型）**：通过将两个模型的结果池合并后随机重分配版本标签，重跑完整分类流程以构建"无真实变化"假设下的统计量分布，用于校准假阳性率。
- **Practical significance threshold（实际显著性阈值 ε）**：设定通过率变化的最小可接受幅度（本文 ε=0.2），与统计显著性结合避免检测到无实际意义的小幅波动。
- **Strict vs. loose scoring（严格与宽松评分）**：IFBench 官方验证器的两种读数，严格模式要求完全格式合规，宽松模式在表面格式标准化后重应用验证函数，二者差异反映格式敏感退化。
- **False discovery rate control（FDR 控制）**：Benjamini-Hochberg 方法在多重假设检验中将错误发现率控制在 5% 水平，避免大量项目级比较中假阳性累积。
- **Repeated sampling（重复采样）**：对同一提示独立查询模型 K 次以估计通过率分布，替代单次采样的二元判断，显著提升项目级变化检测的统计效力。
- **Backward compatibility（向后兼容性）**：模型升级后新版本对旧版本行为（测试用例级）的保留程度，本文将其操作化为项目级通过率的净变化分布。
- **Migration edge（迁移边）**：有序的模型版本对（如 5.4→5.5），代表 API 消费者实际执行的升级路径，是本文的基本比较单位。
