# 论文速读：Multi-Agent-AI-System-for-Radiology-Report-Structuring-and-Q

## 一句话总结
本文开发并评估了一个本地部署的四智能体AI流水线，通过将确定性正则规则与选择性的大语言模型推理分层路由，在完全保留原始CT报告文本的前提下，实现句子级解剖结构重组，并同步完成跨段落/段内不一致、性别-解剖冲突及关键发现未沟通的自动化质控（QA）。

## 研究问题与动机
- **报告结构不一致阻碍临床沟通**：不同放射科医生的Findings组织方式差异大，导致转诊医生难以快速定位关键信息，且不利于二次研究利用。
- **现有NLP/LLM方法破坏原文完整性**：既往结构化工作多侧重于提取标签、生成摘要或重写报告，容易丢失原文细节或引入幻觉，无法满足临床“忠于原意”的合规要求。
- **语音识别普及加剧通信错误风险**：听写报告易引入转录误差、否定反转或Findings-Impression逻辑冲突，人工质控在高容量环境下效率低下。
- **缺乏整合型本地化方案**：现有研究多将结构化与QA割裂，且依赖云端闭源模型；本文旨在构建单一工作流、防火墙内本地部署、兼顾效率与临床可解释性的多智能体系统。

## 核心贡献（创新点）
1. **分层路由的多智能体流水线**：提出Agent 1（规则）→ Agent 2（轻量LLM）→ Agent 3（重型推理LLM）的分级处理机制，约95%的句子由前两级处理，显著降低对高算力模型的依赖。
2. **无损句子级结构化重组**：将自由文本Findings重新分配至预定义解剖章节而不改写原文，从根本上规避了生成式方法常见的临床信息丢失或伪造风险。
3. **多维自动化QA与严重度评级**：Agent 4在同一管道中同步检测跨段/段内矛盾、性别-解剖冲突及关键发现未文档化三类错误，并输出四级严重度（none/minor/major/critical），填补了现有LLM质控研究对后两类错误系统性覆盖的空白。
4. **面向真实异质风格的临床验证**：在15名放射科医生、638份CT报告的混合风格数据集上验证，并通过两名独立认证放射科医生的双盲子集评估，证实了系统在保留医生个人写作习惯前提下的可靠性。

## 方法详解
- **数据预处理**：基于规则的模式匹配提取Findings边界；自定义句子分割算法兼容编号列表、多行句子与标点不一致；短续贯片段（如“Stable since prior”）通过规则合并至前句以保持语境。
- **Agent 1（规则分类器）**：由认证放射科医生参与构建约600条覆盖常见解剖区域与影像发现的正则字典，完成确定性句子分类（处理83.0%的句子）。
- **Agent 2（LLaMA-3上下文推理）**：将全篇Findings文本与目标句子作为上下文输入LLaMA-3-8B（q8量化），处理Agent 1未匹配的模糊句子（12.3%），侧重器官级关联推断。
- **Agent 3（DeepSeek-R1深度推理）**：负责设备相关句子（需同时归入“Devices”与对应解剖区）、Agent 1无法分类的重复句，以及Agent 2归类为“Other”或仍无主句（4.7%），依赖其强化学习推理能力解决歧义。所有结构化智能体均单次前向推理，无重试循环。
- **Agent 4（QA整篇审查器）**：基于DeepSeek-R1-Distill-Llama-70B（q4量化），在报告级别检测侧别差异、否定反转、极性冲突、器官/节段不匹配、尺寸/单位不一致、性别-解剖冲突及潜在关键发现未沟通；抑制Findings与Impression间临床可接受的总结性差异；强制输出结构化JSON，解析失败时最多重试5次。
- **部署与工程**：Python实现，通过Ollama平台在单卡NVIDIA H100 GPU + 12核CPU上本地推理，全程运行于机构防火墙内。

## 实验与结果
- **数据集**：638份胸部/腹部/盆腔CT放射学报告（2023-2024年），由15名认证放射科医生口述，共计22,270个Findings句子。
- **结构化性能**：Agent 1分类18,493句（83.0%），Agent 2分类2,729句（12.3%），Agent 3分类1,041句（4.7%），仅7句（<0.04%）未分类（均为孤立标题）。按作者维度表现稳定，医生3/6/13的规则命中率最高（>90%），医生11的报告最依赖Agent 3（12.7%）。
- **QA性能**：90份报告（14.1%）被标记。错误类型以段落不匹配为主（80份，12.5%）；严重度分布：critical 6份（0.9%）、major 40份（6.3%）、minor 44份（6.9%）。性别-解剖冲突4份（0.6%），关键发现未沟通9份（1.4%）。
- **处理耗时**：平均每份报告总耗时55.6秒；Agent 1（0.54s）、Agent 2（1.31s）、Agent 3（28.62s）、Agent 4（25.13s）。耗时最长者为医生15（265.5s），因其报告解剖组织松散导致Agent 3需深度上下文推理。
- **放射科医生独立评估（45份富集子集）**：69%报告被判定为正确重组，4%不正确，27%意见分歧；100%未发现重要信息遗漏或内容捏造。临床可用性评价：“更好”2%、“相同”51%、“更差”7%。QA方面：不匹配检测准确率82%，关键发现未沟通检测准确率96%，整体评级84%为“excellent”或“good”，0%为“poor”。

## 相关工作脉络
- **结构化报告模板研究**（Weiss & Langlotz, 2008; Nobel et al., 2022）：强调模板标准化价值，但受限于工作流负担与灵活性争议；本文与其定位差异在于不依赖前端模板填写，而是对自由文本进行事后无损重组。
- **LLM报告改写/结构化**（Adams et al., 2023; Woźnicki et al., 2025）：多采用GPT-4等模型重写或压缩报告；本文本质区别在于“仅重分配、不改写”，避免幻觉并保留原始临床表述。
- **本地LLM用于报告精简**（Hartsock et al., 2026）：聚焦内容精简与格式整理；本文在此基础上扩展为多智能体分工架构，并将QA与结构化耦合至单一工作流。
- **LLM放射报告错误检测**（Sun et al., 2025; Gertz et al., 2024; Kim et al., 2025）：主要覆盖侧别、否定、转录错误及Findings-Impression不一致；本文新增性别-解剖冲突与关键发现未沟通的系统性检测，拓宽了QA边界。
- **多通道迭代LLM框架**（Kim et al., 2026）：依赖多轮重试提升检测精度；本文采用规则+轻量LLM+重型推理LLM的分层路由策略，在算力效率与推理深度间取得更优平衡。

## 局限性与未来方向
- 临床评估仅基于45份报告（且富集了14.1%的标记样本），无法提供全集QA性能的无偏估计，样本量与多样性有限。
- 部分多系统相关发现被重复分配至多个解剖章节，虽保障信息完整性，但可能轻微降低报告可读性与浏览效率。
- QA组件为优先捕获潜在不一致而设计，存在一定假阳性率（评估子集中5份出现误报），未来需优化阈值控制以减轻临床干扰。
- 未来工作应在更多机构、不同影像模态（MRI、X线等）及多样化报告风格中进行外部验证；可探索引入医生反馈微调机制，进一步减少跨章节冗余与误报
