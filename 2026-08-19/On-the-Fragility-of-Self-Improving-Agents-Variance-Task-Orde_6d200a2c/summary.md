# 论文速读：On-the-Fragility-of-Self-Improving-Agents-Variance-Task-Orde

## 一句话总结
本文对基于文本记忆的自增强智能体（AWM、ReasoningBank）进行了系统性重评估，发现其在多轮运行下方差显著放大，且在任务顺序随机打乱时性能不升反降；研究指出记忆构建过程中的环境与任务欠规范（underspecification）是导致该脆弱性的核心原因，注入辅助信息可部分修复退化。

## 研究问题与动机
1. **单次运行评估掩盖真实波动**：现有 Web 智能体研究普遍仅报告单次 pass rate，忽视了复杂浏览任务本身的高噪声特性，以及自增强循环对随机性的级联放大效应。
2. **隐式课程偏差隐藏方法短板**： prior works 多采用默认任务顺序，该顺序隐含“由易到难”的课程设计，为自增强方法提供了不公平的成功前提，无法反映真实场景中任务随机到达的鲁棒性。
3. **记忆生成缺乏环境与任务约束**：当记忆构建模块未明确获知环境能力边界（如仅支持浏览器交互）或任务评估细则时，模型易生成合理但不可执行的记忆（如推荐 API 调用），污染后续推理。
4. **高价值部署容错率低**：企业级应用中初始失败会迅速侵蚀用户信任，且错误记忆可能随时间级联造成不可逆损失，亟需在部署前建立严格的可靠性评估协议。

## 核心贡献（创新点）
1. **建立多运行与乱序压力的标准化重评估协议**：首次在相同协议下对 AWM 与 RBank 进行三次独立重复运行与任务顺序扰动测试，量化揭示了自增强方法在 71% 场景下方差显著放大（best-worst gap 最高达 10.4%）。
2. **证实默认顺序是先前成功的关键隐藏前提**：通过引入 Shuffle-1/2 随机顺序，证明先前报道的 +1.5% 性能提升实为隐性课程红利；打乱后 RBank 反而下降 -4.5%，暴露了方法在真实乱序流中的脆弱性。
3. **系统定位“欠规范”为记忆污染与性能退化的根源**：通过人工审计记忆库，首次将失效模式归因为环境欠规范（生成不支持的动作建议）与任务欠规范（模糊查询导致过度推理与错误记忆传播）。
4. **提出并验证多维度记忆构建干预方案**：在记忆生成阶段显式注入评分规则、环境动作反馈与排除性提示词，证明该策略可修复 31% 的性能退化，为后续记忆验证与过滤机制设计提供实证基线。

## 方法详解
- **评估协议扩展**：在 WebArena、VisualWebArena 与 SCUBA 三个 Web 浏览基准上，以 GPT-5-mini 为骨干模型构建强 no-memory baseline，对比 AWM（提取结构化工作流）与 RBank（提取通用推理轨迹）。
- **方差度量体系**：除平均 pass@1 外，统一报告三次运行的标准差（Standard Deviation）与最佳/最差运行差距（Best-worst gap），以量化评估稳定性。
- **任务顺序控制变量**：除默认顺序外，额外设置 Shuffle-1 与 Shuffle-2 两种随机打乱顺序，检验方法对输入分布扰动的敏感性。
- **记忆构建干预设计（Memory Construction Modifications）**：
  - **+Rub（评分规则注入）**：将评估器的函数规则（`must_include` / `exact_match` / `fuzzy_match`）及具体得分反馈至记忆生成阶段，消除任务歧义。
  - **+Env（环境执行反馈注入）**：将动作错误日志（如 `Action error: Failed to input text into index 41`）纳入构建上下文，防止智能体重复无效 UI 操作。
  - **+PMod（提示词显式约束）**：在 prompt 中明确禁止生成 API 调用、外部网站访问、请求人类确认等当前浏览器环境不支持的策略，强制聚焦导航流程与站点交互经验。
  - **+All**：组合上述三种干预进行联合测试。
- **记忆利用机制**：RBank 使用检索器按需召回最相关历史条目；AWM 则将全部去重工作流全量注入后续任务上下文。

## 实验与结果
- **数据集**：WebArena (812 tasks, 6 domains), VisualWebArena (910 tasks, 3 domains), SCUBA (267 tasks, 3 roles)。
- **评估基线**：基于 GPT-5-mini 的 WALT/SCUBA 原始基线智能体（无记忆）。
- **方差结果**：基线自身已存在显著波动（如 WebArena GitLab 子集 best-worst gap 为 4.4%）；引入 AWM/RBank 后，17/24 个实验方差增加（约 71%），其中 11 个相对增幅超 50%（Map 域 RBank 标准差升至 3.89%，GitLab 域 gap 扩至 7.8%）。
- **任务顺序结果**：默认顺序下 RBank 平均提升 +1.5%；Shuffle-1 顺序下平均下降 -4.5%（WebArena），AWM 在 VisualWebArena 上也受显著负面影响；6/8 次打乱实验出现性能下降。
- **强基线下的增益衰减**：在 GPT-5-mini 强基线上，AWM 和 RBank 的整体提升有限（RBank +1.5%, p-value=0.23），统计上不显著，表明简单记忆方法难以进一步挖掘强模型潜力。
