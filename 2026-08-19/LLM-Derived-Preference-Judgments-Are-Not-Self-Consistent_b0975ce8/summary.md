# 论文速读：LLM-Derived-Preference-Judgments-Are-Not-Self-Consistent

## 一句话总结
本文针对将 LLM 生成的数值偏好判断（如支付意愿、出价差异）整合为单一效用函数的假设，提出了一套基于货币计价元的自洽性审计协议；在航班、公寓、酒店三个受控领域对六种 LLM 的审计表明，所有模型的偏好判断均无法由单一准线性美元效用函数一致地解释，查询类型间存在持续且显著的不一致性。

## 研究问题与动机
1. **核心问题**：现有偏好学习系统（如 LISTEN-U、LILO、PEBOL 等）通常假设 LLM 从不同提示或查询类型中给出的数值判断可以被单一稳定的效用函数所复现，但这一"自洽性"假设缺乏实证检验。
2. **测量挑战**：不同提示形式（item query 询问最大支付意愿，offer-pair query 询问使两个报价无差异的价格调整量）给出的数值回答可能基于不同的推理路径，难以保证它们共同对应一个稳定的美元计价效用。
3. **现有不足**：以往工作多关注 LLM 偏好的序数一致性（如传递性）或逻辑条件，缺乏对跨查询类型的基数一致性（cardinal consistency）和货币尺度稳定性的联合检验。
4. **实践风险**：若自洽性不成立，下游基于这些数值判断进行的效用估计、排序或优化结果可能任意依赖于提问方式，影响系统可靠性。

## 核心贡献（创新点）
1. **提出首个针对数值型 LLM 偏好判断的自洽性审计框架**：在有限文本描述商品集合上仅施加准线性货币假设，不引入任何基于特征的效用函数形式，为偏好学习系统的测量基础提供实证检验工具。
2. **设计全局 bootstrap 检验与局部 P1/P2 诊断协议**：全局检验测量所有查询均值相对于最佳拟合效用函数的 RMSE，局部 P1 检验直接报价差异与路径求和的一致性，P2 检验报价差异与两项 item-query 价格调整差值的一致性，二者结合可精确定位不一致来源。
3. **跨六模型三领域的系统性不一致证据**：实验覆盖 Claude Opus 4.8、Gemini 3.5 Flash、GPT-5.5、GPT-OSS 120B、Llama 3.3 70B、Qwen 3.6 27B，在所有模型上联合自洽假设均在 Bonferroni 校正后被拒绝，酒店域 RMSE 高达 18.9%–44.9%，P2 拒绝率达 41.7%–87.5%。
4. **揭示查询类型对决策方向的实质性影响**：2.1%–12.5% 的比较出现支持的序数反转，即基于 item-query 均值与基于 offer-pair 均值的二选一选择器会给出相反推荐，表明提示形式可改变偏好方向。

## 方法详解
**自洽性假设**：固定商品集 $\mathcal{X}$、偏好描述语句、LLM 配置及提示模板，假设每个商品 $x$ 有独立无约束的美元效用 $U(x)$，报价 $a=(x,p)$ 的效用为 $U(a)=U(x)-p$（准线性假设）。对查询集合 $\mathcal{Q}$，假设存在 $U$ 使得每个查询的期望响应等于 $m_c(U)$（item query 为 $U(x)$，offer-pair query 为 $U(b)-U(a)$）。

**全局检验统计量**：通过最小二乘拟合最佳效用 $\widehat{U}=\arg\min_U \frac{1}{Q}\sum_{c\in\mathcal{Q}}\{\overline{Y}(c)-m_c(U)\}^2$，计算根均方误差 $T=\left\{\frac{1}{Q}\sum_{c\in\mathcal{Q}}\{\overline{Y}(c)-m_c(\widehat{U})\}^2\right\}^{1/2}$。使用组内非参数 bootstrap（$B=2000$）估计 $T$ 的零分布并计算 p 值。

**局部 P1 检验**：对源报价 $a$ 到目标报价 $b$ 的路径 $\mathcal{P}=(a=a_0,a_1,\ldots,a_k=b)$，比较直接报价对估计 $\overline{Y}((a,b))$ 与路径求和 $\sum_{j=1}^k \overline{Y}((a_{j-1},a_j))$，残差 $\widehat{R}_{1,\mathcal{P}}(a,b)=\overline{Y}((a,b))-\sum_{j=1}^k \overline{Y}((a_{j-1},a_j))$ 的 95% CI 排除零即为拒绝。

**局部 P2 检验**：对报价 $a=(x,p)$ 和 $b=(y,q)$，比较直接报价对估计 $\overline{Y}((a,b))$ 与价格调整后的 item-query 差值 $[\overline{Y}(y)-q]-[\overline{Y}(x)-p]$，残差 $\widehat{R}_2(a,b)=\overline{Y}((a,b))-\{[\overline{Y}(y)-q]-[\overline{Y}(x)-p]\}$ 的 95% CI 排除零即为拒绝。

**显著性控制**：每模型九个审计组（三域×三语句）使用 Bonferroni 校正，阈值 $p\leq 0.05/9=0.0056$。

## 实验与结果
**数据集与审计设计**：三个受控领域——航班（19 商品/21 报价/3 语句/6 端点对/90 报价对查询/24 商品查询）、公寓（21/21/3/6/90/27）、酒店（3 商品×3 价格=9 报价/3 语句/4 端点对/60/9），共 300 个查询单元格，每单元格 15 次重复调用，每模型 4,500 次 LLM 调用。

**主要结果**：
- 全局检验：所有六模型在 Bonferroni 校正下均拒绝全部九组自洽假设（Qwen 拒绝四组）；酒店域 RMSE 为 18.9%–44.9%（mean $109.2–296.5），航班/公寓域为 1.6%–6.1%。
- P2 局部检验：拒绝率最高（Claude Opus 4.8: 85.4%，Llama 3.3 70B: 87.5%，Qwen 3.6 27B: 41.7%），支持序数反转比例 2.1%–12.5%。
- P1 局部检验：拒绝率较低且跨模型不均（4.2%–68.8%），路径长度压力测试显示 $k=8,16$ 步的平均归一化误差高于 $k=2$，但未建立普适缩放律。
- 最强结果：Llama 3.3 70B 在公寓域 RMSE 达 247.2 美元（7.3%），酒店域 RMSE 达 296.5 美元（53.9%），是所有域–语句组合中最大偏差。

## 相关工作脉络
1. **LISTEN/LILO/PEBOL 等 LLM 偏好学习系统**：将自然语言偏好转化为显式效用、批量选择或特征效用先验，本文指出这些系统隐含依赖判断的自洽性假设但缺乏审计。
2. **HodgeRank 与序数一致性审计**：既往工作检验传递性、交换律等序数逻辑条件，本文扩展至基数一致性，要求 dollar magnitudes 在跨查询类型下也相协调。
3. **LLM-as-a-Judge 评分偏差研究**：Zheng 等（2023）、Wang 等（2024）记录排序、打分、呈现偏差，本文聚焦不同查询形式间的数值一致性而非单形式内的排序稳定性。
4. **从二元选择推断支付意愿**：Reusens 等（2026）通过拟合多项 logit 模型从变价二元选择推断酒店属性 WTP，本文主张直接数值查询可避免间接恢复，但要求货币尺度本身稳定。
5. **受控偏好测试领域**：航班、租房、酒店是常见的人机交互定价场景，本文将其作为受控审计对象以隔离提示形式效应。

## 局限性与未来方向
1. **仅检验内部一致性而非人类保真度**：审计未收集真实人类数据，无法判断 LLM 判断是否更接近人类真实偏好；自洽是通过的必要非充分条件。
2. **受控商品集与固定提示的泛化局限**：三个领域的商品描述为手工构造，未覆盖真实用户输入、模型版本变化、对话历史等动态场景。
3. **准线性货币假设的简化**：忽略财富效应、预算约束及无界补偿情形；P2 仅覆盖无价格的 item query，不涵盖所有效用提示形式。
4. **可解析输出的条件分析**：仅纳入成功解析为有限数值的响应，未比较数值 elicitation 与二元 elicitation 的相对表现。
5. **未来方向**：将同一审计协议应用于真实人类被试并与 LLM 结果对比，以校准不一致程度的实际意义；探索提示工程或模型微调以提升跨查询类型的一致性。

## 研究启发与可借鉴点
1. **可复用的审计协议**：全局 bootstrap 检验结合 P1/P2 局部残差的分析框架可迁移至任何以货币计价元整合多源数值判断的 LLM 偏好系统，作为部署前的自洽性门禁。
2. **查询几何设计的经验教训**：酒店域 RMSE 显著高于航班/公寓域，提示商品-价格交叉结构的查询几何（正交网格 vs 线性特征梯度）可能加剧不一致，设计评估基准时应控制这一变量。
3. **与团队方向的结合机会**：若团队从事 LLM 驱动的定价、推荐或资源配置系统，可将自洽性审计作为 preference learning pipeline 的质量评估环节；亦可探索将 P2 残差作为正则项纳入效用拟合过程以惩罚跨查询类型的不一致。
4. **因果解释与提示设计**：P2 不一致的高发现率表明 item query 与 offer-pair query 触发了不同的推理路径，可进一步分析提示措辞、锚定效应或框架效应在其中的作用，为 prompt engineering 提供实证依据。

## 关键术语表
**Self-consistency（自洽性）**：不同查询类型给出的数值判断可由单一效用函数共同解释的性质，是本文审计的核心假设。
**Quasi-linearity（准线性）**：假设报价效用等于商品效用减去标价，货币作为计价元提供跨商品可比尺度，但不假设效用对商品特征的任何函数形式。
**Item query（商品查询）**：询问用户在给定偏好描述下对无标价商品的最高支付意愿，响应视为商品效用 $U(x)$ 的估计。
**Offer-pair query（报价对查询）**：询问使源报价与目标报价无差异的目标价格调整量，响应视为两报价效用差 $U(b)-U(a)$ 的估计。
**P1 residual（P1 残差）**：直接报价对估计与通过中间报价路径求和估计之差，检验报价对估计的路径可加性。
**P2 residual（P2 残差）**：直接报价对估计与经价格调整后两商品查询之差，检验两类查询的基数一致性。
**RMSE T（全局拟合误差）**：最佳拟合效用相对于所有查询均值的根均方误差，度量自洽性偏离的实际幅度。
**Supported reversal（支持的序数反转）**：两类估计的 95% CI 排除零且方向相反，表明查询类型可改变推荐方向。
