# 论文速读：From-Entity-Mentions-to-Tone-An-LLM-Based-Pipeline-for-Media

## 一句话总结
本文提出了一套基于本地大语言模型（Gemma 4）与 Kedro 框架的端到端新闻媒体偏见与框架分析流水线，通过主题/事件聚类、NER 与情感富集，在阿尔巴尼亚语低资源场景下实现了从源级框架、人物级语气到事件级把关模式的系统化自动化评估。

## 研究问题与动机
- **核心问题：** 在缺乏高质量人工标注语料与专用小语种 NLP 工具的环境中，如何持续、自动化地监测在线新闻的媒体偏见、框架倾向与信息把关行为。
- **现有方法不足：** 传统人工调查成本高且易受主观影响；基于监督学习的分类器严重依赖特定语言标注数据；GDELT 等主流自动化管道对人物实体的提取存在明显遗漏，削弱了后续跨源语气对比的可靠性。
- **单一分数局限：** 仅靠一个整体偏见评分无法刻画复杂媒体行为，必须将信号拆解为源级倾向、人物级语气、事件级覆盖三个正交维度分别观测。
- **工程落地需求：** 推荐算法加剧了选择性曝光，急需可嵌入新闻聚合平台的轻量级监测工具，帮助读者识别同一事件或人物在不同信源中的叙事差异。

## 核心贡献（创新点）
1. **低资源语言下的端到端偏见分析流水线。** 将 TF-IDF/k-means 主题聚类、事件检测与 Gemma 4 本地 NER/情感富集集成至 Kedro 框架，无需针对阿尔巴尼亚语重新训练基础模型即可产出可用信号。与已有工作相比，本文不依赖昂贵的小语种微调数据，而是以通用开源 LLM 作为“快速引导层”实现全链路自动化。
2. **提示词严格性与工程效率的权衡实证。** 系统对比了含强校验规则与简化的两类 Prompt，量化揭示了强约束虽能将标签-分数不一致率降至 0%，但会导致处理耗时翻倍且标注覆盖率显著下降。与已有工作相比，本文明确给出了持续 ingestion 管道中“宽松 Prompt + 后处理规则清洗”优于“复杂 Prompt”的工程取舍依据。
3. **与 GDELT 交叉验证及增量实体挖掘机制。** 在 8,358 篇新闻上验证了 LLM 标注与 GDELT 自动化输出的中等一致性，并证明该流水线能回收大量 GDELT 遗漏的人物提及。与已有工作相比，本文不把 GDELT 视为绝对基准，而是将其作为互补参照，突出 LLM 在细粒度人物实体抽取上的增量价值。
4. **源级-人物级-事件级三层正交评估框架。** 定义了 Avg. bias、Tone balance、Gatekeeping Score、Framing polarity 等可计算指标，并在 124 个阿尔巴尼亚新闻源上完成了可复现的应用示范。与已有工作相比，本文的贡献不仅在于指标设计，更在于提供了一整套从原始 URL 到可解释偏见报告的可复用分析蓝图。

## 方法详解
- **数据流与聚类：** 从 GDELT 拉取阿尔巴尼亚语新闻，先用 TF-IDF + k-means 将文章聚为 50 个主题簇，再结合 TF-IDF、余弦相似度与时间窗口识别出 3,551 个事件簇（其中 1,340 个为多源事件），以支持跨源对比。
